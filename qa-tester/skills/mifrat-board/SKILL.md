# mifrat: доска и документация

## Устройство
- Колонки: `רשימת משימות` → `לביצוע` → `בביצוע` → `בבדיקות` → `הושלם`. Тестируем только `בבדיקות`.
- Типы: FEATURE (`פיצ'ר`), TASK (`משימה`), IMPROVEMENT (`שיפור`), BUG (`באג`).
- **ID тикета — `#hash`** (8 символов, виден в открытой карточке). «TC: N» на карточке — тест-кейсы, не номер.
- Красный бейдж «N» на карточке — пометка реджектов/баг-репорта; остаётся и после `עבר QA`.
- Ссылки: доска `…/Project?id=<id>&tab=tasks`, документация `…&tab=spec`.

## Правила безопасности
- **Документацию («מפרט») только читать — никогда не редактировать** (карточки фич/экранов/персон, AI-кнопки «הוסף למפרט»). Карточки «מפרט» закрывать `ביטול`.
- **Только JS по конкретному элементу**, никогда клик по координатам: доска сдвигается при прокрутке, клик попадает в чужую карточку.
- **Перед любым действием** проверь, что открытая карточка начинается с нужного `#hash`.
- Не нажимать: `מחק`, `סמן כתקלת תפעול`, AI-кнопки (`הוסף למפרט בעזרת AI`, `פרומפט מהיר`, `פרומפט חכם`).
- Закрывать карточку без изменений — `ביטול`.

## Найти тикеты колонки
```js
const out = [];
for (const h of document.querySelectorAll('h4')) {
  let el = h, col = '';
  for (let i = 0; i < 12 && el; i++) { el = el.parentElement;
    const m = (el.innerText||'').match(/^(רשימת משימות|לביצוע|בביצוע|בבדיקות|הושלם)\n/); if (m) { col = m[1]; break; } }
  if (col === 'בבדיקות') out.push(h.innerText.trim());
}
out
```
Длинные колонки подгружаются при прокрутке — если тикет не найден, прокрути колонку вниз и повтори.

## Действия

**עבר QA:** проверь `#hash` → (если есть открытые реджекты — сначала `סמן כטופל` на каждом) → кнопка `עבר QA` → статус в шапке стал `הושלם` → закрыть → проверить, что тикет в колонке `הושלם`.

**דחה משימה:** кнопка `דחה משימה` → форма:
`כותרת הדחייה*`, `התנהגות נוכחית*`, `התנהגות רצויה*`, `שלבים לשחזור` (новое поле — `הוסף שלב`), `סופיקס URL`, `קישור לשחזור`, `קבצים מצורפים` (кнопка `צרף קבצים` → загрузка файла инструментом upload браузера), Allure — не трогать → красная `דחה משימה`.
- Если шаги склеиваются при наборе — заполняй через JS:
```js
const set = Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, 'value').set; // для textarea — HTMLTextAreaElement
set.call(input, 'текст'); input.dispatchEvent(new Event('input', { bubbles: true }));
```
- Проверь, что каждый шаг в своём поле, потом отправляй. После — тикет в `לביצוע`.

**Смена статуса** (сайдбар `סטטוס`): открыть выпадающий список → элемент `[role=option]` с текстом `לביצוע` → если кнопка `שמור` активна — нажать → проверить колонку.

**לא ניתן לשחזר:** кнопка → заметка → подтвердить. Снять старую пометку — `מחק סימון`.

## Новый тикет
`+` / `משימה חדשה` (справа вверху доски) → заголовок «מה צריך לעשות?» → для бага `דיווח על באג` (поля `מה קרה בפועל?*`, `מה צריך לקרות?*`, `שלבים לשחזור`), для задачи — описание по шаблону из `qa-verdict` → `סוג` / `סטטוס` = `לביצוע` / `עדיפות` → `קבצים וקישורים` → צרופות → `צור משימה` → проверить, что тикет появился в `לביצוע`.

## Выделение тикетов и «בדיקה יומית»
- Выделение — **Cmd+клик** по каждой карточке отдельно (Shift выделяет диапазон). Через JS: на заголовок `h4` отправить `pointerdown/mousedown/pointerup/mouseup` с `metaKey: true`, **без** `click`. Не нажимать Esc и не кликать без модификатора — выделение сбросится.
- Проверить счётчик внизу «N נבחרו».
- `עוד` (три точки) → `צור סיכום` → в поле (placeholder «לדוגמה: תיצור סיכום שבועי...») написать `בדיקה יומית` → `שלח ליצירת סיכום` → дождаться окна `סיכום משימות` (10–20 c) → **не закрывать**.

## Документация («מפרט»)
- Режим **`עבודה`**: список фич/экранов/персон/процессов слева. Карточка открывается кликом по названию (JS), значения — из полей формы. Закрывать `ביטול`.
- Режим `ספר` — общий текст (обзор, персоны, процессы), но раскрывает не все фичи.
