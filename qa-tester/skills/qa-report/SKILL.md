# Конец сессии

## 1. Итог пользователю (по `.qa/session.json`) — без запроса

Показывать сам: в конце каждого пакета и в конце сессии. Сначала таблица, потом блок ниже.
```
Итог: прошли N · вернули N · לא ניתן לשחזר N · новые тикеты N · не проверены N
| # | Тикет (#hash — название как на доске) | Вердикт | Почему (одна строка) | Где проверено (десктоп / 390 / роль) |
```

```
Мой вердикт «прошёл» — ждут твоей проверки и «прошли»: #hash заголовок, …
Подтверждены тобой (автотесты записаны): …
Вернули (реджект / статус לביצוע): …
Помечены לא ניתן לשחזר: …
Новые тикеты: …
Не проверены и почему: …
Находки, ждущие решения: …
Конфликты с документацией: …
Тестовые данные для чистки: что / где
```
