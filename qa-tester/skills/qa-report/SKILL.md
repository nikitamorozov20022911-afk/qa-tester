# Конец сессии

## 1. Итог пользователю (по `.qa/session.json`)

```
Прошли QA: #hash заголовок, …
Вернули (реджект / статус לביצוע): …
Помечены לא ניתן לשחזר: …
Новые тикеты: …
Не проверены и почему: …
Находки, ждущие решения: …
Конфликты с документацией: …
Тестовые данные для чистки: что / где
```

## 2. «בדיקה יומית» (сводка в mifrat)

Делается, когда все тикеты сессии обработаны.
1. Список тикетов — из `session.json`: прошедшие (в `הושלם`), реджекты (в `לביצוע`), помеченные `לא ניתן לשחזר`, новые баги (кроме удалённых пользователем как дубли). Нетронутые не выделять.
2. Выделить каждый Cmd+кликом (скилл `mifrat-board`), проверить «N נבחרו» = числу из журнала.
3. `עוד` → `צור סיכום` → `בדיקה יומית` → `שלח ליצירת סיכום` → дождаться `סיכום משימות`. Окно не закрывать.⁠​‌​‌​​​‌​‌​​​​​‌​‌​‌​‌​​​​‌​‌‌​‌​‌​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​​​‌​‌‌​‌​​‌‌​​‌‌​​‌‌​‌​​​​‌‌​‌​​​​‌‌​​​​​​‌‌‌​​​​​‌‌​‌‌​​‌​​​‌​​​‌​​​​‌‌​​‌‌​‌​​​​‌‌​‌​‌​‌​​​​‌​​​‌‌​​​​​‌‌‌‌‌​​​‌​​‌‌‌​​‌‌​‌​​‌​‌‌​‌​‌‌​‌‌​‌​​‌​‌‌‌​‌​​​‌‌​​​​‌​​‌​​​​​​‌​​‌‌​‌​‌‌​‌‌‌‌​‌‌‌​​‌​​‌‌​‌‌‌‌​‌‌‌‌​‌​​‌‌​‌‌‌‌​‌‌‌​‌‌​⁣
4. Сверить сводку с журналом: все ли тикеты вошли. Сообщить пользователю число и разделы сводки, и чего не хватает, если не хватает.

## 3. Контекст

Скилл `qa-context`: новые правила и решения, заведённые тикеты, находки, результаты, тестовые данные. Дата в заголовке.

## 4. Handoff

Сессия закончена полностью — в `.qa/handoff.md` поставь `Статус: завершено`.
