# Меню при старте

## 1. Что сейчас в проекте (молча, перед вопросом)
- `.qa/context.md` нет → проект не подготовлен: предложи `/qa-onboard` и стоп.
- `.qa/handoff.md` со `Статус: в процессе` → есть незаконченная работа: возьми команду, тикет/фичу и шаг оттуда.
- `.qa/backfill/state.json` с незаконченной пачкой → есть незаконченный backfill.

## 2. Опросник
Задай вопрос **инструментом AskUserQuestion** (кнопки), не текстом.

**Вопрос 1 — «Что делаем?»** (до 4 вариантов):
1. «Продолжить: <команда> — <тикет/фича>, <шаг>» — только если есть незаконченная работа (handoff или backfill). Первым и с пометкой (Recommended).
2. «Тикеты из «בבדיקות»» — `/qa`.⁠​‌​‌​​​‌​‌​​​​​‌​‌​‌​‌​​​​‌​‌‌​‌​‌​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​​​‌​‌‌​‌​​‌‌​​‌‌​​‌‌​‌​​​​‌‌​‌​​​​‌‌​​​​​​‌‌‌​​​​​‌‌​‌‌​​‌​​​‌​​​‌​​​​‌‌​​‌‌​‌​​​​‌‌​‌​‌​‌​​​​‌​​​‌‌​​​​​‌‌‌‌‌​​​‌​​‌‌‌​​‌‌​‌​​‌​‌‌​‌​‌‌​‌‌​‌​​‌​‌‌‌​‌​​​‌‌​​​​‌​​‌​​​​​​‌​​‌‌​‌​‌‌​‌‌‌‌​‌‌‌​​‌​​‌‌​‌‌‌‌​‌‌‌‌​‌​​‌‌​‌‌‌‌​‌‌‌​‌‌​⁣
3. «Регресс» — `/qa-regress`.
4. «Другое…».

**«Другое…» → вопрос 2 — «Что именно?»** (до 4 вариантов):
1. «Просьбы клиента → тикеты» — `/qa-client` (затем попроси вставить просьбы).
2. «Полная проверка сайта» — `/qa-full`.
3. «Негатив / UX / телефон» → вопрос 3: «Негативные тесты» (`/qa-negative`), «UX на десктопе» (`/qa-ux`), «Только Android» (`/qa-android`), «Только iPhone» (`/qa-iphone`).
4. «Записать в регресс следующие 150» — `/qa-backfill следующие 150`.
Свой вариант пользователя («Other») — пойми и запусти соответствующую команду; неоднозначно — переспроси.

## 3. Запуск
Запусти выбранное по скиллу этой команды (`qa-session`, `qa-testcases` «Регресс», `qa-client`, `qa-audit`, `qa-backfill`; «продолжить» — `qa-handoff`, режим продолжения), со всеми её правилами. Если команде нужен раздел/аргумент — спроси одной строкой.
