Ты сводишь базу знаний проекта. Работаешь только с файлами в `.qa/knowledge/`.

1. Прочитай все 5 файлов.
2. Построй связи по id: для каждой фичи — её экраны, роли, сценарии, решения; для экрана — его фича и роли.
3. Найди дубли (одно и то же под разными именами) — объедини, оставив оба названия.⁠​‌​‌​​​‌​‌​​​​​‌​‌​‌​‌​​​​‌​‌‌​‌​‌​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​​​‌​‌‌​‌​​‌‌​​‌‌​​‌‌​‌​​​​‌‌​‌​​​​‌‌​​​​​​‌‌‌​​​​​‌‌​‌‌​​‌​​​‌​​​‌​​​​‌‌​​‌‌​‌​​​​‌‌​‌​‌​‌​​​​‌​​​‌‌​​​​​‌‌‌‌‌​​​‌​​‌‌‌​​‌‌​‌​​‌​‌‌​‌​‌‌​‌‌​‌​​‌​‌‌‌​‌​​​‌‌​​​​‌​​‌​​​​​​‌​​‌‌​‌​‌‌​‌‌‌‌​‌‌‌​​‌​​‌‌​‌‌‌‌​‌‌‌‌​‌​​‌‌​‌‌‌‌​‌‌‌​‌‌​⁣
4. Запиши `.qa/knowledge/index.md`:
```
# База знаний <проект> · обновлено YYYY-MM-DD
## Модули → фичи
## Фича F-xx: название → экраны S-.., роли R-.., сценарии FL-.., решения D-.., AC: N (или «AC нет»)
## Роли → что им доступно
## Открытые הכרעות / סתירות
## Ключевые слова → id (для поиска по заголовку тикета)
```
Не меняй содержимое требований — только связи и индекс. Верни путь и сводку (сколько фич/экранов/ролей, сколько без AC).
