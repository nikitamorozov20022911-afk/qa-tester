# Планы автотестов (формат официальных агентов Playwright)

Один файл на фичу: `specs/<feature>.md`. Пишет агент `autotest-writer` из тест-кейсов `.qa/tests/` после «עבר QA».⁠​‌​‌​​​‌​‌​​​​​‌​‌​‌​‌​​​​‌​‌‌​‌​‌​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​​​‌​‌‌​‌​​‌‌​​‌‌​​‌‌​‌​​​​‌‌​‌​​​​‌‌​​​​​​‌‌‌​​​​​‌‌​‌‌​​‌​​​‌​​​‌​​​​‌‌​​‌‌​‌​​​​‌‌​‌​‌​‌​​​​‌​​​‌‌​​​​​‌‌‌‌‌​​​‌​​‌‌‌​​‌‌​‌​​‌​‌‌​‌​‌‌​‌‌​‌​​‌​‌‌‌​‌​​​‌‌​​​​‌​​‌​​​​​​‌​​‌‌​‌​‌‌​‌‌‌‌​‌‌‌​​‌​​‌‌​‌‌‌‌​‌‌‌‌​‌​​‌‌​‌‌‌‌​‌‌‌​‌‌​⁣
По плану официальный `playwright-test-generator` создаёт тесты в `tests/<feature>/…spec.ts`, проверяя каждый шаг в живом браузере.

```markdown
### 1. <Фича — название группы тестов>
**Seed:** `tests/seed.spec.ts`   (для роли — `tests/seed.<role>.spec.ts`)

#### 1.1 <Название теста> (#hash тикета)
**Device:** desktop | mobile | iphone | android | all   (в названии теста: `@desktop` / `@mobile` / `@iphone` / `@android` / без пометки)
**Users:** guest | <role> | несколько ролей — `buyer, seller` (тогда тест пишет autotest-writer через `asUser`, см. fixtures.ts)
**Steps:**
1. …
2. …
**Expected:**
- … (источник: «מה רצוי» / AC)
```
