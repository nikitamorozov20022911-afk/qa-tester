# Просьбы клиента — реестр

Тикеты, заведённые по просьбам клиента (`/qa-client`), и тикеты, которые пользователь подтвердил как просьбу клиента.
Решение клиента главнее документации. Документация проекта при этом **не меняется** — расхождение фиксируется только здесь и в `.qa/context.md`.
