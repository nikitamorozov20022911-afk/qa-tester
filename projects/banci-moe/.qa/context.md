## Правила проекта (важнее общих правил плагина)
- Веб vs мобильное — не вопрос к заказчику, решено (2026-10-04): если тикет требует нативной функции телефона (звонок 101, вспышка, фон, беззвучный режим, блокировка экрана, энергосбережение, камера/push), сообщить пользователю ДО теста — такие пункты тестируем на реальном телефоне вместе с ним, в вебе их не реджектить.
- Сейчас тестируем веб-версию (Expo web). Приложение в будущем станет мобильным — мобильные проверки (iPhone/Android) особенно важны; нативные функции (камера, push) в вебе могут вести себя иначе.

## Технические заметки
- iPhone/Appium: newCommandTimeout 3600; в авиарежиме Appium/Web Inspector недоступны; удержание экрана в Safari только после касания пальцем «בדיקה חוזרת»; мок мониторинга — sessionStorage banci.mock.
- Автотесты: user.json берётся из профиля Mac devA (installation cdad05d4, главное устройство) — не через новый вход (лимит 2/2). Официальный playwright-test-generator 12.10 сломался после 1 теста («seed test not found») — запасной путь autotest-writer + CLI.
- Expo web: элементы — div с role=button, а не <button>/<a>; несуществующий путь → экран «הדף לא נמצא».
- В /sign-in текст «כניסה» встречается дважды (заголовок и кнопка) — кнопка последняя.
- mifrat «מפרט» доступен только в режиме «ספר» (нет прав редактирования); разделы «תהליכי משתמש», «מודל נתונים», «מערכת עיצוב» в «ספר» без содержимого.
- MCP base44 не авторизован; playwright-cli требует Node ≥20 (системный по умолчанию — 18, есть 20/22 в nvm).
