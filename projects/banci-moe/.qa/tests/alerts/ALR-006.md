# ALR-006: Push между телефонами аккаунта — тест и сбой приходят на заблокированный iPhone со звуком, вибрацией и уведомлением (Pixel → iPhone, ВРУЧНУЮ)
- Фича/экран: alerts — «חשבון → התרעות וצפצוף» → «שליחת התרעת בדיקה»; push о сбое мониторинга на «מכשיר נוסף · מקבל התרעות» (F-26 AC2/AC4/AC5; F-28 AC1; D-05, D-12)
- Тикеты: #e9ea54 (id ea49d956d373ae485ce9ea54; закрыты реджекты rej_3477c62d…, rej_179353…, rej_454f0217…)
- Роль/аккаунт: dadayo — оба телефона в аккаунте
- Устройство: нативное приложение — отправитель Pixel 6 (Eitan build 8), приёмник iPhone 17 (Eitan build 7 + OTA). В вебе push нет — только телефоны
- Тип: позитив
- Предусловия: приёмник iPhone заблокирован, лежит экраном вверх, на него не смотрят; беззвучный выкл., громкость макс., «מיקוד»/Focus выкл., Apple Watch нет; в настройках iOS у Eitan вкл. Allow / Sounds / Time Sensitive / Lock Screen
## Шаги
1. iPhone: «זיהוי תשומת לב» (Attention Aware Features) выкл. → Pixel: «חשבון» → «התרעות וצפצוף» → «שליחת התרעת בדיקה» ×2; записать звук / вибрацию / уведомление / время.
2. iPhone: «זיהוי תשומת לב» вкл. (как у пользователей по умолчанию) → повторить шаг 1 ×2.
3. Pixel: начать мониторинг → закрыть камеру Pixel пальцем (сбой «המצלמה מוסתרת») ×2 → на iPhone: звук / вибрация / уведомление.
4. (когда сработает #18bb68) опасность в кадре Pixel → на iPhone сирена/звук + вибрация + уведомление.
## Ожидаемо
- Шаги 1–3: каждый push на заблокированном iPhone — звук + вибрация + уведомление на экране (тикет «תיאור»: התראות בזמן אמת בין מכשירים… במקרה של זיהוי סכנה או כשל בניטור; ערוצי התראה בעדיפות גבוהה; реджект 05.11).
- Шаг 4: тревога опасности звуковая, ощутима без взгляда на экран (F-26 AC2/AC4, D-05).
- Не проверено и вне этого кейса: беззвучный переключатель iOS (без Apple Critical Alerts не обходится — ограничение ОС, решение пользователя по #50a86b6e), Focus/«נא לא להפריע».
- Автотеста нет: push, звук и вибрация на реальном телефоне в вебе (Expo web, Playwright) не воспроизводятся.
