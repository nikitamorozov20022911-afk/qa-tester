# ALR-004: Приложение — окно тревоги «זוהתה סכנה בבריכה» и «זו אזעקת שווא» (ВРУЧНУЮ)
- Фича/экран: alerts — окно тревоги опасности (Figma 09.1)
- Тикеты: #50a86b6e
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 6)
- Тип: позитив
- Предусловия: тревогу вызвать автоматом нельзя (нужен человек/видео бассейна в кадре при запущенном мониторинге) — только вручную. «חיוג למד״א 101» НИКОГДА не нажимать (настоящий звонок)
## Шаги
1. Мониторинг; в кадре опасная ситуация (видео бассейна на экране Mac или человек неподвижно).
2. Дождаться тревоги, осмотреть окно (не нажимать «חיוג למד״א 101»).
3. Сдвинуть слайдер «זו אזעקת שווא».
## Ожидаемо
- Окно «זוהתה סכנה בבריכה» с «בדקו את הילדים עכשיו», кнопками «חיוג למד״א 101» и «עזרה ראשונה והחייאה»; сирена, вибрация, вспышка (в беззвучном тоже).
- Слайдер «זו אזעקת שווא» закрывает окно, сирена замолкает.
- Громкость 0 — без звука (вибрация и вспышка есть): ограничение iOS, не реджект (решение пользователя 2026-10-20).
