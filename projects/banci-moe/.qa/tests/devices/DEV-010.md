# DEV-010: Два iPhone — скан QR «הוספת טלפון» системной камерой второго телефона открывает приложение Eitan (не Safari), телефон подключается как «מכשיר נוסף» (ВРУЧНУЮ)
- Фича/экран: devices — «הוספת טלפון» → «חיבור טלפון נוסף» (главный) → Universal Link `https://banci.expo.app/join?invite=…` (второй) → «מכשירים» (главный)
- Тикеты: #e1b6f2 (id 03a08004b0b4cf8190e1b6f2); связанная находка #096cf616 (QR-подключение не просит разрешение на уведомления)
- Роль/аккаунт: dadayo (user); главный iPhone залогинен; второй iPhone — Eitan установлен, НЕ залогинен (вход вручную, пароль вводит пользователь)
- Устройство: 2 iPhone с Eitan (TestFlight 0.1.1 build 7 или новее): главный iPhone 17 + второй (tania, iPhone 17 Pro)
- Тип: позитив
- Предусловия: у dadayo свободный слот (1/2) — иначе вместо QR сообщение о лимите (удалить лишний телефон заранее — по согласованию); код действует 10 минут. Если iOS «запомнил» открытие ссылки в Safari — переустановка Eitan сбрасывает. Appium видит только один телефон — кейс ручной
## Шаги
1. Главный: «חשבון» → «מכשירים» → «הוספת טלפון» → шторка с QR.
2. Второй: открыть системную «Камеру», навести на QR, тапнуть по плашке-ссылке.
3. Второй: войти в аккаунт dadayo (если просит).
4. Второй: «חשבון» → «התרעות וצפצוף» — посмотреть «התרעות בטלפון הזה» (находка #096cf616).
5. Главный: закрыть шторку «סגירה» → «מכשירים» (обновить).
## Ожидаемо
- Шаг 2: открывается приложение Eitan, не Safari («מה רצוי» #e1b6f2: Universal Link). Без установленного Eitan — сайт/установка.
- Шаг 3: после входа телефон подключён к подписке без повторного сканирования.
- Шаг 4 (#096cf616): приложение запросило разрешение на уведомления, «התרעות בטלפון הזה» включено. Если выключено, а в «מכשירים» стоит «מקבל התרעות» — это #096cf616 (открытый баг, не реджект #e1b6f2).
- Шаг 5: в «מכשירים» главного строка «iPhone, מכשיר נוסף · מקבל התרעות, מחובר» (проверка 01.11).
