# DEV-008: «מכשירים» без сети — ошибка «משהו השתבש» быстро (≤ 15 с), «נסו שוב» после восстановления сети загружает список
- Фича/экран: devices (/account/devices, экран «מכשירים»; вход из «חשבון» → «מכשירים»)
- Тикеты: #0af24eb7
- Роль/аккаунт: user (dadayo1547@aminavin.com)
- Устройство: mobile (iPhone Safari — основное; в приложении — iOS/Android)
- Тип: негатив
- Предусловия: пользователь вошёл; открыт экран «חשבון» (данные аккаунта уже загружены); список телефонов ещё не загружен на этом экране
## Шаги
1. На экране «חשבון» отключить интернет (в приложении — авиарежим / выключить Wi-Fi и мобильные данные). Только веб: вместо авиарежима — подмена `window.fetch` на отклоняющий `TypeError` (Web Inspector) или в автотесте обрыв запросов к серверу данных (`page.route(... abort('internetdisconnected'))`).
2. Нажать «מכשירים» и засечь время.
3. Дождаться экрана ошибки.
4. Включить интернет обратно (только веб: вернуть исходный `fetch` / снять перехват).
5. Нажать «נסו שוב».
## Ожидаемо
- Шаг 3: «טוען…» сменяется экраном ошибки не позже чем через 15 с (по исправлению ~7 с; было ~55–60 с): заголовок «משהו השתבש», текст «לא הצלחנו לטעון את המידע. בדקו את החיבור ונסו שוב.», кнопка «נסו שוב»; списка «הטלפונים בחשבון» нет (источник: «מה רצוי» тикета #0af24eb7, комментарий программиста).
- Шаг 5: загружается список «הטלפונים בחשבון» со строками телефонов («מחובר»); экрана ошибки больше нет (источник: тот же).
