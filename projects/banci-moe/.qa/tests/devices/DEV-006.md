# DEV-006: «מכשירים» после ошибки загрузки и «נסו שוב» — дополнительное устройство (iPhone)
- Фича/экран: devices (/account/devices, S-03; F-01 AC8)
- Тикеты: #1c852837
- Роль/аккаунт: user (dadayo1547@aminavin.com), iPhone = «מכשיר נוסף»
- Устройство: iPhone 17 Safari (mobile)
- Тип: негатив
- Предусловия: 2/2 устройства; ответ на запрос devices подменён на 500 (подмена fetch через Web Inspector) или нет сети
## Шаги
1. Открыть /account/devices со сбоем запроса списка
2. «משהו השתבש» + «נסו שוב»
3. Вернуть нормальный ответ → «נסו שוב»
4. Сравнить с обычной загрузкой
## Ожидаемо
Своя строка «מכשיר נוסף · … · הטלפון הזה»; нет «הטלפון הזה עוד לא מחובר לחשבון»; экран = обычной загрузке (источник: реджект, F-01 AC8)
