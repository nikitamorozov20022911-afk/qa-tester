# HIST-005: Детали сеанса из истории — рядом с «מה קרה» число событий, а не «בלי התרעות»
- Фича/экран: history (/history) → детали сеанса (/history/<id>); сводка после мониторинга (/monitor/summary)
- Тикеты: #92d9fdd3
- Роль/аккаунт: user (dadayo1547@aminavin.com)
- Устройство: iPhone 17 Safari (mobile)
- Тип: позитив (регресс бага)
- Предусловия: в истории есть сеансы трёх видов — со сбоем («N כשלים»), спокойный («בלי אירועים»), с тревогами («N התרעות», часть помечена «זו אזעקת שווא»). Новые сеансы для проверки не нужны (только просмотр)
## Шаги
1. Открыть «היסטוריה»
2. Открыть сеанс со сбоем (в строке «כשל אחד» / «N כשלים»)
3. Посмотреть подпись рядом с заголовком «מה קרה» и посчитать строки событий под ним
4. Вернуться в «היסטוריה», то же для спокойного сеанса («בלי אירועים»)
5. То же для сеанса с тревогами («N התרעות»)
6. (при ручной проверке, если создаётся новый сеанс с тревогами) — то же на сводке сразу после мониторинга
## Ожидаемо
- Рядом с «מה קרה» всегда «N אירועים» (Figma 11.4, node 220-7205), а не «בלי התרעות» — в сеансе со сбоем, без событий и с тревогами (источник: описание #92d9fdd3)
- N = числу строк событий в списке под «מה קרה» (включая «התחלת ניטור» и завершение; тревога с пометкой «סומן כאזעקת שווא» — одна строка)
- У каждой строки события есть время ЧЧ:ММ
