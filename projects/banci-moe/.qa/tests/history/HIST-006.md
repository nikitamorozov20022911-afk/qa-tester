# HIST-006: История — в заголовке дня сразу полное число ניטורים, не меняется после «ניטורים קודמים»
- Фича/экран: history (/history, S-19 AC3)
- Тикеты: #89b3e786
- Роль/аккаунт: user (dadayo1547@aminavin.com), > 20 сеансов, есть день с > 20 сеансами (на 14.10 — 07.10 «33 ניטורים», 05.10 «40 ניטורים»)
- Устройство: iPhone 17 Safari (mobile)
- Тип: позитив (регресс бага)
- Предусловия: только просмотр, новые сеансы не нужны. Даты и числа меняются по мере роста данных — сверять с числом записей на экране, а не с конкретными значениями
## Шаги
1. Открыть «היסטוריה» (/history)
2. Посмотреть заголовок последнего дня перед «ניטורים קודמים» — число рядом с датой и сколько записей этого дня показано
3. Нажимать «ניטורים קודמים», после каждой догрузки сверять числа в заголовках уже показанных дней
4. Догрузить всё (кнопки «ניטורים קודמים» больше нет) и для каждого дня посчитать записи под заголовком
## Ожидаемо
- Уже при первой загрузке у каждого дня число всех ניטורים этого дня, а не только загруженных: у последнего дня число может быть больше показанных записей (на 14.10: 07.10 «33 ניטורים» при 6 показанных) (источник: реджект 14.10, needed_behavior «בכותרת של כל יום מוצג מיד, כבר בטעינה הראשונה, מספר כל הניטורים של אותו יום»; S-19 AC3)
- После «ניטורים קודמים» число в заголовке не меняется (там же: «המספר לא משתנה אחרי «ניטורים קודמים»»)
- После полной загрузки у каждого дня число = числу записей под заголовком; каждый день — одним заголовком
- Формат: дата и число — отдельными строками; один сеанс — «ניטור אחד», несколько — «N ניטורים»
- Не прежнее поведение: число не растёт по мере догрузки (12.10 было «13» → «33») и не прячется до полной загрузки дня (вариант коммита c804bbd)
