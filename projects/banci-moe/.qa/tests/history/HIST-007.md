# HIST-007: Прерванный мониторинг (приложение закрыто) — в истории конец по последнему сигналу, а не по повторному открытию
- Фича/экран: history — «היסטוריה» → строка сеанса «N דק׳ ניטור» → детали «מה קרה»
- Тикеты: #af53b1 (id a08d66b7dcedbf368baf53b1)
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo)
- Устройство: нативное приложение iPhone (Eitan); создаёт сеанс в «היסטוריה» (@data)
- Тип: позитив (регресс бага)
- Предусловия: второй телефон подключён к аккаунту (иначе «בדיקת בטיחות» 4 מתוך 5 — #4a869b); громкость на максимуме; телефон на подставке, на зарядке; кадр освещён. Часы телефона и компьютера синхронизированы (автоматическое время).
## Шаги
1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור». Запомнить время старта.
2. Подождать ~1 мин мониторинга.
3. Закрыть приложение полностью (смахнуть из переключателя; автотест — `terminateApp`). Запомнить время закрытия.
4. Подождать N минут (вручную — сколько угодно, хоть до следующего дня; автотест — `BANCI_INTERRUPT_WAIT_MIN`, по умолчанию 4).
5. Открыть Banci. Запомнить время открытия.
6. «היסטוריה» → верхний сеанс → детали.
## Ожидаемо
- Длительность в строке истории — по фактическому мониторингу: не больше (время до закрытия + 2 мин) и меньше времени до повторного открытия; не «… שעות ניטור» за короткий сеанс («מה רצוי» #af53b1: סוף הניטור = האות/האירוע האחרון, לא זמן הפתיחה מחדש).
- В деталях диапазон «HH:MM–HH:MM»: начало = старт (±1 мин), конец ≤ закрытие + 2 мин.
- В «מה קרה» есть «הניטור הופסק כי האפליקציה נסגרה» со временем ≤ закрытие + 2 мин (не время открытия). Перед ним может быть «כשל בניטור: הטלפון המצלם לא מגיב» с тем же временем — допустимо.
- Автотест: `.qa/e2e-app/tests/history/interrupted-session-end-time.test.mjs` (только с BANCI_MONITORING=1).
