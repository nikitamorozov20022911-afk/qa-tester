## Шаги
1. «חשבון» → «חוקי זיהוי». Нажать числовое поле («מרחק משפת המים»).
2. Посмотреть клавиатуру: есть ли «.» и «,»; видна ли кнопка «שמירת החוקים» над клавиатурой.
3. Стереть значение, нажать «0», «,», «3».
4. Выйти из поля (тап по подписи).
5. То же для поля «ראש מתחת למים».
6. В поле ввести буквы/лишние знаки («abc»), выйти из поля.
## Ожидаемо
- Шаги 2: на клавиатуре есть и «.», и «,» (источник: «מה רצוי» #58001d «מקלדת שמאפשרת גם נקודה וגם פסיק»); «שמירת החוקים» видна (факт проверки 17.11).
- Шаг 3: в поле «0,3» — запятая вставляется, а не игнорируется.
- Шаг 4: «0,3» → «0.3» (прежнее поведение #1b17df не сломано).
- Шаг 6: под полем «צריך להיות מספר בין …» (17.11: «מספר בין 0.05 ל-1»), правила не сохраняются (источник: #89216b AC4; риск: «numbers-and-punctuation» допускает буквы).
- Android не менялось (там обе клавиши уже были); не входит в этот кейс.
