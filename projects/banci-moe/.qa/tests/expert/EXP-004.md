# EXP-004: Значение вне диапазона (999, 0, −5, пусто, abc в «חוסר תנועה») — сообщение, правила не сохраняются
- Фича/экран: expert — /account/expert, раздел «תרחישי סכנה וספי זמן»
- Тикеты: #89216b (id 2c85fc1d2e36dab88b89216b, «בדיקה: מסך «חוקי זיהוי» לאיש המקצוע»); разработка — #a1f74f
- Роль/аккаунт: эксперт (`.qa/auth/expert.json`)
- Устройство: веб — desktop 1440×900 (и 390)
- Тип: негатив / граница
- Предусловия: ОСТОРОЖНО — сохранение действует на все семьи. В «מה נקבע ולמה» любой текст; «שמירה לכולם» никогда не нажимать, при окне подтверждения — «ביטול». В автотесте запросы записи заблокированы (page.route).
## Шаги
1. В «חוסר תנועה» ввести 999.
2. Нажать «שמירת החוקים».
3. Повторить с 0, −5, пустым полем, «abc».
4. Уйти без сохранения (перезагрузить экран).
## Ожидаемо
- Под полем «צריך להיות מספר בין 5 ל-120 שניות» (999, 0, −5) / сообщение под полем (пусто, abc) (источник: AC4 «מופיעה הודעה עם הטווח המותר»).
- После «שמירת החוקים» — плашка «יש שדות שצריך לתקן», окна «לשמור את החוקים?» нет, запроса сохранения нет (источник: AC4 «והחוקים לא נשמרים»).
- После перезагрузки «חוסר תנועה» = исходное значение.
- Не входит: «0,1» (запятая) проходит без ошибки — открытый баг #1b17df.
