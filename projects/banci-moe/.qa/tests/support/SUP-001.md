# SUP-001: «חשבון» → «תמיכה» — форма обращения: тексты, темы «תקלה»/«שאלה»/«אחר», переключение темы
- Фича/экран: support — «חשבון» (строка «תמיכה») → форма обращения
- Тикеты: #39b1c8 (id b40e081daa0bfc44f239b1c8, «בקשת לקוח: כפתור «תמיכה» בעמוד החשבון לשליחת פנייה (תקלה, שאלה או אחר)»)
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo / user2)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7 + OTA); также Android (Pixel) и веб banci.expo.app
- Тип: позитив · безопасно для прода (ничего не отправляется)
- Предусловия: —
## Шаги
1. «חשבון» → прокрутить до строки «תמיכה» → тап.
2. Осмотреть форму.
3. Тап «שאלה», затем «אחר», затем «תקלה».
4. Выйти из формы, ничего не отправляя.
## Ожидаемо
- Шаг 1: в «חשבון» есть строка «תמיכה» (после «תנאי שימוש ודיסקליימר» — комментарий программиста), открывает форму (источник: «מה רצוי» #39b1c8).
- Шаг 2: «נושא הפנייה»; темы «תקלה», «שאלה», «אחר»; «מה תרצו לספר לנו?»; «אפשר לכתוב עד 2000 תווים»; кнопка «שליחה» («מה רצוי»: תקלה / שאלה / כל נושא אחר; комментарий программиста: до 2000 символов, «שליחה»).
- Шаг 3: после каждого тапа выбрана ровно нажатая тема; форма остаётся открытой, «הפנייה נשלחה» не появляется.
- RTL текстов формы — I18N-003 шаг 2.
