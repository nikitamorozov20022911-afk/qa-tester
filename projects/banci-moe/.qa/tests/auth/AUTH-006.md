# AUTH-006: Доступное имя кнопок «המשך עם Apple» / «המשך עם Google» на «יצירת חשבון» и «כניסה»
- Фича/экран: auth (/sign-up «יצירת חשבון», /sign-in «כניסה»)
- Тикеты: #e653a0
- Роль/аккаунт: guest
- Устройство: iPhone (приложение Eitan build 7 + OTA 21d8d5de; в вебе — Expo web, iPhone-эмуляция)
- Тип: позитив (доступность)
- Предусловия: выйти из аккаунта
## Шаги
1. Открыть «יצירת חשבון» → VoiceOver / Accessibility Inspector (в вебе — доступное имя role=button) по кнопкам Apple и Google
2. (только приложение) Нажать «המשך עם Apple», в окне Apple отменить → снова проверить имя кнопки; повторить несколько раз; то же для Google
3. Повторить шаги 1–2 на «כניסה»
## Ожидаемо
- Имя доступности «המשך עם Apple» / «המשך עם Google» на обоих экранах, совпадает с видимой надписью — сразу и после отмены окна провайдера (источник: «מה רצוי» #e653a0)
- «מתחברים…» (busy, кнопки неактивны) — только пока открыто окно входа; после отмены — снова «המשך עם …», без ошибки (источник: «מה רצוי» #e653a0; AC #2faba1 «ביטול בחלון הספק…»)
## Автотест
