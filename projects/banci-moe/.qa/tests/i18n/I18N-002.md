# I18N-002: Сайт на иврите и RTL при английском языке браузера (только веб)
- Фича/экран: /welcome, /sign-in, /sign-up, /forgot-password, «הדף לא נמצא», /home, /children, /account
- Тикеты: #f7167929
- Роль/аккаунт: guest; user
- Устройство: iPhone Safari (язык en-GB) / desktop Chrome en-US
- Тип: позитив · локализация
- Предусловия: только веб — язык задаётся локалью браузера (Accept-Language en-US)
## Шаги
1. Браузер с языком en-US → /welcome, /sign-in, /sign-up, /forgot-password, несуществующий путь.
2. Войти → /home, /children, /history, /account.
## Ожидаемо
- `<html lang="he" dir="rtl">`, тексты на иврите; нет «Peace of mind by the water», «Create account», «Sign in» (источник: «מה רצוי» #f7167929).
