# I18N-003: Приложение — тексты прижаты вправо (RTL) на основных экранах (iOS)
- Фича/экран: «חשבון», «תמיכה», «היסטוריה», «ילדים», «בדיקת בטיחות», «מי בבריכה היום?» (Figma 07.6)
- Тикеты: #50a708 (id d57754c5c2d6a6e6f750a708, баг: тексты выровнены влево вместо вправо — заголовки, строки списков, окна сбоя, формы)
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7 + OTA 29.10)
- Тип: позитив · RTL
- Предусловия: второй телефон подключён к аккаунту (иначе «בדיקת בטיחות» 4 מתוך 5 — #4a869b), громкость на максимуме; у аккаунта ≥ 1 ребёнок
## Шаги
1. «חשבון»: заголовок, строки «מנוי», «מכשירים», «התרעות וצפצוף», «תמיכה».
2. «חשבון» → «תמיכה»: «נושא הפנייה», «מה תרצו לספר לנו?», «אפשר לכתוב עד 2000 תווים» (форму не отправлять).
3. «היסטוריה», «ילדים» («הילדים שלנו»): заголовки.
4. «בית» → «התחלת ניטור» → «בדיקת בטיחות»: заголовок → «המשך» → шаг 2 → галочка → «המשך».
5. Шаг 3 «מי בבריכה היום?»: заголовок, имена детей, «ילד חדש». Мониторинг не запускать.
## Ожидаемо
- Все перечисленные тексты прижаты к правой стороне экрана/контейнера (у строк с иконкой/аватаром — к иконке справа), не к левой («מה רצוי» #50a708: יישור לימין בכל המסכים, RTL).
- Заголовок в шапке подэкранов («תמיכה» и др.) — по центру, это норма (01.11).
- Автотесты: `.qa/e2e-app/tests/rtl/rtl-text-alignment-tabs-support.test.mjs`, `.qa/e2e-app/tests/rtl/rtl-text-alignment-monitoring-setup.test.mjs` (план `.qa/e2e-app/specs/app.md` 1.25–1.26). Окно «המכשיר זז» и экран мониторинга — I18N-004 (вручную).
