# SUM-005: Приложение — итог ниטור: длительность, число сбоев/тревог, дети (RTL), «מה קרה»; то же в «היסטוריה»
- Фича/экран: summary (S-18) → история (S-19), детали сеанса
- Тикеты: #25e8f258
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo; дети «QA בדיקה», «QA קטן»)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 6)
- Тип: позитив
- Предусловия: ручная часть создаёт сеанс мониторинга (тестовые данные); автотест мониторинг НЕ запускает — смотрит последний сеанс в «היסטוריה»
## Шаги
1. (Вручную) мониторинг с обоими детьми → сбои/тревога → «סיום ניטור» (слайдер «כבה את המצלמה») → итог.
2. На итоге: заголовок, строка детей, список «מה קרה»; «לכל הניטורים».
3. «היסטוריה» → верхний сеанс → детали.
## Ожидаемо
- Интервал «היום · HH:MM–HH:MM», длительность «N דק׳» (AC2).
- Число событий: «N תקלות בניטור» / «תקלה אחת בניטור» / «התרעה אחת» (AC4, AC5), совпадает с числом в строке истории («N כשלים» / «N התרעות»).
- «QA בדיקה ו-QA קטן היו בבריכה» — RTL, справа рядом с аватарами (AC3; SUM-001).
- «מה קרה»: «התחלת ניטור», события со временем (например «כשל בניטור: המכשיר זז»), «הניטור הסתיים».
- Сеанс сохранён в истории сверху (AC6).
- Автотест (шаг 3): `.qa/e2e-app/tests/summary/history-last-session-summary.test.mjs`. Шаги 1–2 — вручную.
