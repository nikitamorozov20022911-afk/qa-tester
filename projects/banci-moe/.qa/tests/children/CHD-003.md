# CHD-003: Плашка на «בית» не появляется у ребёнка без фото, если подтверждение не просрочено (чек-лист перепроверки)
- Фича/экран: home (/home, плашка-напоминание) ↔ children (/children)
- Тикеты: #5ffe7018
- Роль/аккаунт: user (dadayo1547@aminavin.com); «QA בדיקה» — без фото, подтверждён 4.10.2026; «QA קטן» — с фото, подтверждён 12.10.2026
- Устройство: iPhone 17 Safari (mobile)
- Тип: негатив
- Предусловия: у ребёнка нет фото, `last_confirmed_at` свежий (<90 дней). Можно подменой ответа (мок «нет фото + свежие даты»)
## Шаги (чек-лист перепроверки)
- [ ] 0. Свежая сборка (не кэш), записать номер entry-…
- [ ] 1. /children — плашка «לילד אחד אין תמונה» (про фото), у ребёнка «אין תמונה — כדאי להוסיף»
- [ ] 2. /home — **нет** плашки «כרטיס אחד מחכה לעדכון» / «X כרטיסים מחכים לעדכון» («בדקו שהפרטים והתמונה עדיין נכונים»)
- [ ] 3. Два ребёнка без фото, даты свежие → /home без «שני כרטיסים מחכים לעדכון»
- [ ] 4. Регресс: подтверждение просрочено (>90 дней) → /home «X כרטיסים מחכים לעדכון», X = числу просроченных (CHD-001)
- [ ] 5. Все фото свежие и даты свежие → плашки нет ни на /home, ни в /children
- [ ] 6. Плашка (если есть) не ломает раскладку /home над «ניטורים אחרונים» (Figma 06.1)
- [ ] 7. Повтор после выхода/входа
## Ожидаемо
Ребёнок без фото не считается карточкой «מחכה לעדכון» ни в «ילדים», ни на «בית»; «מחכים לעדכון» — только при просроченном `last_confirmed_at` (источник: реджект Р4 «ילד בלי תמונה לא נספר…», context.md; реджект 12.10 «מסך בית: ילד בלי תמונה נספר כמחכה לעדכון»)
