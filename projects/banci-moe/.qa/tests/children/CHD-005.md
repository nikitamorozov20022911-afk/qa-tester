# CHD-005: Приложение — периодическое напоминание: «לעדכן פרטים», баннер на «בית», «בדיקה תקופתית» в карточке, уведомление 10:00
- Фича/экран: children (список, карточка 04.4) ↔ home (баннер) · локальное уведомление
- Тикеты: #5ffe7018
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo; «QA בדיקה», «QA קטן», last_confirmed_at 11.7.2026 — > 90 дней)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 6)
- Тип: позитив
- Предусловия: карточки не подтверждались > 90 дней. «הפרטים עדיין נכונים» в автотесте НЕ нажимать — дата подтверждения сбросится, вернуть «просрочено» может только программист
## Шаги
1. «ילדים» — метки у детей.
2. «בית» — баннер; нажать баннер.
3. Карточка ребёнка с меткой — блок «בדיקה תקופתית».
4. (Вручную) на следующий день в 10:00 — локальное уведомление по каждому ребёнку; тап по уведомлению.
5. (Вручную, меняет данные) «הפרטים עדיין נכונים».
## Ожидаемо
- 1: у просроченных детей «לעדכן פרטים».
- 2: «X כרטיסים מחכים לעדכון» / «כרטיס אחד מחכה לעדכון» + «בדקו שהפרטים והתמונה עדיין נכונים»; X = числу детей с меткой; тап → «ילדים» (AC3).
- 3: «בדיקה תקופתית», «אושר לאחרונה: <дата>», ссылка «הפרטים עדיין נכונים» (AC2, AC4).
- 4: в 10:00 по уведомлению на каждого ребёнка; тап → карточка этого ребёнка (AC1, AC3).
- 5: «אושר לאחרונה: <сегодня>», метка и баннер исчезают (AC4).
- Автотест (шаги 1–3, без нажатия «הפרטים עדיין נכונים»): `.qa/e2e-app/tests/children/periodic-review-reminder.test.mjs`. Шаги 4–5 — вручную.
