# CHD-004: Приложение — «צילום ילד לזיהוי»: без лица / темно — подсказка, без «התמונה מוכנה»; лицо — «התמונה מוכנה»
- Фича/экран: children — карточка ребёнка → «צילום תמונה» (S-09 / F-13)
- Тикеты: #3f4c7c1e
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo1547@aminavin.com; «QA בדיקה» — без фото)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 6)
- Тип: негатив + позитив
- Предусловия: разрешение камеры уже выдано; фото НЕ сохранять («שימוש בתמונה» не нажимать) — выход перезапуском
## Шаги
1. «ילדים» → «QA בדיקה» → «צילום תמונה» → экран съёмки.
2. Камера смотрит в комнату (стена/потолок, без людей) — ждать ~10 с.
3. Закрыть камеру пальцем — ждать ~10 с.
4. Чёрный кадр (камера лежит объективом на столе) — ждать ~10 с.
5. (Только вручную) навести на лицо человека в рамке.
## Ожидаемо
- Шаг 2 и 3: «לא רואים פנים בתמונה — כוונו את הפנים למסגרת», «התמונה מוכנה» не появляется.
- Шаг 4: «יש יותר מדי חושך — הדליקו אור או עברו למקום מואר», «התמונה מוכנה» не появляется.
- Шаг 5: «התמונה מוכנה» (превью, «צילום מחדש», «שימוש בתמונה») — только с лицом (решение пользователя 2026-10-14; «מה רצוי» #3f4c7c1e).
