# DS-004: Тексты крупным шрифтом не обрезаны сверху/снизу (цифры, «ל») — приложение
- Фича/экран: design-system — «בית» (баннер карточек), «ילדים», «היסטוריה» («X דק׳ ניטור»), экран мониторинга (таймер)
- Тикеты: #5a6377 (id 5390840559b7b1fb535a6377, старый hash #53908405)
- Роль/аккаунт: аккаунт, под которым залогинено приложение (есть карточки «לעדכן פרטים» → баннер; есть сеансы в истории)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7); в вебе проблемы не было
- Тип: визуал — **только вручную** (автотеста нет)
- Предусловия: для таймера — запустить мониторинг (создаёт сеанс в истории).
## Шаги
1. «בית» — баннер «X כרטיסים מחכים לעדכון» / «כרטיס אחד מחכה לעדכון».
2. «ילדים» — баннер/метки.
3. «היסטוריה» — заголовки карточек «X דק׳ ניטור», «היום · N ניטורים».
4. Экран мониторинга — таймер «0:00:0X».
5. Остальные экраны с крупным шрифтом — бегло.
## Ожидаемо
Глифы целиком: верх цифр и «ל» не срезан («ל» не похожа на «7»), нижние выносные целы, строки не «скачут» («מה רצוי» #5a6377: «כל הטקסטים מוצגים במלואם … כמו ב-Figma»; Figma 06.1, 11.5, 08.1).
## Почему без автотеста
Обрезка — визуальная: Appium отдаёт рамку элемента, а не отрисованные глифы, line-height через доступность не читается; скриншот-сравнение не делаем (указание пользователя 25.10). Проверять глазами на каждой сборке.
