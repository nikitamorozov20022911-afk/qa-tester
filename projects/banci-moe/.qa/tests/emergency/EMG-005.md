# EMG-005: Приложение — «חיוג למד״א 101» → окно «לחייג למד״א 101?» → «ביטול» (только приложение)
- Фича/экран: emergency — «עזרה דחופה» (S-16, Figma 09.6/09.7)
- Тикеты: #1273694f
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone
- Тип: позитив · безопасность звонка
- Предусловия: «חיוג ל-101» в автотесте и агентом НЕ нажимается (реальный звонок) — только пользователь вручную
## Шаги
1. «בית» → «חירום» → экран «עזרה דחופה».
2. «חיוג למד״א 101».
3. В окне подтверждения нажать «ביטול».
4. (Вручную, только пользователь) повторить и нажать «חיוג ל-101» → открывается звонилка iOS с 101.
## Ожидаемо
- Окно «לחייג למד״א 101?» с кнопками «חיוג ל-101» и «ביטול» (Figma 09.7; решение 2026-10-04 — окно допустимо).
- После «ביטול» окно закрыто, остаёмся в Banci на «עזרה דחופה», звонилка не открывалась.
- Шаг 4: звонилка с 101 без сообщения об ошибке; при невозможности позвонить — «לא ניתן לחייג מהמכשיר הזה» / «חייגו 101 מטלפון אחר.» (нативный Alert, EMG-004; на iPhone с SIM не вызвать).
- Автотест (шаги 1–3): `.qa/e2e-app/tests/emergency/call-101-confirm-cancel.test.mjs`
