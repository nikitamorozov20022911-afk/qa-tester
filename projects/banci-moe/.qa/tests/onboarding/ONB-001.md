# ONB-001: Первичный онбординг — 7 шагов, дисклеймер, «סיימתם» (ручная проверка, новый аккаунт)
- Фича/экран: onboarding (Figma «03 Onboarding»: 02.x → 03.1–03.4 → 03.5–03.6 → 03.7)
- Тикеты: #8ff79b80
- Роль/аккаунт: НОВЫЙ аккаунт — регистрирует сам пользователь (email, пароль, подтверждение почты); агент аккаунты не создаёт и пароли не вводит
- Устройство: нативное приложение iPhone (основное); веб — пункты «только веб»
- Тип: позитив · только ручная (на существующем аккаунте онбординг не повторить — автотеста нет)
- Предусловия: порядок как в Figma (решение 2026-10-04); для системных окон разрешений iOS нужна свежая установка приложения
## Шаги
1. После регистрации и подтверждения почты: шаг 1 «עין נוספת על המים» → 2 «התראה מיד» → 3 «עזרה בלחיצה אחת» (на 1–3 есть «דלג»).
2. Шаг 4 «הטלפון הופך למצלמה»: «אפשרו גישה למצלמה» (или «בלי מצלמה»).
3. Шаг 5 «התראה לכל הטלפונים», шаг 6 «צפצוף גם במצב שקט».
4. Шаг 7 — дисклеймер: кнопка «גללו עד הסוף כדי לאשר» неактивна → прокрутить до конца → «קראתי ואני מאשר/ת».
5. «סיימתם, אפשר להתחיל» → «בואו נתחיל» → «בית».
## Ожидаемо
- 7 шагов по порядку, полоса прогресса «שלב N מתוך 7».
- Шаги 4–5 в приложении: системные окна iOS камеры/уведомлений (только при свежей установке; если разрешения уже выданы — окон нет, это норма, решение 2026-10-18).
- Дисклеймер: до конца прокрутки кнопка неактивна и нажатие ничего не делает; в конце — «קראתי ואני מאשר/ת»; есть «תנאי השימוש» и ссылка «לתנאי השימוש המלאים» (источник: «מה רצוי» #8ff79b80, реджект 30.9).
- «סיימתם, אפשר להתחיל» → «בית» с «להשלים הגדרה 1 מתוך 3»; повторно онбординг не показывается.
- Только веб: обновление страницы оставляет на том же шаге; прямые адреса /home и т.п. до дисклеймера возвращают на текущий шаг; вперёд по адресу не перейти; /emergency и /terms доступны; PATCH profiles disclaimer_version / onboarding_completed_at.
