# HOME-003: Прерванный сеанс с несколькими сбоями — первым в «ניטורים אחרונים», «X כשלים» как в «היסטוריה»
- Фича/экран: home (/home «ניטורים אחרונים») ↔ history (/history)
- Тикеты: #09b2de78
- Роль/аккаунт: user (dadayo1547@aminavin.com)
- Устройство: iPhone 17 Safari (mobile)
- Тип: позитив
- Предусловия: `?mock=moved` в первом URL новой вкладки; создаёт сеанс мониторинга. В Safari на шаге «בדיקת בטיחות» строка «הטלפון יישאר דלוק» может быть ⚠ (баг #3bf9dd7f) — коснуться «בדיקה חוזרת» пальцем и прослушать звук, чтобы «המשך» стала активной
## Шаги
1. `/home?mock=moved` → «התחלת ניטור» → проверка → камера → дети → «התחלת ניטור»
2. Дождаться окна сбоя «המכשיר זז» → «כיוון מחדש» → «חזרה לניטור»; повторить, чтобы сбоев было 2
3. Не завершая мониторинг, уйти со страницы (закрыть вкладку / перейти на другой адрес)
4. Открыть /home → «ניטורים אחרונים»
5. Открыть /history
## Ожидаемо
- На /home прерванный сеанс первым: «היום, <время старта> · <длит.> · 2 כשלים», иконка сбоя
- В /history он тоже первым: «<время> · … · 2 כשלים», та же иконка
- Состав и порядок трёх строк «ניטורים אחרונים» = три первые записи «היסטוריה» (по времени старта, новые первыми) (источник: «מה רצוי» бага; комментарии 1b48323, 51746c8)
