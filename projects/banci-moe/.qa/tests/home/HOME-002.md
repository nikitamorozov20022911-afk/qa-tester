- Предусловия: в топ-3 «ניטורים אחרונים» есть сеансы трёх видов — со сбоем мониторинга (`?mock=moved`, «המכשיר זז»), с тревогами (`?mock=headUnder`), без событий (`?mock=calm`); если нет — создать (создаёт тестовые данные)
## Шаги
1. Открыть /home → блок «ניטורים אחרונים»
2. Для каждой строки записать иконку и подпись «<день>, <время> · <длит.> · <события>»
3. Открыть /history → найти те же сеансы по времени старта
4. Сравнить строку на /home с записью в /history
5. Сверить блок с Figma 06.1 (node 220-5765)
## Ожидаемо
- Сбой: «כשל אחד» / «X כשלים», иконка камеры с крестиком и оранжевой точкой — **нет** «בלי התרעות» и часов (Р2 08.10)
- Тревоги: сирена + «התרעה אחת» / «X התרעות»
- Без событий: часы + «בלי אירועים» (Figma 06.1); «בלי התרעות» нигде нет
- Текст и иконка каждой строки = той же записи в «היסטוריה» (источник: реджект Р2, комментарий 51746c8; F-34/S-19 AC6)
- Формат «<день>, <время>», «<длит.> · <события>», шеврон, «הכל» → /history (Figma 06.1)
