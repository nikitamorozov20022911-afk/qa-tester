# MON-034: Входящий звонок на телефоне-камере во время мониторинга (обычный и WhatsApp) — ВРУЧНУЮ (звонит человек)
> **Ручной кейс**: звонок делает и принимает человек, автоматом не воспроизвести. Автоматизируется только проверка состояния при уходе приложения в фон — MON-035.
- Фича/экран: monitoring — экран мониторинга, лист «הניטור הופסק», «היסטוריית אירועים»; «בית» на втором телефоне (заголовок статуса)
- Тикеты: #8b8e4f (id a4107ef438e2d39d518b8e4f, просьба клиента 05.11); связано #7f31a2, #15ae4b, #3c3460 (MON-015), #7b5462 (MON-026)
- Роль/аккаунт: user (dadayo1547@aminavin.com) на обоих телефонах, «התרעות בטלפון הזה» включено на приёмнике
- Устройство: нативное приложение. Камера iPhone 17 (Eitan com.julius.banci 0.1.1 (7) + OTA), приёмник Pixel 6 (com.eitan.poolsafety vc10 + OTA); обратное направление (камера Pixel) — НЕ проверялось
- Тип: позитив + негатив (сбой связи/камеры)
- Предусловия: оба телефона открыть/закрыть 2 раза (OTA); видео бассейна на экране Mac, зона размечена; «התחלת ניטור» → «תקין»; Pixel на «בית», экран разблокирован; звонящий — телефон пользователя
## Шаги
1. Обычный звонок на iPhone, ответ зелёной кнопкой (весь экран), разговор ≥ 40 с. Смотреть «בית» на Pixel.
2. Положить трубку, вернуться в Banci вручную.
3. Обычный звонок, ответ через баннер (разговор в фоне, Banci остаётся на экране); либо ответ из AirPods/Bluetooth-гарнитуры.
4. Обычный звонок без ответа (баннер, не трогать).
5. WhatsApp-звонок, ответ через баннер → открывается экран WhatsApp.
6. Звонок отклонить с баннера (обычный; затем WhatsApp).
7. После всех звонков: «היסטוריה» сеанса и «ניטורים אחרונים» на Pixel.
## Ожидаемо
- Шаг 1: сбой «האפליקציה ירדה לרקע»; на Pixel push «הניטור הפסיק לעבוד» (~1 с) и заголовок «בית» = «הבריכה לא במעקב», НЕ «הניטור פעיל» — весь звонок, в т.ч. после закрытия push (комм. 16.11, реджект №2 15.11).
- Шаг 2: окно «הניטור הופסק» закрывается само за ~6–8 с (автопроверка), «תקין»; на Pixel заголовок снова «הניטור פעיל»; «הניטור חזר לפעול» — одно на сбой.
- Шаг 3: Banci на экране, «תקין» весь звонок, без сбоя и push, «הניטור פעיל» на Pixel не меняется (тикет п.1, п.4). Шаг 4, 6: без сбоя.
- Шаг 5: как шаг 1 (экран WhatsApp = приложение в фоне): сбой, Pixel «הבריכה לא במעקב», автовозврат.
- Шаг 7: на звонок одна пара «האפליקציה ירדה לרקע» / «הניטור חזר לפעול», без дублей; сеанс не «растянут»; приложение не упало.
(источник: «מה רצוי» #8b8e4f; F-23 AC1/AC3, F-24 AC1–3/AC5; реджект №2; решение пользователя 08.11/15.11: iOS при полноэкранном звонке останавливает камеру — это ожидаемо, важно, чтобы второй телефон показал сбой, а не «הניטור פעיל»)
## Не проверено
Android как камера; Bluetooth-гарнитура; Т7 «אין קשר עם הטלפון שמצלם» (обрыв связи ~30 с).
