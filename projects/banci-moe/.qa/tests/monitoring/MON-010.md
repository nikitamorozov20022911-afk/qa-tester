# MON-010: Чекбоксы сообщают состояние «отмечено / не отмечено» (доступность)
- Фича/экран: monitoring — шаг 2 «כיוון מצלמה», шаг 3 «מי בבריכה היום?»
- Тикеты: #e41636dd
- Роль/аккаунт: аккаунт, под которым залогинено приложение (≥ 1 ребёнок; телефон подключён к аккаунту, иначе «המשך» на «בדיקת בטיחות» серая)
- Устройство: нативное приложение iPhone (основное); веб — пункт «только веб»
- Тип: позитив · доступность
- Предусловия: мониторинг не запускать («התחלת ניטור» на шаге 3 не нажимать)
## Шаги
1. «בית» → «התחלת ניטור» → «בדיקת בטיחות» (тестовый сигнал «השמעה» → «שמעתי») → «המשך».
2. Шаг 2: чекбокс «כל שטח המים נראה בתמונה…» — посмотреть значение доступности, нажать, ещё раз нажать, нажать (оставить отмеченным).
3. «המשך» → шаг 3 «מי בבריכה היום?»: строка ребёнка — нажать, нажать ещё раз (вернуть как было); «בחירת כולם» — все отмечены.
4. Выйти без запуска мониторинга.
## Ожидаемо
- Приложение: значение доступности (VoiceOver / Appium value) «checkbox, unchecked» ↔ «checkbox, checked» меняется после каждого нажатия; у строки ребёнка — так же (источник: «מה רצוי» #e41636dd — מצב מסומן/לא מסומן).
- Шаг 2: «המשך» активна только при отмеченном чекбоксе.
- Только веб: `aria-checked` false → true → false → true у того же чекбокса и строк детей (`role=checkbox`).
- Не входит в тикет (находка 18.10, решение пользователя): слова «checkbox, checked» на английском при иврите в приложении.
- Ручное: VoiceOver на слух произносит состояние.
- Автотест: `.qa/e2e-app/tests/accessibility/checkbox-checked-state.test.mjs`
