# MON-031: Поворот телефона (половина / ¾ воды вне кадра) → «הבריכה נחתכה · לא במעקב» + «כיוון מחדש»; без воды не возвращается, вернули телефон → «הניטור חזר לפעול» (iPhone, ВРУЧНУЮ + веб-мок)
- Фича/экран: monitoring — экран мониторинга, окно сбоя «הבריכה נחתכה» (Figma 10.3, node 247-4795; F-21 AC2, AC9; S-14 AC1–3, AC7)
- Тикеты: #15ae4b (id 8991a7fb9ab8c4d6d915ae4b; commit 578d6c7: < 60% размеченных ячеек с водой → сбой; возврат при ≥ 80%)
- Роль/аккаунт: dadayo
- Устройство: нативное приложение iPhone 17 (Eitan build 7 + OTA); создаёт сеанс в «היסטוריה» (@data)
- Тип: позитив + граница (порог 60% / 80%)
- Предусловия: как MON-030 (видео бассейна на Mac, разметка зоны пальцем); поворачивает телефон человек
## Шаги
1. Начать мониторинг, дождаться «תקין».
2. Медленно (~5 с) повернуть телефон так, чтобы ¾ размеченной воды вышло из кадра; держать 60 с.
3. Медленно повернуть так, чтобы вышла половина воды (≥ 50–60% вне кадра); держать 40–60 с. Записать примерный % вне кадра.
4. Вернуть телефон в исходное положение (бассейн снова целиком в кадре).
5. Альтернатива шагу 4: «כיוון מחדש» → разметка → галочка → «חזרה לניטור».
6. Каждый вид поворота ×2.
## Ожидаемо
- Шаги 2–3: «הבריכה נחתכה», «הבריכה לא במעקב — השגיחו עליה בעצמכם.», «חלק מהבריכה יצא מהתמונה. נסו לפי הסדר:», кнопка «כיוון מחדש»; сбой держится, пока воды нет — без самопроизвольного «הניטור חזר לפעול» (тикет «מה רצוי»; реджект 05.11).
- Граница: ~42% вне кадра — может оставаться «תקין» (порог 60% по комментарию 578d6c7); ~59%+ → «הבריכה נחתכה».
- Шаг 4: сам «הניטור חזר לפעול», «תקין» (реджект 05.11: «חזר לפעול» רק כשהבריכה שוב בתמונה). Шаг 5: «תקין» после «חזרה לניטור».
- Веб-мок `?mock=outOfFrame` (видно 60% воды): окно «הבריכה נחתכה» · «לא במעקב» + «כיוון מחדש», событие «חלק מהבריכה יצא מהתמונה», после возврата воды — «הניטור חזר לפעול», «תקין». Автотест: `.qa/e2e/tests/monitoring/pool-cut-not-tracked-auto-return.spec.ts` (@iphone @data). Проверяет только окно/тексты и авто-возврат по мок-сигналу, не распознавание реального поворота — оно только вручную.
