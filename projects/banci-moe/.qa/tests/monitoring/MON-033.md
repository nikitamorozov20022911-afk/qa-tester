# MON-033: Android «בדיקת בטיחות» — медиа на максимуме в режиме вибрации и беззвучном: тестовый звук → «שמעתי» → «5 מתוך 5»; сирена в беззвучном играет
- Фича/экран: monitoring — шаг 1 «בדיקת בטיחות» (F-16 AC6, AC11; S-12 AC5); тревога на мониторинге
- Тикеты: #8edb6e (id 53354b23bdf9b48ed18edb6e); связано #e2f5c7 (MON-012, iPhone), MON-032
- Роль/аккаунт: user (dadayo), приложение уже залогинено
- Устройство: нативное приложение Android — Pixel 6 по кабелю, Eitan 0.1.1 (10) + OTA
- Тип: позитив + граница (максимум громкости в «тихих» режимах)
- Предусловия: как MON-032; режимы и громкость — по adb. **Тестовый звук и сирена громкие** — телефон не у уха.
## Шаги
1. adb: режим VIBRATE, медиа 25 (максимум) → «בית» → «התחלת ניטור» → «בדיקת בטיחות». Прочитать строку «עוצמת צפצוף מקסימלית».
2. То же в режиме SILENT.
3. SILENT + максимум: тап по строке → лист «בדיקת צליל ההתרעה» → «השמעה» (один раз) → «שמעתי».
4. (вручную, на слух) SILENT + максимум: запуск мониторинга до тревоги или тестовая тревога — сирена слышна.
## Ожидаемо
- Шаги 1–2: «עוצמת הקול נמוכה/כבויה» нет, подсказки про режим звонка нет; строка «השמיעו את צליל הבדיקה ואשרו ששמעתם אותו.» (источник: проверка 17.11, медиа max в любом режиме).
- Шаг 3: лист с «השמעה» / «שמעתי»; звук слышен даже в беззвучном (USAGE_MEDIA); после «שמעתי» лист закрыт, «5 מתוך 5», «המשך» активна (S-12 AC5, AC18).
- Шаг 4: сирена тревоги в беззвучном на Pixel играла 28 с (динамик, не заглушена) — пользователь подтвердил на слух 17.11 18:21. Раз сирена не глушится мьютом, подсказка «העבירו למצב צלצול» нужна из-за громкости медиа-потока, а не из-за мьюта: поведение сигнала в вибрации/беззвучном — наблюдение, а не требование тикета.
- Автотесты: `.qa/e2e-app/android/tests/safety-vibrate-max-volume-asks-sound-check.test.mjs` (шаги 1–2, тихий), `.qa/e2e-app/android/tests/safety-silent-sound-check-passes.test.mjs` (шаг 3, ГРОМКИЙ, только BANCI_SOUND=1). Шаг 4 — только вручную.
