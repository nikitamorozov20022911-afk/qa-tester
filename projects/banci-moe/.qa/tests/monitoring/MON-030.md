# MON-030: Палец на объективе 20 с → «המצלמה מוסתרת» за секунды, уведомление на второй телефон, сам снимается после того, как убрали палец (iPhone, ВРУЧНУЮ)
- Фича/экран: monitoring — экран мониторинга, окно сбоя «המצלמה מוסתרת» (F-21 AC3, AC9; S-14 AC1–3; #12436b AC7–8; структура как Figma 10.4, node 247-4936)
- Тикеты: #15ae4b (id 8991a7fb9ab8c4d6d915ae4b; commit 578d6c7, OTA 0.1.1; реджект rej_263598750f104d76288c846f — закрыт 08.11)
- Роль/аккаунт: dadayo — оба телефона в аккаунте
- Устройство: нативное приложение iPhone 17 (Eitan build 7 + OTA, закрыть/открыть ×2) — камера; Pixel 6 — второй телефон (приёмник уведомления); создаёт сеанс в «היסטוריה» (@data)
- Тип: позитив
- Предусловия: видео бассейна на экране Mac (синяя заливка/ролик из .qa/media), нормальный свет; зону воды размечает пользователь пальцем (Appium-перетаскивание прокручивает страницу); палец на объектив кладёт человек
## Шаги
1. iPhone: «בית» → «התחלת ניטור» → проверка → кадр бассейна, разметка 4 точек → «מי בבריכה היום?» → «התחלת ניטור»; дождаться «תקין».
2. Закрыть объектив пальцем на 20 с (секундомер).
3. Смотреть второй телефон (Pixel): пришло ли уведомление о сбое.
4. Убрать палец, не двигать телефон.
5. Повторить шаги 2–4 второй раз (×2).
6. «היסטוריית אירועים» / итог после «כבה את המצלמה».
## Ожидаемо
- Шаг 2: через ~4–5 с сбой «המצלמה מוסתרת», «הבריכה לא במעקב — השגיחו עליה בעצמכם.», «משהו מכסה את עדשת המצלמה…» и шаг «הסירו את מה שמסתיר את המצלמה (…)»; НЕ «הבריכה נחתכה» / «הרחיקו מעט את הטלפון» (тикет «מה רצוי»: כיסוי המצלמה תוך כמה שניות → כשל «המצלמה מוסתרת»; реджект 05.11).
- Шаг 3: уведомление о сбое на втором телефоне (тикет: «התרעה לכל הטלפונים»; звук — вердикт #e9ea54).
- Шаг 4: сбой снимается сам — «הניטור חזר לפעול», «תקין» (комментарий 578d6c7, реджект 05.11).
- Шаг 6: события «המצלמה מוסתרת» и «הניטור חזר לפעול» в истории.
- Не автоматизируется в вебе: в моке Expo web нет сценария закрытого объектива (признак — однотонность настоящего кадра). Только вручную на телефоне.
