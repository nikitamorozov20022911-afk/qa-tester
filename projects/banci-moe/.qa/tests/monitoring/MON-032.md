# MON-032: Android «בדיקת בטיחות» — режим вибрации + низкая громкость медиа: строка «עוצמת צפצוף מקסימלית» объясняет, что выйти нужно из вибрации/беззвучного
- Фича/экран: monitoring — шаг 1 «בדיקת בטיחות» (F-16 AC11, AC15, AC18 / S-12 AC4, AC5, AC7; Figma 07.2, node 220-6698)
- Тикеты: #8edb6e (id 53354b23bdf9b48ed18edb6e); связано #e2f5c7 (MON-012, iPhone)
- Роль/аккаунт: user (dadayo), приложение уже залогинено
- Устройство: нативное приложение Android — Pixel 6 по кабелю, Eitan (com.eitan.poolsafety) 0.1.1 (10) + OTA; в вебе и на iPhone не проверяется (на iPhone мьют не определяется)
- Тип: негатив (⚠) + позитив (после исправления)
- Предусловия: батарея > 30% или зарядка; уведомления и камера разрешены; второй телефон подключён (иначе «5 מתוך 5» недостижимо; с #4a869b он не блокирует «המשך»). Режимы по adb: `cmd audio set-ringer-mode VIBRATE|SILENT|NORMAL`; громкость медиа `cmd audio set-volume 3 N` (**не** `cmd media_session volume --set` — не работает). Мониторинг не запускать.
## Шаги
1. adb: режим VIBRATE, медиа 4 (из 25). Перезапустить приложение → «בית» → «התחלת ניטור» → «בדיקת בטיחות».
2. Прочитать строку «עוצמת צפצוף מקסימלית» и состояние «המשך».
3. adb: режим NORMAL, медиа 25 → «בדיקה חוזרת».
4. (необязательно, не автотест) то же с режимом SILENT и медиа 4.
## Ожидаемо
- Шаг 2: ⚠ у строки, текст говорит про режим: «…אם הטלפון במצב רטט או שקט — העבירו אותו למצב צלצול…» (сборка 0.1.1 (10) + OTA 1db01fa1) — не только «הגבירו את העוצמה». В следующей сборке Android: «הטלפון במצב רטט — העבירו אותו למצב צלצול כדי שהאזעקה תישמע…» (точный текст из «למשל» тикета не требование; требование — понятное сообщение, что переключить на звонок, AC15). «המשך» серая (решение пользователя 08.10, Figma 07.2). Счётчик 4 из 5.
- Шаг 3: строка «השמיעו את צליל הבדיקה ואשרו ששמעתם אותו.», подсказки про режим звонка нет (источник: проверка 17.11, K3/K4).
