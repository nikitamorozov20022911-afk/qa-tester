# MON-017: Палец на объективе — подсказка «משהו מכסה…», «המשך» / «חזרה לניטור» серые (ВРУЧНУЮ)
- Фича/экран: monitoring — шаг 2 «כוונו את המצלמה לבריכה» и «כיוון מחדש» во время мониторинга (F-15 / S-11)
- Тикеты: #f7bfca (реджект rej_42e981ec835649643e396993, закрыт 01.11)
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (Eitan); только вручную — палец на линзе Appium не воспроизводит
- Тип: негатив
- Предусловия: второй телефон подключён к аккаунту (иначе «בדיקת בטיחות» 4 מתוך 5 и «המשך» серая — тикет #4a869b); громкость iPhone на максимуме; приложение Eitan (TestFlight 0.1.1 build 7 + OTA 29.10: закрыть/открыть 2 раза), вход уже выполнен (dadayo); камера на освещённую сцену.
## Шаги
1. «בית» → «התחלת ניטור» → «בדיקת בטיחות» → «המשך» → шаг 2, галочка «כל שטח המים נראה בתמונה…» стоит.
2. Закрыть ЗАДНЮЮ линзу пальцем, держать ≥ 5 с (кадр тёмно-красный, без деталей); нажать «המשך».
3. Убрать палец.
4. Повторить 2–3 ещё 2 раза.
5. (Во время мониторинга, создаёт сеанс в «היסטוריה») «כיוון מחדש» → то же с пальцем → «חזרה לניטור».
## Ожидаемо
- Шаг 2: за 1–2 с подсказка «משהו מכסה את עדשת המצלמה ולא רואים כלום בתמונה. הסירו את האצבע, הכיסוי או מה שמסתיר את העדשה.» (или «חשוך מדי כדי לראות את המים היטב…»), держится, не мигает; «המשך» серая и нажатие ничего не делает, хотя галочка стоит (F-15 AC6, AC8; решение 25.10).
- Шаг 3: подсказка исчезает ≈ 1–2 с, «המשך» активна.
- Шаг 5: так же, кнопка «חזרה לניטור» серая / активна.
