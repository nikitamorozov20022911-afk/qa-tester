# MON-015: Непрерывный мониторинг — входящие звонки и долгая работа без падений
- Фича/экран: monitoring — экран мониторинга (ניטור רציף של אזור הבריכה)
- Тикеты: #3c3460 (id 90a850822102d99a5b3c3460, старый hash #90a85082); связано #0b59fe
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7) + второй телефон для звонков; в вебе не проверяется
- Тип: позитив + стабильность
- Предусловия: телефон на зарядке; камера смотрит на освещённую сцену; запускает мониторинг (сеанс в «היסטוריה»).
## Шаги
1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור».
2. Входящий звонок → ответить → сбросить.
3. Входящий звонок → отклонить.
4. Входящий звонок → ответить → сбросить.
5. Оставить мониторинг идти (25.10 — 1:28).
6. «כבה את המצלמה».
## Ожидаемо
- Шаги 2–4: приложение не падает (реджект 20.10 «звонок → краш»), мониторинг продолжается, статус «תקין».
- Шаг 5: нет падений, таймер растёт, статус «תקין».
- Шаг 6: итог мониторинга.
- Ручное: входящие звонки.
- Автотест: `.qa/e2e-app/tests/monitoring/long-monitoring-no-crash.test.mjs` (шаги 1, 5, 6; длительность BANCI_MONITOR_MINUTES, по умолчанию 5; только с BANCI_MONITORING=1).
