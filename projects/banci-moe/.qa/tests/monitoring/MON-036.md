# MON-036: «ניטורים אחרונים» на втором телефоне обновляется после мониторинга на телефоне-камере (≤ 10 с, вкладка, возврат из фона)
- Фича/экран: «בית» → «ניטורים אחרונים» второго телефона (F-34 AC1–6, F-36 AC3–6; Figma 06.1 — формат строки «היום, hh:mm · N דק׳ · события»)
- Тикеты: #7f31a2 (id bad84986d259f3d0597f31a2; commit 175dab3, OTA 6360fe71); связано HIST-004, HOME-001, #09b2de78, MON-026
- Роль/аккаунт: user (dadayo1547@aminavin.com) на обоих
- Устройство: нативное приложение — камера iPhone 17 (0.1.1 (7) + OTA), приёмник Pixel 6 (vc10 + OTA); камера Pixel → приёмник iPhone — НЕ проверялось
- Тип: позитив
- Предусловия: оба телефона открыть/закрыть 2 раза (OTA); камера на бассейн/любой кадр; создаёт сеансы в «היסטוריה»; звонков не нужно
## Шаги
1. Pixel на «בית» (не уходить). iPhone: мониторинг ~1 мин → «כבה את המצלמה». Засечь секунды до новой строки.
2. Pixel на вкладке «ילדים»; iPhone: сеанс; Pixel → «בית».
3. Pixel: свернуть (Home) / заблокировать; iPhone: сеанс; вернуть Banci на Pixel.
4. Сравнить «בית» Pixel и iPhone (строки, время, длительность, события).
5. (Вручную) убить Banci на iPhone во время мониторинга → ~30–60 с → строка прерванного сеанса на Pixel сама.
## Ожидаемо
- Шаг 1: новая строка первой в «ניטורים אחרונים» на Pixel ≤ ~10 с после конца (факт 17.11: ≤ 5 с, «היום, 18:23 · 17 דק׳ · התרעה אחת»), без ухода с экрана.
- Шаг 2: после «בית» список свежий. Шаг 3: после возврата из фона список свежий сразу (факт 17.11: «היום, 18:52 · 4 דק׳ · 3 כשלים»).
- Шаг 4: те же строки; дублей нет. Шаг 5: прерванный сеанс виден без действий.
(источник: «מה רצוי» #7f31a2 — «בכל הטלפונים … אותם ניטורים אחרונים … מתעדכן כשנגמר ניטור / כשחוזרים לדף בית»; срок ~10 с — ориентир программиста, не требование тикета)
## Не проверено / вручную
Шаг 5; направление камера Pixel → приёмник iPhone; «היסטוריה» на втором телефоне (бонус из комментария программиста).
