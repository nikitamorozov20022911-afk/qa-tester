# MON-014: Мониторинг остановлен блокировкой/фоном — уведомление, лист «הניטור הופסק», «אין חיבור»
- Фича/экран: monitoring — экран мониторинга, лист «הניטור הופסק», окно сбоя «אין חיבור»
- Тикеты: #0b59fe (id 620738da54812c7ec70b59fe, старый hash #620738da); связано #3c3460
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7); в вебе не проверяется
- Тип: позитив + негатив (сбой ОС/сети)
- Предусловия: «חשבון → התרעות וצפצוף → התרעות בטלפון הזה» включено; уведомления приложения разрешены; телефон на зарядке; запускает мониторинг (сеанс в «היסטוריה»).
## Шаги
1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור».
2. Заблокировать экран боковой кнопкой, подождать ~5 с.
3. Нажать на уведомление на экране блокировки (разблокировать).
4. «המשך ניטור».
5. Свернуть приложение (Home), подождать ~5 с, вернуться.
6. Свернуть и вернуться быстрее 2 с.
7. Включить авиарежим на ~30 с, затем выключить.
8. Посмотреть «היסטוריית אירועים»; «כבה את המצלמה».
## Ожидаемо
- Шаги 2, 5: почти сразу локальное уведомление со звуком «המסך ננעל או שהאפליקציה נסגרה — פתחו את Banci כדי לחזור לניטור» (реджект 20.10, AC9).
- Шаг 3 (и возврат на шаге 5): приложение на экране мониторинга с листом «הניטור הופסק»: «המסך ננעל או שהאפליקציה נסגרה, ובזמן הזה הבריכה לא הייתה במעקב. הניטור חזר לפעול עכשיו.»; шаги «השאירו את Banci פתוחה על המסך בזמן ניטור», «אל תנעלו את הטלפון בכפתור הצד», «חברו את הטלפון למטען»; кнопки «המשך ניטור» / «סיום ניטור».
- Шаг 4: лист закрыт, статус «תקין», таймер идёт.
- Шаг 6: уведомления нет.
- Шаг 7: статус «לא במעקב», окно «אין חיבור», событие «החיבור נותק»; после возврата сети — «תקין» (AC8).
- Шаг 8: события «האפליקציה ירדה לרקע», «המצלמה הפסיקה לפעול», «הניטור חזר לפעול».
- Ручное: блокировка, уведомление на экране блокировки и звук, быстрый возврат < 2 с, авиарежим. AC5 (перегрев) не проверялся.
- Автотест: `.qa/e2e-app/tests/monitoring/background-stopped-sheet.test.mjs` (шаги 1, 4, 5, 8 — фон через Appium; только с BANCI_MONITORING=1).
