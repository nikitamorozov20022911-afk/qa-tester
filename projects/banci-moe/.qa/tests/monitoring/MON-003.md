# MON-003: Проверка безопасности: офлайн и медленная сеть
- Фича/экран: monitoring
- Тикеты: #64586270
- Роль/аккаунт: user
- Устройство: iPhone 17 Safari (основное) / desktop
- Тип: негатив
- Предусловия: офлайн — авиарежим на iPhone (Appium в авиарежиме не работает — смотрит пользователь); медленная сеть — задержка ответов ~6 с (подмена/NLC «Edge») и перезагрузка /monitor
## Шаги
1. /monitor офлайн → «בדיקה חוזרת»
2. Онлайн → «בדיקה חוזרת»
3. Обрыв сети при «המשך»
4. Медленная сеть при открытии
## Ожидаемо
«אין אינטרנט…», «המשך» серая → снова активна; ошибка «משהו השתבש» вместо вечной загрузки; при медленной сети — загрузка (07.1: пустые кружки, «בודקים…»), без «המנוי לא פעיל» и без ложной ⚠ «הטלפון מחובר למנוי פעיל» (реджект 08.10 п.1); непроверенные в браузере пункты не отмечены зелёной галочкой
