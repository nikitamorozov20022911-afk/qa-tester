# MON-012: «בדיקת בטיחות» — строка «עוצמת צפצוף מקסימלית» по громкости телефона
- Фича/экран: monitoring — шаг 1 «בדיקת בטיחות» (F-16 / S-12)
- Тикеты: #e2f5c7 (id 64586270b94cf19db5e2f5c7, старый hash #64586270)
- Роль/аккаунт: аккаунт, под которым залогинено приложение (телефон подключён к аккаунту)
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7 и новее); в вебе не проверяется
- Тип: позитив + негатив (состояния громкости)
- Предусловия: батарея > 30% или зарядка; уведомления и камера приложения разрешены; второй телефон подключён — иначе «5 מתוך 5» недостижимо. Громкость выставляется **вручную** кнопками сбоку. Мониторинг не запускать.
## Шаги
1. Громкость iPhone → 0. «בית» → «התחלת ניטור» → «בדיקת בטיחות».
2. Громкость → ниже 50% (не 0) → «בדיקה חוזרת».
3. Громкость → максимум → «בדיקה חוזרת».
4. Тап по строке «השמיעו את צליל הבדיקה ואשרו ששמעתם אותו.» → лист «בדיקת צליל ההתרעה» → «השמעה» → «שמעתי».
## Ожидаемо
- Шаг 1: строка «עוצמת הקול כבויה — הגבירו את העוצמה בכפתורי הצד ולחצו על «בדיקה חוזרת».», «המשך» серая (AC11, AC15, AC18; реджект 20.10).
- Шаг 2: «עוצמת הקול נמוכה — הגבירו את העוצמה עד הסוף…», «המשך» серая (AC6; комментарий программиста 21.10).
- Шаг 3: строка «השמיעו את צליל הבדיקה ואשרו ששמעתם אותו.».
- Шаг 4: лист с кнопками «השמעה» / «שמעתי»; звук слышен; после «שמעתי» — ✓ у строки, «5 מתוך 5», «המשך» активна (S-12 AC5).
- Ручное: звук сигнала слышен на слух; беззвучный переключатель (мьют) вкл/выкл; громкость 50–99%.
- Автотесты: `.qa/e2e-app/tests/monitoring/safety-volume-max-sound-check.test.mjs` (шаги 3–4, громкость на максимуме — ручное предусловие), `.qa/e2e-app/tests/monitoring/safety-volume-low-warning.test.mjs` (шаги 1–2, запуск с BANCI_VOLUME=0 / low после ручной установки громкости; без переменной — пропуск).
- Android (режим вибрации/беззвучный, adb): MON-032, MON-033 (#8edb6e); тесты `.qa/e2e-app/android/tests/`.
