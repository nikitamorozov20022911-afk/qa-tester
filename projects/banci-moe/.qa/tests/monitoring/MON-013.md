# MON-013: «בדיקת בטיחות» — строка «הרשאות מצלמה והתרעות» ведёт в настройки iOS
- Фича/экран: monitoring — шаг 1 «בדיקת בטיחות» (F-16 AC5 / S-12 AC4, AC5, AC7)
- Тикеты: #2bc13b (id 33b0a1db12a341e5b02bc13b, старый hash #33b0a1db); связано #e2f5c7
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7); в вебе не проверяется
- Тип: позитив + негатив (разрешения ОС)
- Предусловия: разрешения меняются **вручную** в Настройках iPhone → приложение. После теста уведомления и камеру включить обратно.
## Шаги
1. Настройки iPhone → приложение → Уведомления: выкл. «בית» → «התחלת ניטור» → «בדיקת בטיחות».
2. Тап по строке «הרשאות מצלמה והתרעות».
3. Вернуться в приложение, включить уведомления → «בדיקה חוזרת».
4. То же для камеры: выключить доступ к камере → «בדיקת בטיחות».
5. Всё включено → «בדיקת בטיחות».
## Ожидаемо
- Шаг 1: строка-кнопка «הרשאות מצלמה והתרעות, אשרו התראות בהגדרות הטלפון כדי לקבל הודעות על תקלות.» с ⚠ и стрелкой, «המשך» серая (S-12 AC7).
- Шаг 2: открываются Настройки iOS (com.apple.Preferences) на странице приложения («מה רצוי» #2bc13b).
- Шаг 3: после «בדיקה חוזרת» строка ✓ (S-12 AC5).
- Шаг 4: текст «אשרו גישה למצלמה בהגדרות הטלפון.», тап тоже открывает настройки (комментарий программиста).
- Шаг 5: строка «הרשאות מצלמה והתרעות» с ✓, без стрелки, не кнопка (traits не Button) — Figma 07.2.
- Ручное: переключение разрешений, возврат из Настроек свайпом «назад в приложение».
- Автотесты: `.qa/e2e-app/tests/monitoring/safety-permissions-row-ok.test.mjs` (шаг 5), `.qa/e2e-app/tests/monitoring/safety-permissions-row-opens-settings.test.mjs` (шаги 1–2, 4: запуск с BANCI_PERMISSION_OFF=notifications / camera после ручного выключения; без переменной — пропуск).
