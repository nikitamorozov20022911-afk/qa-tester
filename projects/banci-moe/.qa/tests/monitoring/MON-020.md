# MON-020: Мониторинг + палец на объективе — сбой «התמונה לא ברורה», возврат «תקין» (ВРУЧНУЮ)
- Фича/экран: monitoring — экран мониторинга, окно сбоя (F-15; связано #0b59fe / #620738da)
- Тикеты: #f7bfca (коммит feb2d22)
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (Eitan); только вручную; создаёт сеанс в «היסטוריה» (@data)
- Тип: негатив
- Предусловия: второй телефон подключён к аккаунту (иначе «בדיקת בטיחות» 4 מתוך 5 и «המשך» серая — тикет #4a869b); громкость iPhone на максимуме; приложение Eitan (TestFlight 0.1.1 build 7 + OTA 29.10: закрыть/открыть 2 раза), вход уже выполнен (dadayo); телефон на зарядке, камера на освещённую сцену.
## Шаги
1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור».
2. Закрыть заднюю линзу пальцем на 5–10 с.
3. Убрать палец.
4. «כבה את המצלמה».
## Ожидаемо
- Шаг 2: сбой «התמונה לא ברורה» (в заметке пользователя — «תמונה לא ברורה»), первый шаг инструкции «ודאו ששום דבר לא מכסה את עדשת המצלמה ונקו אותה».
- Шаг 3: мониторинг сам возобновляется, статус «תקין». Если вместо сбоя «המכשיר זז» — это #8d2595, не этот тикет.
