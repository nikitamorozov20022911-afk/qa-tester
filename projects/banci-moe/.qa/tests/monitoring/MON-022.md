# MON-022: Реальный сдвиг телефона → «המכשיר זז», сбой держится, «כיוון מחדש» → «חזרה לניטור» (ВРУЧНУЮ / полуавтомат)
- Фича/экран: monitoring — сбой 10.2 «המכשיר זז» (Figma 247-4658), экран «כוונו את המצלמה מחדש» (F-21 AC1, AC9; S-14 AC7)
- Тикеты: #8d2595 (реджект rej_abb4c92d08d77356d9604dbd, исправление d27bfb4 — гироскоп)
- Роль/аккаунт: аккаунт, под которым залогинено приложение (dadayo)
- Устройство: нативное приложение iPhone (Eitan); нужны руки; создаёт сеанс в «היסטוריה» (@data)
- Тип: позитив
- Предусловия: как MON-021. Повторы — ×2 на каждый вид (урок L-20261101-1).
## Шаги
1. Запустить мониторинг (как MON-021 шаг 1), дождаться «תקין».
2. Сдвиг: (а) поворот ~90° вокруг вертикальной оси ×2; (б) перенос стол → пол под тем же углом ×2; (в) наклон (камера в потолок/вниз) ×2. После каждого — положить телефон и не трогать.
3. Подождать ≥ 12 с в окне сбоя.
4. «כיוון מחדש» → не меньше 30 с на «כוונו את המצלמה מחדש».
5. Отметить «כל שטח המים נראה בתמונה» → «חזרה לניטור».
6. После последнего сдвига — «כבה את המצלמה».
## Ожидаемо
- Шаг 2: каждый раз (6 из 6) окно «המכשיר זז» с текстами «הבריכה לא במעקב — השגיחו עליה בעצמכם.», «הטלפון זז מהמקום. כדי לחזור לניטור:» и кнопками «כיוון מחדש», «סיום ניטור».
- Шаг 3: сбой не снимается сам, статус не возвращается в «תקין».
- Шаг 4: окно сбоя не открывается поверх «כוונו את המצלמה מחדש», разметку можно закончить.
- Шаг 5: статус «תקין», в «היסטוריית אירועים» событие «הניטור חזר לפעול»; ложного «זז» сразу после возврата нет.
- Тревоги «זוהתה סכנה בבריכה» после сдвига — #18bb68, в этот кейс не входят (записать).
- Полуавтомат: `.qa/e2e-app/tests/monitoring/moves-assist.test.mjs` (@manual-assist: человек двигает, скрипт проверяет шаги 2–5 и сам жмёт «כיוון מחדש», галочку, «חזרה לניטור»; только с BANCI_MONITORING=1 и BANCI_MANUAL_ASSIST=1).
