1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור».
2. Не трогать телефон и стол N минут (вручную — ≥ 20 мин; автотест — BANCI_MONITOR_MINUTES, по умолчанию 5).
