# MON-005: Ручная разметка снимает блок «המשך» при проблемном моке
- Фича/экран: monitoring (S-11, запасной путь «סימון ידני של שטח המים»)
- Тикеты: #7076cfab
- Роль/аккаунт: user
- Устройство: iPhone Safari
- Тип: позитив
- Предусловия: `?mock=noWater` (или другой проблемный сценарий) в первом URL вкладки
## Шаги
1. Дойти до шага камеры, дождаться подсказки — «המשך» неактивна
2. «סימון ידני של שטח המים»
3. Отметить подтверждение «כל שטח המים נראה ושום דבר לא מסתיר אותו»
4. «המשך»
## Ожидаемо
- До подтверждения «המשך» неактивна; после галочки — активна (F-15 AC6, AC8; комментарий 28.9/4.10)
- «המשך» → `/monitor/children` («מי בבריכה היום?»)
