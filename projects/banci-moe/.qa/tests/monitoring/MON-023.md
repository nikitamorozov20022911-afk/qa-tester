## Шаги
1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור».
2. Повернуть телефон ~90°, положить и не трогать → окно «המכשיר זז» → «כיוון מחדש».
3. На «כוונו את המצלמה מחדש» посмотреть превью камеры.
4. Галочка «כל שטח המים נראה בתמונה…» → «חזרה לניטור» → «כבה את המצלמה».
