## Шаги
1. «בית» → «התחלת ניטור» → проверка → камера → «מי בבריכה היום?» → «התחלת ניטור».
2. Открыть Пункт управления (свайп из правого верхнего угла) → включить авиарежим → закрыть Пункт управления; ~30 с ничего не нажимать.
3. Пункт управления → выключить авиарежим → закрыть его; дождаться сети.
4. Лист «הניטור הופסק» → прочитать текст → «המשך ניטור».
5. Смотреть «היסטוריית אירועים» ещё ≥ 30 с при статусе «תקין».
6. (Необязательно, как в проверке 01.11) свернуть приложение на 10 с, вернуться; «כבה את המצלמה» → итог.
