## Шаги
1. «בית» → «התחלת ניטור» → открывается «בדיקת בטיחות» (шаг «שלב 1 מתוך 3»); дождаться окончания проверки.
2. Выйти и снова открыть проверку безопасности — всего 3 раза.
3. «עוצמת צפצוף מקסימלית» → окно «בדיקת צליל ההתרעה» → «השמעה» → «שמעתי».
4. «המשך».
5. Сбой удержания экрана: удержание экрана запрещено системой → «בדיקה חוזרת».
   - Только веб: имитация — `navigator.wakeLock.request` всегда отклоняется `NotAllowedError` (подмена до загрузки страницы).
6. Разрешить удержание экрана → нажать строку «…הקישו כאן כדי לנסות שוב.».
## Ожидаемо
- Шаги 1–2: при каждом открытии строки «הטלפון יישאר דלוק» и «לא הצלחנו להשאיר את המסך דלוק» нет; счётчик «2 מתוך 5»; «המשך» блокирует только звук (источник: «מה רצוי» #3bf9dd7f — удержание экрана без нажатия пользователя не считается сбоем).
- Шаг 3: «3 מתוך 5», «המשך» активна.
- Шаг 4: открывается «שלב 2 מתוך 3 · כוונו את המצלמה לבריכה».
- Шаг 5: запрос удержания экрана уходит по нажатию; если он отклонён — появляется строка «הטלפון יישאר דלוק» с текстом «לא הצלחנו להשאיר את המסך דלוק. הקישו כאן כדי לנסות שוב.», счётчик «3 מתוך 6», «המשך» серая (решение 2026-10-08, D-20).
- Шаг 6: нажатие строки повторяет попытку; при успехе строка пропадает, «3 מתוך 5», «המשך» активна.
- Наблюдение (веб, 14.10): если удержание экрана отклонено при нажатии «המשך» (а не «בדיקה חוזרת»), приложение переходит на шаг 2 без строки и без подсказки — тикет это не запрещает, в автотест не включено.
