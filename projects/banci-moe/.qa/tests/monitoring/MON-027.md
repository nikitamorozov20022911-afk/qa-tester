# MON-027: «בדיקת בטיחות» с одним телефоном в аккаунте — предупреждение, 4 מתוך 5, «המשך» активна, мониторинг стартует
- Фича/экран: monitoring — шаг 1 «בדיקת בטיחות» → шаг 2 → шаг 3 «מי בבריכה היום?» → экран мониторинга
- Тикеты: #4a869b (בקשת לקוח: אפשר להתחיל ניטור עם טלפון אחד בלבד)
- Роль/аккаунт: dadayo (аккаунт, под которым залогинено приложение)
- Устройство: нативное приложение iPhone 17 (Eitan build 7 + OTA 02.11); Android не проверялся (заблокирован #f01e3b)
- Тип: позитив
- Предусловия (ручные): второй телефон удалён из аккаунта (в «מכשירים» только этот iPhone); громкость на максимуме; разрешения выданы; камера на освещённую сцену. После теста второй телефон вернуть по QR (DEV-012 шаги 5–7) — иначе тесты с «מכשיר נוסף» падают на предусловии.
## Шаги
1. «בית» → «התחלת ניטור» → «בדיקת בטיחות», дождаться окончания проверок.
2. Посмотреть строку про второй телефон, счётчик, кнопку «המשך».
3. «המשך» → шаг 2 → галочка «כל שטח המים נראה…» → «המשך» → шаг 3 «מי בבריכה היום?» → «התחלת ניטור».
4. На экране мониторинга подождать ~10 с → «כבה את המצלמה».
## Ожидаемо
- Шаг 2: строка «טלפון נוסף מחובר — ההתרעה תגיע רק לטלפון הזה» с ⚠ (предупреждение, не блок), счётчик «4 מתוך 5», «המשך» активна («מה רצוי» #4a869b).
- Шаг 3: переход на шаг 2, затем шаг 3 «מי בבריכה היום?», после «התחלת ניטור» — экран мониторинга.
- Шаг 4: статус «תקין», «זמן ניטור» (таймер) идёт.
