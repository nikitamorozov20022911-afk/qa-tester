# NAV-005: «איך Banci עובדת» — из «חשבון» и с «בית» открывается страница /about во встроенном браузере
- Фича/экран: navigation — «חשבון» (строка в списке) и «בית» (карточка внизу) → веб-страница https://banci.expo.app/about
- Тикеты: #94e4f3 (id 5fa2020ab27702c83494e4f3, «בקשת לקוח: אתר הסבר על המערכת עם מעבר אליו מתוך האפליקציה»)
- Роль/аккаунт: аккаунт, под которым залогинено приложение; страница /about открывается без входа
- Устройство: нативное приложение iPhone (Eitan, TestFlight 0.1.1 build 7); страница /about — также в вебе
- Тип: позитив
- Предусловия: —
## Шаги
1. «חשבון» → найти строку «איך Banci עובדת».
2. Тап по строке.
3. Прокрутить страницу до конца.
4. Закрыть встроенный браузер (кнопка закрытия SFSafariViewController).
5. «בית» → прокрутить вниз до карточки «איך Banci עובדת» → тап → закрыть.
## Ожидаемо
- Шаг 1: строка «איך Banci עובדת» между «התרעות וצפצוף» (выше) и «תנאי שימוש ודיסקליימר» (ниже).
- Шаг 2: открывается https://banci.expo.app/about во встроенном браузере (SFSafariViewController) — Banci на переднем плане, Safari не запускается.
- Шаг 3: на странице «השגחה חכמה על הבריכה», разделы «איך זה עובד», «מתי מגיעה התרעה», «ברגע של חירום», «אחרי הניטור», «פרטיות», «חשוב לדעת»; в «חשוב לדעת» — «לא תחליף להשגחה»; ссылка «לתנאי השימוש המלאים».
- Шаг 4: браузер закрыт, снова «חשבון» со строкой «איך Banci עובדת».
- Шаг 5: карточка «איך Banci עובדת» внизу «בית» открывает ту же страницу; после закрытия — снова «בית».
- Ручное: адрес в строке браузера, внешний вид страницы и RTL, переход по «לתנאי השימוש המלאים».
- Автотесты: `.qa/e2e-app/tests/navigation/about-from-account.test.mjs` (шаги 1–4), `.qa/e2e-app/tests/navigation/about-from-home-card.test.mjs` (шаг 5 + содержимое); веб — план `.qa/e2e/specs/navigation.md` (5.1).
