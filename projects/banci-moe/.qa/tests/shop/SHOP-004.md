# SHOP-004: Приложение — «פנייה לרכישה בוואטסאפ» → WhatsApp с готовым текстом (только приложение)
- Фича/экран: shop — «מוצרים לבריכה» → страница товара (S-21)
- Тикеты: #c48aff34
- Роль/аккаунт: аккаунт, под которым залогинено приложение
- Устройство: нативное приложение iPhone (WhatsApp установлен)
- Тип: позитив
- Предусловия: товар с номером поставщика — «מצופי ידיים לילדים»
## Шаги
1. «חשבון» → «מוצרים לבריכה» → «מצופי ידיים לילדים».
2. «פנייה לרכישה בוואטסאפ».
3. Системное окно iOS «открыть WhatsApp» — в автотесте «Отменить» (ביטול / Cancel).
4. (Вручную) повторить, в окне «Открыть» → чат WhatsApp с поставщиком; сообщение НЕ отправлять, черновик удалить.
## Ожидаемо
- Кнопка активна; появляется системное окно про WhatsApp; после отмены остаёмся на странице товара.
- Шаг 4: чат с номером поставщика и текстом «שלום, אשמח לפרטים על המוצר: <שם המוצר>. ראיתי אותו באפליקציית Banci.» (источник: «מה רצוי» #c48aff34, AC 2–3).
- AC4 (тост «וואטסאפ לא מותקן בטלפון הזה», если WhatsApp не установлен) — не проверяем (решение пользователя 2026-10-18).
