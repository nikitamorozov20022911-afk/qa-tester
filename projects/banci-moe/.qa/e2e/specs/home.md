### 2. Главная — «ניטורים אחרונים» совпадает с «היסטוריה»
**Seed:** `tests/seed.user.spec.ts`

#### 2.1 «ניטורים אחרונים» на בית: три строки = три первые записи «היסטוריה» (текст и иконка), без «בלי התרעות» у сбоя #09b2de78 @iphone @prod-safe
**Device:** iphone
**Users:** user (сессия `.qa/auth/user.json`; у аккаунта ≥3 сеансов, среди них есть со сбоем, с тревогами и без событий — их создают тесты `@data`)
**Steps:**
1. Открыть `/home`, дождаться блока «ניטורים אחרונים» и ровно 3 строк сеансов в нём (+ ссылка «הכל»).
2. Для каждой из 3 строк записать текст строки (день и время, длительность, события) и признак иконки (src/aria-label/testID изображения слева от текста).
3. Сразу открыть `/history` (таб «היסטוריה»), дождаться первых 3 записей; записать для них время, длительность, события и признак иконки.
4. Вернуться на `/home`, нажать «הכל».
**Expected:** (источник: «מה רצוי» #09b2de78; реджект Р2; F-34/S-19 AC6; Figma 06.1 node 220-5765)
- Порядок и время старта 3 строк на `/home` = первые 3 записи `/history` (новые первыми).
- Для каждой пары: подпись событий одинаковая («כשל אחד» / «X כשלים», «התרעה אחת» / «X התרעות», «בלי אירועים») и признак иконки одинаковый.
- Текст «בלי התרעות» в блоке «ניטורים אחרונים» не встречается (count = 0).
- Строка со сбоем (если есть в топ-3) содержит «כשל»/«כשלים» и не содержит часов-иконки «без событий» (признак иконки ≠ иконке строки «בלי אירועים»).
- Формат строки: день + время по шаблону `/(היום|אתמול|[א-ת]+.*), \d{1,2}:\d{2}/`, затем `· <длит.> · <события>`.
- «הכל» → URL `/history`.
- Примечание: если между шагами 1 и 3 параллельный тест создал сеанс, порядок сдвинется на одну строку — сравнивать по времени старта, допускается сдвиг ровно на одну новую запись сверху.
