# План автотестов: emergency

Источник: `.qa/tests/emergency/EMG-001.md`, `EMG-002.md` (тикет #e824b3d3); группа 2 — `EMG-003.md`, `EMG-004.md` (тикет #1273694f).
Подготовка мониторинга (общая для тестов с `?mock`): на шаге звука нажать «עוצמת צפצוף מקסימלית» → «השמעה» → «שמעתי» → «המשך»; на шаге камеры «המשך»; на шаге «מי בבריכה היום?» «בחירת כולם» → «התחלת ניטור». Мок задаётся ТОЛЬКО параметром `?mock=<сценарий>` в первом URL вкладки (хранится в sessionStorage `banci.mock`). Камера — фейковое устройство из конфигурации Playwright. Звук на слух не проверяется.
ЗАПРЕЩЕНО в тестах: подтверждать звонок (кнопка подтверждения в окне «לחייג למד״א 101?») и нажимать кнопку 101 внутри тем первой помощи — только проверка видимости. Для страховки перехватывать навигацию на `tel:` и проверять, что её не было. Исключение — группа 2 (#1273694f): там «חיוג ל-101» нажимается, но только при установленном шпионе `tel:`, который не даёт открыть звонилку.

### 2. Звонок 101 с экрана «עזרה דחופה»
**Seed:** `tests/seed.user.spec.ts`

Источник: `.qa/tests/emergency/EMG-003.md`, `EMG-004.md` (тикет #1273694f, веб-часть прошла QA 2026-10-08; системный звонок — натив).
Настоящий звонок НЕ вызывать. До загрузки страницы (`page.addInitScript`) поставить шпион, который записывает попытку открыть `tel:` в `window.__telCalls` и НЕ даёт ей уйти: обёртка `window.open` (возвращает `null` без открытия для `tel:`), перехват `click` по `<a href^="tel:">` (`preventDefault`). Если приложение уходит на `tel:` через `location` (react-native-web `Linking.openURL` так делает для `tel:`), дополнительно слушать `page.on('framenavigated')`/`page.on('request')` и проверить URL; генератор сначала выясняет фактический механизм на живой странице.

**Device:** iphone

**Steps:**

2. Нажать «חיוג למד״א 101».

- Текст «לא ניתן לחייג מהמכשיר הזה» не появляется (count = 0); нативного диалога (`page.on('dialog')`) нет.

#### 2.2 Сбой открытия tel: → «לא ניתן לחייג מהמכשיר הזה» / «חייגו 101 מטלפון אחר.» #1273694f @iphone @prod-safe
**Device:** iphone
**Users:** user
**Steps:**

- После закрытия сообщение исчезло, страница `/emergency` на месте.
- ВАЖНО: если без изменения кода сайта сбой открытия `tel:` вызвать нельзя (например, приложение уходит через `location`, которое не бросает исключение) — тест не писать и вернуть основной сессии «не автоматизируется», ожидание не подгонять. Пункт остаётся ручным (в QA подтверждён по коду сборки).
