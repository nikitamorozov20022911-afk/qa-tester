### 4. Выход из аккаунта
**Seed:** `tests/seed.user.spec.ts`

#### 4.1 Выход с подтверждением = Figma 12.6: «ביטול» оставляет в аккаунте, «יציאה» → /welcome, назад/reload не возвращают #fb3b8d53 @iphone @data
**Device:** iphone
**Users:** user
**Steps:**
1. ОБЯЗАТЕЛЬНЫЙ ПРЕДОХРАНИТЕЛЬ: до любых действий `page.route('**/auth/v1/logout**', r => r.fulfill({ status: 204 }))` и счётчик таких запросов. Без него тест не писать — настоящий запрос выхода отзовёт общую сессию `user.json` и сломает все остальные тесты.

3. Проверить окно; нажать «ביטול».

**Expected:** (источник: Figma 264:6594 «12.6 Log out confirmation»; реджект 07.10 «выходит сразу»)
- Окно: заголовок «לצאת מהחשבון?», «אפשר להתחבר שוב בכל רגע.», 2 строки последствий, кнопки «יציאה» и «ביטול».
- После «ביטול» окно закрыто, URL `/account`, вкладка «חשבון» активна.
- После «יציאה» URL `/welcome`; счётчик перехваченных запросов выхода ≥ 1 или токен `sb-…-auth-token` удалён из localStorage.
- После «назад» и после reload URL остаётся `/welcome` (или `/sign-in`), экран аккаунта не открывается.
