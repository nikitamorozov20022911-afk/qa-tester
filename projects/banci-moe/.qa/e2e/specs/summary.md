# План автотестов: summary

Источник: `.qa/tests/summary/SUM-001.md`…`SUM-004.md` (тикет #25e8f258, веб-часть прошла QA 2026-10-08; натив — клипы событий — ждёт приложения).
Подготовка мониторинга — помощник `tests/helpers/monitor.ts`: `startMonitoring(page, '<mock>')` (звук «עוצמת צפצוף מקסימלית» → «השמעה» → «שמעתי» → «המשך»; камера «המשך»; «בחירת כולם» → «התחלת ניטור»), `slide(page, '<подпись слайдера>')`, `endMonitoring(page)`. Мок задаётся ТОЛЬКО параметром `?mock=<сценарий>` в первом URL вкладки (sessionStorage `banci.mock`).
Каждый тест создаёт сеанс мониторинга в истории аккаунта (удалить нельзя) → пометка `@data`, тесты идут по одному; мониторинг в конце обязательно завершается. Не `@prod-safe`.
Предусловие аккаунта: ровно 2 ребёнка — «QA בדיקה», «QA קטן».
Без фиксированных пауз: ожидание тревог/сбоев — `expect(...).toBeVisible({ timeout })`.

### 1. Сводка мониторинга
**Seed:** `tests/seed.user.spec.ts`

#### 1.1 Сводка без событий: длительность, дети справа RTL, «בלי אירועים», «חזרה לבית» #25e8f258 @iphone @data
**Device:** iphone
**Users:** user
**Steps:**
1. `startMonitoring(page, 'calm')` — дождаться `/monitor/live`.
2. `slide(page, 'כבה את המצלמה')` (полный свайп) — дождаться `waitForURL(/\/monitor\/summary/)`.
3. Проверить заголовок, интервал времени, строку детей и блок «מה קרה».
4. Нажать «חזרה לבית».
**Expected:** (источник: AC1–4 F-33 / S-18, Figma 11.2, SUM-001, SUM-002)
- После свайпа URL `/monitor/summary`.
- Виден текст длительности по шаблону `/\d+ דק׳/` и интервал `/\d{1,2}:\d{2}\s*[–-]\s*\d{1,2}:\d{2}/`.
- Виден текст «QA בדיקה ו-QA קטן היו בבריכה»; у его элемента computed `direction` = `rtl`; правый край строки ближе к правому краю экрана, чем левый к левому (выравнивание справа, рядом с аватарами).
- Видны «בלי אירועים» и «בלי התרעות»; в ленте «התחלת ניטור» и «הניטור הסתיים».
- Видны кнопки «לכל הניטורים» и «חזרה לבית»; «חזרה לבית» → `waitForURL(/\/home/)`.

#### 1.2 Сводка после двух тревог: «2 התרעות במהלך הניטור» #25e8f258 @iphone @data
**Device:** iphone
**Users:** user
**Steps:**
1. `startMonitoring(page, 'headUnder')`.
2. Дождаться слайдера «זו אזעקת שווא» (timeout до 30 с) → `slide(page, 'זו אזעקת שווא')` → дождаться, что слайдер исчез.
3. Дождаться второй тревоги (снова «זו אזעקת שווא», timeout до 60 с) → `slide(page, 'זו אזעקת שווא')` → дождаться исчезновения.
4. `slide(page, 'כבה את המצלמה')` → `waitForURL(/\/monitor\/summary/)`.
**Expected:** (источник: AC4 F-33 «מספר ההתראות», Figma 11.1, комментарий программиста 4.10)
- Виден текст «2 התרעות במהלך הניטור».
- В ленте «מה קרה» встречается «סומן כאזעקת שווא» (count ≥ 1).
- Видны «לכל הניטורים» и «חזרה לבית».

#### 1.3 Сводка со сбоем «המכשיר זז» и новая запись сверху в истории #25e8f258 @iphone @data
**Device:** iphone
**Users:** user
**Steps:**
1. `startMonitoring(page, 'moved')`.
2. Дождаться сообщения сбоя «המכשיר זז» (timeout до 30 с).
3. `endMonitoring(page)` (на экране сбоя — «סיום ניטור») → `waitForURL(/\/monitor\/summary/)`.
4. Запомнить время начала из интервала `HH:MM–HH:MM` на сводке.
5. Нажать «לכל הניטורים».
**Expected:** (источник: AC5–6 F-33, S-18 AC4/AC7, SUM-004)
- На сводке видны «תקלה אחת בניטור» и «כשל בניטור: המכשיר זז».
- После «לכל הניטורים» открыт экран истории; первая (верхняя) запись содержит запомненное время начала.
