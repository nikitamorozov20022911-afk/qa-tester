# План автотестов: monitoring (наведение камеры, S-11)

Источник: `.qa/tests/monitoring/MON-001.md`, `MON-004.md`, `MON-005.md` (тикет #7076cfab, веб-часть прошла QA 2026-10-08; живая камера/автоопределение воды/свет/акселерометр — натив).
Подготовка (общая): `page.goto('/home?mock=<сценарий>')` → «התחלת ניטור» → «עוצמת צפצוף מקסימלית» → «השמעה» → «שמעתי» → «המשך» → `waitForURL(/\/monitor\/camera/)`. Мок — ТОЛЬКО в первом URL вкладки (sessionStorage `banci.mock`); для следующего мока — новая вкладка (`context.newPage()`), не переход в той же.
Тесты останавливаются до «התחלת ניטור» на шаге детей → сеанс мониторинга не создаётся → без `@data`, `@prod-safe`.
Проверки «המשך» неактивна: `toHaveAttribute('aria-disabled', 'true')` и после клика URL всё ещё `/monitor/camera`.
Точные тексты подсказок blocked/unclear в QA записаны по Figma 07.4c/d — генератор фиксирует фактический текст со страницы; если он не соответствует смыслу кейса — остановиться и сообщить, не подгонять.
