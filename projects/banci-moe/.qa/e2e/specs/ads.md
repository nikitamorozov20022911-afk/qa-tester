# План автотестов: ads

Источник: `.qa/tests/ads/ADS-001.md`, `ADS-002.md` (тикеты #840d8543, #a5b844f5).
Подготовка мониторинга (общая для тестов с `?mock`): на шаге звука нажать «עוצמת צפצוף מקסימלית» → «השמעה» → «שמעתי» → «המשך»; на шаге камеры «המשך»; на шаге «מי בבריכה היום?» «בחירת כולם» → «התחלת ניטור». Мок задаётся ТОЛЬКО параметром `?mock=<сценарий>` в первом URL вкладки (хранится в sessionStorage `banci.mock`). Камера — фейковое устройство из конфигурации Playwright. Звук на слух не проверяется.
Тесты с мониторингом создают сеансы в истории аккаунта → пометка `@data`, в конце мониторинг обязательно завершается.

### 1. Реклама — где показывается и где нет
**Seed:** `tests/seed.user.spec.ts`

#### 1.1 Баннер «פרסומת» на шагах подготовки и в сводке, клик ведёт в /products #840d8543 #a5b844f5 @iphone @data
**Device:** iphone
**Users:** user
**Steps:**
1. Открыть `/home?mock=calm`.
2. Нажать «התחלת ניטור» → шаг 1 (звук): проверить баннер; пройти «עוצמת צפצוף מקסימלית» → «השמעה» → «שמעתי» → «המשך».
3. Шаг 2 (камера): проверить баннер; «המשך».
4. Шаг 3 «מי בבריכה היום?»: проверить баннер и его положение; «בחירת כולם» → «התחלת ניטור».
5. Дождаться экрана мониторинга; завершить мониторинг («כבה את המצלמה») и дождаться экрана сводки.
6. На сводке проверить баннер и нажать на него.
**Expected:** (источник: «מה רצוי» #840d8543 / AC #a5b844f5)
- На шагах 1, 2, 3 и в сводке виден баннер с меткой «פרסומת».
- На шаге 3 баннер ниже списка детей и ниже «ילד חדש» (`banner.y >= ילד_חדש.y + ילד_חדש.height`); кнопка «התחלת ניטור» не перекрыта баннером (боксы не пересекаются, кнопка кликабельна).
- Клик по баннеру ведёт на URL `/products` (`waitForURL(/\/products/)`).
