### 2. История — загрузка и догрузка
**Seed:** `tests/seed.user.spec.ts`

#### 2.1 История: при медленной загрузке — индикатор, не пусто и не ошибка; «ניטורים קודמים» догружает следующие записи #78e3149c @iphone @prod-safe
**Device:** iphone
**Users:** user (в истории > 20 сеансов)
**Steps:**
1. До перехода включить `page.route` на запрос списка истории (генератор определяет URL по сетевым запросам при открытии `/history`; первый запрос страницы): ответ удерживается до сигнала (promise), без `waitForTimeout`.
2. Открыть `/history`.
3. Проверить состояние экрана, пока ответ удержан; затем отпустить ответ (`route.continue()`).
4. Дождаться записей; посчитать число записей N1.
5. Перехватить следующий запрос страницы истории тем же способом (удержание); прокрутить до конца списка и нажать / дождаться «ניטורים קודמים».
6. Проверить состояние, пока ответ удержан; отпустить; дождаться новых записей; посчитать N2.
**Expected:** (источник: S-19 AC1; комментарий программиста 04.10)
- Пока первый ответ удержан: виден индикатор загрузки (progressbar / спиннер); тексты «עוד אין ניטורים» и «משהו השתבש» не видны (count = 0).
- После ответа видны записи, N1 ≥ 20.
- Пока ответ догрузки удержан — виден индикатор загрузки у «ניטורים קודמים».
- После ответа N2 > N1 и N2 − N1 ≤ 20.

#### 2.2 История: в заголовке каждого дня сразу полное число ניטורים, после «ניטורים קודמים» не меняется, после полной загрузки = числу записей дня #89b3e786 @iphone @prod-safe
**Файл:** `tests/history/day-header-count-full-day.spec.ts` (записан вручную — официальный генератор сломан)
**Device:** iphone
**Users:** user (> 20 сеансов; есть день, чьи записи не помещаются на первую страницу)
**Steps:**
1. Открыть `/history`, дождаться записей.
2. Для каждого заголовка дня («היום» / «אתמול» / дата) прочитать число рядом («ניטור אחד» = 1, «N ניטורים» = N) и число записей в секции этого дня; запомнить числа.
3. Пока есть «ניטורים קודמים»: нажать, дождаться новых записей и конца загрузки; снова прочитать заголовки.
4. Когда кнопки больше нет — прочитать заголовки и записи последний раз.
**Expected:** (источник: реджект 14.10 needed_behavior «בכותרת של כל יום מוצג מיד, כבר בטעינה הראשונה, מספר כל הניטורים של אותו יום… המספר לא משתנה אחרי «ניטורים קודמים»»; S-19 AC3)
- У каждого заголовка есть число; число ≥ показанных записей дня (у последнего дня страницы — полное, не загруженное).
- После каждой догрузки число у уже показанных дней не изменилось.
- После полной загрузки у каждого дня число = числу записей под заголовком; заголовки дней не повторяются; все записи стоят под заголовками.
- Даты и числа не зашиты (данные растут) — всё считается со страницы. Только просмотр.
