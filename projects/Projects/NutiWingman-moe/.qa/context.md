## Технические заметки
- Вход: сайт сразу выдаёт АНОНИМНУЮ сессию Supabase (гость видит чат /home). Сохранять вход только скриптом `cd .qa/e2e && ../bin/with-node22 node login-supabase.mjs <id>` (ждёт sb-*-auth-token с email и is_anonymous=false; окно 480x760). manual-login.mjs здесь вход не замечает.
- (2026-11-11) Playwright Chromium 1254 на этой машине не запускается («side-by-side configuration is incorrect»), к тому же песочница Claude Code блокирует запуск браузера (spawn UNKNOWN). Браузер — через установленный Google Chrome (`channel: 'chrome'`, в playwright-cli `--browser chrome`), запуск вне песочницы. login-supabase.mjs переключается на Chrome сам.
- API под тестовым пользователем: `node .qa/e2e/api.mjs <id|anon> <METHOD> <path> [body]` (только access_token, ~1 ч). Ключ publishable — .qa/auth/.sbkey. Схема REST закрыта (нужен secret key) — имена RPC/таблиц брать из бандла .qa/research/bundle/*.js.
- НЕ подменять часы (page.clock) на основной сессии аккаунта: приложение тратит refresh token Supabase и вход сгорает («Already Used»). Для тестов «завтра» — отдельный одноразовый вход или только чтение до истечения access token.
- Доска mifrat: MCP 401 → браузер; Playwright-сессия mifrat — .qa/auth/mifrat.json (вход через Google, `node .qa/e2e/mifrat-login.mjs <board-url>`).
