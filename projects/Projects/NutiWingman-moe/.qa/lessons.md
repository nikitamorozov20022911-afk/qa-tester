## L-20261111-1 · Figma онбординга — где искать кадры
- Правило: дизайн смотреть в Figma на странице «Design — Mobile»; для онбординга — секции «06 Onboarding DS v2 light» и «06 Onboarding v3» (сверять с обеими, при расхождении между ними — спросить, какая эталон).
- Почему: пользователь указал, где актуальный дизайн; агенты искали кадры по названиям и могли взять не те секции.
- Источник: сообщение пользователя, 2026-11-11
- Область: проект
- Статус: действует

## L-20261111-2 · Скриншоты в каждом реджекте, в том числе для API-тикетов
- Правило: к каждому реджекту прикладывать скриншоты. Для тикетов без экрана — снимок запроса и ответа API (рендер JSON в браузере / странице с подписью «запрос → ответ», красная обводка на ключевом поле), для логики по коду — снимок фрагмента кода с обводкой. Реджект без вложений не отправлять.
- Почему: пользователь спросил «почему ты скрины не делаешь в тикетах?» — 19 реджектов ушли без вложений, программисту нечем подтвердить дефект.
- Источник: сообщение пользователя, 2026-11-11
- Область: проект (вероятно, общий)
- Статус: действует
