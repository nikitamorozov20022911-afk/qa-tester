## Аккаунты
Учётки лежат в `.qa/accounts.env` (в git не попадает). Значения в чат и отчёты не копировать.

| Роль | Переменные | Роль в системе |
|---|---|---|
| Будущий админ компании | `ADMIN_*` | מנהל חשבון — приглашает пользователей, управляет орг-аккаунтом |
| Будущий пользователь | `USER_*` | משתמש רגיל — работа с тендерами без админ-действий |

**Статус (2026-10-25):** оба аккаунта ещё НЕ зарегистрированы — намеренно. Регистрация, создание компании и Onboarding-визард тестируются как часть QA. Порядок: 1) ADMIN регистрируется и проходит онбординг → 2) ADMIN приглашает USER → 3) USER принимает приглашение. Скрипт входа / сохранённые сессии (`.qa/auth/`) делаем только после шага 3; до этого не регистрировать аккаунты «для подготовки».

Отдельно в продукте есть: внешний исполнитель (עו"ד / רו"ח / מורשה חתימה) — только по защищённой ссылке, без аккаунта; и внутренний Admin системы (команда эксплуатации) — учётки пока нет.
