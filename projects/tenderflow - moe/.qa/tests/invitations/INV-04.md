# INV-04: Ссылка с испорченным токеном — то же сообщение, без формы
- Фича/экран: invitations — /accept?token=…
- Тикеты: #af0ff2
- Роль/аккаунт: guest (без входа)
- Устройство: desktop 1440×900
- Тип: негатив (граница)
- Предусловия: нет. Приглашения не создаются.
- Автотест: `.qa/e2e/tests/invitations/cancelled-invite-link.spec.ts`
## Шаги
1. Открыть ссылку приглашения с несуществующим токеном (64 случайных hex-символа) и правдоподобными параметрами: `/accept?token=<random>&email=qa-<run>%40example.com&name=QA&company=QA+Company+B&inviter=`.
2. Открыть `/accept?token=abc` (короткий мусор).
## Ожидаемо
- В обоих случаях: «ההזמנה אינה תקפה» + «ההזמנה בוטלה או שאינה תקפה עוד. פנו למנהל החשבון.», кнопка «חזרה לכניסה»; полей «סיסמה חדשה» и кнопки «קבע סיסמה והיכנס» нет; запроса `auth/v1/signup` нет (источник: «מה רצוי» #af0ff2 — недействительная ссылка не ведёт к форме; Julius: «expired/invalid → понятное сообщение»).
- Параметры email/company из адреса не превращают недействительный токен в форму.
