# INV-08: Отменённый или случайный token + подменённые параметры — «ההזמנה אינה תקפה»
- Фича/экран: invitations — /accept?token=…
- Тикеты: #83bf5b (продолжение INV-01, INV-04 — #af0ff2)
- Роль/аккаунт: ADMIN2 (компания B) приглашает и отменяет; гость без входа
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: для отменённого — свежее приглашение `qa-auto-inv-<run>@example.com`, отмена через окно «ביטול ההזמנה» (`@data`). Случайный token — данных не создаёт (`@prod-safe`).
- Автотест: `.qa/e2e/tests/invitations/accept-from-server.spec.ts`
## Шаги
1. ADMIN2 приглашает → ссылка L → «ביטול הזמנה» → «ביטול ההזמנה».
2. Гость открывает L + подменённые email/name/company/inviter (как INV-06).
3. Гость открывает `/accept?token=<64 случайных hex>` + те же подменённые параметры.
## Ожидаемо
- В обоих случаях: «ההזמנה אינה תקפה», «ההזמנה בוטלה או שאינה תקפה עוד. פנו למנהל החשבון.», «חזרה לכניסה»; формы пароля нет; подменённые значения не показаны; запроса `auth/v1/signup` нет (источник: «מה רצוי» #83bf5b; «מה רצוי» #af0ff2).
