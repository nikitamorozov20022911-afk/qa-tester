1. «עריכה» у участника → изменить телефон/תפקיד → сохранить → перезагрузить `/users`.
2. Пустое имя → сохранить.
3. «הרשאה עבור <участник>» → «מנהל חשבון» → перезагрузить; войти этим участником — меню «חשבון» содержит «משתמשי החברה».
4. Вернуть «משתמש רגיל» → перезагрузить; доступ к `/users` снова закрыт.
5. Вернуть исходные данные участника.
