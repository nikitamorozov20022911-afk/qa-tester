# PI-09: Компания B не может изменить компанию A на сервере
- Фича/экран: permissions-isolation — Supabase REST companies
- Тикеты: #55dc54
- Роль/аккаунт: ADMIN2 (`ADMIN2_EMAIL`), מנהל חשבון компании B «QA Company B»; сессия `.qa/auth/admin2.json`; ADMIN (`ADMIN_EMAIL`), מנהל חשבון компании A; сессия `.qa/auth/admin.json`
- Устройство: desktop 1440×900
- Тип: негатив (безопасность)
- Предусловия: id компании A — из company_members сессии ADMIN.
- Автотест: `.qa/e2e/tests/permissions-isolation/server-rls.spec.ts`
## Шаги
1. ADMIN: прочитать name компании A.
2. ADMIN2: GET companies?id=eq.<A>.
3. ADMIN2: PATCH companies?id=eq.<A> {name: то же значение}.
4. ADMIN: перечитать name.
## Ожидаемо
- GET → `[]`; PATCH → 200 и `[]` (0 строк); имя A не изменилось (AC3; F-03 д4).
- Пишется то же значение — данные не меняются даже при дыре.
