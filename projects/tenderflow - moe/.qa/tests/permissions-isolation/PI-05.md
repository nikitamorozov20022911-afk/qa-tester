- Тикеты: #1ccd9e
- Роль/аккаунт: USER (`USER_EMAIL`), משתמש רגיל компании A «QA Test בע"מ»; сессия `.qa/auth/user.json`
- Устройство: desktop 1440×900
- Тип: негатив (безопасность)
- Предусловия: Вход под USER; токен из sb-*-auth-token, anon key из бандла.
- Автотест: `.qa/e2e/tests/permissions-isolation/server-rls.spec.ts`
## Шаги
1. Прочитать свою строку company_members (role=member).
2. PATCH company_members?user_id=eq.<свой id> {role:'admin'} с return=representation.
3. Перечитать роль.

- Ответ 200 и `[]` (0 изменённых строк); роль осталась member (AC3 «נחסם גם בשרת»; F-02 д3).
