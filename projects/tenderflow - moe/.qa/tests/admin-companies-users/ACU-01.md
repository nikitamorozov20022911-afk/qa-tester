# ACU-01: Список компаний и пользователей: колонки, число строк = числу в заголовке, «חסימה» и статус в каждой строке

- Роль/аккаунт: platform admin (`auth/platform.json`, qa-tester-platform; один вход — не параллелить)

- Автотест: `.qa/e2e/tests/admin-companies-users/admin-readonly.spec.ts`
## Шаги
1. Открыть /admin. 2. Прочитать заголовки «חברות (N)», «משתמשים (M)», колонки таблиц. 3. Посчитать строки и кнопки «חסימה»/«ביטול חסימה», бейджи статуса.
## Ожидаемо
- «ניהול חברות ומשתמשים» (h1), подзаголовок «מסך תפעולי לצוות המערכת.», поиск «חיפוש חברה או משתמש…», «יצירת חברה חדשה» (דרישות 1, 2).
- Компании: «שם החברה», «משתמשים», «סטטוס»; пользователи: «שם», «אימייל», «חברה», «הרשאה», «סטטוס».
- Строк столько же, сколько в заголовке (N и M ≥ 1; числа не зашиты — растут).
- В КАЖДОЙ строке компании и пользователя есть «חסימה» (או «ביטול חסימה»), у каждой — бейдж «פעילה/חסומה», «פעיל/חסום» (דרישות 6, 7, 9).
