- Предусловия: своё приглашение `QA-AUTO Confirm` / `qa-auto-confirm-…@example.com` (создаётся в тесте, в конце все такие приглашения отменяются).

## Шаги
1. `/users` → «ביטול הזמנה» в строке своего приглашения.
2. «חזרה». Снова «ביטול הזמנה» → Escape. Снова → клик вне окна.
3. Снова «ביטול הזמנה» → «ביטול ההזמנה».
## Ожидаемо
- Окно «ביטול הזמנה»: текст «לבטל את ההזמנה של QA-AUTO Confirm? קישור ההצטרפות שנשלח יפסיק לעבוד.», кнопки «חזרה» и «ביטול ההזמנה»; фокус на «חזרה» (комм. программиста 12.11; заголовок тикета).
- «חזרה» / Escape / клик вне окна: окно закрыто, строка «הזמנה ממתינה» на месте (и после F5), запросов записи на сервер нет.
- «ביטול ההזמנה»: строка исчезает и не возвращается после F5 (L-20261025-6).
