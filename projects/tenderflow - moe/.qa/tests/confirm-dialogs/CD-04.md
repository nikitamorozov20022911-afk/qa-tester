## Шаги
1. `/users` → «הרשאה עבור QA Inv14 Member» → «מנהל חשבון».
2. «חזרה». Снова выбрать «מנהל חשבון» → Escape.
3. Снова выбрать → «שינוי הרשאה» → F5.
4. Вернуть «משתמש רגיל» → «שינוי הרשאה» → F5.
