# План автотестов: «תרגול קריאה» — сбои завершения, пауза, «לא מצאתי», длинный текст (#be8521); сообщение о микрофоне в вебе (#0f3aa5)

Источник: брифы `.qa/research/be8521.md`, `.qa/research/0f3aa5.md` (ретест 17.11), тикеты прошли QA 17.11 (пользователь `עבר QA`). Веб 1194 прошёл: role=alert 3/3, «נסה שוב» один запрос 3/3, пауза без «מקשיבה…»/спиннера 6/6, «לא מצאתי» только «חזרה הביתה» 3/3, 50 слов — кнопка видна (`session.json`). Не проверено руками: фокус на «נסה שוב», Figma D5 — в план не входит.
Роль — слот `parent-auto` (QA-R2-V, режим ребёнка, постоянно; `CHILD_SLOTS['QA-R2-V']`, `goChildHome`, `saveSlot` в `afterEach` из `tests/child-slot.helpers.ts`). Основной `parent` в режим ребёнка не переводится (решение 08.11). Тесты чтения создают попытки у QA-R2-V → `@data` (проект `data`, одно окно; ширина — `page.setViewportSize`). Новых детей `QA-AUTO-…` тесты не создают (решение 08.11 про передачу устройства новому ребёнку остаётся в силе).
**Голос и распознавание.** Реального микрофона в headless нет. Мок задаётся `page.addInitScript` до загрузки: `navigator.mediaDevices.getUserMedia` → разрешён (фейковый поток), `window.SpeechRecognition`/`webkitSpeechRecognition` — класс-заглушка, который на `start()` отдаёт `onresult` словами отрывка по порядку (слова берутся из карточки), а `stop()` вызывает `onend`; в headless he-IL слов не возвращает (как в #2ae0c8/#f0ebdd). Сетевые сбои — `page.route` (fulfill 500 один раз, затем `route.continue()`). Переход на экран чтения — кликами («תרגול קריאה» → карточка отрывка), без reload на экране чтения.
Без `waitForTimeout`/`networkidle`: только `expect(...)`, `waitForResponse`, счётчик запросов в `route`.
Данные и чистка: каждый прогон оставляет попытки чтения у QA-R2-V (постоянный ребёнок, не удалять); в `testInfo.annotations` (`type: 'cleanup'`) — id попыток из ответов `complete_reading_attempt`.
**Кто пишет:** группа 1 и 2 — `autotest-writer` (запасной путь/`page.route`, мок распознавания, подсчёт запросов — официальный генератор не умеет); при необходимости 2.1 — генератор.
