**⚠ Режим ребёнка и слоты входа (с 08.11, #8ca267).** Режим ребёнка теперь хранится на сервере по session_id входа. После «<имя>, בואו נתחיל!» сессия из файла `.qa/auth/<slot>.json` остаётся в режиме ребёнка, пока не введены пароль или PIN (автотест их не вводит). Вход Supabase одноразовый — новую сессию даёт только `npm run qa-login:manual -- <slot>`.
- Приём «очистка = удалить `benjico\child-context`» **больше НЕ выводит из режима ребёнка** (сервер вернёт в дом ребёнка + гейт) и **не используется** как очистка/выход ни в одном плане. В разделе 4 удаление ключа — это сама проверка (обход не должен работать), а не выход.
- **Решение пользователя 08.11:** тесты, входящие в режим ребёнка, работают только на отдельных слотах, постоянно в режиме ребёнка — **один слот на одного ребёнка**: `parent-auto` (аккаунт parent, QA-R2-V), `parent-r21-auto` (аккаунт parent, QA-R2-1). Слоты выдаёт пользователь вручную: `npm run qa-login:manual -- <slot>`. Слота семьи с PIN (`parent-b-auto`, QA-B1) **не будет**. `parent.json`, `parent-b.json`, `parent-3.json` в режим ребёнка **не переводятся никогда**.
- Вход в дом ребёнка на слоте — `goChildHome` (`tests/child-slot.helpers.ts`): слот ещё не в режиме ребёнка → передача «<имя>, בואו נתחיל!» (→ «אחר כך»); уже в режиме → сервер ведёт в дом ребёнка + гейт → закрыть «ביטול» (без PIN) / «חזרה לתרגול» (PIN), ничего не вводя. В конце теста — `saveSlot` (refresh-токен Supabase одноразовый). Тесты одного слота — `@data` или serial. Слот в режиме **другого** ребёнка или вышедший из сессии — `goChildHome` падает с подсказкой «выдать заново».
- Тесты, создающие нового ребёнка QA-AUTO и передающие ему устройство, — пропущены (`test.skip`, «пропущено по решению 08.11»). Тесты режима ребёнка семьи с PIN (QA-B1) — пропущены: «нет слота parent-b-auto — пропущено по решению 08.11».
- Раздел 4 ниже — слот `parent-auto`. Раздел 5 (семья с PIN) — пропущен, слота нет.
- Выход из режима ребёнка по верному паролю/PIN — **не автоматизируется** (CH-17, CH-18). Неверный пароль/PIN в тестах **не вводить** (лимит 3 ошибки → минута блокирует общий аккаунт).

**Жёсткие ограничения.** PIN не вводится (цифры клавиатуры не нажимать), пароль не вводится, из аккаунта не выходим. Флажок «בפעם הבאה לעבור ישר…» на B1 не трогать (предпочтение семьи).
**Очистка режима ребёнка:** не делается (с 08.11 невозможна без пароля/PIN). Слот остаётся в режиме ребёнка — так задумано; в конце теста `saveSlot`.
**Новый ребёнок** (1.4): имя `QA-AUTO-<6 случайных латинских букв>` (без цифр). Удаление профиля требует пароль родителя → чистка ручная: имя и id в `testInfo.annotations` (`type: 'cleanup'`, «child QA-AUTO-… <id> — удалить вручную (нужен пароль)»).
**Expo-роутер:** скрытые экраны в DOM — локаторы только по видимым элементам. Без `waitForTimeout`/`networkidle`.
Пометки: передача открывает детскую сессию на сервере → без `@prod-safe`; только просмотр (1.1, 2.3) → `@prod-safe`; создание ребёнка (1.4) → `@data`.
