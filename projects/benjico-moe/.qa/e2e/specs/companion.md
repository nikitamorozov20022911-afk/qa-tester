# План автотестов: «חבר מלווה» — ארנבת и Бенджи на экранах ребёнка (#aed9e0, тексты — #b3210e)

Источник: `.qa/tests/companion.md` (CP-01…CP-08), бриф `.qa/research/aed9e0.md`, скрины раунда 3 `.qa/screenshots/aed9e0-*`. Пользователь провёл `עבר QA` 05.11 (staging https://benjico.expo.app).
«מה רצוי»: «ההורה בוחר «הארנבת» ← בכל המסכים שבהם מופיעה הדמות המלווה (מסירה, בית הילד, תרגול קריאה וכתיבה, מבחן פתיחה) מוצגת הארנבת, עם הקול שלה; ילד שבחר בנג׳י — רואה ושומע את בנג׳י. בכל המסכים — אותה דמות כמו בבחירה». Подзаголовок A6: «אפשר להחליף בכל זמן בהגדרות». Комментарий программиста 05.11: спутник по `children.companion` также на «המסלול שלי» и «התכנית שלי»; картинка ארנבת на «מי ילווה» 1,28 MB → ~400 KB.
**Как узнать фигуру:** `img` с `alt="הארנבת"` (rabbit) / `alt="בנג'י"` (benji) — только видимые (`.filter({ visible: true })`, Expo-роутер держит скрытые экраны в DOM). На «מי ילווה» у картинки ארנבת `alt` пустой (находка R3) — искать картинку внутри карточки «הארנבת» по `src`, содержащему `rabbit` (сверить при записи). В режиме ребёнка `POST rpc/child_profile` → `companion: "rabbit" | "benji"`. Голос: `POST <supabase>/functions/v1/tts`, тело `voice`, ответ `url` `/tts/<voice>/<hex>.mp3` (план `benji-voice.md`).
**Роль:** экраны ребёнка — слот этого ребёнка (QA-R2-V → `parent-auto`, QA-R2-1 → `parent-r21-auto`), `goChildHome`; действия родителя (выбор спутника, создание детей) — `parent.json` без режима ребёнка.
**⚠ Режим ребёнка — только на слотах (решение пользователя 08.11, #8ca267).** Режим ребёнка хранится на сервере по сессии входа и «запирает» файл входа до пароля/PIN (тесты их не вводят). Поэтому: один слот = один ребёнок, слот постоянно в режиме этого ребёнка — `parent-auto` (QA-R2-V), `parent-r21-auto` (QA-R2-1); слоты выдаёт пользователь вручную `npm run qa-login:manual -- <slot>`. `parent.json` / `parent-b.json` в режим ребёнка **не переводятся никогда**. Удаление `benjico\child-context` из режима ребёнка не выводит — как шаг «очистки/выхода» **не используется**. Вход в дом ребёнка — `goChildHome` из `tests/child-slot.helpers.ts`: слот ещё не в режиме ребёнка → передача «<имя>, בואו נתחיל!» (→ «אחר כך»); уже в режиме → сервер ведёт в дом ребёнка + гейт → закрыть «ביטול»/«חזרה לתרגול» (ничего не вводить). В конце теста — сохранить сессию слота (`saveSlot`: refresh-токен Supabase одноразовый). Тесты на одном слоте — `@data` (проект `data`, по одному) или serial. Действия родителя — отдельное окно `parent` без входа в режим ребёнка. Тесты, которые создают нового ребёнка QA-AUTO и передают ему устройство, или в одной сессии переходят ребёнок ↔ зона родителя, — пропущены (`test.skip`, «пропущено по решению 08.11»). Слота семьи с PIN (`parent-b-auto`, QA-B1) нет — такие тесты пропущены.
**Дети:** **QA-R2-V** `26592b73-eaa6-439f-ab3f-d98a0bd1871b` — спутник rabbit, постоянный, НЕ удалять; стартовый тест у него не закончен (передача ведёт на intro). Любой тест, меняющий его спутника, в конце (и при падении — в `finally`/`afterEach`) возвращает rabbit и проверяет это. Новые дети — `QA-AUTO-<6 латинских букв>` («שנת לידה» = текущий год − 9; спутник по умолчанию — Бенджи), id → annotation `cleanup`, удаляет пользователь.
**Не проверять в разделах 1–2** (находки R3, не требования #aed9e0): тексты «בנג׳י»/мужской род у ארנבת, пустой `alt` на «מי ילווה», позу ארנבת; на слух — только вручную. Тексты спутника с 08.11 — требование #b3210e, проверяются только в разделе 3.
**Очистка после теста в режиме ребёнка:** не нужна и не делается (слот остаётся в режиме ребёнка — так задумано); в конце — `saveSlot`.
Без `waitForTimeout`/`networkidle`: ожидание `expect(...)`, `waitForURL`, `waitForResponse`.
Пометки: передача открывает детскую сессию → без `@prod-safe`; тесты, которые открывают практику (создают попытки), меняют спутника или создают детей — `@data` (только десктоп-проект `data`).
