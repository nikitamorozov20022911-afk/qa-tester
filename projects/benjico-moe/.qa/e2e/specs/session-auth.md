Пользователь провёл `עבר QA` 02.11 (staging https://benjico.expo.app).
Роли: `parent-b` (сессия `.qa/auth/parent-b.json`, без паролей) и гость. Проверено на Chrome 1280 и iPhone WebKit 390 → десктоп `@desktop` (окно 1280×800 в файле), iPhone `@iphone` (WebKit 390×844 в файле).

**Жёсткие ограничения.** Автотесты **не выходят из аккаунта** (выход отзывает токен на сервере и ломает сохранённую сессию parent-b), **не вводят пароли и PIN**, **не двигают часы**. SA-01, SA-02, SA-03 — только вручную (раздел 3).
**Expo-роутер.** Скрытые экраны остаются в DOM — все локаторы только по видимым элементам (`.filter({ visible: true })`).
**API.** Заголовки Supabase (apikey, authorization) снимаются с запроса самого приложения (`captureSupabase`), паролей и ключей в коде нет. Без `waitForTimeout`/`networkidle`.

### 3. Только вручную (manual) — кода нет

#### 3.1 SA-01 Выход отзывает токен — manual #a337fd
Причина: выход («יציאה מהחשבון» → подтвердить) отзывает токен на сервере и ломает сохранённую сессию `parent-b.json`; повторный вход — пароль, его вводит пользователь.
Шаги/ожидаемо — `.qa/tests/session-auth.md` SA-01 (401 `session_revoked` без данных сразу/1/5 мин; refresh → 400 `refresh_token_not_found`; `/sign-in`). AC2.

#### 3.2 SA-02 Вторая вкладка после выхода — manual #a337fd
Причина та же (нужен выход). Ожидаемо: действие во вкладке B → `/sign-in` с «החיבור לחשבון הסתיים. היכנסו שוב כדי להמשיך.» AC2.

#### 3.3 SA-03 Истечение во время работы — manual #a337fd
Причина: требование «по времени» (часы +2 ч, порча refresh-токена) — в регресс не входит. Ожидаемо: `/sign-in` с тем же сообщением. «תפוגת session» в описании тикета.

Не автоматизировано также: нейтральная ошибка входа (AC1 — нужен ввод пароля, хоть и неверного) — в кейсы SA не входит.
