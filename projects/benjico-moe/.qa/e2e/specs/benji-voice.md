Источник: бриф `.qa/research/789f1a.md` (раунд 2, 19.11), тикет #789f1a (iPad build 8 → fix commit 7b9f3b6, iPad build 9) — пользователь проверил на iPad build 9 и провёл `עבר QA` 19.11. Скриншоты «как было»: `.qa/screenshots/2026-11-19-r2/ipad/`.
«מה רצוי»: «הסמל מראה את המצב הנוכחי, כמו השם הנגיש: קול פעיל — רמקול עם גלים; מושתק — רמקול עם קו». Комментарий программиста: звук активен («השתק») — динамик с волнами; выключен («בטל השתקה») — динамик с чертой. Опора: #151ef2, F-20/G2 «состояние не только цветом/формой — имя и иконка совпадают».
Роль — слот `parent-auto` (QA-R2-V, режим ребёнка), `goChildHome(page, CHILD_SLOTS['QA-R2-V'])`, `saveSlot` в `afterEach`; все тесты `@data` (одно окно на слот, ширина — `page.setViewportSize`). Кнопка — `page.getByTestId('benji-mute')` (testID из тикета; запасной поиск — `getByRole('button', { name: /^(השתק|בטל השתקה)$/ })`).
**Звук (L-20261119-1):** `addInitScript` ДО загрузки: `speechSynthesis.speak` → логгер без воспроизведения (`ss-speak`/`ss-cancel` в `window.__qaAudio`), `HTMLMediaElement.prototype.play` → muted + лог `play-ok`, `pause` логируется. На слух не проверяется (только пользователь на iPad).
**Как сравнивать иконку (без картинки-эталона):** снять «сигнатуру» иконки внутри кнопки — `outerHTML` её `svg` (или `img`/`src`/`alt`, если иконка не svg; точный способ выбирает генератор по живому DOM и фиксирует в тесте) — отдельно для состояния A (имя «השתק») и B (имя «בטל השתקה»). Утверждения: (1) сигнатуры A и B различаются; (2) сигнатура «волны» — у A, «черта» — у B (различие конкретное: у B есть элемент-диагональ/косая линия, у A — дуги-волны; генератор формулирует по DOM); (3) на втором экране сигнатура того же состояния та же; (4) имя и иконка меняются в одном кадре — после клика `expect` по имени и по сигнатуре сходится одновременно. Если на живом сайте состояние↔иконка расходятся с «מה רצוי» — остановиться и сообщить, ожидание не подгонять.
Без `waitForTimeout`/`networkidle` — `expect.poll`/`expect(locator)`. Путь на экран чтения — только кликами («תרגול קריאה» → карточка отрывка), как в группе 3.
**Кто пишет:** официальный `playwright-test-generator` (одна роль, одно окно).

«מה רצוי»: «בנג׳י מדבר רק בקול שלו … בכשל — לנסות שוב; אם לא הצליח — להשאיר טקסט בבועה בלי קול, בלי speechSynthesis».

**Звук (L-20261119-1):** `addInitScript` ДО загрузки: `speechSynthesis.speak` → логгер без воспроизведения (счётчик `ss-speak`, `cancel` не считается), `HTMLMediaElement.prototype.play` → muted + счётчик вызовов и исхода (`play`, `play-ok`, `play-err`), `pause`, `ended` в `window.__qaAudio`.
