# План автотестов: Запросы удаления данных и поддержка (#c3aa39)

Источник: `.qa/tests/data-requests-reauth.md` (кейсы DR-01…DR-06), тикет #c3aa39 «בקשת מחיקת נתוני ילד נשלחת בלי «אימות זהות»; אין דרך לפנות לתמיכה». Пользователь провёл `עבר QA` 02.11 (staging https://benjico.expo.app).
«מה רצוי»: «בקשת מחיקה דורשת «אימות זהות» כמו שאר הפעולות הרגישות; דרך פנייה לתמיכה (מייל/טופס) מוצגת.» Комментарий программиста 01.11: пароль перед отправкой удаления ребёнка и всей семьи; сервер отклоняет такой запрос без входа по паролю за последние 5 минут; контакт поддержки на /privacy, /settings и экранах документов.
Роль: `parent-b` (сессия `.qa/auth/parent-b.json`). Проверено на Chrome 1280 и iPhone WebKit 390 → `@desktop` (1280×800 в файле) и `@iphone` (WebKit 390×844 в файле).

**Жёсткие ограничения.** Запрос на удаление **не отправляется**, пароль **не вводится**, «אישור» в окне не нажимается, письмо не отправляется. Страховка в коде — `blockDataRequestWrites()`: любая не-GET запись в `rpc/create_data_request` / `data_requests` обрывается в браузере и учитывается (тест падает, если она была до пароля). DR-03 — только вручную.
**Expo-роутер.** Скрытые экраны в DOM — локаторы только по видимым элементам. Без `waitForTimeout`/`networkidle`.
**Кто пишет.** MCP `playwright-test` отключён → тесты записаны запасным путём в `tests/data-requests-reauth/`. Тексты — со скриншотов проверки 02.11 (`.qa/screenshots/c3aa39-*`); в браузере при записи не проходились, места с `TODO verify selector` — сверить при первом `/qa-regress`.

### 4. Статус запросов: легенда на телефоне 390 без обрезки (#a78c78, реджект R3)
**Seed:** `tests/seed.parent-b.spec.ts`

Источник: бриф `.qa/research/a78c78.md` (ретест 17.11, реджект R3 12.11), тикет #a78c78 прошёл QA 17.11 (пользователь `עבר QA`). Веб прошёл: легенда 390/360/375 Chrome+webkit — 2 строки без обрезки; 1194/1366 — одна строка (`session.json`).
«מה רצוי» (R3, «לפי החלטת הפרויקט שטלפון (390) בתחולה ו-Figma E10»): «כל תוויות המקרא גלויות ברוחב 390 — המקרא נשבר לשתי שורות (או נכנס ברוחב המסך), בלי חיתוך ובלי גלילה אופקית». Легенда: «מקרא: בטיפול · הושלם · ממתין לצד שלישי · מוחרג · נדחה» (5 меток). Комментарий программиста (commit 15769de): легенда переносится на две строки на 390, все 5 меток видны.
**Роль и данные.** `parent-b` (семья с запросами в разных статусах; только просмотр — ничего не создаётся и не отправляется → без `@data`). Страница `/privacy/data-request`. Если страница пуста и легенды нет (запросов у семьи не осталось) — тест останавливается и сообщает (данные: запросы, выставленные оператором 12.11); новых запросов тест не создаёт (удаление — пароль, решение пользователя).
Замеры: `getBoundingClientRect` каждой метки легенды: `left ≥ 0`, `right ≤ innerWidth`; `document.documentElement.scrollWidth ≤ innerWidth`. Без `waitForTimeout`/`networkidle`.
**Кто пишет:** `autotest-writer` (замеры по нескольким размерам окна и WebKit — официальный генератор не умеет).
