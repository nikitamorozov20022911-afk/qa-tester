# План автотестов: Результаты стартового теста и две шкалы уровней (#c121d3)

Источник: `.qa/tests/placement-results.md` (кейсы PR-01…PR-07), тикет #c121d3 прошёл QA 2026-10-29 (staging https://benjico.expo.app).
Роль — `parent` (сессия `.qa/auth/parent.json`, без паролей). Устройство — только десктоп (`@desktop`): тикет не про мобильную версию.
Голос не автоматизируется: часть чтения проходит без микрофона (карточка «לא שומעים אותך כרגע» → «לנסות שוב» → самооценка). Фейковый микрофон / `addInitScript` — не использовать.
Без фиксированных пауз и `networkidle`: только `expect(...)`, `waitForURL`, `waitForResponse`.

**Тестовые данные и чистка.** Группа 1 создаёт за прогон 2 профиля ребёнка `QA-AUTO-<буквы>` (имя **без цифр**: оно выводится на C3, а проверка C3 ищет цифры). Удаление профиля требует повторного ввода пароля родителя (E9 + context.md) → **в `afterAll` не удаляем, чистка ручная**: тест записывает имя и id ребёнка в `testInfo.annotations` (`type: 'cleanup'`), список для удаления берётся из отчёта прогона. Тарифный лимит детей на аккаунте `parent` не известен — при росте числа профилей создание может упереться в лимит.

**Кто пишет.** Группа 2 — официальный `playwright-test-generator`. Группа 1 — **запасной путь** (`autotest-writer` сам): цикл неизвестной длины (адаптивный тест), `window.confirm`, два окна (режим ребёнка + зона родителя) и REST-проверка — генератор это не осилит. Подробности — в конце файла.

### Как писать группу 1 (запасной путь)
- `import { test, expect } from '../../fixtures'`; первая строка файла — подпись qa-tester; `test.describe.configure({ mode: 'serial' })`; `test.setTimeout(6 * 60_000)` на прохождение (тест длинный, это не пауза).
- Окно ребёнка: `const kid = await asUser('parent')`; окно родителя: `const parent = await asUser('parent-3')` (нужен `.qa/auth/parent-3.json`; нет — `npm run qa-login:manual -- parent-3`).
- Помощник `passPlacement(page, { reading: 'קל' | 'לא בטוח/ה', writing: 'confident' | 'unsure' })` в `tests/placement-results/placement.helpers.ts`: цикл `while` с ожиданием «любого из» состояний через `expect(locator.or(...)).toBeVisible()`, затем ветвление по видимому; лимит итераций (напр. 40) → понятная ошибка. Без `waitForTimeout`.
- `window.confirm`: Playwright по умолчанию отклоняет окна — до каждого «שלחתי!» `page.once('dialog', d => d.accept())`, иначе отправка не произойдёт.
- Имя ребёнка без цифр: `'QA-AUTO-' + случайные 6 латинских букв`.
- Чистка: `test.info().annotations.push({ type: 'cleanup', description: 'child QA-AUTO-… <id> — удалить вручную (нужен пароль)' })`.
- Не прогонять — запуск только по `/qa-regress`.
- **Записано 2026-10-29** (без браузера): селекторы с `// TODO verify selector` сверить на первом `/qa-regress` — форма `/children/new`, «מתחילים!» на C1, колонки `skill_levels`.
