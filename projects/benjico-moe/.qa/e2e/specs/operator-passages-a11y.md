# План автотестов: Доступность окон и форм Back-Office — фокус в окнах подтверждения, после «הסרה», aria-invalid «גיל עד» (#12abdb)

Источник: бриф `.qa/research/12abdb.md` (ретест 17.11), тикет #12abdb прошёл QA 17.11 (пользователь `עבר QA`). Веб 1280/390 прошёл: фокус на «ביטול», Enter закрывает 3/3; после «הסרה» фокус на «שחזור»; aria-invalid на обоих возрастах (`session.json`).
«מה רצוי» (F-20 «מוקד … מוחזר באופן צפוי אחרי חלון», «שגיאה … מקושרת לשדה»): в окне подтверждения необратимого действия первичный фокус на безопасной кнопке «ביטול»; после «הסרה» фокус на логичном элементе строки («שחזור»), не на `BODY`; поле «גיל עד» при ошибке — `aria-invalid="true"` и связано с сообщением. Комментарий программиста (commit 15769de): так же в «שאר החלונות ההרסניים» (в т.ч. «יציאה»).
**Роль и данные.** `parent` (режим родителя, оператор: `/passages` доступен — `research/2293dd.md`; постоянное разрешение 02.11 — свои тестовые QA-тексты публиковать, снимать «הסרה»; чужие не трогать). Ребёнок не используется. Группа `serial` (`test.describe.configure({ mode: 'serial' })`): `beforeAll` создаёт один свой текст в `/passages` («+ פריט חדש») с названием `QA-AUTO-12abdb-<время>` и публикует его; `afterAll` снимает («הסרה»), если он ещё опубликован. Все тесты — `@data` (меняют данные общего аккаунта; проект `data`, одно окно); ширина — `page.setViewportSize` (1280×800 и 390×844).
Фокус проверяется через `expect(page.getByRole('button', { name: … })).toBeFocused()` (или `document.activeElement` по accessible name), без пауз: после «הסרה» — `expect(...).toBeFocused()` с ожиданием (строка становится «שחזור» ~270 мс). Только клавиатура для «שחזור»: **клик мышью по «שחזור» не работает — находка 17.11, в тест не входит** (Enter работает).
**Защита от потери сессии:** перед `Enter` в окне «יציאה» (и «הסרה») сначала `expect(<кнопка «ביטול»>).toBeFocused()`; если фокус не на «ביטול» — тест падает, Enter не нажимается (иначе Enter подтвердит выход из аккаунта и испортит слот).
**Кто пишет:** официальный `playwright-test-generator`; создание/снятие текста в `beforeAll/afterAll` — `autotest-writer` (запасной путь).
