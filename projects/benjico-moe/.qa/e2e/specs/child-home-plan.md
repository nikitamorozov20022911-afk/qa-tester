# План автотестов: Дом ребёнка и план на сегодня — при сбое рекомендации контекст не стирается (#fa0336, реджект R3)

Источник: бриф `.qa/research/fa0336.md` (ретест 17.11, реджект R3 12.11), тикет #fa0336 прошёл QA 17.11 (пользователь `עבר QA`). Веб прошёл: при обрыве/500 на `next_activity` «המשך» и «התכנית שלי להיום» остаются 24/24 и 30/30, «למה זה הומלץ?» скрыта, нет «בנג׳י ממליץ», «נסה שוב» без дубля (`session.json`).
«מה רצוי» (R3; S-01 «מצבי loading, empty ו-error אינם מוחקים הקשר», F-12 «כשל בהמלצה מציע חזרה לקטלוג בטוח ולא חוסם תרגול»): при сбое рекомендации — сообщение об ошибке с «נסה שוב», но «המשך מהנקודה האחרונה» (если есть незавершённая активность) и ссылка на план остаются на доме. Комментарий программиста (commit 15769de): после сбоя — карточка «המשך מהנקודה האחרונה», затем «משהו השתבש / נסה שוב», ссылка «התכנית שלי להיום» остаётся (высота 44), «למה זה הומלץ?» скрыта только когда нет рекомендации, карточки чтения и письма остаются.
**Роль и данные.** Слот `parent-auto` (QA-R2-V, режим ребёнка постоянно; `CHILD_SLOTS['QA-R2-V']`, `goChildHome`, `saveSlot` в `afterEach`; основной `parent` в режим ребёнка не переводится — решение 08.11). Тесты создают черновик письма у QA-R2-V → `@data` (проект `data`, одно окно). Ширина 1194×834 (как в реджекте) — `page.setViewportSize`; 390 в этот план не входит (на 17.11 не проверялась).
Сбой: `page.route('**/rpc/next_activity', …)` — в одном тесте `route.fulfill({ status: 500 })`, в другом `route.abort('failed')` (обрыв). Предусловие «есть незавершённая активность»: общий `beforeAll`/helper в serial-группе — «תרגול כתיבה» → первое задание → «הקלדה» → ввести несколько слов `QA-AUTO-fa0336` → «בית» (без отправки); если на доме уже есть карточка «המשך מהנקודה האחרונה» — шаг пропускается. В конце группы черновик чистится («תרגול כתיבה» → то же задание → «ניקוי» → подтвердить), чтобы не оставлять состояние (#156d3f: открытый черновик не дублируется).
Без `waitForTimeout`/`networkidle`: только `expect(...)`/`waitForResponse`.
Чистка: черновик письма QA-R2-V (постоянный ребёнок); в `annotations` `type: 'cleanup'` — задание и текст.
**Кто пишет:** `autotest-writer` (запасной путь: `page.route`, serial-предусловие) — официальный генератор такие мок-сети не делает.
