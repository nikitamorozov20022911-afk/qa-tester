# План автотестов: Стартовый тест — только чтение (#8bf5a8, после #be58fd)

Источник: `.qa/tests/placement-reading.md` (кейсы PRD-01…PRD-09), тикет #8bf5a8 прошёл QA 2026-11-01 (раунд 3, все кейсы ✅ дважды), staging https://benjico.expo.app.
По согласованной просьбе клиента #be58fd **части письма в стартовом тесте нет**: C1 → 3 отрывка чтения → C3 `/assessment/results`; `/assessment/writing` всегда ведёт в дом ребёнка.
Роль — `parent` (сессия `.qa/auth/parent.json`, без паролей), режим ребёнка — через передачу устройства (`/children/<id>/handover` → «<имя>, בואו נתחיל!» → `/<childId>/assessment/intro`). Refresh-токен Supabase одноразовый: одну сессию в двух окнах не использовать; второе окно (повторный вход) — `parent-3`.
Устройство — десктоп (`@desktop`), кроме PRD-09 (`@iphone`, 390, WebKit). Все тесты создают ребёнка → `@data` (проект `data`, по одному окну, десктоп 1440×900; проверено вручную на 1280×800 — вёрстка C1–C3 одинаковая). iPad 1194×834 проверялся вручную (Figma, мелкие сдвиги) — в автотесты не входит.
Голос не автоматизируется (в headless микрофона нет): кнопка микрофона (aria «קראתי!») → карточка «לא שומעים אותך כרגע» → «לנסות שוב» → «איך היה?» → «בסדר». Фейковый микрофон / `addInitScript` не использовать.
Без фиксированных пауз и `networkidle`: только `expect(...)`, `waitForURL`, `waitForResponse`. `@prod-safe` — нет (тесты создают детей).

**Тестовые данные и чистка.** Каждый файл создаёт 1 ребёнка `QA-AUTO-<6 латинских букв>` (имя без цифр: C3 проверяется на отсутствие цифр), за прогон — 6 детей. Удаление требует пароль родителя → по решению 29.10 удаляет пользователь: имя и id — в `testInfo.annotations` (`type: 'cleanup'`). Много детей на аккаунте ломает аватары («Too many active WebGL contexts», находка 01.11) — чистить после регресса.

### Как писать группу 2 (запасной путь)
- `import { test, expect } from '../../fixtures'`; первая строка файла — подпись qa-tester; общий ребёнок в файле → `test.describe.configure({ mode: 'serial' })`; `test.setTimeout(5 * 60_000)` на прохождение 3 отрывков (это лимит, не пауза).
- Помощники — новый `tests/placement-reading/reading.helpers.ts`; из `tests/placement-results/placement.helpers.ts` взять `qaChildName`, `annotateCleanup`, `createChild`, `openSharedUserPage` (для окна, живущего через несколько тестов). `startPlacementAsChild` и `passReading` там рассчитаны на письмо (ждут `writing-input`) — не использовать; нужен `passReadingToResults(page, 'בסדר')`: цикл с ожиданием «любого из» (`/assessment/results` | «איך היה?» | «לנסות שוב» | «קראתי!») через `expect(locator.or(...)).toBeVisible()`, лимит итераций → понятная ошибка, без `waitForTimeout`.
- Повторный вход — новое окно с другой сессией (`parent` ↔ `parent-3`), предыдущее окно закрыть; одну сессию в двух открытых окнах не держать.
- Чистка: `annotateCleanup(testInfo, name, id)` — удаляет пользователь.
- Не прогонять — запуск только по `/qa-regress`.
