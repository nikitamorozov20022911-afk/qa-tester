# План автотестов: Шапка и экран настроек родителя, меню выхода (#f8756c)

Источник: `.qa/tests/parent-settings-header.md` (PS-01…PS-07), бриф `.qa/research/f8756c.md` (повторная проверка 05.11), Figma A4 178-1869. Пользователь провёл `עבר QA` 05.11 (staging https://benjico.expo.app).
AC тикета: «יציאה מבטלת session פעיל; … שינוי פרטים רגישים מחייב אימות מחדש». Комментарий программиста 04.11: «סדר הלשוניות כמו ב-A4 — «סקירה» מימין, «הגדרות» (נבחרת) משמאל. … כפתור כחול «מעבר למצב ילד» (156×44) ולידו אווטאר ההורה 44px … הכפתור מוביל לבחירת ילד». Комментарий 01.11: единый выход — меню аккаунта в /children и в настройках, одно подтверждение «לצאת מהחשבון במכשיר הזה?».
Роль: `parent` (`.qa/auth/parent.json`). Гостевые проверки тикета — в `specs/session-auth.md`, раздел 4.

**Жёсткие ограничения.** Выход **не подтверждается** (только «ביטול»), пароль не вводится. Страховка в каждом тесте с меню выхода: `page.route('**/auth/v1/logout**', r => r.abort())` + счётчик таких запросов — тест падает, если запрос был (выход отозвал бы токен и сломал сессию parent для всего прогона).
**Expo-роутер:** скрытые экраны в DOM — локаторы только по видимым элементам. Без `waitForTimeout`/`networkidle`.
Пометки: только просмотр и «ביטול» → `@prod-safe`, без `@data`.
**Кто пишет:** официальный `playwright-test-generator` (одна роль).

#### 1.5 Меню аккаунта в /children: выход только через подтверждение «לצאת מהחשבון במכשיר הזה?», «ביטול» оставляет вход @desktop @prod-safe #f8756c
**Device:** desktop
**Users:** parent
**Steps:**
1. Включить страховку: `**/auth/v1/logout**` → abort, считать запросы.
2. Открыть `/children`, нажать иконку аккаунта в шапке.
3. В меню нажать пункт выхода («יציאה מהחשבון»).
4. В подтверждении нажать «ביטול».
**Expected:**
- После 2: открылось меню с пунктом «יציאה מהחשבון», адрес по-прежнему `/children` (не выход сразу; комментарий 01.11 «תפריט חשבון»).
- После 3: видно подтверждение с текстом «לצאת מהחשבון במכשיר הזה?» и кнопкой «ביטול».
- После 4: подтверждения нет, адрес `/children`, «מי מתרגל היום?» виден; в localStorage есть ключ `sb-…-auth-token`; запросов `/auth/v1/logout` — 0 (AC3 не срабатывает без подтверждения).

#### 1.6 «יציאה מהחשבון» в /settings: то же подтверждение, «ביטול» оставляет вход @desktop @prod-safe #f8756c
