### 1. Пометка ребёнка → вид у родителя → запрос (autotest-writer, serial)
**Seed:** `tests/seed.parent-r21-auto.spec.ts` (ребёнок) / `tests/seed.parent.spec.ts` (родитель)

#### 1.1 Ребёнок: «לבקש בדיקה» → «ההורה יראה את הבקשה…», кнопка выключена, запрос проверки не создаётся @desktop @data #37cdff
**Device:** desktop
**Users:** parent-r21-auto (слот, окно ребёнка), parent (окно родителя)
**Steps:**
1. Окно parent: `/children/<QA-R2-1>` → «תובנות והמלצות» → «המלצות אחרונות»; запомнить число меток «הילד ביקש לבדוק».
2. Окно слота: `goChildHome` QA-R2-1 (передача «QA-R2-1, בואו נתחיל!» или закрыть гейт) → `/<id>/home` → «למה זה הומלץ?».
3. Нажать «לבקש בדיקה».
**Expected:**
- Перед шагом 3 кнопка активна (иначе — данные: остановиться и сообщить).
- После шага 3: ответ `rpc/respond_recommendation` 200; текст «ההורה יראה את הבקשה…»; кнопка выключена (RM-01; тикет «מה קיים»).
- Ни одного POST к `feedback_review*` / `rpc/request_*review` из режима ребёнка (решение 28.10 #73248f: формальный запрос открывает родитель).

#### 1.2 Родитель: метка «הילד ביקש לבדוק», а не «בבדיקה»; на «למה זה הומלץ» — блок, пояснение и «פתיחת בקשת בדיקה» @desktop @data #37cdff
**Device:** desktop
**Users:** parent
**Steps:**
1. Обновить «המלצות אחרונות».
2. Открыть строку с меткой «הילד ביקש לבדוק».
**Expected:**
- Меток «הילד ביקש לבדוק» на одну больше, чем до 1.1 (RM-02; «מה רצוי» «ההורה רואה בבירור שהילד ביקש בדיקה»).
- Ни одна строка с «הילד ביקש לבדוק» не содержит «בבדיקה» (RM-05; «מה רצוי» ««בבדיקה» רק כשיש בקשת בדיקה אמיתית»).
- На «למה זה הומלץ»: «הילד ביקש לבדוק», пояснение, что запрос ещё не у команды, кнопка «פתיחת בקשת בדיקה» (RM-03; комментарий программиста 01.11).

#### 1.3 Родитель: «פתיחת בקשת בדיקה» → форма предзаполнена → «שליחת בקשה» → «בקשה #…», метка → «בבדיקה» @desktop @data #37cdff
**Device:** desktop
**Users:** parent
**Steps:**
1. «פתיחת בקשת בדיקה».
2. «שליחת בקשה».
3. Вернуться в «המלצות אחרונות».
**Expected:**
- Причина «אחר» выбрана (aria-checked=true), текст содержит «הילד ביקש לבדוק» (RM-04).
- После шага 2: статус «בקשה #xxxxxxxx» (8 hex).
- После шага 3: меток «הילד ביקש לבדוק» на одну меньше, «בבדיקה» — на одну больше (RM-04/RM-05; «מה רצוי» «ויכול לפתוח בקשה»).
