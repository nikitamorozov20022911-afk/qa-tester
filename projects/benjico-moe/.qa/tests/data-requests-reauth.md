# Запросы удаления данных и поддержка (#c3aa39)
Источник: #c3aa39, проверено 02.11 (Chrome 1280, iPhone webkit 390), роль parent-b; ввод пароля — пользователь.

| ID | Кейс | Шаги | Ожидаемо |
|---|---|---|---|
| DR-01 | Удаление данных ребёнка требует пароль | /privacy/data-request → ребёнок → «למחוק מידע» → «שליחת הבקשה» | окно «אימות זהות» с полем пароля, до пароля нет POST; «ביטול» — запрос не создан, форма на месте |
| DR-02 | Удаление всей семьи требует пароль | /settings → «מחיקת כל נתוני המשפחה» → «שליחת הבקשה» | то же окно, без POST до пароля |
| DR-03 | Неверный / верный пароль (вручную) | в окне неверный пароль → верный | ошибка; затем «הבקשה נשלחה» (или «כבר יש בקשה כזו בטיפול») |
| DR-04 | Сервер без свежего входа | rpc/create_data_request p_kind=delete, вход по паролю >5 мин назад | 403 not_authorized |
| DR-05 | «עיון» без пароля | «לראות את המידע» | отправляется без окна пароля |
