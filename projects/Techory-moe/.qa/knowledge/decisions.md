Поэтому всё ниже взято из текста «ספר»: обзор, סיכומי מודולים, בלוקי פיצ'רים, מילון מונחים, תהליכי משתמש, פרק ב «מיפוי תכונות», страницы всех 67 פריטים (открывались через «סינון תוכן» порциями по ≤8 — без фильтра «ספר» показывает только פריטים 01–08) и פרק ה «ארכיטקטורה טכנית». Разделы ז «מודל נתונים» и ח «מערכת עיצוב» есть в оглавлении, но в «ספר» их содержимое не отображается.
- Номера פריטים `#NN` — сквозная нумерация из פרק ב «מיפוי תכונות» (01–67). `F-N` / `S-N` — внутренние ссылки самого текста спецификации (F-1 RBAC, F-2 היררכיה, F-3 הקצאה, F-4 SMS, F-5 התראות, F-6 LSA, F-7 תמלול, F-8 VIP dialer, F-9 רכב→מפתח, F-10 Workiz, F-11 QuickBooks, F-12 תור, F-13 GPS, F-14 מדרגי מנוי, F-15 הפניות, F-16 מעקב שימוש, F-17 אפליקציית טכנאי, F-18 מצב כהה).
- Статусы: **принято** — в документе зафиксировано как решение (часто с обоснованием «כי …»); **открыто** — документ сам помечает как нерешённое (TODO / SPEC-GAP) либо разные места документа противоречат друг другу. Противоречия цитируются дословно с обеих сторон; какая сторона верна — в документации не указано.
- Язык по умолчанию: в «מפרט» сказано только «בממשק דו-לשוני עברית/אנגלית» (סקירת הפרויקט); какой язык по умолчанию — в документации нет (по данным проекта: английский).
- Ветка dark mode (`feat-dark-mode`): к ней относятся D-14 (решения по F-18 / S-13).
