# Flows (תהליכי משתמש) — Techory

Источник: «מפרט» https://mifrat.com/Project?id=685436cef855c52a98e8bef2&tab=spec, режим «ספר», раздел «ד · תהליכי משתמש» (страницы «תהליך משתמש · N / 20» и «תרשים תהליך · N / 20»). Извлечено 2026-10-04.
Режим «עבודה» недоступен для этой учётки («אין הרשאות עריכה»), поэтому всё взято из режима «ספר». В «ספר» у процесса нет полей персоны или связанных фич. Здесь их нет — не додумывать.
Всего процессов в документе: 20. Текст ниже дословный, на иврите. В поле «Экраны» — экран из подписи под каждым шагом.

Общее замечание: процесс FL-09 говорит о трёх тарифах (Free ← 49$ ← 99$). В списке тарифов («מיפוי תכונות», пункт 24) их пять: «Lite / Starter $49 / Pro $99 / Growth $199 / Enterprise $299». Расхождение передано в decisions.

- מטרה: קליטת ליד LSA ומענה אוטומטי
- סיום מוצלח: העבודה משובצת לטכנאי
- כשל / חסימה: כשל המרה/שיבוץ נרשם וניתן לחזרה
- Шаги:
  1. טריגר חיצוני: פולינג (cron) מושך ליד חדש; הליד נשמר ונשלח מענה SMS אוטומטי דרך Twilio. מצב ריק: 'חבר את חשבון Google'. שגיאה: טוקן שפג או כשל פולינג — ניסיון חוזר; ליד כפול נמנע ב-idempotency — экран: מסך הגדרות וחיבור LSA ופיד לידים

  3. הליד מומר לעבודה ונכנס לתור השיבוץ. שגיאה: כשל המרה/שיבוץ נרשם וניתן לחזרה — экран: מסך שיבוץ ולוח הקצאת עבודות
- Экраны: מסך הגדרות וחיבור LSA ופיד לידים → מסך תיבת הודעות SMS (שיחות) → מסך שיבוץ ולוח הקצאת עבודות
