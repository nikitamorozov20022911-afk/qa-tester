# Экраны (screens) — Techory

Источник: «מפרט» в mifrat — https://mifrat.com/Project?id=685436cef855c52a98e8bef2&tab=spec (PDF нет).
Снято: 2026-10-04, режим «ספר» (режим «עבודה» недоступен: «מצב עבודה זמין רק למשתמשים עם הרשאות עריכה»). Карточки по одной открыть нельзя, поэтому текст взят из книги через фильтр «סינון תוכן» (по 8 пунктов за раз).
Номер `#NN` — порядковый номер пункта в разделе «פרק ב › מיפוי תכונות» (полный список 67 пунктов). `S-N` в «Связи» — номер экрана из «סיכומי מודולים», `F-N` — номер фичи оттуда же.

Что есть в «מפרט»:
- 14 пунктов с типом «מסך» (в обзоре «סוגי פריטים במפרט»: «מסך … 14»). Это S-01…S-07, S-09…S-15 ниже.
- «מסך אנליטיקס ומעקב שימוש» в «מפרט» имеет тип «תכונה», но в «סיכומי מודולים» это экран S-8 → S-08.
- Страницы продукта из модуля «ללא מודול» (тип «תכונה», но по сути это страницы: «עמוד …», «דף נחיתה», «דו"חות», «ספר מחירים») → S-16…S-29.
- Экраны, которые упоминаются только в шагах «תהליכי משתמש» и не имеют своей карточки → S-30, S-31.

Общие пробелы: у экранов нет состояния «загрузка» (нигде не описано). Описание и состояния у типизированных экранов даны одной строкой: «вход ← результат» + «מצבים: ריק — …; שגיאה — …». Блок «תלויות וקשרים» в отфильтрованной книге не выводится. Полностью он виден только у S-03 и S-04 (в нефильтрованной книге). У остальных связи взяты из «סיכומי מודולים» / «בלוקי פיצ'רים» и шагов «תהליכי משתמש».
