# AD-06: Clients — Unit в адресе клиента сразу после улицы, не после страны
- Фича/экран: адреса — Clients (/customers), таблица
- Тикеты: #b2f74544 («ה-Unit מוצג אחרי המדינה ברשימת הלקוחות וחסר ברשימת העבודות של הלקוח»)
- Роль/аккаунт: admin, компания «test», .qa/auth/admin.json
- Устройство: desktop 1440×900
- Тип: позитив / визуал
- Предусловия: только просмотр (безопасно для прода). Клиенты «test» (id …52bde720) и «QA-unit client» (id …50d37684).
## Шаги
1. Открыть /customers.
2. Найти строку клиента «test» и строку «QA-unit client».
## Ожидаемо
- «test»: «2221 NW Federal Hwy, Unit 3123, Stuart, FL 34994, USA» (Unit сразу после улицы, не в конце).
- «QA-unit client»: «2221 Northwest Federal Highway, Apt 5B, Stuart, Florida» — тип «Apt» как есть, без «Unit Apt».
- Во всей таблице нет «USA, Unit…», «, ,», «Unit Apt».
Общий шаблон формата (вместо точных строк — тестовые данные могут меняться): Unit/Apt/Suite/# — второй частью адреса, сразу после улицы; нет «USA, Unit», нет «Unit Apt»/«Unit #», нет «, ,», нет пустого «Unit,».
(источник: «מה רצוי» — ה-Unit מוצג מיד אחרי הרחוב: "2221 NW Federal Hwy, Unit 3123, Stuart, FL 34994, USA"; комментарий программиста — Apt 5B / Suite 200 / #12 как есть)
