# JA-05: Уход через меню Jobs сразу после X — снятие техника сохраняется
- Фича/экран: страница работы (JobDetail) → Schedule & Assignment → Assign Technician; Assignment history; Jobs
- Тикеты: #04d33a ([F-3]; реджект 2 — снятие техника при Allow Multiple Techs OFF)
- Роль/аккаунт: admin (`auth/admin.json`), компания «test» (никогда не «Onsite Locksmith»)
- Устройство: desktop 1440×900, EN
- Тип: граница (автосохранение, связано с #550b46)
- Предусловия: Account Settings «Allow Multiple Techs» = OFF (если ON — тест пропускается, настройку не переключать). Работа «QA-AUTO 04d33a job» (клиент QA-quota client) в статусе Submitted без техника. Техники только QA-Tech Alpha/Beta (вымышленные номера, без согласия на SMS → «No SMS»).
## Шаги
1. Назначить QA-Tech Alpha, дождаться «Assigned to QA-Tech Alpha».
2. Нажать X и сразу (без ожидания) — пункт меню Jobs.
3. Вернуться на страницу работы.
## Ожидаемо
- Поле Assign Technician пустое, статус Submitted, верхняя строка истории «QA-Tech Alpha taken off the job».
(источник: «מצב רצוי» реджекта 2; #550b46 — изменения назначения не теряются при уходе до автосохранения)
- Вне ожидания (известная находка 12.11, не реджект): список Jobs сразу после быстрого ухода может показывать устаревшего техника (6/9) — в автотесте не проверяется.
