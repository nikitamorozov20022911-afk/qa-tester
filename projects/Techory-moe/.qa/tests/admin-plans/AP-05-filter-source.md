# AP-05: Фильтр по источнику — каждое значение
- Фича/экран: Admin Panel → Plans, фильтр «All sources» / «כל המקורות»
- Тикеты: #ca557707, #2ae9da4d
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив
## Шаги
1. По очереди выбрать каждое значение источника (в данных: Free, Trial, Assigned, Stripe, Grandfathered…).
2. Посмотреть колонку «Source».
3. Вернуть «All sources».
## Ожидаемо
- Все строки имеют выбранный источник (0 несовпадений) или пустое состояние; «All sources» возвращает всё.
(источник: «תיאור» — «הצגת מקור המסלול (Stripe / הקצאה ידנית)»; фильтр по источнику — #2ae9da4d)
