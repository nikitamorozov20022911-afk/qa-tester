# AP-04: Фильтр по тарифу — каждое значение
- Фича/экран: Admin Panel → Plans, фильтр «All plans» / «כל החבילות»
- Тикеты: #ca557707, #2ae9da4d
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив
## Шаги
1. Открыть фильтр, по очереди выбрать каждое значение (кроме «All plans»).
2. После каждого — посмотреть колонку «Plan».
3. Вернуть «All plans».
## Ожидаемо
- Для каждого значения все строки имеют в «Plan» именно это значение (0 несовпадений) либо показано «No accounts match these filters.».
- «All plans» возвращает исходное число строк.
