# AP-08: Assign — прошедшая дата: сообщение и Save неактивна
- Фича/экран: Plans → диалог «Assign a plan»
- Тикеты: #6eed7c73 / #2b3784 (реджект 1), #b42657 (дубль), #ca557707
- Роль/аккаунт: admin; строка «בדיקה»
- Устройство: desktop 1440×900
- Тип: негатив / граница
## Шаги
1. Найти «wojeg», нажать «Assign plan» в строке «בדיקה».
2. Ввести причину «QA-AUTO past-date check» (чтобы Save блокировала только дата).
3. В «Until (inclusive)» ввести вчерашнюю дату.
4. Затем — сегодняшнюю.
5. Нажать «Cancel» (ничего не сохранять).
## Ожидаемо
- Вчера: под полем «Pick today or a later date.» (HE «יש לבחור את היום או תאריך מאוחר יותר.»), «Save» неактивна.
- Поле даты: min = сегодня.
- Сегодня: сообщения нет, «Save» активна.
- После Cancel диалог закрыт, строка «בדיקה» не изменилась.
