# AP-06: Фильтр «Subscription status» — каждое значение, вместе с поиском и тарифом
- Фича/экран: Admin Panel → Plans, фильтр «All statuses» / «כל הסטטוסים»
- Тикеты: #ca557707
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив
## Шаги
1. По очереди выбрать каждое значение статуса (פעיל / ניסיון / הניסיון הסתיים / בעיית תשלום / בוטל / חינם; EN — Active, Trial, Trial ended, … , Free).
2. Посмотреть колонку «Subscription status».
3. Комбинация: поиск «wojeg» + статус «Trial» → строка «בדיקה» есть (её статус — Trial); поиск «wojeg» + статус «Free» → пусто или строки только со статусом Free.
4. Вернуть «All statuses».
## Ожидаемо
- Каждое значение: только строки с этим статусом (0 несовпадений) или пустое состояние; «All statuses» возвращает всё.
- Комбинация фильтров = пересечение.
(источник: комментарий программиста 30.9 — новая колонка и фильтр «סטטוס מנוי»; «תיאור» — «סינון לפי מסלול/סטטוס»)
