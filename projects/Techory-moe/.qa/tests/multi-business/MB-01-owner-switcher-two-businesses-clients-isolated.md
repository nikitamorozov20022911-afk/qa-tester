# MB-01: Владелец — в переключателе 2 бизнеса, клиенты видны только в своём бизнесе
- Фича/экран: шапка → переключатель компаний; Clients (/customers)
- Тикеты: #04d339
- Роль/аккаунт: admin (владелец, iamdejar@gmail.com)
- Устройство: desktop 1440×900, EN
- Тип: позитив (изоляция данных)
- Предусловия: у владельца 2 бизнеса — «test» (4432bd2f-3f47-43cf-8ef2-b0c16436f025) и «Onsite Locksmith». В Onsite есть клиент «QA-B2 client» (создал пользователь 18.10), в test — «QA-quota client». Только просмотр.
## Шаги
1. Компания «test». Открыть переключатель в шапке.
2. /customers → поиск «QA-B2».
3. Переключатель → «Onsite Locksmith» → /customers → поиск «QA-B2».
4. Вернуть переключатель на «test».
## Ожидаемо
- В переключателе ровно 2 бизнеса: «test» и «Onsite Locksmith».
- В test клиента «QA-B2 client» нет; в Onsite он есть (а «QA-quota client» из test — нет).
