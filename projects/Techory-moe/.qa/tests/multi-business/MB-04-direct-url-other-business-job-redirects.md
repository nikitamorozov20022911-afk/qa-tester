# MB-04: Прямая ссылка на работу чужого бизнеса — тихий редирект на /Jobs
- Фича/экран: JobDetail (/JobDetail?id=…) → Jobs
- Тикеты: #04d339
- Роль/аккаунт: admin (владелец, чтобы узнать id работы) + dispatcher (только «test»)
- Устройство: desktop 1440×900, EN
- Тип: негатив (изоляция, доступ по URL)
- Предусловия: JOB-1036 «QA-B2 job» — в Onsite Locksmith. Только просмотр.
## Шаги
1. Владелец: переключатель → «Onsite Locksmith» → /jobs → поиск «QA-B2» → открыть JOB-1036, запомнить адрес /JobDetail?id=<id>. Вернуть «test».
2. Диспетчер (бизнес «test»): открыть этот адрес напрямую.
## Ожидаемо
