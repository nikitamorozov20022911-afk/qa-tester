# MB-02: Владелец — работы видны только в своём бизнесе
- Фича/экран: шапка → переключатель компаний; Jobs (/jobs), JobDetail
- Тикеты: #04d339
- Роль/аккаунт: admin (владелец)
- Устройство: desktop 1440×900, EN
- Тип: позитив (изоляция данных)
- Предусловия: JOB-1036 «QA-B2 job» (клиент «QA-B2 client») — только в Onsite Locksmith; JOB-0094 (id 854ea3bb-134d-4c1b-b0a4-a0419854f1f6) — только в test. Только просмотр, в JobDetail ничего не менять (автосохранение).
## Шаги
1. Компания «test»: /JobDetail?id=854ea3bb-… → страница JOB-0094; /jobs → поиск «QA-B2».
2. Переключатель → «Onsite Locksmith» → /jobs → поиск «QA-B2», затем «JOB-0094».
3. Вернуть переключатель на «test».
## Ожидаемо
- В test JOB-0094 открывается, JOB-1036 в списке нет.
- В Onsite JOB-1036 (QA-B2 client) в списке есть, JOB-0094 — нет.
