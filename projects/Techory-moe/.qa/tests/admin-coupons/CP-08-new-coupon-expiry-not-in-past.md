# CP-08: New coupon — дата окончания не раньше сегодня
- Фича/экран: Admin Panel → Coupons → New coupon → «Expires on (optional)»
- Тикеты: #b93722
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: негатив / граница
- Предусловия: — (форма НЕ сохраняется)
## Шаги
1. New coupon, Code QA-AUTO-…, Value 1.
2. Посмотреть ограничение календаря; ввести вчерашнюю дату.
3. Ввести сегодняшнюю дату → Cancel.
## Ожидаемо
2. У поля min = сегодня; вчера → «Pick today or a later date.», Save неактивна.
3. Ошибки нет, Save активна (не нажимаем).
