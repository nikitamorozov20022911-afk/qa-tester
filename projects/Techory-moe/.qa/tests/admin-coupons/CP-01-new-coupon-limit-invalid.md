# CP-01: New coupon — лимит 0 / отрицательный / дробный → ошибка, Save неактивна; пусто — допустимо
- Фича/экран: Admin Panel → Coupons → New coupon
- Тикеты: #351eb3
- Роль/аккаунт: admin
- Устройство: desktop
- Тип: негатив / граница
- Предусловия: только чтение — Save не нажимать (купоны нельзя удалить, живой Stripe).
## Шаги
1. /adminpanel → Coupons → New coupon; Code QA-AUTO-351-…, Value 1.
2. Redemption limit: 0, затем -1, затем 1.5.
3. Очистить поле. Cancel.
## Ожидаемо
- Для 0 / -1 / 1.5: под полем «At least 1, or leave it empty for no limit.» (HE «לפחות 1, או להשאיר ריק ללא הגבלה.»), Save неактивна, запроса сохранения нет.
- Пустое поле: ошибки нет, Save активна.
(источник: «מה רצוי» — מגבלה 0 לא נשמרת: מוצגת הודעת שגיאה ו-Save לא שומר)
