# CP-06: Поиск купонов по коду и e-mail без учёта регистра, пустой результат
- Фича/экран: Admin Panel → Coupons → «Search by code or e-mail…»
- Тикеты: #b93722
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив / негатив
- Предусловия: купон QA-R1-ONLY-1910 (только iamdejar@gmail.com).
## Шаги
1. Ввести «qa-r1-only-1910» (строчными).
2. Ввести «IAMDEJAR@GMAIL.COM» (прописными).
3. Ввести несуществующий код QA-AUTO-NOMATCH-….
4. Очистить поле.
## Ожидаемо
1–2. Видна строка QA-R1-ONLY-1910; все строки — с этим кодом / e-mail.
3. «No coupons match these filters.», строк нет.
4. Список снова полный.
(источник: комментарий программиста п.6 — поиск по коду или e-mail)
