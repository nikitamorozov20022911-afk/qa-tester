#### 17.1 ID-01 Окно «+» по типу — заголовок = тип, поля по типу; у сохранённой אזכרה видно имя и a11y-имя правки #6a86f7e0 @data
**Device:** all (390 и 1440 — без пометки)
**Users:** user1
**Steps:**
1. `/home` → «הוספת תאריך חשוב» → меню «תאריך חשוב» / «אזכרה».
2. «תאריך חשוב» — прочитать окно, закрыть «סגירה».
3. «הוספת תאריך חשוב» → «אזכרה» → прочитать окно; «שם הנפטר» = «QA-AUTO-נפטר», выбрать прошедший день → «הוסף תאריך».
4. Прочитать запись в «תאריכים חשובים».
5. Уборка (finally): «אזכרה, QA-AUTO-נפטר: פתיחה לעריכה» → «מחיקת התאריך» → «מחיקה».
**Expected:**
- «תאריך חשוב»: заголовок «תאריך חשוב», одно поле «שם התאריך» (placeholder «הגדר שם לתאריך»), нет «אחרי השקיעה» (источник: AC2; реджекты 22.09, 23.09; Figma 454:11002).
- «אזכרה»: заголовок «אזכרה», поле «שם הנפטר», checkbox «הפטירה הייתה אחרי השקיעה»; «הוסף תאריך» неактивна, пока нет имени и дня (источник: AC3).
- После сохранения: запись «אזכרה» + строка «QA-AUTO-נפטר» + «האזכרה הבאה: …» + «סדר אזכרה»; кнопки «אזכרה, QA-AUTO-נפטר: פתיחה לעריכה» и «אזכרה, QA-AUTO-נפטר: פתיחת סדר האזכרה» (источник: реджект 23.09).
- После уборки записи «QA-AUTO-נפטר» нет (источник: ID-01 шаг 4).

#### 17.2 ID-02 Карандаш → правка (имя, дата, тип) → сохранить → удалить с подтверждением #6a86f7e6 @data @mobile
**Device:** mobile (390)
**Users:** user1
**Steps:**
1. `/home` → «הוספת תאריך חשוב» → «תאריך חשוב» → «שם התאריך» = «QA-AUTO-היום», день = сегодня → «הוסף תאריך».
2. Карандаш «QA-AUTO-היום: פתיחה לעריכה» → окно «עריכת תאריך»: проверить поля; имя → «QA-AUTO-מחר», день → завтра → «שמירת השינויים»; reload.
3. Карандаш → переключить тип на «אזכרה» (не сохранять) → проверить поля; выбрать день в будущем → закрыть без сохранения.
4. Уборка (finally): карандаш → «מחיקת התאריך» → прочитать окно → «מחיקה»; reload `/home` и `/profile`.
**Expected:**
- Окно правки: заголовок «עריכת תאריך», radio «תאריך חשוב» (checked) / «אזכרה», имя подставлено, выбранный день отмечен, кнопки «שמירת השינויים» и «מחיקת התאריך» (источник: AC2; реджект 27.09 п.4).
- После сохранения — «QA-AUTO-מחר» и новая дата в «תאריכים חשובים» после reload (источник: ID-02 «Ожидаемо»).
- Тип «אזכרה» в правке: поле «שם הנפטר», появляется «הפטירה הייתה אחרי השקיעה»; будущий день → «תאריך הפטירה לא יכול להיות בעתיד.», «שמירת השינויים» неактивна (источник: ID-02 «Ожидаемо»).
- Удаление: «למחוק את התאריך?» / ««QA-AUTO-מחר» יימחק מהתאריכים החשובים שלך, ואי אפשר יהיה לשחזר אותו.» / «ביטול» / «מחיקה»; после — записи нет на `/home` и `/profile` (источник: ID-02 «Ожидаемо»).

**Users:** user1
**Steps:**
