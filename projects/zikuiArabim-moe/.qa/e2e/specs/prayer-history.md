### 10. История молитв
**Seed:** `tests/seed.user1.spec.ts`

#### 10.1 PH-01 /journey/history: группировка по дням, HH:mm, поиск, подгрузка #6a86f800 @prod-safe
**Device:** all (390 и 1440 — без пометки)
**Users:** user1
**Steps:**
1. Открыть `/journey/history`.
2. По очереди ввести в поиск: «ערבית», «23 בספט», «תשרי», «י״ב», «יב», «zzzqq»; после каждого прочитать группы; очистить поиск.
3. Нажать «טען תפילות קודמות».
**Expected:**
- Заголовок «היסטוריית התפילות שלי» (док. S-26; #9e970625 / #56d002bd עבר QA 21.10/25.10; старое «היסטוריית תפילות שלי» — регресс); группы «<евр. дата> · <греч. дата>», в строке — молитва и время HH:mm (источник: реджект rej_1790158670832; ответ 27.09).
- Поиск находит по названию, григорианской и еврейской дате; пока не все записи загружены — «חיפוש בתפילות שנטענו בלבד — יש תפילות קודמות שטרם נטענו» (источник: PH-01 «Ожидаемо»).
- «zzzqq» → «לא נמצאו תפילות שמתאימות ל״zzzqq״.» (источник: PH-01 «Ожидаемо»).
- До подгрузки 100 строк; после «טען תפילות קודמות» — все (= «סה״כ תפילות» на `/home`), кнопка исчезает (источник: PH-01 «Ожидаемо»; История).

#### 10.3 PH-02 Две записи одной молитвы в одну минуту — с секундами (история и «תפילות אחרונות») #6a86f7e9 @prod-safe @mobile
**Device:** mobile (390)
**Users:** user1
**Steps:**
1. Открыть `/journey/history` → группа «י״ב תשרי · 23 בספט׳».
2. До перехода: `page.route('**/rest/v1/prayer_completions**', …)` — получить реальный ответ (`route.fetch()`), добавить копию первой записи с временем на 3 с раньше, вернуть (`route.fulfill`).
3. Открыть `/home` → блок «תפילות אחרונות».
4. Открыть `/journey/history` (подмена активна).
**Expected:**
- Шаг 1: одиночная в минуте запись — HH:mm (напр. «מנחה 15:12»); серия в одну минуту — HH:mm:ss (напр. «15:11:14», «15:11:12») (источник: needed_behavior rej_1790684508668).
- Шаг 3: первые две записи «תפילות אחרונות» — с секундами `HH:mm:ss`, разница 3 с (напр. «· 02:22:33» и «· 02:22:30») (источник: тот же реджект).
- Шаг 4: те же две записи в истории — тоже `HH:mm:ss`; правило одинаково в истории и в «תפילות אחרונות» (источник: тот же реджект).
