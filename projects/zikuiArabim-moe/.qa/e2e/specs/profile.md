#### 11.1 PR-01 «פרופיל אישי» — все предпочтения видны и открываются на правку; «סיסמה» нет #6a86f7f9 @prod-safe
**Device:** all (390 и 1440 — без пометки)
**Users:** user1
**Steps:**
1. Открыть `/home` → клик по имени → `/profile`.
2. Проверить разделы и строки.
3. Открыть «רמת התחזקות»: прочитать slider, нажать клавишу-стрелку, прочитать `aria-valuetext`; закрыть «סגירה» без сохранения.
4. Открыть «נוסח תפילה»: прочитать radio; закрыть «סגירה» без сохранения.
**Expected:**
- Заголовок «פרופיל אישי», «חזרה», аватар («העלאת תמונת פרופיל»), имя с «עריכת השם», e-mail (источник: PR-01 «Ожидаемо»; Figma profile 643:1031).
- «פרטים אישיים»: נוסח תפילה, תאריך לידה, מיקום, היעד שלי, רמת התחזקות — каждая кнопка с a11y-именем «<поле>: <значение>. מעבר לשלב כדי לשנות»; разделы «תאריכים חשובים», «פרטי ההרשמה» (שם מלא, טלפון, אימייל), «הגדרות» (switch «תזכורות במערכת», «הודעות במייל, SMS ו־WhatsApp»), «אודות», «התנתקות» (не нажимать) (источник: F «עריכת פרופיל והעדפות» AC1).
- Нигде в профиле нет слова «סיסמה» (источник: финальный реджект 29.09 abd60e27, ответ 30.09).
- «רמת התחזקות»: slider `aria-valuemin=1`, `aria-valuemax=7`, `aria-valuetext` = сохранённый уровень («כל יום»); подписи «פעם בשבוע»/«כל יום» по краям; стрелка меняет уровень («6 פעמים בשבוע»); «שמירה» неактивна, пока уровень не изменён (источник: ответ 97b86fa0ce22 22.09).
- «נוסח תפילה»: radio «נוסח אשכנז» (`aria-checked=true`), «נוסח ספרד», «נוסח עדות המזרח — בקרוב» (`aria-disabled=true`) (источник: PR-01 «Ожидаемо»).
- Нет горизонтальной прокрутки (источник: PR-01 «Ожидаемо»).

#### 11.2 PR-02 Правка имени — видно везде, переживает reload; пустое и >60 символов не сохраняются #ba9c188c @data @mobile
**Device:** mobile (390)
**Users:** user1 (исходное имя «אקדא טסט»)
**Steps:**
1. Открыть `/profile` → «עריכת השם» → поле «שם מלא».
2. Очистить поле; затем ввести только пробелы; затем ввести 65 символов.
3. Ввести «QA-AUTO-שם בדיקה» → «שמירה».
4. Reload `/profile`; открыть `/journey` и `/home`.
5. Уборка (finally): `/profile` → «עריכת השם» → «אקדא טסט» → «שמירה»; reload `/profile` и `/home`.
**Expected:**
- Пустое поле и только пробелы — «שמירה» неактивна (источник: ответ 28.09 ba9c188c).
- 65 символов — «השם ארוך מדי: אפשר עד 60 תווים.», «שמירה» неактивна (источник: тот же ответ).
- После сохранения: «שם מלא: השינוי נשמר.»; новое имя в шапке профиля, буква аватара «Q», «פרטי ההרשמה → שם מלא», в «המסע שלי» и на главной («… QA-AUTO-שם בדיקה»); после reload сохраняется (источник: PR-02 «Ожидаемо»).
- После возврата везде снова «אקדא טסט» (источник: PR-02 «Ожидаемо»).
