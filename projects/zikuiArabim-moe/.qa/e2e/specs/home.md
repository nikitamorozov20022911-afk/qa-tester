#### 7.1 HM-01 Главная: приветствие с именем, дата, ближайшая молитва, счётчики, навигация из 5 табов #6a86f7ea @prod-safe
**Device:** all (390 и 1440 — без пометки)
**Users:** user1
**Steps:**
1. Открыть `/home`.
2. Проверить шапку, карточку молитвы, счётчики, секции, нижнюю навигацию.
3. Нажать «התחל תפילה»; вернуться на `/home`.
4. По очереди нажать каждый таб нижней навигации.
**Expected:**
- Имя пользователя «אקדא טסט» (не e-mail) рядом с аватаром и в приветствии по времени суток (источник: 207781fc0813).
- Еврейская дата «… תשפ״ז» и окно молитвы формата `HH:mm - HH:mm` (источник: 64c76883f464; F-98 AC1, AC2).
- Название ближайшей молитвы + «נוסח …»; «התחל תפילה» → `/prayer/<key>` этой молитвы (при נוסח אשכנז — напр. `/prayer/mincha_ashkenaz`) (источник: F-98 AC3, AC6).
- 3 счётчика «ימים רצופים», «תפילות היום», «סה״כ תפילות» с числами (источник: F-98 AC5).
- Блоки «תזכורות מהירות» и «תאריכים חשובים» видны (источник: HM-01 «Ожидаемо»).
- Табы ровно 5: «תהילים», «תפילות», «בית» (по центру, выбран), «המסע שלי», «ברכות» → `/tehilim`, `/prayers`, `/home`, `/journey`, `/blessings` (источник: правка требования 23.09 в 8e651941580c и реджект 29.09 в 65fa18912a83).

#### 7.3 HM-03 Окно времени под датой (вверху слева); тег важной даты еврейский #6a86f7e5 @prod-safe
**Device:** all (390 и 1440 — без пометки)
**Users:** user1
**Steps:**
1. Открыть `/home`: `getBoundingClientRect` еврейской даты, окна времени `HH:mm - HH:mm` и строки «נוסח …».
2. Блок «תאריכים חשובים»: прочитать тег карточки и вторичную строку.
**Expected:**
- Окно `HH:mm - HH:mm` под еврейской датой в левом верхнем углу (top окна > top даты, окно у левого края), а не под «נוסח …» (top окна < top «נוסח …») (источник: реджект rej_1789394826147; на 390: дата y≈10, окно y≈30, «נוסח אשכנז» y≈236).
- Тег карточки — еврейский месяц/день (напр. «תשרי / י״ט», «אייר / ט׳»), григорианская дата — вторичной строкой (источник: тот же реджект).
