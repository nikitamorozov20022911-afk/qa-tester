#### 1.1 PM-01 Переключатель «יחיד/מניין» вверху, по умолчанию «יחיד», выбранный отмечен не только цветом #6a86f7e7 @prod-safe
**Device:** all (mobile 390×844 и desktop 1440×900 — без пометки)
**Users:** user1
**Steps:**
1. Открыть `/prayer/shacharit_sfarad`.
2. Нажимать «קודם», пока счётчик не покажет «1 מתוך 57».
3. Посмотреть верх экрана под счётчиком «X מתוך N»: найти `role=radio` «יחיד» и `role=radio` «מניין».
4. Нажать «מניין».
5. Нажать «יחיד».
**Expected:**
- Два варианта «יחיד» / «מניין» вверху экрана, под счётчиком (источник: F-103 описание; AC3).
- По умолчанию выбран «יחיד»: `role=radio` «יחיד» имеет `aria-checked=true`, «מניין» — `aria-checked=false` (источник: F-103 AC4). Если в сохранённой сессии режим уже «מניין» — тест сначала проверяет значение по умолчанию в чистом localStorage.
- Выбранный вариант: золотой фон + жирный шрифт (Discovery_Fs-Bold) + `aria-checked=true`, другой — `aria-checked=false` и обычный шрифт (источник: реджект «המצב הנבחר מוצג בצבע בלבד»).
- После шага 4: «מניין» `aria-checked=true`, «יחיד» `false`; после шага 5 — обратно «יחיד» `true`, «מניין» `false` (источник: тот же реджект).
