# Z2-03: подписи нижней навигации не рвутся внутри слова в зуме 200%
- Фича/экран: зум 200% · нижняя навигация (תהילים, תפילות, בית, המסע שלי, ברכות)
- Тикеты: #d73fd4
- Роль/аккаунт: Android — вошедший аккаунт телефона (09.11 «QA reg 0311»); веб — user1 (.qa/auth/user1.json)
- Устройство: Android Pixel 6, `adb shell wm density 840` (≈205dp, шрифт устройства 1.15) — основное; веб — viewport 195×422 (эквивалент 200% для 390)
- Тип: визуал
- Предусловия: приложение открыто и вошло. Android: `adb shell wm density 840` → приложение перерисовалось. **В конце всегда** `adb shell wm density reset` и проверить `adb shell wm density` — только «Physical density: 420».
## Шаги
1. Android density 840 (веб: viewport 195).
2. По очереди сделать активной каждую вкладку: «תהילים», «תפילות», «בית», «המסע שלי», «ברכות» (активная — жирная).
3. На каждом экране посмотреть все 5 подписей. 3 раза, в том числе после перезапуска приложения (активная «תפילות» рвалась «תפילו / ת»).
4. Android: `adb shell wm density reset`.
## Ожидаемо
- Ни одна подпись — ни активная, ни неактивная — не разорвана внутри слова; «המסע שלי» может перейти на 2 строки только между словами; подписи не налезают друг на друга. (источник: AC #d73fd4 «תוויות הלשוניות בסרגל הניווט התחתון אינן נשברות באמצע מילה»)
