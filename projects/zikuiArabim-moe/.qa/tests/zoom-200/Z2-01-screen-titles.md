- Фича/экран: зум 200% · заголовки экранов (общая шапка): תפילות, זמני תפילות, תהילים ג׳, פרופיל אישי, שיעורי תורה, урок
- Тикеты: #63e34a
- Роль/аккаунт: Android — вошедший аккаунт телефона (09.11 «QA reg 0311»); веб — user1 (.qa/auth/user1.json)
- Устройство: Android Pixel 6, `adb shell wm density 840` (≈205dp, шрифт устройства 1.15) — основное; веб — viewport 195×422 (эквивалент 200% для 390)
- Тип: визуал
- Предусловия: приложение открыто и вошло. Android: `adb shell wm density 840` → приложение перерисовалось. **В конце всегда** `adb shell wm density reset` и проверить `adb shell wm density` — только «Physical density: 420».
## Шаги
1. Android density 840 (веб: viewport 195).
2. Открыть «תפילות» (вкладка), «זמני תפילות» (главная → «זמני התפילות של היום»; веб /zmanim), «תהילים ג׳» (веб /tehilim/3), «פרופיל אישי» (имя в шапке главной; веб /profile), «שיעורי תורה» («תפילות» → карточка; веб /lessons) и любой урок (веб /lessons/<item>).
3. На каждом посмотреть заголовок в шапке.
4. Android: `adb shell wm density reset`.
## Ожидаемо
- Заголовок виден целиком, без «…», внутри экрана; если не помещается — переносится на 2 строки только между словами («זמני / תפילות», «שיעורי / תורה»). (источник: AC #63e34a «הכותרת של /prayers, /zmanim, /tehilim/[chapter] ו-/profile מוצגת במלואה ואינה נחתכת לשלוש נקודות»)
