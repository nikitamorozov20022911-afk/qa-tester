# ZM-01: Строки זמנים — имя + час рядом, полное название метода, без переносов

- Устройство: 320, 360, 390, desktop 1440
- Тип: позитив · визуал · регресс реджектов 1–4
## Шаги
1. Открыть /zmanim.
2. Найти «בין השמשות», «צאת הכוכבים (רבנו תם…)», «סוף זמן קריאת שמע (מג״א, 72 דקות)».
## Ожидаемо
- Каждая строка: имя זמן + час рядом; при нескольких שיטות — каждая с названием.
- «בין השמשות» + на второй строке тем же шрифтом полное «(רבנו תם, 13.5 דקות לפני 7.083°)» — не сокращено до «(ר״ת)» (реджект 4); «(7.083°)» в правильном направлении (реджект 3).
- «סוף זמן קריאת שמע (מג״א, 72 דקות)» в одну строку (реджект 1); названия не переносятся; нет горизонтальной прокрутки.
