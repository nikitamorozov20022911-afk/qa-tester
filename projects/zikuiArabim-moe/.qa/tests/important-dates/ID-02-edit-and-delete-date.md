# ID-02: Карандаш → правка (имя, дата, тип) → сохранить → удалить с подтверждением
- Фича/экран: «לוח תאריכים אישי ואזכרות» AC2
- Тикеты: 6a86f7e6d81dc311e455cfae (реджект 27.09 п.4); дубли 7b04425bf1e17c4a007962ec, 6a86f7dc50c11941ed276057
- Роль/аккаунт: user1
- Устройство: mobile 390
- Тип: позитив · @data (запись QA-AUTO- создаётся и удаляется)
## Шаги
1. Создать «תאריך חשוב» «QA-AUTO-היום» на сегодня (как в RM-04).
2. Карандаш → окно «עריכת תאריך»: проверить заполненные поля, радио типа; сменить имя на «QA-AUTO-מחר» и день → «שמירת השינויים»; reload.
3. Карандаш → переключить тип на «אזכרה» (не сохранять) → проверить поля.
4. «מחיקת התאריך» → окно → «מחיקה»; reload /home и /profile.
## Ожидаемо
- Окно правки: заголовок «עריכת תאריך», radio «תאריך חשוב»(checked)/«אזכרה», имя подставлено, выбранный день отмечен, кнопки «שמירת השינויים» и «מחיקת התאריך».
- После сохранения — новое имя и новая дата в «תאריכים חשובים» после reload.
- Тип «אזכרה» в правке: поле становится «שם הנפטר», появляется «הפטירה הייתה אחרי השקיעה»; будущий день → «תאריך הפטירה לא יכול להיות בעתיד.», «שמירת השינויים» неактивна.
- Удаление: «למחוק את התאריך?» / ««<имя>» יימחק מהתאריכים החשובים שלך, ואי אפשר יהיה לשחזר אותו.» / «ביטול» / «מחיקה»; после — записи нет на /home и /profile.
