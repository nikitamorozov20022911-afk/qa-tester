## Шаги
1. Медленная загрузка: до перехода `page.route('**/rest/v1/personal_commitments**')` — GET задержать на 4–5 с, затем пропустить (`route.continue()`); прочие методы не трогать. Открыть /journey; пока видна «טוענים את הקבלה האישית…» — раскрыть «מקבל על עצמי». Следить за запросами POST/PATCH/DELETE к personal_commitments.
2. Не трогая поле, дождаться конца загрузки.
3. Ошибка загрузки: GET personal_commitments → `route.abort()`. Открыть /journey, раскрыть «מקבל על עצמי». Снять блокировку (пропускать GET) → «נסו שוב».
4. (@data) Как в шаге 1 открыть карточку во время загрузки → дождаться «test» в поле → сразу «שמירה» → reload. Уборка: если после reload не «test» — ввести «test» → «שמירה» → reload.
5. Пустая קבלה: GET personal_commitments → ответ `[]` (`route.fulfill`). Открыть /journey.
## Ожидаемо
- Во время загрузки: строка «טוענים את הקבלה האישית…» над полем; textarea недоступна (`disabled` или `readOnly`), «שמירה» `aria-disabled="true"`; «הסרת הקבלה» нет; клик по «שמירה» не шлёт POST/PATCH/DELETE.
- После загрузки поле само (без повторного раскрытия) показывает «test», не placeholder; поле и «שמירה» становятся доступны; появляется «הסרת הקבלה».
- Ошибка: «הקבלה האישית לא נטענה. נסו שוב בעוד רגע.» + кнопка «נסו שוב»; поле с текстом не показывается (нельзя сохранить пустое). После «נסו שוב» — «test».
- «שמירה» сразу после загрузки не стирает: после reload «test», не «עדיין לא הגדרת קבלה אישית.».
- Пустая: «עדיין לא הגדרת קבלה אישית.»; «הסרת הקבלה» скрыта; после раскрытия поле пустое с placeholder «מה אני מקבל על עצמי», без сообщения об ошибке.
- «הסרת הקבלה» только очищает поле, удаление — только «שמירה» (подробно — JR-04).
