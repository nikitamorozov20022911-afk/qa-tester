# AD-07: Загрузка MP3 для молитвы, воспроизведение у пользователя, удаление
- Фича/экран: ממשק ניהול — «הקלטת התפילה (MP3)» + «האזן להקראה» у пользователя
- Тикеты: #a5decf4a · a5decf4a9de744b22c38c93f
- Роль/аккаунт: admin + user1
- Устройство: mobile 390
- Тип: позитив · ТОЛЬКО ВРУЧНУЮ (загрузка файла на прод; запись видна всем пользователям)
- Предусловия: тестовый MP3 (сгенерированный), удалить после проверки.
## Шаги
1. admin: молитва (напр. שחרית ספרד, מנחה אשכנז) → «מקור ההקלטה» → «העלאת קובץ MP3».
2. user1: открыть эту молитву → «השמע» на первом, среднем, последнем קטע; соседние молитвы — без записи.
3. Повреждённый файл (bad.png/bad.pdf) → ошибка.
4. admin: удалить запись → подтверждение.
5. user1: молитва снова «אין הקראה לקטע הזה».
## Ожидаемо
- После загрузки у пользователя «השמע» активна и играет; источник записи под кнопкой; у других молитв записи нет (источник: «קובץ האודיו… משויך לתפילה/קטגוריה המתאימה ולשמש להשמעת התפילה»).
- Без записи — «אין הקראה לקטע הזה», «השמע» неактивна (F-91 AC4) — автотест GP-08 (только чтение).
