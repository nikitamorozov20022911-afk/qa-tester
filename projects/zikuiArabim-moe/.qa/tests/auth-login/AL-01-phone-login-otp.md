## Предусловия
- Гость (выйти из аккаунта). С 28.10 вход только реальным SMS (Pulseem) — код из SMS вводит человек (@manual-otp); тестовый OTP из .qa/accounts.env работает, только если его длина = 6 и номер — тестовый в Supabase.
- Автотесты: app-e2e/specs/auth-login/al-01-phone-login-otp.e2e.ts (шаги 1–3, 6), app-e2e/specs/qa-0311/q-21…q-23 (шаги 4–5, офлайн, resend).
## Шаги
1. Открыть /. Нажать «בואו נתחיל».
2. На /phone поле «מספר נייד» (#phone-input) заполнено мокапом 0501112233 — очистить, ввести 0501112243.
3. Проверить текст «כניסה דרך מספר נייד», «לקבלת קוד הזן את מספר הנייד שלך», ссылки «תנאי השימוש» и «מדיניות הפרטיות» (две отдельные).
4. Нажать «שילחו קוד אימות» (Pixel 6: сначала спрятать клавиатуру) → экран «קוד אימות»: «הכנס את שש הספרות שקיבלת בנייד», «הקוד בן שש הספרות נשלח למספר <введённый номер>», 6 клеток «ספרה N מתוך שש», «שלח קוד מחדש», нет строки «מצב בדיקה».
5. Ввести неверный код (111111) → «שלח» → «הקוד שהוזן אינו נכון. בדקו את שש הספרות שקיבלתם והזינו שוב, או בקשו קוד חדש.», остаёмся на экране кода, цифры не стёрты (подробно — AL-06).
6. Ввести верный код из последнего SMS → главная («בית»).
## Ожидаемо
- Шаги 1–3: /phone, поле с мокапом очищается, два отдельных линка на документы (F-88 AC2, F-80; L-20261003-2).
- Код **6 цифр** (6 клеток, тексты «שש הספרות») — согласованное отличие от «ארבע ספרות» в F-88 AC1 / S-11 AC3 / Figma (context.md 26.10); экран говорит, на какой номер отправлен код (F-39 AC1, F-88 AC3); есть видимая «שלח קוד מחדש» (F-88 AC5, F-39 AC4); неверный код — ошибка на иврите без ухода с экрана (F-88 AC4); обходного режима нет (реджект #41747e).
- После верного кода — /home (9fed4f69d553).
