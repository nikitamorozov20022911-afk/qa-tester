## Технические заметки
- 2026-10-28: Android Pixel 6 (adb serial 1A151FDF6007QZ, 1080×2400) — управление adb + uiautomator dump (хелпер scratchpad at.py: tap по text/desc). На экране кода «שלח» закрыта клавиатурой — сначала KEYCODE_BACK, но не после перехода экрана (BACK уводит назад). adb input text не вводит иврит. Вход теперь только реальным SMS (Pulseem) — без рабочего SMS войти нельзя.
- 2026-10-26: на iPhone ошибка Appium «xcodebuild failed with code 65» после пересборки WDA = не доверен сертификат разработчика (пользователь: Настройки → Основные → VPN и управление устройством → «Доверять»). Админка: удаление קטע с MP3 (утверждённой или «לא תואמת») теперь черновик → после «אישור ופרסום השינוי» удаляется вместе с записью (#544d9c). Текст вне сезона פרקי אבות: «…הסימון יחזור בשבוע של השבת הראשונה שאחרי פסח.» (#70ef78).
- Вход: / → «בואו נתחיל» → /phone (поле «מספר נייד», кнопка «שילחו קוד אימות») → экран OTP. Тестовый OTP — только в .qa/accounts.env.
- На /phone поле телефона заранее заполнено мокап-номером — это не баг. В тестах очищать поле и вводить номер нужного аккаунта (user1/user2).
- В этом проекте `#hash` (8 символов) НЕ уникален: задачи создавались пачкой, 48 коллизий (напр. #6a86f7ed — 3 тикета). Перед действием на доске сверять #hash + заголовок (и полный id из выгрузки).
- Сессии приложения (Supabase): access-token живёт 1 час, но в localStorage есть refresh-token — приложение само продлевает сессию при открытии. Refresh-token одноразовый (ротация): после работы в браузере под ролью ПЕРЕСОХРАНЯТЬ .qa/auth/<role>.json (storageState), иначе файл устареет. Переключение user1↔user2 в одном браузере — подменой localStorage из файла, затем пересохранить. Срок самого токена (1 ч) — настройка Supabase проекта, мы её не меняем.
- ВАЖНО: один refresh-token нельзя подставлять повторно (Supabase reuse detection отзывает всю сессию → нужен новый вход по коду). После каждого использования сессии сразу пересохранять .qa/auth/<role>.json и восстанавливать только из самого свежего файла; для подмены даты — брать текущий localStorage, а не старый файл.
- Напоминания (generate_reminders): с фикса #3cc72778 (c695450, 2026-10-04) каждый запуск пишет напоминания на p_day и УДАЛЯЕТ строки других дней, а приложение перезапускает генератор при возврате к уже показанному дню → порядок дат при подмене часов любой (старый артефакт «перемотка вперёд ломает прошлые даты» больше не воспроизводится). После подмены часов один раз открыть /home на реальном времени (в автотестах — restoreTodayReminders из _helpers/reminders.ts), чтобы в аккаунте были напоминания на сегодня.
- Проверка других дат: подмена часов браузера (page.clock.setFixedTime) + в копии токена в localStorage сдвинуть expires_at на fake+1ч (иначе приложение разлогинит). Сервер проверяет токен по реальному времени. После — вернуть часы (setSystemTime(now)+resume) и исходный localStorage.
- Есть регистрация: ссылка «הצטרפו אלינו» на /phone.
- (2026-10-04, обновлено после #22c9d541) Окно «עלית דרגה — המשך כך» на /journey: признак показанного уровня хранится в аккаунте (user_profiles.last_announced_rung, у user1 = 10) и на устройстве (localStorage `journey`). После нового входа (qa-login:manual) окно больше НЕ появляется — закрывать его и пересохранять user1.json не нужно. suppressMilestoneWindow в автотестах остаётся страховкой для подменённых ответов и тестов, завершающих молитвы.
