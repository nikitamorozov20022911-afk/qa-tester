# ZIXE — находки для тикетов в Mifrat

Статус: **ждём доступ к Mifrat**. Когда появится — открыть тикет на каждую строку ниже (тексты тикетов на иврите, по правилам qa-verdict), приложить скриншоты из `.qa/screenshots/`, перед созданием проверить дубли. После создания — проставить номер тикета в колонку «Тикет».
Подробности шагов по номерам «#N» — в `.qa/bug-report-2026-11-05.md`. Окружение всех находок — TEST, Android, версия 1.0.5.

Серьёзность: 🔴 критично · 🟠 важно · 🟡 средне · ⚪ мелочь

## Решения клиента (не тикеты — вопросы)
- Meta Ads: показывать ли статистику рекламы (нужен `ads_read`/Insights + App Review); реальная публикация пока не реализована.
- Автоподтверждение записей с публичной страницы — оставить или сделать подтверждение владельцем.
- Выбор эквайера (Cardcom / Tranzila / Grow / PayPlus…) для оплаты клиентами и Apple/Google Pay.
- Подписка в iOS (In-App Purchase обязателен для цифровой услуги).
