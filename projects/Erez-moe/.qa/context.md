## Правила и уроки этого проекта
- Никогда не нажимать «איפוס מלא של העסק», «הגדרות העסק» (мастер без выхода), не проводить реальные платежи, не выходить из аккаунта.
- Кнопка «Назад» Android закрывает приложение — не использовать для закрытия шторок.
- Автозакрытие шторок по дереву элементов ненадёжно (в дереве остаются старые кнопки): закрывать по координатам со снимком после каждого шага. Один раз так открылся WhatsApp (ничего не отправлено).
- Нагрузку с одного компьютера ограничивает канал (~5 МБ/с) — указывать в отчётах. Создавать записи можно (разрешение пользователя), с пометкой QA-LOAD.
- Данные устройства — только в `~/.qa-tester/devices.md`, не в `.qa/`.
