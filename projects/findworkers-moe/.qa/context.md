## Технические заметки
- iPhone + Appium: после переподключения кабеля/нового дня — «Code=41 Not authorized for UI testing» или «Timed out while enabling automation mode». Лечится: пользователь выключает/включает Настройки → Для разработчика → UI Automation (телефон разблокирован), затем завершить процесс WebDriverAgentRunner-Runner (`xcrun devicectl device info processes` → `device process terminate --pid`) и создать сессию заново (2026-11-02/03).
- iPhone + Appium: `tap "<label>"` по кнопкам «Go back»/«סגור» иногда не срабатывает (попадает в контейнер) — жать по координатам центра кнопки.
- С 2026-10-07 тесты — на реальных телефонах по кабелю: Android + iPhone 17 (iOS 26.6.1), управление через Appium. Эмулятор Pixel_7 — запасной вариант.
- Инструмент автотестов для регресса пользователь оставил на выбор QA (2026-10-07): Appium + WebdriverIO (один стек для реальных Android и iPhone; Maestro не умеет полноценно работать с реальным iPhone). Пункт про Maestro ниже — устарел. Регресс: `.qa/appium/` (mocha + webdriverio; данные устройств — только в ~/.qa-tester/devices.json).
- Эмулятор: AVD Pixel_7 (Android 13, Google Play). На этом Intel-маке запускать так: `~/Library/Android/sdk/emulator/emulator -avd Pixel_7 -gpu swiftshader_indirect -no-snapshot` — без `-gpu swiftshader_indirect` чёрный экран и adb «offline». Первая загрузка ~2–3 мин, может выскочить «System UI isn't responding» → Wait.
- Автотесты: **Maestro** (решение пользователя 2026-10-03), workspace `.qa/maestro/` (config.yaml, flows/, subflows/login-otp.yaml). Playwright (.qa/e2e) к нативному UI неприменим — каркас остался от шаблона, не использовать для регресса.
- «מפרט»: פרסונות (0), תהליכים (0), модулей нет, все 16 пунктов — «תכונה». Почти все AC отсылают к Figma.
