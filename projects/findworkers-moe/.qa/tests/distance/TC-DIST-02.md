## Ожидаемо
Чип вида «NN.N KM», не «3.5 KM» и не `--- KM`; значение 84–88 (ожидаемо 85.7 — по прямой, haversine по центрам городов; реджект 3 закрыт как «не дефект», маршрут по дороге ~101 км НЕ является ожиданием). Число в профиле = числу в строке поиска для того же человека (проверено вручную 26.10: טסט טסט 94.0 = 94.0).
