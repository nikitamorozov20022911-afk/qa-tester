# TC-DIST-01: поиск работников на иврите — в строках реальное расстояние, нет «3.5 KM»
- Фича/экран: חיפוש → «עובדים» → выдача (F-11 «חישוב והצגת מרחק», S-07)
- Тикеты: #ad36ca (6a6215b61ff760b468ad36ca)
- Роль/аккаунт: свой (iPhone — נקיה מורוזוב, באר שבע, id 140; Android — Alina Alina, בת ים, id 146)
- Устройство: iPhone 17 (1.0.78), Pixel 6
- Тип: позитив, @prod-safe (только чтение)
## Шаги
1. חיפוש → «עובדים» → запрос «פועל כללי» (иврит)
2. Посмотреть чипы расстояния в строках выдачи
## Ожидаемо
Ни в одной строке нет постоянного «3.5 KM»; хотя бы у одной строки реальное число «NN.N KM» (не у всех `--- KM`). `--- KM` допустим только у пользователей без города. Источник: тикет «מה קיים», реджект 1, реджект 4 («בכל חיפוש – בעברית… שורת התוצאה מציגה את אותו מרחק שמוצג בפרופיל»).
