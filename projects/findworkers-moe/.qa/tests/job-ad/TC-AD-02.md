# TC-AD-02: форма публикации — город обязателен, проверка суммы
- Фича/экран: פרסם → מודעת דרוש עובד/שירות
- Тикеты: #7c30a0f9 (реджект 1)
- Тип: негатив / граница
## Шаги
1. Выбрать «יומי», сумму не вводить → «פרסם מודעה»
2. Сумма 0 / 100001 / 1.5 / -5
3. Очистить «מיקום העבודה» → «פרסם מודעה»
## Ожидаемо
1) «הזינו סכום»; 2) «סכום בשקלים שלמים, בין 1 ל-100,000»; 3) публикация блокируется «חובה למלא את השדה» (место сообщения — под «מיקום העבודה», исправлено в #5a3976, см. TC-AD-04).
