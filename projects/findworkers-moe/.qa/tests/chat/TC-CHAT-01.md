# TC-CHAT-01: клавиатура в чате закрывается одним тапом, поле ввода внизу
- Фича/экран: צ'אט (экран переписки)
- Тикеты: #6a8560fb
- Роль/аккаунт: iPhone = נקיה מורוזוב, Android = Alina Alina (переписка только между ними)
- Устройство: iPhone 17 (iOS 26), Pixel 6 (Android 16), сборка 1.0.77
- Тип: позитив
- Предусловия: оба аккаунта залогинены, есть чат между ними
## Шаги
1. חיפוש → «עובדים» → найти собеседника → иконка чата в карточке
2. Тап по полю ввода → клавиатура открыта, поле вплотную над клавиатурой
3. Один тап по пустому месту между сообщениями → клавиатура закрыта, поле внизу
4. Повторить шаги 2–3 10 раз
## Ожидаемо
Клавиатура закрывается с первого тапа 10/10, поле возвращается к нижнему краю (источник: «מה רצוי» тикета).
