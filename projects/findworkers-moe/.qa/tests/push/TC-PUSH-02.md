# TC-PUSH-02: push о новом сообщении iPhone → Android, получатель — фон
- Фича/экран: Push-уведомление о новом сообщении в чате (системный баннер / шторка / экран блокировки)
- Тикеты: #aaeb71 (6a60d51d27f90c73a1aaeb71), реджект 1, 2
- Роль/аккаунт: отправитель iPhone = נקיה מורוזוב (140), получатель Android = Alina Alina (146) (переписка только между ними)
- Устройство: Pixel 6 (Android 16) + iPhone 17 (iOS 26.6.1), сборка 1.0.78
- Тип: позитив · полуавто: проверка прихода на Android — автотест appium/tests/push-android.test.js (adb dumpsys notification), отправка с iPhone — вручную
- Предусловия: оба аккаунта залогинены; у получателя уведомления для приложения разрешены (Allow) и включены в настройках ОС; на iPhone выключен «Фокус»/«Не беспокоить»; чат נקיה↔Alina уже есть
## Шаги
1. Получатель (Android): Приложение получателя свёрнуто кнопкой «Домой» (в фоне), экран включён, не заблокирован
2. Отправитель: חיפוש → «עובדים» → найти получателя → «צ׳אט» → отправить сообщение `QA-AUTO push <состояние> <ЧЧММСС>`
3. Получатель: смотреть баннер / шторку до 1 мин
   (авто: `adb shell dumpsys notification --noredact` → запись pkg=com.yb.findworkers с android.text = отправленный текст)
## Ожидаемо
За ≤ 1 мин (в проверке 2–3 с) у получателя появляется push от приложения Find Workers: заголовок — имя отправителя («נקיה»/«נקיה מורוזוב»), текст — текст сообщения. Источник: реджект 1 «מה רצוי» (push «גם כאשר הוא אינו נמצא במסך הצ'אט»), реджект 2 «מה רצוי» (Android и iOS). Куда ведёт тап по push — в тикете не задано, не проверяется.
