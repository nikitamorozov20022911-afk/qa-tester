## Шаги
1. Получатель (iPhone): Приложение получателя выгружено: смахнуто из списка недавних (на Android в автотесте — «Домой» + `am kill`, НЕ force-stop: после force-stop Android сам блокирует доставку FCM)
2. Отправитель: חיפוש → «עובדים» → найти получателя → «צ׳אט» → отправить сообщение `QA-AUTO push <состояние> <ЧЧММСС>`
3. Получатель: смотреть баннер / шторку до 1 мин
## Ожидаемо
За ≤ 1 мин (в проверке 2–3 с) у получателя появляется push от приложения Find Workers: заголовок — имя отправителя («Alina»), текст — текст сообщения.
