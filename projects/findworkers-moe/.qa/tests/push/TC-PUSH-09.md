# TC-PUSH-09: свежая установка на Android + «Allow» → push приходит сразу, без перезапуска
- Фича/экран: Push-уведомление о новом сообщении; системный диалог разрешения уведомлений
- Тикеты: #aaeb71 (6a60d51d27f90c73a1aaeb71), реджект 1 (корень: getToken() вызывался, пока открыт диалог разрешения, fcmToken оставался пустым — коммент 29.09)
- Роль/аккаунт: получатель Android = Alina Alina (146), отправитель iPhone = נקיה מורוזוב (140)
- Устройство: Pixel 6 (Android 16) + iPhone 17 (iOS 26.6.1), сборка 1.0.78
- Тип: позитив · только вручную (сброс данных/переустановка и вход по OTP — не автоматизируем, новых аккаунтов не создаём)
- Предусловия: на получателе можно сбросить приложение; код OTP даёт пользователь
## Шаги
1. Получатель: `adb shell pm clear com.yb.findworkers` (или удалить и поставить сборку) → первый запуск → системный диалог разрешения уведомлений → «Allow» → вход Alina (OTP вводит пользователь)
2. Не перезапуская приложение, свернуть его (фон)
3. Отправитель: отправить в чат сообщение `QA-AUTO push fresh <ЧЧММСС>`
4. Получатель: ждать push до 1 мин
## Ожидаемо
Push приходит с первого раза после «Allow», без перезапуска приложения и без повторного входа: заголовок «נקיה», текст — текст сообщения. Источник: реджект 1 «מצב קיים/מה רצוי» (новый пользователь разрешил уведомления → должен получать push). Ветку «регистрация нового пользователя» заменяет сброс/переустановка + повторный вход (нового номера нет).
