# TC-VID-02: сбой загрузки видео (режим полёта) — понятная ошибка вместо вечной загрузки
- Тикеты: #5055f4 (6a9fc38e), реджект 2
- Роль: свой (Alina 146) · Устройство: Pixel 6 · Тип: негатив, только вручную (режим полёта в автотест не включаем)
## Шаги
1. Начать загрузку видео в профиль
2. Включить режим полёта
## Ожидаемо
Через ~1 мин лоадер закрывается, показано «ההעלאה נכשלה» / «לא הצלחנו להעלות את הקובץ. נסו שוב מאוחר יותר.», вечной загрузки нет. После теста выключить режим полёта.
