# TC-VID-01: видео в профиле — загрузка, автозапуск, пауза/продолжение, удаление
- Фича/экран: «פרופיל» → блок медиа (плитка «+» видео) → полноэкранный плеер
- Тикеты: #5055f4 (6a9fc38e)
- Роль/аккаунт: свой профиль (Alina 146); просмотр — также чужой (נקיה 140)
- Устройство: Pixel 6 (≥ 1.0.78); iPhone не проверялся в этом цикле
- Тип: позитив, @data (загружает видео; удалить в конце)
## Предусловие
В галерее телефона есть видео с движением (13 с / ~3MB, метка длительности «00:13»); у аккаунта нет других видео в профиле.
## Шаги
1. Плитка «+» видео → Google Photos → Videos → выбрать ролик → Done
2. Дождаться конца загрузки
3. Открыть плитку видео
4. Тап по видео; ещё тап
5. Корзина → «למחוק את התוכן הזה?» → «מחק»
## Ожидаемо
2) загрузка ~15 с, лоадер закрывается, «ההעלאה נכשלה» нет, плитка видео появилась; 3) видео играет само; 4) первый тап — пауза (▶ по центру), второй — продолжение с того же места; 5) «התוכן נמחק», плитки нет. Источник — «מה רצוי» тикета + реджект 2.
