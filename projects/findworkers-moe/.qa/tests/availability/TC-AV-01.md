# TC-AV-01: экран «זמינות» — несколько статусов одновременно
- Фича/экран: нижняя навигация «זמינות» → «זמינות לעבודה/אספקת שירות», режим «רגילה»
- Тикеты: #732f80 (6a9ff813)
- Роль/аккаунт: свой (Android — Alina id 146)
- Устройство: Pixel 6 (≥ 1.0.78); iPhone не проверялся
- Тип: позитив, @data (меняет статус своего аккаунта; в конце вернуть как было)
## Шаги
1. Записать исходный `availabilityStatus` (GET /user/146)
2. Отметить «ייעוץ ראשוני טלפוני» и «זמין לעבודה מיידית» → «עדכן זמינות»
## Ожидаемо
Вторая опция не снимает первую; на сервере `availabilityStatus` = обе (`phone_consult,immediate_work`), `contactMethods` не изменились; в своём профиле видны оба статуса. Источник — «מה רצוי» тикета.
## Очистка
Снять все → «עדכן זמינות» → вернуть исходный набор (на 26.10 — null).
