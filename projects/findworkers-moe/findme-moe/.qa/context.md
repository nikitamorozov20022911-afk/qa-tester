## Правила проекта (важнее общих правил плагина)
- Обычный пользователь (user) — тестируем только на Android-телефоне по кабелю, в нативном приложении `com.trivoln.app`. Пользователь уже вошёл в приложение на телефоне.
- Admin / Super Admin / Support — тестируем только через веб (https://trivoln.expo.app, админка /admin). Данные аккаунтов заполнены в .qa/accounts.env.
- Тест на телефоне — в основной сессии, не фоном. Загружать внутри приложения можно; кросс-постинг — только с предупреждением, куда уходит пост.
- Пока только проверка фиксов тикетов. Регресс/автотесты из принятых тикетов («הושלם») пока НЕ делать, /qa-backfill не запускать.
- С какого тикета начать — скажет пользователь.
