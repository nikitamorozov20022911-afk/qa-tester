## F-02 — הרשמה והתחברות

- Номер в «מפרט»: нет
- mifrat id: `69fb11f7794420a02cf069b9`
- Модуль: תשתית

- Источник: «מפרט» → פיצ'רים → «הרשמה והתחברות» (get_feature_detail id `69fb11f7794420a02cf069b9`)

**Описание (תיאור):**

> פיצ'ר ליבה המנהל את כל ההיבטים של זיהוי המשתמש (Identity & Authentication) בפלטפורמת FindMe.
> הפיצ'ר מספק את התשתית הטכנית והעסקית להרשמה, להתחברות, לאימות, לאיפוס סיסמה, לניהול session, ולשמירה על אבטחת המשתמשים.
>
> הפיצ'ר תומך במספר שיטות הרשמה והתחברות:
> - **אימייל + סיסמה** - מסורתי, עם דרישות סיסמה חזקה.
> - **OAuth** - Google, Apple, Facebook (single sign-on).
> - **OTP טלפון** - שליחת קוד אימות ב-SMS.
> - **OTP אימייל** - שליחת קוד אימות באימייל.
> - **Magic Link** - קישור התחברות חד-פעמי באימייל.
> - **2FA / MFA** - אופציונלי לאבטחה מוגברת (TOTP, SMS).
>
> **מודל אבטחה:**
> - סיסמאות נשמרות מוצפנות (bcrypt / Argon2).
> - Session tokens עם JWT, refresh token mechanism.
> - Rate limiting לעצירת brute-force.
> - Account lockout אחרי 5 ניסיונות כושלים.
> - Audit log לכל פעולת התחברות (כניסה, יציאה, שינוי סיסמה).
> - IP-based anomaly detection.
> - תמיכה ב-device management (רשימת מכשירים מחוברים, אפשרות להתנתק מרחוק).
>
> **Recovery:**
> - שכחתי סיסמה - שליחת קישור איפוס באימייל (תוקף 1 שעה).
> - שכחתי ID - שחזור לפי אימייל / טלפון.
> - חשבון נחסם - תהליך פניה לשירות לקוחות.

**User Story:**

> "כמשתמש חדש או חוזר בפלטפורמת FindMe, אני רוצה תהליך הרשמה והתחברות פשוט, מהיר ובטוח - עם אפשרות להירשם דרך אימייל, OTP או OAuth (Google/Apple) - כדי שאוכל לגשת לפלטפורמה בקלות ובבטחה"

**AC:** AC нет

**Требования (דרישות):**

1. המשתמש רוצה תהליך להרשמה למשתמש שם id
2. ההרשמה כולל יוצר id חדש שלמשתמש שניתן לערכי
3. ההרשמה כולל אישור ה id במספר טלפון או אימייל
4. ההרשמה והתחברות יתנו אפשרות להתחבר עם מספר id והסיסמה, או עם התחברות otp עם מייל או טלפון נופל
5. תמיכה ב-OAuth (Google, Apple, Facebook) להרשמה מהירה
6. תמיכה ב-Magic Link - קישור התחברות חד-פעמי באימייל
7. Audit log לכל פעולת אימות (login, logout, שינוי סיסמה, MFA)
8. תהליך 'שכחתי סיסמה' - קישור איפוס באימייל עם תוקף שעה
9. תהליך 'שכחתי ID' - שחזור לפי אימייל / טלפון
10. תמיכה ב-multilanguage לכל הטקסטים והודעות
11. תאימות GDPR - אפשרות מחיקה מלאה של נתונים
