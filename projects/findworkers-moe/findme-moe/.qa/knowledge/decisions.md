## D-05 — MFA: обязательно только для сотрудников (противоречие фич 17 и 21)

- **Уточнение из QA-реджекта (resolved):** до завершения 2FA "ה־Sidebar לא יוצג או לא יהיה נגיש. כל פונקציות המערכת יהיו חסומות."
- **Влияет на:** «הרשמה והתחברות» (фича 17), «מסך ניהול משתמשים» (фича 21), вход в `/admin`.
- **Источник:** Task «פיתוח: MFA חובה לחשבונות צוות (staff) בפאנל הניהול» (`6a8a96c821e5a64ca7a411de`), description, AC, qa_rejections.

## D-10 — Admin не может управлять Super Admin

- **Тема:** права на чужие сотруднические аккаунты.
- **Статус:** принято (тикет `done`).
- **Решение (дословно, «מה רצוי»):** "1) אין להציג לו פעולות ניהול כגון חסימה, השעיה, איפוס סיסמה, שינוי סטטוס/חיפוש וכדומה. 2) כל השדות של ה־Super Admin צריכים להיות במצב קריאה בלבד. 3) לא צריכה להיות אפשרות לערוך, למחוק, לחסום, להשעות או לבצע כל שינוי אחר על משתמש Super Admin. 4) יש להסתיר גם את כפתורי הפעולה עצמם, ולא רק למנוע את הפעולה לאחר הלחיצה."

- **Источник:** Task «Panel Admin - אדמין רגיל רואה פעולות ניהול ויכול לערוך פרטי Super Admin…» (`6a8ffb0e8bf7df90e282158e`), description + comments.
