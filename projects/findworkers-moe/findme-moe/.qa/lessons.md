## L-20261012-1 · Экран «התחברות» — кнопка «назад» не нужна
- Правило: в TrivoLN на экране входа «התחברות» отсутствие кнопки «назад» (и выход из приложения системной «назад» при входе с приветственного экрана) — не дефект: с экрана есть путь «יצירת חשבון». Не реджектить и не заводить баг по этому поводу.
- Почему: «там не нужна кнопка назад так как есть кнопка "יצירת חשבון" в случае чего».
- Пример: #19aa1fac, пункт 5 реджекта от 01.10 — «התחברות» исключён из требования «назад на 5 экранах».
- Источник: сообщение пользователя, 2026-10-12
- Область: проект
- Статус: действует

## L-20261012-2 · Экран «ה-TrivoLN ID שלך» — стрелки «назад» быть не должно
- Правило: на экране выдачи TrivoLN ID после регистрации стрелки «назад» быть не должно (аккаунт уже создан, возврат на «יצירת חשבון» не имеет смысла). Наличие стрелки — дефект.
- Почему: «там где получаешь trivoln ID надо убрать стрелочку назад».
- Источник: сообщение пользователя, 2026-10-12
- Область: проект
- Статус: действует

## L-20261012-3 · RTL-проверки — один прогон
- Правило: для тикетов про RTL/вёрстку (визуальная сверка направления) достаточно одного прогона; повторный прогон (общий урок L-20261003-7) не нужен.
- Почему: «достаточно 1 ходки что бы сверить что РТЛ правильный».
- Пример: #6aa90d07, 2026-10-12.
- Источник: сообщение пользователя, 2026-10-12 · Область: проект · Статус: действует

## L-20261012-4 · Тесты на телефоне — не фоном
- Правило: тесты на реальном Android-телефоне вести в основной сессии, на виду (не отдавать фоновым агентам qa-tester/bug-verifier и не запускать в фоне).
- Почему: «на телефон тесты не делай фоновыми».
- Источник: сообщение пользователя, 2026-10-12 · Область: проект · Статус: действует

## L-20261012-5 · Ничего не загружать и не публиковать без отдельного «да»
- Правило: в TrivoLN не загружать медиа в профиль и не публиковать посты (в т.ч. в подключённые соцсети) самостоятельно. Проверять экраны, лимиты и ошибки до отправки; каждую реальную загрузку/публикацию — сначала показать пользователю и выполнить только после его «да» (потом удаление делает пользователь).
- Почему: «ничего пока не выставляй сам. мне надо будет потом удалить».
- Пример: #6a16cf42, #6a16cf41, #6a16cf3d, 2026-10-12.
- Источник: сообщение пользователя, 2026-10-12 · Область: проект · Статус: действует

## L-20261012-6 · Уточнение к L-20261012-5: загрузка внутри приложения — можно; кросс-постинг — с предупреждением
- Правило: загружать медиа/данные внутри самого приложения TrivoLN можно без отдельного вопроса. Публикацию через кросс-постинг во внешние соцсети — только с предупреждением заранее: в какие сети уходит пост (чтобы пользователь сразу удалил).
- Почему: «можешь выставлять если это в самом приложение но если будешь выставлять через кросс постинг в приложение то предупреждай меня куда что бы я потом сразу удалил».
- Источник: сообщение пользователя, 2026-10-12 · Область: проект · Статус: действует (заменяет L-20261012-5 в части загрузок в приложении)

## L-20261012-7 · Галерея «המדיה שלי» — скриншот перед КАЖДЫМ удалением
- Правило: порядок элементов в галерее «הועלו» меняется после каждого удаления. Удалять тестовые элементы по одному: скриншот → определить свой элемент по картинке → удалить → снова скриншот. Никогда не удалять несколько подряд по заранее вычисленным координатам.
- Почему: 2026-10-12 при чистке тестовых загрузок серией из трёх удалений удалена одна исходная картинка пользователя (космонавт) — порядок перемешался между удалениями.
- Источник: ошибка агента, 2026-10-12 · Область: проект · Статус: действует

## L-20261013-1 · Фичи, которых ещё нет в Android-сборке, — проверять на вебе
- Правило: если фича пользователя есть только на вебе (https://trivoln.expo.app), а в установленной Android-сборке её нет («בגרסה הבאה לחנויות»), проверять её на вебе под user, не ждать новую сборку. Исключение из правила «user — только на Android».
- Почему: «проверяй фид на вебе».
- Пример: #dc2c9a12 פיד, #6aa90e40 תיוג, 2026-10-13.
- Источник: сообщение пользователя, 2026-10-13 · Область: проект · Статус: действует

## L-20261022-1 · «N фото по счёту» = N-е по порядку, а не первые N
- Правило: когда пользователь говорит «возьми 6 фото по счёту», выбирать одно, шестое по порядку в галерее. Если неоднозначно — переспросить до выбора.
- Почему: «не все 6. а только 6 фото».
- Источник: сообщение пользователя, 2026-10-22 · Область: проект · Статус: действует

## L-20261022-2 · Тестировать в приложении, которое уже открыто на телефоне
- Правило: на реальном телефоне подключаться к уже открытому приложению (Appium без перезапуска, autoLaunch=false), не переустанавливать и не перезапускать его.
- Почему: «тесты делай в приложение которое щас открыта у мнея».
- Источник: сообщение пользователя, 2026-10-22 · Область: проект · Статус: действует

## L-20261101-1 · Новые тикеты — только на доске FindMe

- Почему: «если что новые тикеты открывай в find me и не в v2».
