Как читать:
- Текст из «מפרט» дословно, на иврите. Пояснения на русском — только служебные.
- «AC» — поле «דרישות» (demands) экрана, дословно, с номерами.
- «Состояния» — какие AC относятся к пусто / загрузка / ошибка / успех (ссылка на номер AC). «нет в «מפרט»» — такого состояния в AC нет.
- «Элементы/действия» — номера AC, описывающих элементы и действия экрана.
- «Роли» — персона из User Story и роли, названные в описании/AC. Отдельного поля ролей у экрана в «מפרט» нет.
- «Связи» — поле related_features экрана (тип связи: relates / blocks / blocked_by).
- В «מפרט» 0 пользовательских сценариев (flows) и 0 переходов между экранами — переходы известны только из текста AC.
- Тестируем веб https://magnet.expo.app/ в мобильном виде. Светлая тема (Figma №14) не реализована — не тестируем.
- Figma (общий файл): https://www.figma.com/design/lR2nkiJj5nafuSiXkRdGeR/Magnet?node-id=863-128 (Dev handoff).
