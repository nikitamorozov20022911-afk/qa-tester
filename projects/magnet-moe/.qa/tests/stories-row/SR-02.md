# SR-02: ряд сторис в «קהילה» — «הסטורי שלי» с «+» первым справа, чужие идут влево
- Фича/экран: ряд сторис на /social («קהילה», раньше «חדרים»)
- Тикеты: #b4decb (связан #c32a98)
- Роль/аккаунт: reg1 (в ленте есть сторис reg2)
- Устройство: mobile — iPhone (веб, 390; автотест — iPhone 13 Mini 375)
- Тип: позитив
- Предусловия: как SR-01
## Шаги
1. Открыть /social, дождаться ряда сторис («הסטורי שלי»).
2. Не прокручивая ряд, снять координаты элементов ряда и его стиль.
## Ожидаемо
- Ряд — `direction: rtl`, `scrollLeft` = 0 (начало справа).
- «הסטורי שלי» с «+» («סטורי חדש») — крайний правый, целиком в экране.
- Чужие сторис (если есть) — левее, x убывает по порядку.
