# SR-01: ряд сторис на «גילוי» — «הסטורי שלי» с «+» первым справа, чужие идут влево
- Фича/экран: ряд сторис (פס הסטוריז) на /discover
- Тикеты: #b4decb (связаны #576c2d, #795416, #c32a98)
- Роль/аккаунт: reg1 (в ленте есть сторис reg2)
- Устройство: mobile — iPhone (веб, 390; автотест — iPhone 13 Mini 375), тёмная тема
- Тип: позитив
- Предусловия: вход reg1 сохранённой сессией. Чужие сторис в ленте — желательно (если их нет, проверяется только положение «הסטורי שלי»)
## Шаги
1. Открыть /discover, дождаться ряда сторис (кнопка «הסטורי שלי»).
2. Не прокручивая ряд, снять координаты элементов ряда и его стиль.
## Ожидаемо
- Ряд (горизонтальный контейнер с «הסטורי שלי») — `direction: rtl`; начальная прокрутка — правый край (`scrollLeft` = 0).
- «הסטורי שלי» — крайний правый элемент ряда: его правый край правее всех остальных кружков, кружок целиком в экране; на нём кнопка «+» («סטורי חדש»).
- Чужие сторис (если есть) — левее «הסטורי שלי», каждый следующий левее предыдущего (x убывает); сторис reg2 — левее «הסטורי שלי».
