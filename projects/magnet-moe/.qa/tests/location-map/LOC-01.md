# LOC-01: шаринг выключен — объяснение перед включением, приложение работает без шаринга
- Фича/экран: карта /map (вкладка «מפה»)
- Тикеты: #2a31ff
- Роль/аккаунт: free (или user2) — share_location=false
- Устройство: mobile — iPhone 390×844 (геолокация эмулирована: Тель-Авив; реальная не используется)
- Тип: позитив
- Предусловия: шаринг у роли выключен
## Шаги
1. Открыть /map.
2. Посмотреть карточку состояния.
3. Перейти во вкладку «גילוי» и обратно.
## Ожидаемо
- Карточка «שיתוף מיקום כבוי» с объяснением, что раскроется («המפה מציגה רק מי שמשתפ/ת מיקום… המיקום הנוכחי שלך יוצג במפה למי שמתאימים/ה להעדפות שלך…»), кнопка «הפעלת שיתוף מיקום».
- Без нажатия кнопки запросов PATCH profiles share_location нет — местоположение не раскрывается.
- Остальное приложение доступно (вкладка «גילוי» открывается).
