# LOC-09: Карта «מיקום» при включённом шаринге сразу показывает «אני» на новом месте при входе, без выключения/включения (веб, эмулированная геолокация) (@data)
- Фича/экран: /map
- Тикеты: #6575d3 (связаны #736c37, #b2f39b)
- Роль/аккаунт: reg5 (шаринг ВКЛ)
- Устройство: веб 390×844 + эмуляция геолокации
- Тип: позитив (меняет данные: место)
- Предусловия: шаринг у reg5 включён; геолокация эмулируется (реальная не используется)
## Шаги
1. Контекст 1: геолокация Тель-Авив 32.0809,34.7806 → /map → дождаться «שיתוף מיקום פעיל».
2. Закрыть контекст. Контекст 2 (холодный): геолокация Or-Akiva 32.5067,34.9186, та же сессия → /map, тумблер не трогать.
3. Возврат: контекст 3 с Тель-Авив → /map.
## Ожидаемо
- В течение ≤ 10 с: «אני» на новых координатах, карта центрирована на них, карточки людей вокруг этого места.
- Уходит запрос обновления места (record_location) сразу при входе, не через минуту; тумблер остаётся ВКЛ.
- Возврат состояния: после шага 3 место снова Тель-Авив, шаринг ВКЛ как было.
