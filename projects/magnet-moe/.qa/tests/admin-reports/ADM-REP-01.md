# ADM-REP-01: смена вкладки פתוחים / הוסלמו / סגורים — сразу выделение и каркас загрузки, без старого списка
- Фича/экран: админка · /reports (вкладки статуса)
- Тикеты: #06e5ab
- Роль/аккаунт: admin (auth/admin.json), https://magnet-admin.vercel.app
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: есть жалобы во всех 3 вкладках (10.11: 16 / 3 / 20)
## Шаги
1. /reports (вкладка «פתוחים»), дождаться списка.
2. Задержать ответ с данными вкладки (перехват запроса), нажать «סגורים».
3. Пока ответ задержан — проверить вкладку и область списка; отпустить ответ.
4. Повторить для פתוחים→הוסלמו и סגורים→פתוחים.
## Ожидаемо
- Нажатая вкладка выделена сразу (aria-selected/активный вид) до прихода данных.
- Область списка в состоянии загрузки: каркас (skeleton) с aria-busy="true"; строк жалоб прежней вкладки нет.
- После ответа — список новой вкладки, aria-busy снят; адрес содержит status новой вкладки.
- (источник: AC 11 «מציג מצב טעינה בזמן שליפת הדיווחים»; реджект 08.11 «סבב QA 7: אין מצב טעינה במעבר בין הלשוניות»)
## Заметки
- Находки r8 (не требование): каркас при первом входе (1 блок) ≠ каркас при смене вкладки (3 колонки); назад/вперёд в WebKit 0.2–0.5 с прежний список без каркаса, итог верный.
