# SC-03: Приложение: публикация сторис при запрещённом доступе к «Фото», в авиарежиме (ручной, iOS)
- Фича/экран: создание сторис в приложении
- Тикеты: #f54d1d
- Роль/аккаунт: user4 / reg5 (iPhone 17)
- Устройство: iOS build 11
- Тип: позитив/негатив
- Предусловия: настройки телефона меняет пользователь; изображение на телефоне — не из личной галереи
## Шаги
1. Настройки → Magnet → Фото → «Нет» → гилуй → «הסטורי שלי» (+) → галерея открывается → публикация.
2. Авиарежим → «לפרסם» → причина + «לנסות שוב».
## Ожидаемо
- Галерея открывается без запроса разрешения; «הסטורי פורסם»; в авиарежиме — причина и «לנסות שוב».
- Не автоматизируется: системные настройки и режим полёта телефона. Проверено вручную на iOS build 11.
