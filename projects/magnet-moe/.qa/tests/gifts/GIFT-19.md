# GIFT-19: экран «שליחת מתנה» (платный подарок «דובי פרחים»): превью, карточка «מתנה מ־…», поле сообщения 0/140, чипы-подсказки, цена на кнопке (без оплаты)
- Фича/экран: чат/профиль → 🎁 → магазин → «דובי פרחים» → «שליחת מתנה»
- Тикеты: #47a8b8 (AC 1–6, 9; пункт 7 — оплата, см. GIFT-22)
- Роль/аккаунт: new02 «QA П2 0011» → «בדיקה כללי» (new10) (автотест); веб-проверка r13 — new02/new01 → user4
- Устройство: веб 390 + iOS (build 12)
- Тип: позитив
- Предусловия: чат с получателем есть; кнопку отправки НЕ нажимать в автотесте.
## Шаги
1. Чат → 🎁 → «דובי פרחים».
2. Посмотреть экран; нажать чип-подсказку; ввести длинный текст (>140).
3. Стрелка «назад».
## Ожидаемо
- Заголовок «שליחת מתנה»; «כך <имя> תראה/יראה את זה»; подпись-превью «<отправитель> שלח/ה לך מתנה»; карточка «מתנה מ־<отправитель>» с названием «דובי פרחים».
- Поле «הוסף הודעה (לא חובה)» со счётчиком «0/140»; чип подставляет текст в поле, счётчик = длине текста; ввод ограничен 140 («140/140»).
- Пояснения: «<имя> תקבל/יקבל התראה, וההודעה שלך תופיע אצלו/אצלה ראשונה» и «מתנה וירטואלית: מופיעה באפליקציה בלבד, בלי פריט פיזי».
- Кнопка «שליחת מתנה • ₪7.90» (у платного подарка цена видна до подтверждения; «חינם» только у наградных при гранте).
- Назад — выход с экрана, запросов `/rpc/send_gift` нет.
