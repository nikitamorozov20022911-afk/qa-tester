# SV-08: ответ на сторис: поле «תגובה ל<имя>…», Enter, ответ уходит той сторис, на которой начали печатать; автор видит его в чате
- Фича/экран: S-17 «מסך צפייה בסיפור» (/story/<id>), вход из ряда сторис на /discover
- Тикеты: #f71f8d (связаны #24d071, #a85b92, #714b7a)
- Роль/аккаунт: reg1 → user2 (мэтч 8571b9f7)
- Устройство: mobile — iPhone 13 Mini (WebKit, 375×629), тёмная тема
- Тип: позитив
- Предусловия: у user2 активная сторис QA-AUTO
## Шаги
1. Открыть сторис user2.
2. Запомнить показанную сторис, медленно напечатать «QA-AUTO …» (дольше длительности сторис).
3. Enter.
4. У user2 открыть чат с reg1.
## Ожидаемо
- Поле с плейсхолдером «תגובה ל<имя автора>…» (AC 5).
- POST story_replies 201: story_id = сторис, на которой начали печатать (таймер на паузе при вводе — наблюдение 29.10), to_user_id = автор, body = текст (AC 6).
- Тост «התגובה נשלחה לצ'אט».
- user2 видит текст в чате «הגיב/ה לסטורי שלך».
- Очистка: ответ удалить нельзя (RLS story_replies) — в список чистки.
