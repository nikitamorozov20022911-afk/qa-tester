# SV-01: открытие из ряда сторис: загрузка (спиннер, прогресс стоит) → содержимое и автор
- Фича/экран: S-17 «מסך צפייה בסיפור» (/story/<id>), вход из ряда сторис на /discover
- Тикеты: #f71f8d (связаны #24d071, #a85b92, #714b7a)
- Роль/аккаунт: reg1
- Устройство: mobile — iPhone 13 Mini (WebKit, 375×629), тёмная тема
- Тип: позитив
- Предусловия: в ленте reg1 (story_feed) есть ≥1 сторис
## Шаги
1. Открыть /discover.
2. Дождаться, когда кружок автора в ряду сторис станет верхним элементом (ушёл сплэш), нажать его (картинка сторис задержана).
3. Посмотреть экран до загрузки картинки.
4. Отпустить картинку.
## Ожидаемо
- Адрес /story/<id> первой сторис автора.
- До загрузки: спиннер (progressbar), заполнение прогресса 0 (AC 1; Р1).
- После загрузки: спиннера нет, показана картинка сторис = image_url из story_feed (AC 2), в шапке кнопка с именем автора и его аватаром, время «לפני …» / «עכשיו» (AC 3), заполнение прогресса > 0.
