# PC-01: открытие формы «פוסט חדש» из ленты
- Фича/экран: פיד חברתי /social → FAB «פוסט חדש» → /post/new (S-21)
- Тикеты: #1ff0f4 (связан #2eae9b)
- Роль/аккаунт: free («QA חופשי»)
- Устройство: iPhone 13 Mini (WebKit), тёмная тема
- Тип: позитив
- Предусловия: вход free; сплэш ушёл (элемент — сам цель касания)
## Шаги
1. Открыть /social, дождаться ухода сплэша.
2. Тапнуть FAB «פוסט חדש».
## Ожидаемо
- URL /post/new; заголовок «פוסט חדש», кнопка «סגירה» (✕), аватар.
- Поле ввода с placeholder «מה בא לך לשתף?», ячейка «הוספת תמונה», кнопка «לפרסם» неактивна.
