# PC-05: редактирование своего поста
- Фича/экран: /social → ⋯ своего поста → «עריכת הפוסט» → /post/new?id=<id>
- Тикеты: #1ff0f4 (связан #9918e9)
- Роль/аккаунт: free
- Устройство: iPhone 13 Mini (WebKit)
- Тип: позитив · меняет данные (пост QA-AUTO удаляется)
- Предусловия: свой пост QA-AUTO (создаётся в тесте)
## Шаги
1. Опубликовать пост QA-AUTO.
2. ⋯ → «עריכת הפוסט».
3. Изменить текст, «שמירה».
4. Очистка: удалить пост.
## Ожидаемо
- Заголовок «עריכת פוסט», поле заполнено текущим текстом, кнопка «שמירה».
- PATCH /rest/v1/posts?id=eq.<id> 2xx с новым текстом; в ленте новый текст, старого нет.
