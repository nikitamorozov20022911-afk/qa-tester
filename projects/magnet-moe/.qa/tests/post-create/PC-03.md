# PC-03: публикация текста — спиннер, без двойной отправки, возврат в ленту
- Фича/экран: /social → «פוסט חדש» → «לפרסם» → /social
- Тикеты: #1ff0f4 (связан #2eae9b)
- Роль/аккаунт: free
- Устройство: iPhone 13 Mini (WebKit)
- Тип: позитив · меняет данные (пост QA-AUTO, удаляется в конце)
- Предусловия: вход free
## Шаги
1. /social → «פוסט חדש», ввести «QA-AUTO <дата> …».
2. Тапнуть «לפרסם»; пока запрос идёт — тапнуть кнопку ещё раз.
3. Дождаться ответа.
4. Очистка: ⋯ своего поста → «מחיקת הפוסט» → «מחיקה».
## Ожидаемо
- Во время сохранения: кнопка disabled со спиннером (progressbar); повторный тап второго POST не создаёт.
- Ровно один POST /rest/v1/posts (201), body = введённый текст.
- Переход на /social, пост виден в ленте ровно один раз.
- Удаление: DELETE /rest/v1/posts?id=eq.<id> 2xx, пост пропал.
