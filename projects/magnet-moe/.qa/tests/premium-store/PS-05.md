# PS-05: Тап по тарифу/пакету или «לשדרג ל-Premium» → «התשלום יתחבר בגרסה הבאה», без оплаты (веб)
- Фича/экран: «חנות»
- Тикеты: #431208
- Роль/аккаунт: reg1
- Устройство: mobile — iPhone (веб, iPhone 13 Mini 375×629 и 390×844), тёмная тема
- Тип: позитив
- Предусловия: вход; открыть «חנות»
## Шаги
1. Нажать тариф «חודש», затем пакет «בוסט 1», затем «לשדרג ל-Premium».
## Ожидаемо
- После каждого нажатия — сообщение «התשלום יתחבר בגרסה הבאה».
- Нет перехода на внешнюю платёжную страницу, нет запросов к платёжному провайдеру, подписка не изменилась.
- Когда оплата будет подключена — тест заменить (платёж не автоматизируется).
