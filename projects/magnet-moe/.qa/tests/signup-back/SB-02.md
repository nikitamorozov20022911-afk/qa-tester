# SB-02: iOS: «חזרה» из «זהות דתית» не оставляет пустой экран — 4 захода (ручной, iOS)
- Фича/экран: онбординг в приложении
- Тикеты: #a3a6e0
- Роль/аккаунт: новый номер (0017)
- Устройство: iOS build 11 (iPhone 17)
- Тип: негатив (плавающий дефект 2 из 4)
- Предусловия: новый номер; регистрацию до конца не доводить
## Шаги
1. Выбрать «מסורתי \ דתי» → вперёд до «את מי אני מחפש/ת».
2. «חזרה» подряд (каждые ~3 с, затем быстро) до «כיצד את/ה מגדיר/ה את עצמך?» и ещё раз; повторить 4 раза.
## Ожидаемо
- 4/4: «איך את/ה מתחבר/ת ליהדות?» на экране, выбор сохранён, без тёмного пустого экрана (замер 3 с, 3 с, 1 с, 0.6 с).
- Не автоматизируется: дефект нативной анимации перехода (плавающий, 2 из 4), только на реальном приложении. Проверено вручную.
