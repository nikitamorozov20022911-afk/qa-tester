# PREF-07: автосохранение «העדפות חיפוש»: «מי מעניין אותי» — в момент нажатия, слайдеры возраста и расстояния — при отпускании; значения сохраняются после повторного открытия
- Фича/экран: /prefs?from=settings; строка-сводка в הגדרות («עד N ק״מ • A–B»)
- Тикеты: #2911c1 (связан #56c55c)
- Роль/аккаунт: reg1 (веб 390×844), user4 (iOS build 12; после перезапуска приложения значения сохранены)
- Устройство: веб (мышь, Chromium 390×844) + iOS
- Тип: позитив
- Предусловия: запомнить исходные значения (интерес, возраст, расстояние); после проверки вернуть исходные.
## Шаги
1. Открыть «העדפות חיפוש»; нажать другую опцию «מי מעניין אותי» (например «נשים»).
2. Отпустить ручку возраста на новом значении; отпустить ручку расстояния.
3. Выйти назад в הגדרות — посмотреть сводку; снова открыть экран / перезагрузить страницу (iOS — перезапустить приложение).
4. Вернуть исходные значения (тоже автосохранением).
## Ожидаемо
- Выбор опции «מי מעניין אותי» сразу сохраняется (PATCH profiles `interested_in`) без отдельной кнопки; ползунок — PATCH при отпускании (`pref_age_min/pref_age_max`, `pref_distance_km`), не раньше. («מה רצוי»: сохранять сразу после каждого изменения)
- В הגדרות строка «העדפות חיפוש» показывает новые значения; после перезагрузки/перезапуска экран открывается с ними.
- Возврат исходных значений сохраняется так же.
