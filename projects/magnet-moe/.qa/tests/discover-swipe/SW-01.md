# SW-01: Свайп карточки вправо до половины порога: наклон, ❤ проявляется, отпустил — возврат, лайка нет
- Фича/экран: גילוי — drag-анимация карточки
- Тикеты: #de1cb5
- Роль/аккаунт: reg5 (free, 30 действий/день)
- Устройство: mobile — iPhone (веб, iPhone 13 Mini 375×629 и 390×844), тёмная тема
- Тип: позитив
- Предусловия: вход сохранённой сессией; в ленте есть карточка
## Шаги
1. Открыть /discover, найти карточку (центр ≈ середина экрана).
2. Медленно вести карточку вправо до ~20% ширины карточки (порог — треть ширины), снимая transform и opacity знака несколькими кадрами.
3. Отпустить до порога.
## Ожидаемо
- Во время drag карточка следует за пальцем (translateX растёт) и наклонена по направлению движения: 0 < угол ≤ ~6° у порога.
- Знак ❤ (розовый круг по центру карточки) виден, его opacity растёт с расстоянием (между 0 и 1 на полпути).
- После отпускания карточка плавно (≤ ~1 с) возвращается: translateX ≈ 0, угол ≈ 0, ❤ исчез.
- За весь жест нет запросов лайка/свайпа (карточка та же, «נשארו N פעולות» не изменилось).
