# ADM-FLT-01: сброс фильтров × на чипе — URL чистый, панель «הכול», «החלה» не возвращает
- Фича/экран: админка · /users
- Тикеты: #33347a
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив
## Шаги
1. /users → «מסננים» → «מגדר: אישה», «דת / שיוך דתי: חילוני/ת» → «החלה» → чип «מסננים: 2».
2. Нажать × (`a[aria-label="ניקוי המסננים"]`), дождаться навигации.
3. Открыть «מסננים», нажать «החלה» без изменений.
## Ожидаемо
- После ×: URL /users без параметров gender/religion; чип «מסננים» без числа.
- В панели все поля (מגדר, דת, אונבורדינג) = «הכול»; после «החלה» чип без числа, фильтры не вернулись.
