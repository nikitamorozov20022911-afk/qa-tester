# DN-04: выключение шаринга выключает Date Now
- Фича/экран: /map — тумблер «שיתוף מיקום פעיל» при активном Date Now
- Тикеты: #1fd43a
- Роль/аккаунт: user2 (Premium)
- Устройство: mobile — iPhone 390×844 (геолокация 32.0840, 34.7832)
- Тип: позитив (условие AC 7)
- Предусловия: Date Now у user2 включён («30 דק׳»).
## Шаги
1. Нажать «שיתוף מיקום פעיל» → «לכבות את שיתוף המיקום?» → «כיבוי שיתוף מיקום».
2. Посмотреть карту.
## Ожидаемо
- PATCH `share_location: false` 2xx; на карте «שיתוף מיקום כבוי», плашки с таймером «דייט עכשיו • …» нет.
- После перезагрузки /map Date Now по-прежнему выключен (сервер: в `nearby_live` у наблюдателя `date_now=false` — проверяется в DN-06).
