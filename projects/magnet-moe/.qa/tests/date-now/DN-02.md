# DN-02: Premium — включение с согласием на шаринг, плашка с таймером, выключение «לכבות» в любой момент
- Фича/экран: /map → шит «דייט עכשיו» (выкл. / активный)
- Тикеты: #1fd43a (связан #a5ce54)
- Роль/аккаунт: user2 (Premium, женщина)
- Устройство: mobile — iPhone 390×844 (геолокация эмулирована: 32.0840, 34.7832)
- Тип: позитив
- Предусловия: Date Now у user2 выключен, шаринг выключен.
## Шаги
1. /map → «דייט עכשיו» → в шите выбрать «30 דק׳» → «להפעיל עם שיתוף מיקום».
2. Посмотреть карту.
3. Нажать плашку «דייט עכשיו • 0:30» — шит активного режима.
4. Нажать «לכבות».
5. Выключить шаринг (очистка).
## Ожидаемо
- Шаг 1: PATCH `profiles` `share_location: true` и `rpc/set_date_now` — 2xx.
- Шаг 2: плашка «דייט עכשיו • 0:30» (или 0:29), тумблер «שיתוף מיקום פעיל», «אני» с янтарным кольцом. (AC 1, 2)
- Шаг 3: шит «דייט עכשיו פעיל», «נשארו 30 דק׳», кнопки «לכבות» и «סגירה».
- Шаг 4: `rpc/set_date_now` (выкл.) 2xx, шит закрывается, на карте кнопка «דייט עכשיו» без таймера. (AC 8)
