# ADM-SUB-02: вкладка «תשלום נכשל»: пользователи с неудавшейся оплатой
- Фича/экран: админка → «מנויים ורכישות» → «תשלום נכשל»
- Тикеты: #01f23b (AC 3–4)
- Роль/аккаунт: admin
- Устройство: десктоп 1440×900
- Тип: позитив (просмотр)
- Предусловия: у тест-аккаунтов есть неудачные платежи («לדמות כישלון»: new03 ×3, new02, user4).
## Шаги
1. Вкладка «תשלום נכשל».
2. Открыть строку пользователя.
## Ожидаемо
- Вкладка активна; в таблице ≥1 строка, счётчик «מוצגים N מתוך N» согласован со строками; у строки колонка «תשלום» — «נכשל»/«שולם» по последнему платежу.
- Клик по строке открывает карточку пользователя (ADM-SUB-03).
