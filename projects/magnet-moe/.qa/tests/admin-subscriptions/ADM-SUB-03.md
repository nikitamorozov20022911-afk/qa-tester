- Фича/экран: админка → «מנויים ורכישות» → строка пользователя
- Тикеты: #01f23b (AC 3–4: «סטטוס התשלום», «רכישות נוספות»)
- Роль/аккаунт: admin; пользователь с покупками (new03 «QA П3 0012»)
- Устройство: десктоп 1440×900

1. Открыть карточку; посмотреть блоки и таблицу «רכישות».
## Ожидаемо
- Заголовок с именем и «מנוי ורכישות», «Magnet Premium» + статус «פעיל», сумма/«לחודש», «עד החידוש»; строка «נרכש», «אמצעי תשלום» («תשלום בדיקה»), «תשלום אחרון», «חידוש הבא».
- «יתרות»: бусты, суперлайки, «חזרה אחורה», «מתנות חינם»; ссылки «הענקת בוסט/סופר לייק/חזרה אחורה/מתנה» (не нажимать).
- «רכישות (N)»: колонки הזמנה, פריט, סכום, תשלום, סטטוס; номер заказа «P-XXXXXX», сумма «₪…», чипы «שולם» и «נכשל».
