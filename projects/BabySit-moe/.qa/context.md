## Технические заметки
- 2026-11-15: регистрация НОВЫХ аккаунтов в QA невозможна — почта не отправляется (нет провайдера; временная почта не получила письмо за 2+ мин), а фиксированный код работает только для 6 заранее созданных аккаунтов (для нового @babysit.test: functions/v1/test-signin → 404, auth/v1/verify → 403). Пункты «регистрация с нуля» и SMS-подтверждение — «не проверено (окружение)».
- Подтверждение телефона (SMS) при регистрации — приходит НАСТОЯЩИЙ код. Использовать номер пользователя из .qa/accounts.env (QA_SMS_PHONE); перед отправкой SMS предупредить пользователя, код он даёт в чат. Делает основная сессия, не фоновые агенты.
- Сервер «засыпает» без нагрузки: первый запрос после простоя может висеть — повторить один раз.
- Сессия хранится в localStorage (`sb-…-auth-token`).
