## FL-04 בקשה עד הזמנה מאושרת — Request to confirmed booking
- Источник: «מפרט» → תהליכי משתמש, flow 6a86046760398e6702ba0a39
- Актор: הורה — Parent
- Описание: מהרגע שההורה יוצר בקשה ועד להזמנה מאושרת: סינון בייביסיטרים מתאימות, דירוגן, הבעת עניין במקביל, בחירת ההורה וסגירת הבקשה עבור היתר. בקשה שלא נסגרה עוברת לסטטוס Last Minute 12 שעות לפני תחילת המשימה.
- Триггер: הורה יוצר Request חדש
- Цель: להגיע ל־Confirmed Booking עם בייביסיטר אחת מתאימה
- Шаги:
  1. כתיבת הבקשה [решение] — экран: יצירת בקשה — Create request
  2. סוננו בייביסיטרים, ממתין להבעת עניין [решение] — экран: מצב הבקשה — Request status
  3. Last Minute — בקשה דחופה [решение] — экран: מצב הבקשה — Request status
  4. בייביסיטרים שהביעו עניין — לבחירת ההורה — экран: בייביסיטרים שהביעו עניין — Interested sitters
  5. הבקשה נסגרה ללא התאמה — экран: מצב הבקשה — Request status
  6. הזמנה מאושרת — экран: פרטי הזמנה — Booking detail
- Успех: ההזמנה הפכה ל־Confirmed Booking והבקשה נסגרה עבור יתר הבייביסיטרים
- Сбой/блокировка: ההורה סגר את הבקשה ללא התאמה. פקיעה אוטומטית במועד תחילת המשימה אינה מוגדרת במסמך ולכן אינה ממודלת
- Экраны: יצירת בקשה — Create request; מצב הבקשה — Request status; בייביסיטרים שהביעו עניין — Interested sitters; פרטי הזמנה — Booking detail
- Фича: בקשה, התאמה והזמנה — Request to confirmed booking (модуль מרקטפלייס — Marketplace, must)

## FL-05 הזמנה חוזרת — Repeat booking
- Источник: «מפרט» → תהליכי משתמש, flow 6a86046760398e6702ba0a3c
- Актор: הורה — Parent
- Описание: הזמנה חוזרת של בייביסיטר מוכרת: נפתח Request חדש כשהיא מסומנת כמועדפת, וההזמנה נוצרת רק לאחר אישורה. אין יצירה אוטומטית.
- Триггер: ההורה בוחר "הזמן שוב" מתוך כרטיס בייביסיטר קיימת
- Цель: לסגור הזמנה חדשה עם בייביסיטר מוכרת
- Шаги:
  1. בייביסיטרים שכבר עבדו עם המשפחה — экран: בייביסיטרים קודמות — Past sitters
  2. בקשה חדשה, הבייביסיטר מסומנת כמועדפת — экран: יצירת בקשה — Create request
  3. ממתין לאישור הבייביסיטר [решение] — экран: מצב הבקשה — Request status
  4. נוצרה הזמנה חדשה — экран: פרטי הזמנה — Booking detail
  5. הבייביסיטר דחתה — экран: מצב הבקשה — Request status
- Успех: הבייביסיטר אישרה ונוצרה Booking חדשה
- Сбой/блокировка: הבייביסיטר דחתה את ההזמנה
- Экраны: בייביסיטרים קודמות — Past sitters; יצירת בקשה — Create request; מצב הבקשה — Request status; פרטי הזמנה — Booking detail
- Фича: הזמנה חוזרת — Repeat booking (модуль צמיחה — Growth & Marketing, must)

## FL-06 צ׳אט בין ההורה לבייביסיטר — In-product chat

## FL-07 יום המשימה — Task day
- Источник: «מפרט» → תהליכי משתמש, flow 6a86046760398e6702ba0a3e
- Актор: בייביסיטר — Sitter
- Описание: יום המשימה: "בדרך", Check-in עם בדיקת התאמת המיקום לכתובת ההזמנה, אישור ההורה, ביצוע המשימה ו־Check-out. כשל GPS אינו חוסם — ניתן אישור ידני והמשימה מסומנת Location not verified.
- Триггер: הגיע מועד ההזמנה המאושרת
- Цель: לבצע את המשימה עם תיעוד הגעה וסיום
- Шаги:
  1. הזמנה מתוזמנת [решение] — экран: פרטי הזמנה — Booking detail
  2. הבייביסיטר בדרך [решение] — экран: הזמנה פעילה — Live booking
  3. הבייביסיטר לא הגיעה — No-show — экран: פרטי הזמנה — Booking detail
  4. בוצע Check-in, ממתין לאישור ההורה — экран: הזמנה פעילה — Live booking
  5. מיקום ה־Check-in לא אומת — экран: הזמנה פעילה — Live booking
  6. המשימה בביצוע [решение] — экран: הזמנה פעילה — Live booking
  7. בוצע Check-out, ממתין לאישור ההורה — экран: הזמנה פעילה — Live booking
  8. מיקום ה־Check-out לא אומת — экран: הזמנה פעילה — Live booking
  9. המשימה הושלמה — экран: סיכום הזמנה — Booking summary
- Успех: בוצע Check-out וההורה אישר את סיום המשימה
- Сбой/блокировка: המיקום לא אומת — המשימה נמשכת באישור ידני והאירוע נשמר לבקרה
- Экраны: פרטי הזמנה — Booking detail; הזמנה פעילה — Live booking; סיכום הזמנה — Booking summary
- Фича: יום המשימה — Task day execution (модуль ביצוע המשימה ובטיחות — Task Execution & Safety, must)
- Примечание: шаг 3 (No-show) есть в шагах, но в поле «outcome_failure» не упомянут.
