# Экраны (screens) — BabySit AI

Источник: mifrat, вкладка «מפרט», проект «BabySit AI» (project_id `6a86019d1bf21e0e88b74971`), чтение через mifrat MCP (`read_screen_map`, `query_features` feature_type=screen / feature, `query_flows`, `query_personas`), 2026-11-15. PDF нет.

Общие факты по всем экранам (из полей формы):
- В «מפרט» 32 экрана (feature_type `screen`), 8 модулей. У всех: priority `must`, status `טרם התחיל`, design_status `none`, figma_url пусто, user_story пусто, поле `related_features` пусто.
- У экранов нет отдельных полей для элементов, состояний (пусто/загрузка/ошибка/успех) и ролей. «Элементы» ниже — дословно поле описания; «Состояния» — шаги user flow, которые в «מפרט» привязаны к экрану. Пустое/загрузка/ошибка/успех в «מפרט» не заданы ни для одного экрана.
- Связанная фича экрана в «מפרט» явно не проставлена. Она указана по совпадению текста требования экрана с требованием фичи (дословно одна и та же строка). Где совпадение неоднозначно — сказано отдельно.
- Роли: у персон поле `accessible_screens` пустое. Роли ниже — персоны, у которых связанная фича есть в `accessible_features`, плюс actor тех flows, где экран встречается.
- AC: у самих экранов есть только одно требование (demand); отдельного DoD у экрана нет. В пункте «AC» приведены требование экрана и DoD связанной фичи — дословно.
- Предупреждения карты экранов mifrat: 8 экранов не входят ни в один flow (S-11, S-15, S-17, S-18, S-19, S-22, S-23, S-32).
