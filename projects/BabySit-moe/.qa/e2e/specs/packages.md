1. В авторизованной сессии взять access-token родителя (`localStorage`) и его `id`.
2. Отправить `PATCH {baseURL Supabase}/rest/v1/packages?user_id=eq.<self-id>` с `Authorization: Bearer <token>`, `apikey: <anon>`, `Prefer: return=representation`, тело со сменой плана/статуса/даты (например `{"status":"cancelled"}` или смена типа пакета).
3. Перечитать свою запись пакета: `GET /rest/v1/packages?user_id=eq.<self-id>&select=*`.
**Expected:**
- PATCH отклонён: 401/403 либо 200 с пустым массивом = 0 изменённых строк. (источник: коммент 1 — клиент не может назначать план/статус/даты, только admin/service; Т4.)
