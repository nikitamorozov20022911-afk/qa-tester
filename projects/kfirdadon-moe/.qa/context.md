## Технические заметки
- Входы (2026-10-12): `npm run qa-login` создаёт по 3 слота на роль — .qa/auth/<admin|business|user>.json, -2.json, -3.json. Один слот = один агент одновременно; в конце агент делает state-save в свой слот (refresh-токен Supabase одноразовый, см. L-20261012-2).
- Playwright требует Node 20+; в оболочке по умолчанию Node 18 → перед npm-командами в .qa/e2e: `nvm use` (.nvmrc = 22). Сервер playwright-test в .mcp.json запускается абсолютным путём к Node 22.
- Встроенный браузер не пускает fetch с mifrat на localhost — дамп «מפרט» в файл так не сделать.
