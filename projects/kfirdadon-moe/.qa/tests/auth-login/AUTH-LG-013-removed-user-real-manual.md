# AUTH-LG-013 (вручную): участник бизнеса заблокирован, затем удалён — в сессии и при входе
- Фича/экран: /settings/users (менеджер) → экран участника → /login
- Тикеты: #5121408da9c3e79d47922c63 (#922c63); связано #cea3ed (блок/разблокировка/удаление участника)
- Роль/аккаунт: менеджер своего QA-бизнеса (сессия, напр. passmgr/pilotmgr или вход пользователя) + новый участник «R1» (входит ТОЛЬКО пользователь)
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: QA-бизнес, где есть менеджер со своей сессией (22.10: QA-PILOT-a2c2d9). Агент пароли не вводит, аккаунты не создаёт.
## Шаги
1. Пользователь даёт новый адрес temp-mail.org (пример 22.10: sofego9727@proguidex.com).
2. Менеджер: /settings/users → «הזמנת משתמש» → «שם מלא» «QA-R1-<ддмм>», «מייל» = адрес, «הרשאה» «מנהל/ת מגייס/ת», без шиуха → «שליחת הזמנה». Ожидаемо: «ההזמנה נשלחה», строка «ממתין להצטרפות · בתוקף עד …».
3. Пользователь: письмо в temp-mail → ссылка /invite/… в инкогнито → задать пароль, согласие → «הצטרפות». Ожидаемо: дашборд R1. Окно не закрывать.
4. Менеджер: строка R1 → «חסימה» → в окне «חסימת משתמש» подтвердить. Ожидаемо: «המשתמש/ת נחסם/ה. הנתונים שיצר/ה נשמרים.», статус «חסום».
5. Пользователь в окне R1: перейти по меню (без F5). Ожидаемо: /login, «הגישה לחשבון חסומה» — «המשתמש שלכם חסום כרגע, ולכן לא ניתן להיכנס. לבירור ולחידוש הגישה אפשר לפנות למנהל/ת החשבון בעסק או לתמיכה.»
6. Пользователь: ввести почту и пароль R1 → «כניסה». Ожидаемо: отказ, та же плашка.
7. Менеджер: строка R1 → «ביטול החסימה» → «החסימה בוטלה. אפשר להתחבר שוב.»; пользователь входит R1 → дашборд. Окно не закрывать.
8. Менеджер: строка R1 → «הסרה» → в окне «הסרה מהעסק» подтвердить. Ожидаемо: «המשתמש/ת הוסר/ה מהעסק. הנתונים שיצר/ה נשמרים.», строки нет.
9. Пользователь в окне R1: перейти по меню. Ожидаемо: /login, «הגישה לעסק הוסרה» — «המשתמש שלכם הוסר מהעסק, ולכן לא ניתן להיכנס. כדי לחזור לעסק צריך הזמנה חדשה ממנהל/ת החשבון בעסק. לשאלות אפשר לפנות לתמיכה.»; слова «חסום» нет.
10. Пользователь: ввести почту и пароль R1 → «כניסה». Ожидаемо: та же плашка «הגישה לעסק הוסרה».
## Ожидаемо
См. шаги (источник: «מה רצוי» #922c63).
## Почему вручную
Нужен вступивший участник с паролем и одноразовые блокировка/удаление; тексты экрана покрыты автотестом AUTH-LG-012.
