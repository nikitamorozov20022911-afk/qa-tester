# AUTH-LG-008: «התנתקות» → вход; «назад» и прямой адрес снова требуют входа
- Фича/экран: выход (F-05 AC5, треб.3)
- Тикеты: #6a993d794918a5e83bc3231b
- Роль/аккаунт: user (сохранённая сессия)
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: в автотесте запрос /auth/v1/logout подменяется (204), иначе выход «scope=global» отзовёт общую сессию .qa/auth/user.json. Реальный отзыв токена на сервере — tests/user-access/logout-old-token.spec.ts (#4cfd0ae4, запуск вручную).
## Шаги
1. Под user открыть «/», нажать «התנתקות».
2. «Назад»; затем открыть /candidates напрямую.
## Ожидаемо
- Запрос выхода отправлен с scope=global; переход на /login, h1 «כניסה לחשבון»; токен `sb-*-auth-token` удалён из localStorage.
- «Назад» и /candidates → /login (from = /candidates), «התנתקות» нет (AC5: «כל גישה חוזרת לנתונים מחייבת התחברות מחדש»).
