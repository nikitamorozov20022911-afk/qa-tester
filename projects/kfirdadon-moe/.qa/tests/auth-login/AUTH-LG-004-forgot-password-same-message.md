# AUTH-LG-004: «שכחתי סיסמה» — одинаковый экран для существующего и несуществующего адреса
- Фича/экран: /forgot-password (F-05 AC3, треб.2)
- Тикеты: #6a993d794918a5e83bc3231b
- Роль/аккаунт: guest; несуществующий qa-nonexistent@example.test; существующий — только тестовый адрес на example.com из accounts.env (QA_USER_PASSPEND_EMAIL), не чаще 1 раза за прогон
- Устройство: desktop 1440×900
- Тип: негатив / безопасность
- Предусловия: лимит писем Supabase — запрос по существующему адресу отправляет настоящее письмо
## Шаги
1. /login → «שכחתי סיסמה» → /forgot-password (h1 «איפוס סיסמה»).
2. «מייל» = qa-nonexistent@example.test → «שליחת קישור לאיפוס».
3. В новом окне повторить с существующим тестовым адресом.
## Ожидаемо
- Оба раза: h1 «בדקו את תיבת המייל», текст «אם המייל רשום במערכת, שלחנו אליו קישור לבחירת סיסמה חדשה. הקישור תקף למשך 30 דקות ולשימוש אחד בלבד.», в карточке «המייל שהזנתם» — введённый адрес; ответ /auth/v1/recover — одинаковый статус (AC3: «ההודעה במסך זהה גם כאשר המייל אינו קיים»).
- Ошибки «הקישור לא נשלח» нет.
