# AUTH-LG-011 (вручную): пользователь бизнеса, который заблокировали, а потом удалили — в сессии и при входе
- Фича/экран: любой экран бизнеса → /login; карточка бизнеса у Super Admin (/admin/businesses/<id>)
- Тикеты: #3a666c3dd8f5b45f7892bd0e (#92bd0e); тот же прогон закрывает #6a993d7725c79eed60ef15fd (#ef15fd) треб.7 — см. UA-007
- Роль/аккаунт: admin (агент, сессия .qa/auth/admin.json) + новый менеджер «D» своего QA-бизнеса (входит ТОЛЬКО пользователь, пароль задаёт и вводит сам)
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: одноразовый QA-бизнес. Агент пароли не вводит и аккаунты не создаёт — регистрацию по ссылке делает пользователь.
## Шаги
1. Пользователь открывает https://temp-mail.org/ (или аналог) и даёт агенту новый адрес (пример 22.10: cojonot762@moravita.com).
2. admin: /admin/businesses → «יצירת בית עסק» → «שם העסק» «QA-CHAIN-<ддмм>», все обязательные поля, почта первого менеджера = адрес из п.1 → «יצירת בית העסק». Ожидаемо: блок «בית העסק נוצר», приглашение первому менеджеру «ממתינה».
3. Пользователь: в ящике temp-mail письмо от simulator@shnaider.pro со ссылкой /invite/… → открыть в отдельном (инкогнито) окне → задать пароль, отметить согласие → «הצטרפות». Ожидаемо: дашборд бизнеса, «התנתקות» в меню. Окно не закрывать.
4. admin: карточка QA-CHAIN-<ддмм> → кнопка блокировки бизнеса → подтвердить. Ожидаемо: «סטטוס החשבון» — «חסום».
5. Пользователь в окне D: перейти по любому пункту меню (без F5). Ожидаемо: /login, плашка «החשבון העסקי אינו פעיל» — «החשבון העסקי שהמשתמש שלכם שייך אליו חסום או נסגר, ולכן לא ניתן להיכנס. לבירור מצב החשבון אפשר לפנות לתמיכה.» + «פנייה לתמיכה».
6. Пользователь: ввести почту и пароль D → «כניסה». Ожидаемо: вход отклонён, та же плашка «החשבון העסקי אינו פעיל».
7. admin: в карточке QA-CHAIN-<ддмм> → кнопка удаления бизнеса → подтвердить. Ожидаемо: бизнеса нет в списке /admin/businesses.
8. Пользователь: ввести почту и пароль D → «כניסה». Ожидаемо: плашка «החשבון העסקי נמחק» — «החשבון העסקי שהמשתמש שלכם שייך אליו נמחק, והגישה אליו לא תחזור. אם נראה לכם שמדובר בטעות, אפשר לפנות למנהל המערכת דרך התמיכה.» + «פנייה לתמיכה»; текста «הגישה לחשבון חסומה» нет.
9. Вариант «в сессии»: повторить п.2–3 с новым адресом, сразу удалить бизнес (без блокировки), в открытом окне D перейти по меню. Ожидаемо: /login с той же плашкой «החשבון העסקי נמחק».
## Ожидаемо
См. шаги (источник: «מה רצוי» #92bd0e — удалённый бизнес → «נמחק… הגישה לא תחזור», заблокированный → «אינו פעיל»).
## Почему вручную
Нужен вступивший пользователь с паролем (создание аккаунта и ввод пароля) и одноразовые блокировка/удаление бизнеса; тексты экрана покрыты автотестом AUTH-LG-010.
