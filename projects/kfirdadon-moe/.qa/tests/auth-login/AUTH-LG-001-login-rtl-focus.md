# AUTH-LG-001: экран входа — RTL, фокус в поле «מייל», видимый фокус по Tab, вход только по приглашению
- Фича/экран: вход (F-05, S-03, FL-05 шаг 1)
- Тикеты: #6a993d794918a5e83bc3231b, #172fd7d688f4438bdadda900 (#dda900 — фокус в «מייל» при загрузке + текст «הכניסה בהזמנה בלבד…»)
- Роль/аккаунт: guest
- Устройство: desktop 1440×900
- Тип: позитив / доступность
- Предусловия: нет
## Шаги
1. Гостем открыть /login.
2. Прочитать `document.documentElement.dir`, `lang`, активный элемент.
3. Нажимать Tab: «סיסמה» → «הצגה» → «שכחתי סיסמה» → «כניסה».
## Ожидаемо
- `<html dir="rtl" lang="he">`, computed direction формы = rtl (AC6).
- h1 «כניסה לחשבון»; фокус при загрузке — в поле «מייל» (type=email, autocomplete=username) (FL-05: «מיקוד בשדה המייל»).
- Каждый элемент при Tab получает `:focus-visible` с видимой обводкой (outline или box-shadow) (AC6: «מיקוד מקלדת נראה לעין»).
- Есть «הכניסה בהזמנה בלבד. אין לכם חשבון? בקשו הזמנה ממנהל החשבון בעסק.», ссылка «שכחתי סיסמה» → /forgot-password, внизу «פנייה לתמיכה»; ссылок регистрации нет (FL-05, FL-08 шаг 2).
