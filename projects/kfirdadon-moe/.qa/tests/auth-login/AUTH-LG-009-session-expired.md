# AUTH-LG-009: истёкшая сессия → «כניסה מחדש» с плашкой «פג תוקף החיבור», почта подставлена
- Фича/экран: вход после истечения сессии (F-05 AC5, Figma 717:1043)
- Тикеты: #6a993d794918a5e83bc3231b
- Роль/аккаунт: user (сохранённая сессия, в окне теста подменено время истечения)
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: в окне теста `expires_at` в прошлом, refresh_token заменён, ответ обновления токена подменён (400) — общая сессия не тратится
## Шаги
1. Открыть /candidates с истёкшей сессией.
## Ожидаемо
- Переход на /login?notice=expired (from = /candidates); h1 «כניסה מחדש»; плашка «פג תוקף החיבור» / «מטעמי אבטחה החיבור שלכם הסתיים. היכנסו שוב כדי להמשיך.»; «מייל» = почта пользователя; нет бесконечной загрузки; «התנתקות» нет (AC5).
