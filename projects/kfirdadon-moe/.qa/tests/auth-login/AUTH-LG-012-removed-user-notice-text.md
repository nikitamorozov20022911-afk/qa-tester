# AUTH-LG-012: экран входа — «הגישה לעסק הוסרה» (пользователь удалён из бизнеса) отличается от «הגישה לחשבון חסומה» (пользователь заблокирован)
- Фича/экран: вход /login, плашка `account-blocked` (F-05 AC4, F-07)
- Тикеты: #5121408da9c3e79d47922c63 (#922c63)
- Роль/аккаунт: guest
- Устройство: desktop 1440×900
- Тип: негатив / визуал текста
- Предусловия: нет. Причина из адреса: /login?notice=blocked&reason=removed|user (бандл index-BT4tmDRk.js).
## Шаги
1. Гостем открыть /login?notice=blocked&reason=removed.
2. Гостем открыть /login?notice=blocked&reason=user.
3. Гостем открыть /login?notice=blocked (без причины) — контроль общего текста.
## Ожидаемо
- п.1: data-reason=removed; «הגישה לעסק הוסרה» / «המשתמש שלכם הוסר מהעסק, ולכן לא ניתן להיכנס. כדי לחזור לעסק צריך הזמנה חדשה ממנהל/ת החשבון בעסק. לשאלות אפשר לפנות לתמיכה.» + «פנייה לתמיכה»; слова «חסום» нет (источник: «מה רצוי» #922c63 — удалённый не должен видеть «המשתמש שלכם חסום»).
- п.2: data-reason=user; «הגישה לחשבון חסומה» / «המשתמש שלכם חסום כרגע, ולכן לא ניתן להיכנס. לבירור ולחידוש הגישה אפשר לפנות למנהל/ת החשבון בעסק או לתמיכה.» (источник: «מה רצוי» #922c63 — для заблокированного прежнее сообщение).
- п.3: data-reason=unknown; «הגישה לחשבון חסומה» / «המשתמש או החשבון העסקי אינם פעילים כרגע…» (как AUTH-LG-007).
