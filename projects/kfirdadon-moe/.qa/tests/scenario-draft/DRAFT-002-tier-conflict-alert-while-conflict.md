## Шаги
1. «עריכת הטיוטה» → в «מידע גלוי» добавить строку скрытого пункта («הוא היה מעורב בתאונה קלה…») → «שמירה כגרסה חדשה».
2. Ещё раз «שמירה כגרסה חדשה» без изменений.
3. Вернуть «מידע גלוי» к исходному тексту → «שמירה כגרסה חדשה».
4. Снова добавить конфликт → сохранить → «ביטול».
