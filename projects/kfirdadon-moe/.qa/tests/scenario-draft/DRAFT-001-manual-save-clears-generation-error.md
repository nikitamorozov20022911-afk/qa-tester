2. Генерация (авто или «הפקת טיוטת תרחיש») получает 422 draft_rejected → алерт «הפקת הטיוטה נכשלה» с «ניסיון נוסף» и «כתיבת טיוטה ידנית».
3. «כתיבת טיוטה ידנית» → заполнить пустые разделы 01–05 → «שמירה כגרסה חדשה».
4. Повторить на 375×812.
