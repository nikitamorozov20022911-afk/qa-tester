# SIM-102: 3 уровня раскрытия; «רק בשאלה» без условия закрывает переход; «לגלות בשיחה» — без условия (null); предпросмотр — только «מוצג מראש»
- Фича/экран: редактор симуляции S-08, шаг 2
- Тикеты: #6a993d767a46a91b6fdf30ff
- Роль/аккаунт: business (testim)
- Устройство: desktop 1440×900
- Тип: позитив + негатив
- Предусловия: черновик из SIM-101
## Шаги
1. Заполнить «מצב הלקוח…», «הצורך…»; «קשר קודם» пусто.
2. 3 пункта: מוצג מראש / לגלות בשיחה / רק בשאלה (без условия) → «הבא: התנגדות».
3. Ввести условие → «הבא: התנגדות».
## Ожидаемо
- У каждого пункта 3 варианта; поле «נחשף:» только у «רק בשאלה» (AC1, AC2).
- Без условия: «אי אפשר לעבור לשלב 3 — …», «חסר תנאי: איזו שאלה חושפת את המידע?», сохранения нет (AC2).
- «מה המועמד יראה לפני השיחה» — только пункт «מוצג מראש», «2 פריטים מוסתרים — ייחשפו רק בשיחה» (AC4).
- С условием: 200, у «לגלות בשיחה» reveal_condition:null; пустой «קשר קודם» не мешает (AC5); открыт шаг 3.
