## Шаги
1. «להמשיך לתרגול» → экран «פרטי לקוח לתרגול».
2. Отключить сеть браузера (context.setOffline(true); вариант — route.abort('failed') на rpc/candidate_start_attempt).
3. «להתחיל תרגול».
4. «לפנות לצוות לעזרה» → Esc.
5. Ещё раз «נסו שוב» (сеть всё ещё отключена).
## Ожидаемо
- После шага 3: сообщение «לא הצלחנו להתחיל את התרגול, כנראה בגלל תקלה בחיבור לאינטרנט. בדקו את החיבור ונסו שוב.» (блок start-failure, data-reason=network) + кнопки «נסו שוב» и «לפנות לצוות לעזרה»; URL тот же, «פרטי לקוח לתרגול» на месте (нет тихой перезагрузки шага); ровно 1 запрос candidate_start_attempt на нажатие; нет горизонтальной прокрутки (scrollWidth = 390) (источник: AC «כשל רשת בבקשת התחלת התרגול … מציג למועמד הסבר, ניסיון חוזר ונתיב פנייה»).
