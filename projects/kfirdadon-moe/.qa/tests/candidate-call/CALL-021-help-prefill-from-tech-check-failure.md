# CALL-021: помощь из сбоя тех. проверки — «תקלה טכנית» выбрана и описание по сбою; из других мест — пусто
- Фича/экран: кандидат «בדיקה טכנית» → лист «צריכים עזרה?»
- Тикеты: #487826 (38c0a78f545c8aeac8487826); связан #6e5ece (CALL-017)
- Роль/аккаунт: business (кандидат link_only «QA-AUTO-HELP-…») + кандидат (гость)
- Устройство: iPhone (Safari)
- Тип: негатив (подмена микрофона)
- Предусловия: подмена до загрузки: нет navigator.mediaDevices; getUserMedia → NotAllowedError / NotReadableError / прочая ошибка; ожидание разрешения (getUserMedia не отвечает). Обращение не отправляется.
## Шаги
1. Ссылка → ברוכים הבאים → איך זה עובד → פרטי הלקוח → согласие → «להתחיל בדיקה».
2. На экране сбоя: «נתקלת בבעיה? פנייה לגורם אנושי» (у неподдерживаемого браузера — «פנייה לגורם אנושי»), закрыть; затем «?» в шапке.
3. Без сбоя: «?» на вступлении тех. проверки; «?» и ссылка помощи во время ожидания разрешения.
## Ожидаемо
- Из сбоя: радио «תקלה טכנית» выбрано, описание: нет mediaDevices — «הבדיקה הטכנית לא מצליחה: הדפדפן לא מאפשר מיקרופון.»; NotAllowed — «…: המיקרופון חסום בדפדפן.»; NotReadable — «…: המיקרופון תפוס על ידי תוכנה אחרת.»; прочая — «…: משהו השתבש בגישה למיקרופון.» (источник: AC1, Figma 827:2940).
- Из мест без сбоя: ни одно радио не выбрано, описание пустое (источник: AC2).
