# CALL-009: перед официальной — предупреждение «חד-פעמי» и обязательная галочка; без галочки старт не идёт
- Фича/экран: звонок кандидата, экран «פרטי לקוח לשיחה» (перед официальной попыткой)
- Тикеты: #6a993d711bef8ed807d9d257
- Роль/аккаунт: business + кандидат (гость)
- Устройство: Chrome 390×844 + 1440×900
- Тип: негатив/позитив; без звонка; НЕ prod-safe (создаёт кандидата). Страховка: старт попытки/голосовой сессии обрывается (route.abort).
- Предусловия: как CALL-008; на экране практики «לדלג ישר לשיחה הרשמית» (или после практики).
## Шаги
1. Экран «פרטי לקוח לשיחה»: прочитать плашку, посмотреть галочку.
2. Не отмечая «הבנתי שזה ניסיון חד-פעמי», нажать «מוכן, מתחילים».
3. 1440×900.
## Ожидаемо
- «השיחה הבאה היא השיחה הנספרת, והיא מתקיימת פעם אחת. אפשר לחזור עליה רק אחרי תקלה טכנית או באישור חריג של צוות הגיוס…» (источник: AC5 / דרישה 3 «אזהרה שהניסיון הרשמי חד-פעמי ונדרש אישור מפורש»).
- Галочка «הבנתי שזה ניסיון חד-פעמי» по умолчанию не отмечена.
- Шаг 2: «כדי להתחיל יש לאשר שזה ניסיון חד-פעמי.»; запросов candidate_start_attempt / start-voice-session — 0.
- 1440: без горизонтальной прокрутки.
