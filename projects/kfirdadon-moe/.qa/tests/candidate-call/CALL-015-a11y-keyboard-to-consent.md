# CALL-015: клавиатура — путь до листа согласия Tab+Enter, видимый фокус, лист помощи и Esc
- Фича/экран: ברוכים הבאים → איך זה עובד → פרטי הלקוח → «לפני שמתחילים»; «?» → «צריכים עזרה?»
- Тикеты: #6a993d666cd36172db6e5ece
- Роль/аккаунт: business (кандидат link_only) + кандидат (гость)
- Устройство: desktop Chrome 1440×900
- Тип: позитив; НЕ prod-safe (создаёт кандидата «QA-AUTO-A11Y-K-…», отмечает флажок согласия)
- Предусловия: как CALL-014
## Шаги
1. Вступление: Tab до «בוא נתחיל».
2. Shift+Tab до «?», Enter; Esc.
3. Tab+Enter: «בוא נתחיל» → «לראות פרטי לקוח» → «להמשיך».
4. На листе согласия Tab до флажка, Space; Tab до «להתחיל».
## Ожидаемо
- Каждая интерактивная остановка — видимая обводка (outline ≥2px или box-shadow; факт: 2px белый); «?» раньше основной кнопки; если есть «חזרה» — раньше «?» (источник: AC5 «סדר המעבר הגיוני ומיקוד המקלדת נראה לעין»).
- Лист помощи: фокус на «סגירה וחזרה למסך»; Esc закрывает, фокус снова на «?» (факт 14.10).
- Лист согласия: фокус внутри листа; флажок отмечается пробелом (источник: AC7 «כל פעולה ניתנת לביצוע במקלדת»).
