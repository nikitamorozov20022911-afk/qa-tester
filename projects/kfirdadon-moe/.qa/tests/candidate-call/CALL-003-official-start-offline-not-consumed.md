# CALL-003: сбой сети при старте официального звонка — объяснение, «נסו שוב», путь к человеку; попытка не тратится
- Фича/экран: звонок кандидата /c/<token>, S-16 «מסך שיחת הסימולציה החיה» (подтверждение «הבנתי שזה ניסיון חד-פעמי» → «מוכן, מתחילים»); у бизнеса — список кандидатов /candidates
- Тикеты: #1a311effdd4a2d2ba5fe9c67
- Роль/аккаунт: business (создаёт кандидата, смотрит статус) + кандидат (гость)
- Устройство: Chrome 390×844 (кандидат), business — десктоп
- Тип: негатив; НЕ prod-safe (создаёт кандидата)
- Предусловия: активная симуляция «מערכות סולאריות» в бизнесе testim; новый кандидат «QA-AUTO-CALL-…» (business, канал link_only — без письма/SMS); Chrome с --use-fake-ui-for-media-stream --use-fake-device-for-media-stream --use-file-for-fake-audio-capture=.qa/audio/mic-check.wav; кандидат прошёл вступление, согласие и тех. проверку («כן, שומעים טוב»).
## Шаги
1. «להמשיך לתרגול» → «לדלג ישר לשיחה הרשמית» (или пройти практику).
2. Галочка «הבנתי שזה ניסיון חד-פעמי»; отключить сеть (context.setOffline(true); вариант — route.abort('failed') на rpc/candidate_start_attempt).
3. «מוכן, מתחילים».
4. «לפנות לצוות לעזרה» → Esc; «נסו שוב» (сеть отключена).
5. business: /candidates → найти кандидата по имени.
## Ожидаемо
- Шаг 3: «לא הצלחנו להתחיל את השיחה, כנראה בגלל תקלה בחיבור לאינטרנט…» + «נסו שוב» + «לפנות לצוות לעזרה»; ровно 1 запрос candidate_start_attempt; звонок не начался (источник: AC «כשל רשת בבקשת התחלת … השיחה הרשמית מציג למועמד הסבר, ניסיון חוזר ונתיב פנייה»).
- Шаг 4: лист «צריכים עזרה?» открывается, Esc возвращает к сообщению; повтор без сети — снова сообщение.
- Шаг 5: статус кандидата «בדיקה טכנית החלה» — не «הסימולציה החלה», не «תקלה טכנית», не «הושלמה» (источник: D-12 — одна официальная попытка, повтор только при сбое; S-15 «הניסיון הרשמי נותר זמין ולא נצרך»).
