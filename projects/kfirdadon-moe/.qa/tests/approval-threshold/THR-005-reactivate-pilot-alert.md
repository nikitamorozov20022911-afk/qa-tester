# THR-005: «הפעלה מחדש» неактивной симуляции при другой активной — тот же диалог пилота; «ביטול» оставляет неактивной
- Фича/экран: F-19 · список симуляций /simulations · rpc set_simulation_status
- Тикеты: #6a993d73690eb2387da2c2d9 (#a2c2d9) · реджект 05.10 п.1
- Роль/аккаунт: business
- Устройство: desktop 1440×900
- Тип: негатив · ТОЛЬКО ВРУЧНУЮ (нужна неактивная симуляция; своя неактивная появляется только после активации, а автотестам на testim активировать запрещено; чужие QA-симуляции не трогаем)
- Предусловия: в бизнесе есть активная и неактивная («לא פעילה») симуляции.
## Шаги
1. /simulations → «פעולות עבור <неактивная>» → «הפעלה מחדש».
2. «ביטול».

- set_simulation_status {p_status: active, p_confirm_pilot_overrun: false} → 400 pilot_scope_exceeded.
- Диалог «חריגה מהיקף הפיילוט המומלץ»: «לעסק כבר יש סימולציה פעילה. … <имя> תופעל רק לאחר אישור מפורש.», кнопки «הפעלה בכל זאת» / «ביטול».
- После «ביטול» статус inactive. («הפעלה בכל זאת» → активна; затем вернуть «לא פעילה».)
