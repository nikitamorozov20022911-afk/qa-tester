# THR-007: новые кандидаты активной симуляции получают ту же версию сценария
- Фича/экран: F-19 / F-20 · кандидаты
- Тикеты: #6a993d73690eb2387da2c2d9 (#a2c2d9) · смежно b950c145 (CAND-001/002)
- Роль/аккаунт: business
- Устройство: desktop 1440×900
- Тип: позитив · ТОЛЬКО ВРУЧНУЮ (создание кандидатов неудаляемо и тратит квоту; выбор только активных версий уже покрыт CAND-001/002)
- Предусловия: активная симуляция с одним кандидатом.
## Шаги
1. Добавить второго кандидата на ту же активную симуляцию.
2. Сравнить версию симуляции и экран открытия у обоих.
## Ожидаемо
- Одна и та же simulation id/версия, одинаковые информация и условия окончания (AC3, треб.3).
