# UA-008: строка вступившего участника на /settings/users — 4 пункта меню, тексты окон блокировки / удаления / разблокировки (без подтверждения)
- Фича/экран: /settings/users, меню «⋮» строки участника (F-07, S-05, FL-07)
- Тикеты: #6a993d7ae4562a7e48cea3ed (#cea3ed) — треб.1, AC3 (текст), требование «הנתונים נשמרים»
- Роль/аккаунт: business (מנהל/ת חשבון testim), сессия .qa/auth/business.json
- Устройство: desktop 1440×900
- Тип: позитив (только чтение)
- Предусловия: в testim есть активный (פעיל) участник «מנהל/ת מגייס/ת». Окна закрываются без подтверждения; в автотесте все записи (POST/PATCH/DELETE к rest/functions) после загрузки списка обрываются — даже случайное подтверждение не заблокирует сохранённые аккаунты.
## Шаги
1. /settings/users; строка с «אתה» — есть ли меню «⋮».
2. Строка активного «מנהל/ת מגייס/ת» <имя> → «פעולות עבור <имя>».
3. «חסימת משתמש» → прочитать окно → Esc.
4. Меню → «הסרה מהעסק» → прочитать окно → Esc.
5. Если в списке есть «חסום» участник — его меню → «ביטול החסימה» → прочитать окно → Esc.
## Ожидаемо
- п.1: у своей строки меню нет.
- п.2: пункты «שינוי הרשאה», «עריכת שיוך לסימולציות», «חסימת משתמש», «הסרה מהעסק»; пунктов приглашения нет (треб.1).
- п.3: «לחסום את <имя>?» — «הסשן הפעיל של <имя> יסתיים מיד, ולא ניתן יהיה להתחבר עד לביטול החסימה. הנתונים שיצר/ה נשמרים.» (AC3).
- п.4: «להסיר את <имя> מהעסק?» — «הגישה של <имя> לנתוני העסק תסתיים מיד. הנתונים שיצר/ה נשמרים ומשויכים אליו/אליה.» (FL-07 «רשומות שיצר נותרות משויכות אליו»).
- п.5: «לבטל את החסימה של <имя>?» — «…יוכל/תוכל להתחבר שוב עם ההרשאה הקיימת.».
- После Esc: окна нет, статус строки не изменился; ни одной записи на сервер.
## Не входит
Само подтверждение блокировки/разблокировки/удаления и вход участника — вручную, UA-009 (нужен вступивший участник с паролем).
