# UA-010 (вручную): последнего активного מנהל/ת חשבון нельзя удалить, заблокировать или понизить
- Фича/экран: /admin/businesses/:id (Super Admin) и /settings/users (менеджер) (F-07, S-05)
- Тикеты: #6a993d7ae4562a7e48cea3ed (#cea3ed) — AC5, треб.6
- Роль/аккаунт: admin; бизнес, где ровно один активный מנהל/ת חשבון (21.10 — QA-бизнес с «QA Recruiter A»)
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: бизнес с единственным менеджером. В testim менеджеров несколько — там не проверяется.
## Шаги
1. admin: карточка бизнеса → строка единственного менеджера <имя> → «הסרה».
2. Закрыть «סגירה»; та же строка → понижение до «מנהל/ת מגייס/ת».
3. (Если есть) «חסימה» той же строки.
## Ожидаемо
- п.1: окно «להסיר את <имя> מהעסק?» с блоком «הפעולה נחסמה» — «בעסק חייב להישאר לפחות מנהל/ת חשבון פעיל/ה אחד/ת, ולכן לא ניתן להסיר, לחסום או להוריד את ההרשאה של <имя>. כדי לעשות זאת, יש קודם להפוך משתמש/ת אחר/ת למנהל/ת חשבון.»; кнопка только «סגירה» (AC5).
- п.2: «להפוך את <имя> למנהל/ת מגייס/ת?» — тот же блок «הפעולה נחסמה», только «סגירה» (треб.6).
- п.3: аналогично — блок «הפעולה נחסמה».
- Статус и роль менеджера не изменились.
## Почему вручную
Нет постоянного бизнеса с единственным менеджером и известным id; автотест на чужом бизнесе рискован. При появлении такого QA-бизнеса — автоматизировать как @desktop @prod-safe (только открыть окно и «סגירה»).
