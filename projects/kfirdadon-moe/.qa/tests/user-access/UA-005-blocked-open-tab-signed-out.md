# UA-005: заблокированный участник с открытой вкладкой отключается при переходе
- Фича/экран: /settings/users «חסימה» (F-07, FL-07 шаг 2), /login?notice=blocked
- Тикеты: #f6e816402bc7433839ec2a6f
- Роль/аккаунт: business + РАСХОДНЫЙ участник testim (жертва) — два окна
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: расходный участник, активен. Блокировка завершает его сессию (выход клиента) → после кейса .qa/auth/spare.json мёртв, нужен qa-login spare. В конце — «ביטול חסימה».
## Шаги
1. Жертва открыта на /settings/users.
2. business → строка жертвы → «חסימה».
3. Жертва без F5 переходит по меню.
4. Жертва: «назад» в браузере.
5. Консоль жертвы.
6. business → «ביטול חסימה».
## Ожидаемо
- При переходе — /login?notice=blocked, плашка «הגישה לחשבון חסומה» с текстом «…יש לפנות לתמיכה או למנהל/ת החשבון בעסק.»; меню и данных нет.
- «Назад» → снова /login, данные не показываются.
- Консоль: одна 403 и выход, без циклов 401/403 (источник: «מה רצוי» «ומשתמש חסום מנותק»; F-07 AC «…כאשר אני חוסם אותו, אז הסשן הפעיל שלו מסתיים»).
- Повторный вход заблокированного — вручную (пароль).
