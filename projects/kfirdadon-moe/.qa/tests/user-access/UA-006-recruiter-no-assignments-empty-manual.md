# UA-006 (вручную): מנהל/ת מגייס/ת без назначений — пустой список «עדיין לא שויכו אליך מועמדים»
- Фича/экран: /candidates (FL-09 шаг 2 «מצב ריק»; F-07 изоляция по роли)
- Тикеты: #6a993d7725c79eed60ef15fd (#ef15fd) Р2
- Роль/аккаунт: новый מנהל/ת מגייס/ת без шиуха (готового слота в .qa/auth нет: user/user-2/user-3 имеют назначения) — входит ТОЛЬКО пользователь
- Устройство: desktop 1440×900
- Тип: граница (пустое состояние)
- Предусловия: QA-бизнес с менеджером (агент — его сессией); бизнес, где у рекрутёра нет ни симуляций, ни кандидатов.
## Шаги
1. Пользователь даёт новый адрес temp-mail.org.
2. Менеджер: /settings/users → «הזמנת משתמש» → «מנהל/ת מגייס/ת», в «שיוך לסימולציות» ничего не отмечать → «שליחת הזמנה». Строка: шиух «ללא שיוך».
3. Пользователь: письмо → /invite/… → пароль, согласие → «הצטרפות».
4. Пользователь (новый рекрутёр): меню «מועמדים».
5. Пользователь: меню «סימולציות».
## Ожидаемо
- п.4: `candidates-empty` «עדיין לא שויכו אליך מועמדים» — «מועמדים שמנהל/ת החשבון ישייך/תשייך אליך יופיעו כאן; מועמדים של עמיתים אינם מוצגים ברשימה שלך. לשיוך מועמדים או סימולציה יש לפנות למנהל/ת החשבון.»; кнопки «הזמנת מועמד» нет; кандидатов коллег нет (источник: FL-09 шаг 2 «מצב ריק — טרם שויכו אליו מועמדים»; реджект 13.10).
- п.5: «עדיין אין סימולציות» — «עדיין לא שויכו אליך סימולציות.».
## Почему вручную
Нужен вступивший рекрутёр без назначений (создание аккаунта, пароль). Если появится сохранённая сессия такого рекрутёра (.qa/auth/<slot>.json) — кейс автоматизируется как @desktop @prod-safe (только просмотр).
