# BSET-001: экран «הגדרות העסק» — текущие значения, язык he/en, блок квоты
- Фича/экран: S-06 /settings/business (вкладка «פרטי העסק והמכסה»)
- Тикеты: #ebdb2f (6a993d7890d7492f45ebdb2f)
- Роль/аккаунт: business (testim, .qa/auth/business.json)
- Устройство: desktop 1440×900
- Тип: позитив (только чтение)
- Предусловия: у testim квота не задана (22.10).
## Шаги
1. Открыть /settings/business.
2. Сверить поля с businesses (своя строка), список опций «שפת ברירת מחדל».
3. Блок «מכסת סימולציות» против rpc get_business_usage.
## Ожидаемо
- «שם העסק», «תפקיד איש הקשר» = значения бизнеса; select «שפת ברירת מחדל» доступен, опции he=עברית, en=אנגלית (источник: AC2, факт 22.10).
- Без квоты: число «נוצלו» = used и текст «לא הוגדרה מכסה לחשבון, ולכן אין חסימה. הצריכה נספרת…»; с квотой — «נוצלו מתוך N» и остаток (AC3, S-06 пусто). Полей изменения квоты нет (R-02).
