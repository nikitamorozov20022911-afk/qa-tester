# CAND-015: /candidates у business — те же поиск и 4 фильтра, счётчик, комбинации, URL, пустое состояние
- Фича/экран: /candidates (S-10), Figma 678:652
- Тикеты: #cddab4 (6a993d6920b26e2d36cddab4)
- Роль/аккаунт: business (auth/bizt.json, testim)
- Устройство: desktop 1440×900
- Тип: позитив, только чтение (prod-safe)
- Предусловия: у аккаунта есть кандидаты (testim); ожидания берутся из list_candidates и обхода списка, не из фиксированных чисел.
## Шаги
1. Открыть /candidates (1440×900).
2. Проверить поиск и 4 фильтра: «תפקיד», «סימולציה», «מנהל מגייס», «סטטוס».
3. Обойти все страницы без фильтра, собрать менеджеров из колонки и число строк на каждого.
4. Выбирать каждого менеджера в «מנהל מגייס», сверять строки и счётчик «מציג x–y מתוך N»; сбрасывать.
5. Менеджер + каждый «סטטוס»; затем + поиск по имени первой строки.
6. Менеджер → URL → перезагрузка; поиск → перезагрузка.
7. Поиск несуществующего имени + менеджер → «ניקוי החיפוש והסינון».
## Ожидаемо
- Видны поиск и все 4 фильтра; итог счётчика без фильтров = числу строк list_candidates (AC3, реджект 3).
- Опции «מנהל מגייס» включают всех менеджеров из списка (реджект 3).
- Выбор менеджера: все строки этого менеджера, N «מתוך» = числу таких строк в полном списке, строк на странице = to−from+1 (AC3).
- Фильтры комбинируются: итог не больше, чем по одному менеджеру; строки удовлетворяют обоим условиям; поиск по имени сужает дальше (AC3).
- Состояние в URL: после reload тот же URL, значение фильтра, счётчик и строки; поиск тоже сохраняется (AC2).
- Пустой результат: «אין מועמדים שמתאימים לחיפוש ולסינון.», 0 строк, кнопка «ניקוי החיפוש והסינון» сбрасывает поиск и все 4 фильтра, счётчик возвращается к исходному, URL без параметров (AC5).
