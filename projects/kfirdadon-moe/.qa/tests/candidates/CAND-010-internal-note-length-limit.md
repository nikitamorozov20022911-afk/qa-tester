# CAND-010: заметка длиннее 4000 — не обрезается молча: сообщение о превышении, счётчик, блокировка сохранения, note_too_long от сервера → сообщение, текст остаётся
- Фича/экран: /candidates/:id/report — «הערה פנימית» (data-testid internal-note)
- Тикеты: #5f2fdf (08ef33ad7c5ff1b2945f2fdf); связан #7ea9a3 (CAND-006/007)
- Роль/аккаунт: business
- Устройство: desktop 1440×900
- Тип: граница + негатив
- Предусловия: кандидат с готовым отчётом QA-G4-A-1321 (QA_DECISION_CANDIDATE). Заметки не удаляются → add_internal_note перехватывается в браузере, до сервера ничего не доходит.
## Шаги
1. Вставить в поле 4500 символов («QA-AUTO-NOTE-5f2fdf-» + иврит).
2. «הוספת הערה».
3. Заменить текст на 3500, 3700, 4000 символов.
4. 3900 символов, ответ сервера 400 P0001 «note_too_long» (подмена) → «הוספת הערה».
## Ожидаемо
- Шаг 1: в поле все 4500 символов; «ההערה ארוכה מדי: 4,500 תווים מתוך 4,000. קצרו 500 תווים כדי לשמור.»; aria-invalid=true (источник: AC1/AC2, «מצב נדרש»).
- Шаг 2: запроса нет, alert «ההערה ארוכה מדי. קצרו אותה ונסו שוב.», текст на месте (источник: «ולא מאבד טקסט בשקט»).
- Шаг 3: 3500 — счётчика нет; 3700 — «נותרו 300 תווים מתוך 4,000»; 4000 — «נותרו 0 תווים מתוך 4,000», без aria-invalid (источник: AC1 «כמה תווים נותרו»).
- Шаг 4: alert «ההערה ארוכה מדי. קצרו אותה ונסו שוב.», текст в поле, новой заметки нет (источник: «note_too_long … מגיע למשתמש»).
