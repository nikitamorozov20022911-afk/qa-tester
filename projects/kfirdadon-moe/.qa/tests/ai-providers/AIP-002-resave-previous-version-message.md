# AIP-002: повторное сохранение той же יכולת+שפה — с «הגרסה הקודמת נשמרה», история פעילה + הוחלפה
- Фича/экран: AI-провайдеры, /admin/providers
- Тикеты: #c937f5ca1b172513b5ce1e2d
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: AIP-001 выполнен для того же тестового кода.
## Шаги
1. «עריכה של תמלול ב<код>» (יכולת заблокирована, «ביטול העריכה»).
2. Изменить הגדרות → «שמירת גרסה חדשה».
## Ожидаемо
- «נשמרה גרסה חדשה» + «… הגרסה הקודמת נשמרה בהיסטוריה.» (источник: «מה רצוי»)
- История «תמלול · <код>»: 2 строки — פעילה + הוחלפה, автор admin@admin.com (AC F-38: נשמרים מבצע השינוי ומועדו).
- Известное (не автоматизировано): устаревшая вкладка без перезагрузки не показывает фразу (stale-tab, находка 2026-10-04).
