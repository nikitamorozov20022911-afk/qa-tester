# AIP-001: первая конфигурация для языка без конфигураций — без «הגרסה הקודמת נשמרה»
- Фича/экран: AI-провайдеры, /admin/providers (F-38, FL-39)
- Тикеты: #c937f5ca1b172513b5ce1e2d
- Роль/аккаунт: admin (admin@admin.com)
- Устройство: desktop 1440×900 (контроль 375 — вручную)
- Тип: позитив
- Предусловия: тестовый код языка без единой конфигурации (q + 2 буквы, диапазон qaa–qtz). Конфигурации НЕУДАЛЯЕМЫ; рабочий he не трогать никогда.
## Шаги
1. /admin/providers → «הגדרת ספק»: יכולת «תמלול», שפה = тестовый код, ספק soniox, מודל stt-async-v5, הגדרות {"qa":"QA-AUTO-…"}.
2. «שמירת גרסה חדשה».
## Ожидаемо
- RPC admin_set_provider_config 200; уведомление «נשמרה גרסה חדשה» / «תמלול ב<код>: soniox · stt-async-v5.» БЕЗ «הגרסה הקודמת נשמרה בהיסטוריה.» (источник: «מה רצוי» — «ההודעה מוצגת רק כשקיימת גרסה קודמת»)
- В «היסטוריית גרסאות» одна строка «תמלול · <код>» — פעילה.
