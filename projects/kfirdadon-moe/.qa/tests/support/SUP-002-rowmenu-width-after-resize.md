# SUP-002: меню строки (⋮) после 700 → 1440 не сохраняет узкую ширину
- Фича/экран: /admin/support, RowMenu
- Тикеты: #8140c180a9bf2e83d1a17783 (комментарий программиста про RowMenu.tsx:84)
- Роль/аккаунт: admin
- Устройство: desktop, окно 1440 → 700 → 1440
- Тип: визуал (только чтение, prod-safe)
- Предусловия: в таблице есть строка с меню «⋮».
## Шаги
1. 1440: открыть меню строки, замерить ширину, закрыть (Esc).
2. 700: открыть то же меню, закрыть.
3. 1440: открыть снова, замерить.
## Ожидаемо
- Ширина меню на шаге 3 равна ширине на шаге 1 (±1 px), меню целиком в viewport (источник: комментарий программиста — «לא לשמור רוחב / לאפס בסגירה»).
