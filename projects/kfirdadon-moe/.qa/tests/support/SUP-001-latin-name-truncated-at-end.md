# SUP-001: /admin/support 1440 — латинское имя видно с начала, обрезано в конце с «…»
- Фича/экран: «תמיכה ותפעול» /admin/support (S-02, F-03)
- Тикеты: #8140c180a9bf2e83d1a17783
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: визуал (только чтение, prod-safe)
- Предусловия: в таблице есть строки с длинным латинским именем кандидата/бизнеса (напр. «QA-G4b-K3-13…»).
## Шаги
1. admin → /admin/support при 1440×900.
2. Колонки «בית עסק» и «מועמד»: для ячеек с текстом, начинающимся с латиницы, — Range на первом символе и проверка обрезки.
## Ожидаемо
- Прямоугольник первой буквы внутри прямоугольника текстового элемента (начало видно).
- У длинных имён scrollWidth > clientWidth, text-overflow: ellipsis, последний символ за пределами элемента — обрезка в конце (источник: «מה רצוי» — «שם ארוך נחתך בסופו עם שלוש נקודות, ותחילתו נשארת גלויה»; AC).
