# BIZ-INV-012: ожидающее приглашение на /settings/users — меню «העתקת קישור / שליחה חוזרת / ביטול ההזמנה», новая ссылка гасит прежнюю, отмена гасит ссылку
- Фича/экран: /settings/users, меню «⋮» строки приглашения; /invite/<token> (F-07, S-05, FL-07)
- Тикеты: #6a993d7ae4562a7e48cea3ed (#cea3ed) — AC1, AC2, треб.1, треб.3
- Роль/аккаунт: business (מנהל/ת חשבון testim), сессия .qa/auth/business.json; гость — окно без входа
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: приглашение создаёт сам тест — «QA-AUTO-cea3ed-<stamp>» на delivered+qa-auto-cea3ed-<stamp>@resend.dev (тестовый приёмник Resend, delivery_status=sent, реальному человеку не уходит). Чужие строки не трогаются.
## Шаги
1. /settings/users → «הזמנת משתמש» → «שם מלא» QA-AUTO-cea3ed-<stamp>, «מייל» delivered+qa-auto-cea3ed-<stamp>@resend.dev, роль по умолчанию, без шиуха → «שליחת הזמנה».
2. «פעולות עבור ההזמנה של QA-AUTO-…» — посмотреть пункты меню.
3. «העתקת קישור» → прочитать буфер; гостем открыть ссылку.
4. Меню → «שליחה חוזרת» (подтвердить, если спросит).
5. Гостем открыть прежнюю ссылку, затем новую.
6. Меню → «ביטול ההזמנה» → в окне «השארת ההזמנה».
7. Меню → «ביטול ההזמנה» → в окне «ביטול ההזמנה».
8. Гостем открыть последнюю ссылку.
## Ожидаемо
- п.2: пункты «העתקת קישור», «שליחה חוזרת», «ביטול ההזמנה»; пунктов участника («שינוי הרשאה», «חסימת משתמש», «הסרה מהעסק») нет (треб.1).
- п.3: в буфере `<сайт>/invite/<token>` созданного приглашения; гость видит форму «הצטרפות לחשבון העסק» с полем «סיסמה».
- п.4: resend-invitation 200, новый token ≠ прежнего; строка остаётся «ממתין להצטרפות» (AC1 «מופק קישור חדש… והסטטוס נותר ממתינה»).
- п.5: прежняя ссылка — «ההזמנה בוטלה» + «נשלחה הזמנה חדשה במקום ההזמנה הזו, ולכן הקישור הזה כבר לא פעיל.», полей нет (AC1 «הקישור הקודם מתבטל», треб.3); новая — форма.
- п.6: окно «לבטל את ההזמנה של QA-AUTO-…?» — «הקישור יפסיק לפעול מיד. מי שיפתח אותו יראה שההזמנה בוטלה ויתבקש לפנות למנהל/ת החשבון. אפשר לשלוח הזמנה חדשה בכל עת.», кнопки «השארת ההזמנה» и «ביטול ההזמנה»; «השארת ההזמנה» закрывает окно, строка «ממתין להצטרפות» на месте, cancel_invitation не вызывался.
- п.7: cancel_invitation ok, «ההזמנה בוטלה», строки «ממתין להצטרפות» с этим именем нет.
- п.8: «ההזמנה בוטלה» + «מנהל/ת החשבון ביטל/ה את ההזמנה, ולכן הקישור כבר לא פעיל.», блок «איך מקבלים הזמנה חדשה?» — «יש לפנות למנהל/ת החשבון בעסק שהזמין אותך ולבקש הזמנה חדשה.», полей нет (AC2 «…הודעה שההזמנה בוטלה עם נתיב פנייה למנהל החשבון»).
