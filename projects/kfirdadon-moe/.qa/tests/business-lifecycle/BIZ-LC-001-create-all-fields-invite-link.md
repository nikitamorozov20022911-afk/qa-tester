# BIZ-LC-001: создание бизнеса со всеми полями — карточка и ссылка первому менеджеру с копированием
- Фича/экран: /admin/businesses/new → /admin/businesses/:id (S-01, F-01, FL-01 ш.1)
- Тикеты: #6a993d795019333734edc22d (#edc22d)
- Роль/аккаунт: admin (Super Admin) + guest (открыть ссылку)
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: имя бизнеса «QA-AUTO-…» (одноразовый, удаляется в конце). Почты на example.com — письмо не уходит (delivery send_failed), это нормально.
## Шаги
1. /admin/businesses/new: проверить значения по умолчанию — «שפת ברירת מחדל» = עברית, «סטטוס החשבון» = פעיל.
2. Заполнить: שם העסק, תחום פעילות, שם איש הקשר, תפקיד איש הקשר, טלפון, מייל; מנהל/ת החשבון הראשון/ה — שם מלא, מייל; הערה פנימית (необязательно) → «יצירת בית העסק».
3. В карточке — блок «בית העסק נוצר» → «העתקת הקישור».
4. Гость открывает скопированную ссылку.
## Ожидаемо
- admin-create-business 201; переход на /admin/businesses/<uuid>; h1 = имя бизнеса, статус «פעיל» (AC1).
- «פרטי העסק»: איש קשר «<имя>, <תפקיד>», טלפון, מייל, שפת ברירת מחדל «עברית», הערה פנימית (треб.1, треб.5).
- Блок «בית העסק נוצר» с полной ссылкой https://…/invite/<token> и кнопкой «העתקת הקישור»; после нажатия — «הקישור הועתק», в буфере та же ссылка (FL-01 ш.1, реджект 05.10 Р2).
- «הזמנות»: строка менеджера «מנהל/ת חשבון», «ממתינה» (FL-01 ш.2).
- Гость по ссылке: «הצטרפות לחשבון העסק», поле «סיסמה» (AC1 «מפיקה קישור הזמנה»).
