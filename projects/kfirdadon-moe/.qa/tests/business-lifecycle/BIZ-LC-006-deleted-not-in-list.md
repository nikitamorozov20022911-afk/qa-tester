# BIZ-LC-006: удалённый бизнес не показывается в списке, его ссылки не работают
- Фича/экран: /admin/businesses/:id → /admin/businesses (F-01 AC6)
- Тикеты: #6a993d795019333734edc22d (#edc22d)
- Роль/аккаунт: admin + guest
- Устройство: desktop 1440×900
- Тип: позитив (необратимо — только бизнес, созданный тестом)
- Предусловия: бизнес из BIZ-LC-001.
## Шаги
1. «סטטוס חדש» = נמחק → «עדכון סטטוס» → «אישור» (текст подтверждения «בית העסק יוסר מהרשימה, משתמשיו לא יוכלו להתחבר ונתוניו לא יהיו נגישים לאף משתמש עסקי.»).
2. Список /admin/businesses (новая загрузка).
3. Гость открывает ссылку приглашения.
## Ожидаемо
- Переход на /admin/businesses, сообщение «בית העסק נמחק» и «<имя> הוסר מהרשימה…».
- admin_list_businesses не содержит id бизнеса; в таблице «רשימת בתי העסק» строки с именем нет (AC6). Внимание: имя есть в сообщении об удалении — проверять таблицу, а не весь текст страницы.
- Ссылка приглашения — «החשבון העסקי אינו פעיל» (BIZ-INV-007).
- Пользователи удалённого бизнеса со старой сессией — /login, «פג תוקף החיבור» (BIZ-LC-010, вручную; решение пользователя 14.10 — этого достаточно для AC6).
