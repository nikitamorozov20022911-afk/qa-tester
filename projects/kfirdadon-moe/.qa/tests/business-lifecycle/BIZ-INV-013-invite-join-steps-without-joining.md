# BIZ-INV-013: гость по ссылке приглашения — шаги «אימות מייל → סיסמה → פרטים → תנאים» без вступления; чек-лист пароля, блоки; отмена → «ההזמנה בוטלה»
- Фича/экран: /settings/users (менеджер) → /invite/<token> (F-08, S-04)
- Тикеты: #6a993d7ada81dff9be145887 (#145887) — AC1, AC3, AC4, AC5, треб.7, треб.8
- Роль/аккаунт: business (מנהל/ת חשבון testim, .qa/auth/business.json) создаёт приглашение; гость — окно без входа
- Устройство: desktop 1440×900
- Тип: позитив + негатив (слабый пароль, без галочек)
- Предусловия: приглашение создаёт сам тест — «QA-AUTO-145887-<stamp>», delivered+qa-auto-145887-<stamp>@resend.dev, роль «מנהל/ת מגייס/ת», шиух — первая симуляция (если есть). Финальное «הצטרפות לחשבון» с обеими галочками НЕ нажимается (аккаунт не создаётся); пароль — случайная строка, нигде не хранится.
## Шаги
1. Менеджер: «הזמנת משתמש» → имя/почта/роль/симуляция → «שליחת הזמנה» → «ההזמנה נשלחה»; ссылка /invite/<token>.
2. Гость открывает ссылку (шаг 1), смотрит степпер, заголовок, карточку, низ → «המשך».
3. Шаг 2: карточка приглашения; поле «סיסמה» — «הצגה»/«הסתרה»; ввести «a» → «המשך»; затем по частям: 10 строчных → + заглавная → + цифра → + «!»/«#» → «המשך».
4. Шаг 3: карточка с «שיוך לסימולציות», «טלפון נייד» пустой → «המשך».
5. Шаг 4: «הצטרפות לחשבון» без галочек; отметить только «תנאי השימוש» → снова «הצטרפות לחשבון».
6. Менеджер: отменить приглашение; гость: та же ссылка.
## Ожидаемо
- п.2: степпер «1 · אימות מייל / 2 · סיסמה / 3 · פרטים / 4 · תנאים», текущий — первый; h1 «הצטרפות לצוות»; «<מזמין> הזמין/ה אתכם לחשבון של <עסק>…»; карточка «המייל שלכם / עסק / הזמין/ה אתכם»; «כתובת המייל מאומתת באמצעות הקישור האישי… הקישור בתוקף עד <дата> ולשימוש אחד בלבד.»; «פנייה לתמיכה», «תנאי שימוש · מדיניות פרטיות» (AC1).
- п.3: карточка שם/הרשאה «מנהל/ת מגייס/ת»/מייל/עסק/הזמין/ה אתכם, без полей ввода + «הפרטים נקבעו בהזמנה ואי אפשר לשנות אותם כאן. טעות בפרטים? פנו ל<מזמין>.» (треб.7). Чек-лист «לפחות 10 תווים», «אות גדולה וקטנה», «ספרה», «סימן, למשל ! או #» — пусто: ничего не отмечено; «a» — отмечено только «קטנה», «המשך» не переходит, у поля ошибка, значение «a» сохранено (AC5); пункты отмечаются по мере ввода; полный — переход на шаг 3.
- п.4: «הפרטים שלכם», «השם, המייל וההרשאה נקבעו בהזמנה. נשאר להשלים את מספר הטלפון.», «שיוך לסימולציות» = симуляция (или «טרם שויכו סימולציות»), «טלפון נייד» «לא חובה».
- п.5: «עוד צעד אחד», «קראו ואשרו את התנאים — ואתם בצוות של <עסק>.», сводка «סיסמה נקבעה» / «פרטים <שם>» с двумя «עריכה»; под галочками «הנוסח המאושר טרם פורסם. עם פרסומו הוא יוצג כאן.» (или после публикации — «גרסה X · בתוקף מתאריך …», задача #1f3466, треб.8); без галочек — «כדי להצטרף צריך לאשר את תנאי השימוש» и «כדי להצטרף צריך לאשר גם את מדיניות הפרטיות», остаёмся на шаге 4 (AC3); с одной галочкой — остаётся только вторая ошибка; accept-invitation не вызывается.
- п.6: «ההזמנה בוטלה», «מנהל/ת החשבון ביטל/ה את ההזמנה, ולכן הקישור כבר לא פעיל.», «איך מקבלים הזמנה חדשה?», полей нет (AC4).
