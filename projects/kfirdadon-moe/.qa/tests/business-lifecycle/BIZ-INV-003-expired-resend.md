# BIZ-INV-003: פג תוקף — без метки, только «שליחה מחדש»; после — ממתינה, новая ссылка работает, прежняя «ההזמנה בוטלה»
- Фича/экран: /admin/businesses/<id>, блок «הזמנות»; /invite/<token>
- Тикеты: #ce0c4c2aa2fc0dbfcddfcb74
- Роль/аккаунт: admin + guest
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: истечение — 7 дней (D-22), руками не получить. Автотест: подмена ответа admin_get_business (реальное приглашение показано как expired); «שליחה מחדש» вызывает настоящий resend-invitation.
## Шаги
1. Карточка → строка «פג תוקף».
2. «שליחה מחדש».
3. Гость открывает новую ссылку, затем прежнюю.
## Ожидаемо
- Строка «פג תוקף»: нет «שליחת המייל נכשלה» и «בתוקף עד», единственная кнопка «שליחה מחדש» (источник: «מה רצוי» — «הזמנה שפג תוקפה ניתנת לשליחה מחדש»).
- resend-invitation 200, строка становится «ממתינה», новый токен ≠ прежнему.
- Новая ссылка → «הצטרפות לחשבון העסק» с полем «סיסמה»; прежняя → «ההזמנה בוטלה», полей нет (AC F-07).
