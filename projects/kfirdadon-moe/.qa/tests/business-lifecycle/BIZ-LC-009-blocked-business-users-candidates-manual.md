# BIZ-LC-009 (вручную): блокировка — пользователи не входят, ссылки кандидатов не работают; после разблокировки — снова работают
- Фича/экран: /login, открытые сессии пользователей, ссылка кандидата (F-01 AC3, треб.4)
- Тикеты: #6a993d795019333734edc22d (#edc22d)
- Роль/аккаунт: admin + вступившие менеджер и מנהל/ת מגייס/ת своего QA-бизнеса + кандидат со ссылкой
- Устройство: desktop 1440×900 (кандидат — телефон)
- Тип: позитив
- Предусловия: свой QA-бизнес, в который пользователь сам вступил по приглашению (нужен пароль — не автоматизируется), опубликованная симуляция и приглашённый кандидат.
## Шаги
1. admin блокирует бизнес.
2. Открытые вкладки менеджера и рекрутёра — любое действие/переход; затем вход по паролю.
3. Ссылка кандидата этого бизнеса.
4. admin разблокирует; повторить 2–3.
## Ожидаемо
- Открытые сессии → /login с «הגישה לחשבון חסומה»; вход → «החשבון העסקי אינו פעיל» (AC3).
- Ссылка кандидата → «הסימולציה אינה זמינה כרגע», кнопка «לפנות לצוות הגיוס» (AC3).
- После разблокировки вход и ссылка кандидата снова работают (треб.4; зафиксировано 13.10).
## Почему вручную
Вступление в бизнес и вход требуют пароля; кандидат нужен в бизнесе, созданном тестом.
