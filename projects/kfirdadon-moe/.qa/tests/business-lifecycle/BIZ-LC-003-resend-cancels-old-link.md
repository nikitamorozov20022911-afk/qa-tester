# BIZ-LC-003: повторная отправка приглашения первому менеджеру отменяет прежнюю ссылку
- Фича/экран: /admin/businesses/:id → «הזמנות»; /invite/<token> (F-01 треб.8, F-07)
- Тикеты: #6a993d795019333734edc22d (#edc22d)
- Роль/аккаунт: admin + guest
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: бизнес из BIZ-LC-001 (приглашение ממתינה, токен известен).
## Шаги
1. В строке менеджера «שליחה מחדש».
2. Гость открывает прежнюю ссылку и новую.
## Ожидаемо
- resend-invitation 200, новый токен ≠ прежнего; в строке сообщение «נוצר קישור חדש, אך שליחת המייל נכשלה. אפשר להעתיק אותו.»; строка остаётся «ממתינה».
- Прежняя ссылка: h1 «ההזמנה בוטלה», текст «נשלחה הזמנה חדשה במקום ההזמנה הזו…», полей нет; новая — форма вступления (треб.8 «שליחה חדשה מבטלת את הקודמת»).
- Наблюдение 14.10: после «שליחה מחדש» блок «בית העסק נוצר» показывал прежнюю ссылку — баг #e17f2c, исправлен 21.10, проверяется кейсом BIZ-LC-011.
