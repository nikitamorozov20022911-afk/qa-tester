# BIZ-INV-011 (вручную): письмо приглашения приходит, вступление по ссылке, строка «ממתין להצטרפות» → «פעיל»
- Фича/экран: /settings/users (менеджер) → письмо → /invite/<token> → дашборд нового участника
- Тикеты: #6a993d7b083193c466c31690 (#c31690) треб.2, треб.4; связано #145887 (форма вступления)
- Роль/аккаунт: менеджер QA-бизнеса (агент — своей сессией, напр. business или pilotmgr) + новый участник (входит ТОЛЬКО пользователь)
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: агент пароли не вводит и аккаунты не создаёт — вступление делает пользователь.
## Шаги
1. Пользователь открывает https://temp-mail.org/ и даёт агенту новый адрес (пример 22.10: sofego9727@proguidex.com).
2. Менеджер: /settings/users → «הזמנת משתמש» → «שם מלא» «QA-R1-<ддмм>», «מייל» = адрес, «הרשאה» «מנהל/ת מגייס/ת» (шиух — по задаче) → «שליחת הזמנה».
3. Ожидаемо у менеджера: «ההזמנה נשלחה — QA-R1-… יקבל/תקבל במייל … קישור הצטרפות אישי…»; строка «ממתין להצטרפות · בתוקף עד <сегодня+7>».
4. Пользователь: в temp-mail письмо от simulator@shnaider.pro (тема/текст с названием бизнеса), кнопка/ссылка ведёт на https://kfir-dadon.vercel.app/invite/…; ссылка личная (токен в адресе).
5. Пользователь: открыть ссылку в инкогнито → видны название бизнеса и «מנהל/ת מגייס/ת» (только чтение) → задать пароль, согласие → «הצטרפות». Ожидаемо: дашборд нового участника.
6. Менеджер: обновить /settings/users. Ожидаемо: строка QA-R1-… — «פעיל», «בתוקף עד» нет; в приглашениях — «התקבלה».
7. Пользователь: снова открыть ту же ссылку /invite/… → «כבר נעשה שימוש בהזמנה» (одноразовая).
8. Очистка (только с «да» пользователя): строка → «הסרה».
## Ожидаемо
См. шаги (источник: AC1 «נשלח מייל הזמנה עם קישור אישי חד-פעמי»; треб.2; треб.4 «לאחר השלמת ההרשמה עוברת לסטטוס פעיל»).
## Почему вручную
Чтение почты и вступление с паролем (создание аккаунта) — только пользователь.
