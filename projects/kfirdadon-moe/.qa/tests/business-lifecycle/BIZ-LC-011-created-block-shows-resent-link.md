# BIZ-LC-011: блок «בית העסק נוצר» после «שליחה מחדש» показывает новую ссылку, прежняя отменена
- Фича/экран: /admin/businesses/:id сразу после создания — блок «בית העסק נוצר» и «הזמנות» (F-01 треб.8, F-07)
- Тикеты: #84a6c7b9b86bbe3ff8e17f2c (#e17f2c)
- Роль/аккаунт: admin (Super Admin) + guest
- Устройство: desktop 1440×900
- Тип: позитив (регресс бага)
- Предусловия: новый бизнес, созданный в этой же вкладке (блок «בית העסק נוצר» виден), почта менеджера на example.com (письмо не уходит).
## Шаги
1. /admin/businesses/new → заполнить все обязательные поля → «יצירת בית העסק»; запомнить ссылку L1 из блока «בית העסק נוצר».
2. Без перезагрузки: «הזמנות» → строка менеджера → «שליחה מחדש» (L2).
3. Ещё раз «שליחה מחדש» (L3).
4. В блоке «בית העסק נוצר» → «העתקת הקישור».
5. Гость открывает L1, L2, L3.
## Ожидаемо
- После каждой повторной отправки блок «בית העסק נוצר» показывает ссылку с новым токеном (из ответа resend-invitation), прежней ссылки в блоке нет; копирование даёт новую ссылку.
- Строка приглашения — «ממתינה», «נוצר קישור חדש, אך שליחת המייל נכשלה. אפשר להעתיק אותו.».
- L1 и L2 — «ההזמנה בוטלה», полей нет; L3 — форма «הצטרפות לחשבון העסק» (источник: «מה רצוי» #e17f2c; треб.8 «שליחה חדשה מבטלת את הקודמת»).
