# BIZ-LC-005: блокировка и разблокировка бизнеса из карточки — статус в карточке и в списке
- Фича/экран: /admin/businesses/:id «סטטוס החשבון», /admin/businesses (F-01 AC3, треб.4)
- Тикеты: #6a993d795019333734edc22d (#edc22d)
- Роль/аккаунт: admin (+ guest — ссылка приглашения, см. BIZ-INV-005/004)
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: только бизнес, созданный тестом (BIZ-LC-001). Чужие бизнесы не блокировать.
## Шаги
1. «סטטוס חדש» = חסום → «עדכון סטטוס» → подтверждение «לאשר את שינוי הסטטוס?» → «אישור».
2. Список /admin/businesses — строка бизнеса.
3. Гость открывает ссылку приглашения.
4. Обратно «פעיל» тем же путём.
## Ожидаемо
- admin_set_business_status 200; в карточке статус «חסום»; в списке ячейка «סטטוס» = «חסום».
- Ссылка приглашения — «החשבון העסקי אינו פעיל», без формы (немедленный эффект, треб.4; подробно — BIZ-INV-005).
- После «פעיל» — карточка «פעיל», ссылка снова показывает форму (BIZ-INV-004).
- Вход пользователей и ссылки кандидатов заблокированного бизнеса — BIZ-LC-009 (вручную).
