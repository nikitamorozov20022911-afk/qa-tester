# BIZ-INV-010: менеджер приглашает участника — форма «הזמנת משתמש», «ההזמנה נשלחה», строка «ממתין להצטרפות · בתוקף עד …»
- Фича/экран: /settings/users, окно «הזמנת משתמש» (F-06, S-05, FL-06)
- Тикеты: #6a993d7b083193c466c31690 (#c31690)
- Роль/аккаунт: business (מנהל/ת חשבון testim), сессия .qa/auth/business.json
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: в testim есть хотя бы одна активная симуляция (иначе вместо списка — «עדיין אין בעסק סימולציות לשיוך…», тест это допускает).
## Шаги
1. /settings/users → «הזמנת משתמש».
2. Сразу «שליחת הזמנה» с пустыми полями.
3. Переключить «הרשאה» на «מנהל/ת חשבון», затем обратно на «מנהל/ת מגייס/ת».
4. «שם מלא» = QA-AUTO-c31690-<stamp>, «מייל» = delivered+qa-auto-c31690-<stamp>@resend.dev (тестовый приёмник Resend — письмо «доставлено», реальному человеку не уходит), отметить первую симуляцию (если есть) → «שליחת הזמנה».
5. Очистка: «פעולות עבור ההזמנה של QA-AUTO-…» → «ביטול ההזמנה» → подтвердить «ביטול ההזמנה».
## Ожидаемо
- Окно: заголовок «הזמנת משתמש», «נשלח מייל עם קישור אישי להצטרפות לחשבון של …»; поля «שם מלא», «מייל»; «הרשאה»: «מנהל/ת מגייס/ת» выбрано по умолчанию, подсказка «רואה רק את הסימולציות שתסמנו כאן ואת המועמדים שלהן.»; блок «שיוך לסימולציות»; строка «ההזמנה בתוקף 7 ימים — עד <дата> — ולשימוש אחד» (AC1, треб.1, F-08 AC4 «7 ימים, שימוש אחד»).
- п.2: «יש להזין שם מלא», «יש להזין כתובת מייל»; запрос invite-user не отправлен.
- п.3: при «מנהל/ת חשבון» блока «שיוך לסימולציות» нет, подсказка «…ולכן אין צורך לשייך סימולציות.»; обратно — блок снова есть.
- п.4: invite-user 200, delivery_status=sent; окно закрыто; плашка «ההזמנה נשלחה» — «QA-AUTO-… יקבל/תקבל במייל <адрес> קישור הצטרפות אישי. ההזמנה מופיעה ברשימה בסטטוס ממתינה עד להצטרפות.»; в списке строка QA-AUTO-…: «ממתין להצטרפות», «בתוקף עד …», «מנהל/ת מגייס/ת», шиух = выбранная симуляция (или «ללא שיוך») (AC1 «נוצרת הזמנה בסטטוס ממתינה ונשלח מייל», треб.4).
- п.5: «ההזמנה בוטלה»; строки «ממתין להצטרפות» с этим именем нет.
