# BIZ-LC-010 (вручную): пользователи удалённого бизнеса со старой сессией не получают данных
- Фича/экран: любой экран бизнеса; API (F-01 AC6)
- Тикеты: #6a993d795019333734edc22d (#edc22d)
- Роль/аккаунт: вступившие пользователи своего QA-бизнеса (сессии сохранены до удаления)
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: свой QA-бизнес с вступившими пользователями (пароль), затем удалён admin.
## Шаги
1. Открыть сайт со старой сессией каждого пользователя.
2. Вызвать API бизнеса со старым токеном; попробовать обновить токен.
## Ожидаемо
- Редирект на /login?notice=expired, «פג תוקף החיבור…», данных бизнеса в DOM нет.
- API → 401 (JWT expired), refresh → 400 refresh_token_not_found. Решение пользователя 14.10: отказа на входе достаточно, проверка RLS с действующим токеном не требуется.
## Почему вручную
Нужны сессии вступивших пользователей (пароль) удалённого бизнеса; в автотесте их не получить.
