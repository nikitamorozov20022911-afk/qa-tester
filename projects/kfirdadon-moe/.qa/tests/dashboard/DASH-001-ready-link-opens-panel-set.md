# DASH-001: ссылка «לכל הדוחות המוכנים» в панели решений открывает тот же набор, что панель
- Фича/экран: дашборд (/) → панель «ממתינים להחלטה שלכם» → /candidates
- Тикеты: #a8e7e24c31c0c182cdc6043e
- Роль/аккаунт: business (testim)
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: в панели есть ≥1 карточка (готовый отчёт без решения).
## Шаги
1. / → панель «ממתינים להחלטה שלכם» (подпись «דוחות מוכנים שעוד לא נקבע להם סטטוס גיוס»). Запомнить имена карточек панели.
2. Ссылка «לכל הדוחות המוכנים»: href.
3. Клик по ссылке.
4. На открывшемся списке — колонка «החלטת גיוס» во всех строках; поиск каждого имени из панели.
## Ожидаемо
- href = /candidates?status=awaiting_decision; после клика URL с status=awaiting_decision, фильтр статуса «ממתינים להחלטה» (источник: AC — «פותח את אותה קבוצה שהפאנל מציג (דוחות מוכנים שעדיין אין להם החלטת גיוס)»).
- Во всех строках «החלטת גיוס» = «טרם נקבע»; каждое имя из панели находится в этом списке.
