# ACL-005: SA — выбор причины открывает контент и пишет запись в журнал (кто, кандидат, тип контента, причина, время)
- Фича/экран: /admin/support → «צפייה בתוכן» → /admin/support/candidates/<id>/report?reason=<код>; /admin/access-log (F-04)
- Тикеты: #6a993d78df85add81c766e3c
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив (добавляет запись в неизменяемый журнал — не prod-safe; удалить запись нельзя по требованию)
- Предусловия: строка /admin/support с data-report-status="ready" и пунктом «צפייה בתוכן».
## Шаги
1. admin → /admin/support; строка с готовым отчётом → меню → «צפייה בתוכן».
2. «סיבת הגישה» = «תמיכה תפעולית» → «צפייה בתוכן».
3. На странице отчёта проверить шапку.
4. /admin/access-log → «מזהה מועמד» = id кандидата, «מתאריך»/«עד תאריך» = сегодня → «סינון».
## Ожидаемо
- Адрес /admin/support/candidates/<id>/report?reason=support; видно data-testid="attempt-view"; шапка «צפייה בתוכן לצורך תמיכה תפעולית · הצפייה נרשמת ביומן הגישה», заголовок — имя кандидата.
- В журнале первая (самая свежая) строка: «פעולה» = «צפייה בתוכן מועמד»; «תוכן וסיבה» содержит «דוח · תמיכה תפעולית»; «משתמש» — admin (super admin); «מועמד» = id; «מועד» — сегодня, не раньше момента шага 2 (источник: AC2 «זהות המשתמש, המועמד, סוג התוכן, הסיבה וחותמת הזמן»).
- Очистка: не требуется и невозможна (журнал неизменяем, AC5).
