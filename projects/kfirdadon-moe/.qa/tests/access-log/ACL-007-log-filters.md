# ACL-007: SA — фильтры журнала доступа: по кандидату, по пользователю, по диапазону дат; пустой результат и ошибки ввода
- Фича/экран: /admin/access-log «רישום גישה» (F-04)
- Тикеты: #6a993d78df85add81c766e3c
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив + негатив (только чтение, prod-safe)
- Предусловия: в журнале есть записи с кандидатом (кнопка «כל הגישות»).
## Шаги
1. admin → /admin/access-log.
2. В строке с кандидатом нажать «כל הגישות».
3. «ניקוי הסינון»; «משתמש» = первый пользователь списка (не «כל המשתמשים») → «סינון».
4. «ניקוי הסינון»; «מתאריך» = «עד תאריך» = дата из «מועד» первой строки → «סינון».
5. «מתאריך»/«עד תאריך» = 2099-01-01 → «סינון».
6. «מתאריך» = 2026-10-10, «עד תאריך» = 2026-10-01 → «סינון».
7. «מזהה מועמד» = «abc» → «סינון».
## Ожидаемо
- Шаг 2: «מזהה מועמד» заполнен id; во всех строках столбец «מועמד» = этот id; «נמצאו N רשומות».
- Шаг 3: все строки ответа rpc/admin_list_access_log имеют actor_id выбранного пользователя; в «משתמש» — его имя/почта.
- Шаг 4: у всех строк ответа occurred_at в выбранном дне (локально) (источник: AC3 «לסנן לפי מועמד, לפי משתמש ולפי טווח תאריכים»).
- Шаг 5: «לא נמצאו רשומות גישה» + «…אפשר להרחיב את טווח התאריכים או לנקות את הסינון.» (FL-04).
- Шаг 6: «תאריך הסיום חייב להיות אחרי תאריך ההתחלה», запрос не уходит.
- Шаг 7: «יש להזין מזהה מועמד מלא, כפי שהוא מופיע ברשומה», запрос не уходит.
