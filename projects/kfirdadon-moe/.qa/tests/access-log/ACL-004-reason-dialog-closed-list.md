# ACL-004: SA — диалог «לפתוח את התוכן של …?»: закрытый список причин, без выбора не открывается, «ביטול» ничего не открывает и не пишет в журнал
- Фича/экран: S-02 «מסך תמיכה ותפעול» /admin/support → меню строки «צפייה בתוכן» (F-04, FL-04)
- Тикеты: #6a993d78df85add81c766e3c
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: негатив / граница (только чтение, prod-safe)
- Предусловия: строка кандидата с официальным ניסיון на /admin/support.
## Шаги
1. admin → /admin/support; в строке кандидата меню (row-menu) → «צפייה בתוכן».
2. Открыть список «סיבת הגישה».
3. Не выбирая причину, нажать «צפייה בתוכן».
4. Нажать «ביטול».
5. /admin/access-log → «כל הגישות» / «מזהה מועמד» = id кандидата → «סינון»; сравнить количество записей до шага 1 и после шага 4.
## Ожидаемо
- Диалог «לפתוח את התוכן של <имя>?» с текстом «…כל צפייה נרשמת ברישום הגישה עם הסיבה שנבחרה».
- В списке ровно: «בחירת סיבה» (пусто) + «תמיכה תפעולית», «בקרת איכות», «טיפול מורשה» (источник: req. «רשימה סגורה»; FL-04 «תמיכה, בקרת איכות או טיפול מורשה בלבד»).
- Без выбора: ошибка «יש לבחור את סיבת הגישה לתוכן», адрес остаётся /admin/support.
- «ביטול»: диалог закрыт, адрес /admin/support, число записей журнала по кандидату не изменилось (источник: AC1, AC2 — запись только при показе контента).
