# ACL-003: SA — прямой адрес отчёта кандидата без причины (или с причиной вне списка) не показывает контент
- Фича/экран: S-19 «דוח המועמד» в контуре SA, /admin/support/candidates/<id>/report (F-04)
- Тикеты: #6a993d78df85add81c766e3c
- Роль/аккаунт: admin (admin@admin.com, super_admin)
- Устройство: desktop 1440×900
- Тип: негатив (только чтение, prod-safe)
- Предусловия: на /admin/support есть строка кандидата с официальным ניסיון (пункт меню «צפייה בתוכן»).
## Шаги
1. admin → /admin/support, взять data-candidate-id первой строки с «צפייה בתוכן».
2. Открыть /admin/support/candidates/<id>/report (без ?reason).
3. Открыть тот же адрес с ?reason=foo.
## Ожидаемо
- Оба раза: панель «נדרשת סיבת גישה» с текстом «צפייה בתוכן של מועמד מחייבת סיבה מהרשימה הסגורה…» и ссылкой «חזרה לתמיכה ותפעול» (→ /admin/support).
- Контента нет: нет data-testid="attempt-view", нет транскрипта/плеера; запрос rpc/get_candidate_report не уходит (источник: AC1 «נדרשת בחירת סיבת גישה מתוך רשימה מוגדרת לפני שהתוכן מוצג»; FL-04 «ניסיון לפתוח תוכן ללא בחירת סיבה נחסם»).
