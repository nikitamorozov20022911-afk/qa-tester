# ACL-008: журнал доступа неизменяем — в UI нет правки/удаления, PATCH/DELETE через API отклоняются (403)
- Фича/экран: /admin/access-log; REST /rest/v1/audit_log (F-04)
- Тикеты: #6a993d78df85add81c766e3c
- Роль/аккаунт: admin (самая сильная роль)
- Устройство: desktop 1440×900
- Тип: негатив / безопасность
- Предусловия: в журнале есть запись, сделанная admin. Попытки записи безвредны даже при сбое защиты: PATCH ставит полю reason его же текущее значение, DELETE адресован несуществующему id (права на таблицу проверяются до поиска строк).
## Шаги
1. admin → /admin/access-log.
2. GET /rest/v1/audit_log?actor_id=eq.<admin>&limit=1 — снимок записи.
3. PATCH /rest/v1/audit_log?id=eq.<id> {"reason": <то же значение>}.
4. DELETE /rest/v1/audit_log?id=eq.00000000-0000-0000-0000-000000000000.
5. GET той же записи.
## Ожидаемо
- UI: описание «הרישום אינו ניתן לעריכה או למחיקה»; в строках нет кнопок/меню правки и удаления (единственная кнопка в строке — «כל הגישות»).
- PATCH → 403, code 42501 «permission denied for table audit_log»; DELETE → 403, 42501.
- Запись после = снимок до (источник: AC5 «הפעולה נחסמת ורישום הגישה נותר בלתי ניתן לשינוי»; api-1310 п.1–4).
