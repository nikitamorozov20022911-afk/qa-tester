# ADM-002: боковое меню Super Admin — «בקשות מידע» 4-м пунктом со значком, ведёт на /admin/data-requests (активный); «התנתקות» со значком
- Фича/экран: боковое меню SA (app-sidebar) на всех экранах /admin; экран «בקשות עיון ומחיקת מידע» (S-22)
- Тикеты: #59e715 (193a63d7d3f3e0502e59e715)
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив, визуал (только чтение)
- Предусловия: сессия admin.
## Шаги
1. /admin/businesses → меню «ניווט ראשי».
2. Нажать «בקשות מידע».
3. Перезагрузить /admin/data-requests.
4. Повторить осмотр меню на /admin/access-log, /admin/support, /admin/providers, /admin/templates.
## Ожидаемо
- Пункты по порядку: בתי עסק, רישום גישה, תמיכה ותפעול, **בקשות מידע**, ספקי AI ותמלול, תבניות סימולציה; у каждого значок 20×20; значок «בקשות מידע» свой (не повторяет другие) (источник: AC1, Figma 812:448 / 816:1183).
- Клик → /admin/data-requests, h1 «בקשות עיון ומחיקת מידע», пункт «בקשות מידע» активен (aria-current=page), остальные нет; после reload так же (источник: AC1 «פותח את בקשות המידע», S-22 «כניסה — מתפריט ה-Super Admin», Figma 822:2114).
- «התנתקות» — со значком icon/logout 20×20 (источник: AC2).
- Меню одинаково на всех разделах (источник: Figma 816:1183).
