# RPTASIDE-002: колесо над транскриптом листает его до конца, затем страницу
- Фича/экран: отчёт кандидата в режиме поддержки Super Admin (/admin/support/candidates/<id>/report?reason=support), боковая колонка
- Тикеты: #799398 (7e5e16903a1b3d1d88799398)
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив, замер
- Предусловия: сессия admin; кандидат QA-C2-2110-D2 (71c9d469-5992-466f-a592-67e7a1c0f50e) с готовым отчётом
## Шаги
1. Открыть отчёт с ?reason=support, навести мышь на транскрипт.
2. Колесо вниз по 300 px, пока транскрипт не дойдёт до конца; затем ещё.
## Ожидаемо
- Пока транскрипт не в конце — страница стоит (scrollY 0); дойдя до конца, колесо над ним листает страницу (источник: AC2).
