# AUTH-RT-005: внешний адрес в from → после входа главная своего домена (нет открытого редиректа)
- Фича/экран: вход (F-05, S-03)
- Тикеты: #01649c9c8c436e2d1a46f007
- Роль/аккаунт: business — вход формой в собственном окне
- Устройство: desktop 1440×900
- Тип: негатив (безопасность)
- Предусловия: нет
## Шаги
1. Гость: /login; в history.state записать `usr.from = 'https://evil.example'` (`history.replaceState`), перезагрузить.
2. Войти как business.
3. Повторить с `usr.from = '//evil.example'`.
## Ожидаемо
- Адрес остаётся на домене сайта, путь «/», h1 «שלום, …» (источник: «מה רצוי» — «…אם מותר לו»; внешний адрес не разрешён).
- Примечание: `from='/\evil.example'` → пустой /login (находка, низкий риск) — не критерий кейса.
