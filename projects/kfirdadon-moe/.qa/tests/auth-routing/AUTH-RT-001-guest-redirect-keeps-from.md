# AUTH-RT-001: гость на защищённой странице → /login, запрошенный путь запомнен
- Фича/экран: вход (F-05, S-03), защищённые маршруты
- Тикеты: #01649c9c8c436e2d1a46f007
- Роль/аккаунт: guest (окно без сессии)
- Устройство: desktop 1440×900 (проверено также на 375)
- Тип: позитив
- Предусловия: нет
## Шаги
1. Открыть по очереди: /settings/users, /admin/businesses, /admin/providers, /simulations, /candidates?x=1#h.
2. После каждого перехода прочитать `history.state.usr.from`.
## Ожидаемо
- Каждый раз — переход на /login (h1 «התחברות», поля «כתובת מייל», «סיסמה»).
- `history.state.usr.from` = исходный путь; query сохраняется (`/candidates?x=1`), #hash отбрасывается (источник: «מה רצוי» — «המשתמש מוחזר לדף שביקש»).
