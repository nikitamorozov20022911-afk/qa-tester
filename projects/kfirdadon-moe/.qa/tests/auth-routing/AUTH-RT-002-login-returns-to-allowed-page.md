# AUTH-RT-002: после входа — возврат на запрошенную страницу, если роли она разрешена
- Фича/экран: вход (F-05, S-03)
- Тикеты: #01649c9c8c436e2d1a46f007
- Роль/аккаунт: business, admin — вход формой в СОБСТВЕННОМ окне (данные из .qa/accounts.env); не через общую сессию и не через «התנתקות»
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: нет
## Шаги
1. Гость открывает /settings/users → /login → вход как business.
2. Гость (новое окно) открывает /admin/providers → /login → вход как admin.
## Ожидаемо
- business → /settings/users, h1 «משתמשים והזמנות».
- admin → /admin/providers, не 404 («המסך לא נמצא» нет).
- (источник: «מה רצוי» — «אחרי התחברות המשתמש מוחזר לדף שביקש אם מותר לו»)
