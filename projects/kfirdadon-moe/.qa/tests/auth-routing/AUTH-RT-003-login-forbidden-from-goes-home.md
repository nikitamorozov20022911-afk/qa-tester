# AUTH-RT-003: запрошенная страница не разрешена роли → после входа главная роли
- Фича/экран: вход (F-05, S-03)
- Тикеты: #01649c9c8c436e2d1a46f007
- Роль/аккаунт: business; user (מנהל/ת מגייס/ת) — вход формой в собственном окне
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: нет
## Шаги
1. Гость открывает /admin/businesses → /login → вход как business.
2. Гость (новое окно) открывает /settings/users → /login → вход как user.
## Ожидаемо
