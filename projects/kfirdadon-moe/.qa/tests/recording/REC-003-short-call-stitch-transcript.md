# REC-003: короткий звонок (~2.5 мин, конец кандидатом) — все части, быстрая склейка, транскрипт ≤ 300 с, отчёт и плеер
- Фича/экран: звонок кандидата /c/<token> (F-36) → end-candidate-attempt → отчёт /candidates/<id>/report (F-37)
- Тикеты: #3257d0efcc42561f5bc1ef6c
- Роль/аккаунт: business (кандидат «QA-AUTO-REC-…», канал link_only) + кандидат (гость)
- Устройство: кандидат — Chrome 390×844 с fake mic; business — desktop 1440×900
- Тип: позитив; регулярный регресс (короткая версия REC-002, ~6–8 мин всего), НЕ prod-safe (создаёт кандидата, тратит официальный звонок и AI)
- Предусловия: активная симуляция «מערכות סולאריות» (или QA_CALL_SIMULATION); Chrome с фальшивым микрофоном.
## Шаги
1. business: /candidates/new → кандидат, канал «רק ליצור קישור» → ссылка /c/…
2. Кандидат: путь до «מוכן, מתחילים» (как в REC-002, шаг 2).
3. Дождаться ~30 загруженных частей (~2.5 мин) → «לסיים שיחה» → «לאשר סיום שיחה» → «הסימולציה הושלמה».
4. business: опрос get_candidate_report до transcription_status=completed и report.status=ready.
5. business: отчёт → «משך», плеер, длительность файла, клик по последней реплике.
## Ожидаемо
- end-candidate-attempt 200, recording.is_partial=false, время запроса < 30 с (источник: AC тикета про склейку; параллельность короткий звонок не доказывает — это REC-002).
- Части 000000…N-1 без пропусков, у каждого билета успешный PUT (F-36 AC1 «הקלטת השיחה במלואה»).
- Транскрипт completed ≤ 300 с от ended_at (AC «התמלול מוכן בתוך 300 שניות מסוף השיחה»); отчёт ready ≤ 10 мин (decisions).
- «משך MM:SS» = duration_seconds; файл ≈ длительности звонка (±10 с); клик по последней реплике → currentTime = её start, плеер «MM:SS / MM:SS» (F-37 AC8).
