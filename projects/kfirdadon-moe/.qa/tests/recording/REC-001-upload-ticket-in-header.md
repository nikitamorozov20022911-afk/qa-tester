# REC-001: билет загрузки части записи — в заголовке, не в URL; загрузка работает
- Фича/экран: звонок кандидата по ссылке /c/<token> (F-36), recording-upload-url
- Тикеты: #ecc64c3ab613e945688cddaf
- Роль/аккаунт: business (создаёт кандидата «QA-AUTO-REC-…» со ссылкой без отправки) + кандидат (гость)
- Устройство: Chrome 390×844 (как звонки G4), fake mic .qa/audio/g4/A.wav
- Тип: позитив; медленный (~3–5 мин), НЕ prod-safe (создаёт кандидата, тратит официальный звонок и AI)
- Предусловия: активная симуляция «מערכות סולאריות» в бизнесе testim; Chrome с --use-fake-device-for-media-stream --use-file-for-fake-audio-capture.
## Шаги
1. business: /candidates/new → кандидат «QA-AUTO-REC-<stamp>», канал «link_only» → «יצירת קישור» → ссылка /c/…
2. Кандидат: ссылка → «בוא נתחיל» → «לראות פרטי לקוח» → «להמשיך» → согласие → «להתחיל» → «להתחיל בדיקה» → «כן, שומעים טוב» → «להמשיך לתרגול» → «לדלג ישר לשיחה הרשמית» → «הבנתי שזה ניסיון חד-פעמי» → «מוכן, מתחילים».
3. Дождаться ≥6 загруженных частей → «לסיים שיחה» → «לאשר סיום שיחה» → «הסימולציה הושלמה».
## Ожидаемо
- Каждый ответ POST recording-upload-url: upload_url без query (нет «?», нет «ticket=»), upload_headers.x-upload-ticket есть.
- Каждый PUT части: в URL нет «ticket=», заголовок x-upload-ticket есть, ответ 2xx; число успешных PUT = числу выданных билетов (источник: AC — «כרטיס העלאת חלק הקלטה אינו מופיע בכתובת הבקשה, וההעלאה עובדת כמו קודם»).
