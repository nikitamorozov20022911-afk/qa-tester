# REC-002: звонок 20 мин до конца по таймеру — все части загружены, склейка быстрая, транскрипт ≤ 300 с, отчёт и плеер
- Фича/экран: звонок кандидата /c/<token> (F-36, запись частями) → end-candidate-attempt (склейка) → отчёт /candidates/<id>/report (F-37)
- Тикеты: #3257d0efcc42561f5bc1ef6c
- Роль/аккаунт: business (создаёт кандидата «QA-AUTO-REC20-…», канал link_only) + кандидат (гость)
- Устройство: кандидат — Chrome 390×844 (мобильный вид) с fake mic; business — desktop 1440×900
- Тип: позитив / граница (максимальная длина звонка, D-20: «משך הסימולציה נבחר בטווח 5 עד 20 דקות»); ОЧЕНЬ медленный (~25–30 мин), НЕ prod-safe (создаёт кандидата, тратит официальный звонок и 20 мин AI)
- Предусловия: активная симуляция длиной 20 мин в бизнесе testim (13.10 — «QA-20MIN-1619»); Chrome с --use-fake-device-for-media-stream --use-file-for-fake-audio-capture (файл зацикливается).
## Шаги
1. business: /candidates/new → кандидат на 20-минутную симуляцию, канал «רק ליצור קישור» → ссылка /c/…
2. Кандидат: «בוא נתחיל» → «לראות פרטי לקוח» → «להמשיך» → согласие → «להתחיל» → «להתחיל בדיקה» → «כן, שומעים טוב» → «להמשיך לתרגול» → «לדלג ישר לשיחה הרשמית» → «הבנתי שזה ניסיון חד-פעמי» → «מוכן, מתחילים».
3. Не завершать звонок: дождаться конца по таймеру → «הסימולציה הושלמה». Записывать сеть: POST/PUT recording-upload-url, POST end-candidate-attempt.
4. business: опрашивать get_candidate_report каждые ~3–6 с до transcription_status=completed и report.status=ready.
5. business: открыть отчёт → шапка «משך», плеер; файл записи (get-recording-url) — длительность; клик по последней реплике.
## Ожидаемо
- end-candidate-attempt: 200, end_reason=duration_elapsed, recording.is_partial=false; время запроса ≪ 60 с (факт 8.2 с на 240 частей; до исправления 59.7–68.3 с на 262 части) — источник: AC «איחוד חלקי ההקלטה אינו מוריד את החלקים בזה אחר זה», מצב נדרש «מורדים במקביל במגבלת מקביליות … נשאר מרווח ביטחון בתקציב». Сам порядок скачивания снаружи не виден — только по времени.
- Части записи: индексы 000000…N-1 (20 мин ≈ 240) без пропусков, у каждого выданного билета успешный PUT (единичный 5xx с успешным повтором допустим) — источник: F-36 AC1 «הקלטת השיחה במלואה».
- Транскрипт: transcription_status=completed ≤ 300 с от attempt.ended_at (факт +85–86 с, запас ≥ 213 с) — источник: AC «בשיחה רשמית באורך המרבי התמלול מוכן בתוך 300 שניות מסוף השיחה».
- Отчёт: status=ready, generated_at ≤ 10 мин от конца (факт +94.5 с) — источник: decisions «סך הזמן עד דוח מוכן אינו עולה על 10 דקות».
- Отчёт: «השיחה הרשמית הסתיימה ב־… · משך 20:09», плеер «/ 20:09»; файл записи декодируется в ≈ длительность звонка (факт 1205.46 с при 1209 с, разница ≤ 10 с), без «дыр» (самая длинная тишина 4–4.5 с — проверка вручную).
- Клик по последней реплике («מועמד 20:04 הבנתי») → audio.currentTime = start сегмента (1204.533), плеер «20:04 / 20:09» — источник: F-37 AC8.
