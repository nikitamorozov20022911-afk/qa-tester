# REC-004: транскрипт длинного звонка (20 мин) — только иврит, ни одного сегмента в латинском транслите
- Фича/экран: транскрипт попытки (get_candidate_report → transcript.segments), отчёт /candidates/<id>/report (F-37)
- Тикеты: #0e9f9a (30024c6427c460c2480e9f9a)
- Роль/аккаунт: business (testim), только чтение
- Устройство: desktop 1440×900 (проверка по данным API)
- Тип: позитив / регресс бага (только чтение, без нового звонка)
- Предусловия: готовый транскрипт длинной официальной попытки на иврите — кандидат «QA-0e9f9a-2110» (попытка bc0fc9a2, 1250 с, транскрипт 2d3d4a95, 115 сегментов, язык he). Новый 20-мин звонок для регресса НЕ делаем.
## Шаги
1. Найти кандидата по имени, вызвать get_candidate_report (p_reason = null).
2. Пройти по всем transcript.segments.
## Ожидаемо
- attempt.duration_seconds ≥ 900 (≥ 6 частей по 150 с), transcription_status = completed, transcript.language = he.
- Ни в одном сегменте нет латинских букв [A-Za-z] (факт 21.10: 0/115) — источник: описание бага #0e9f9a «חלק מהקטעים יוצאים בתעתיק לטיני».
- В каждом сегменте есть хотя бы одна буква иврита (факт: 0 сегментов без иврита).
