# DREQ-005: панель «קליטת בקשה» закрывается ×/Esc/«ביטול», заявка не создаётся
- Фича/экран: «בקשות עיון ומחיקת מידע» /admin/data-requests (S-22)
- Тикеты: #4a3af4 (6a993d67608817ae234a3af4)
- Роль/аккаунт: admin
- Устройство: desktop 1440
- Тип: позитив, визуал/состояния
- Предусловия: сессия admin; данные не создаются
## Шаги
1. Нажать «קליטת בקשה» — открыть панель.
2. Закрыть ×; снова открыть — Esc; снова — «ביטול».

- Панель закрывается всеми тремя способами; список/счётчики не меняются, записывающих запросов нет (источник: реджект 1 п.1; Figma 843:3162).
