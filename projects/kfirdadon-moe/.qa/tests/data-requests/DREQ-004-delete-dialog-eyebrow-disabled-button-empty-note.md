# DREQ-004: окно завершения удаления — eyebrow, disabled-кнопка, пустой תיעוד
- Фича/экран: «בקשות עיון ומחיקת מידע» /admin/data-requests (S-22)
- Тикеты: #4a3af4 (6a993d67608817ae234a3af4)
- Роль/аккаунт: admin
- Устройство: desktop 1440
- Тип: позитив, визуал/состояния
- Предусловия: сессия admin; данные не создаются; завершать удаление нельзя
## Шаги
1. Заявка удаления в «בטיפול» (в автотесте — мок; вручную — QA-DEL-… заявка).
2. Меню строки → «השלמת הבקשה».
3. Осмотреть eyebrow и кнопку; поставить галочку; нажать при пустом «תיעוד הטיפול (חובה)».
4. Закрыть «ביטול» (в автотесте удаление не завершается).
## Ожидаемо
- eyebrow «מחיקה · מנהל/ת מערכת בלבד» = rgb(233,150,127) (источник: реджект 2 п.2; Figma 823:3093).
- До галочки «השלמת הבקשה» disabled, тёмная прозрачная, светлый текст, 220 px; после — активна, тёмный текст (источник: реджект 2 п.3; Figma 823:3099).
- Пустой תיעוד: «יש לתעד את אופן הטיפול בבקשה», окно открыто, запрос не уходит (источник: דרישה «חובה»).
