# DREQ-002: ошибка загрузки — «ניסיון נוסף» со стрелкой слева, без счётчиков
- Фича/экран: «בקשות עיון ומחיקת מידע» /admin/data-requests (S-22)
- Тикеты: #4a3af4 (6a993d67608817ae234a3af4)
- Роль/аккаунт: admin
- Устройство: desktop 1440 + 390
- Тип: позитив, визуал/состояния
- Предусловия: сессия admin; данные не создаются
## Шаги
1. Заблокировать запрос admin_list_data_requests (route abort).
2. Открыть экран; осмотреть «ניסיון נוסף» и чипы.
## Ожидаемо
- «לא הצלחנו לטעון את הבקשות», «ניסיון נוסף» ≈131×40, стрелка слева (17 px от края) (источник: Figma 822:2683).
- В чипах нет цифр (источник: реджект 1 п.3; Figma 822:2603).
