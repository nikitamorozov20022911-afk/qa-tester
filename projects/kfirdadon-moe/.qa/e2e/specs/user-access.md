# План автотестов: доступ, сессии и пользователи бизнеса

> Все тесты записаны autotest-writer вручную (не playwright-test-generator): несколько ролей одновременно (asUser),
> прямые вызовы Supabase REST/Auth и тесты, отзывающие сессии. Файлы — tests/user-access/*.spec.ts.
> Запуск с особыми условиями:
> - @logout — только `QA_RUN_LOGOUT=1 npx playwright test --project tests --grep @logout --workers=1`, отдельно от остальных
>   (выход отзывает ВСЕ сессии business; тест сам заново входит и пишет .qa/auth/business.json, иначе — npm run qa-login).
> - блокировка spare — только с `QA_RUN_SESSION_KILL=1`, затем qa-login для spare.
> - тесты со spare пропускаются, пока нет .qa/auth/spare.json (расходный участник testim с ролью מנהל/ת חשבון).
> Не прод: ни один тест не помечен @prod-safe.
