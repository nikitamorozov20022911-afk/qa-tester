# GUIDES-04: файлы видео и постеров — статус, тип, длительность, есть звуковая дорожка
- Фича/экран: /guides/<id>.mp4, /guides/<id>.jpg
- Тикеты: #8790d6 (озвучка во всех 5), #d012a3 (signup), #92bc03 (search); версия 2026-11-04 — #94553b, #66ad36, #d152dd, #dc52b7
- Роль/аккаунт: без сессии (HTTP GET) — только файлы; страницу /guides с #359741 видит только admin
- Устройство: не важно (HTTP) → desktop
- Тип: позитив (технический), прод, только чтение (@prod-safe)
- Предусловия: нет.
## Шаги
1. Для id home, signup, publish, search, area: GET `/guides/<id>.mp4` и `/guides/<id>.jpg`.
2. Разобрать контейнер MP4 (ftyp/moov/mvhd/trak/hdlr/stsd).
## Ожидаемо
- mp4: 200, `video/mp4`; jpg: 200, `image/*`.
- Длительность (mvhd) ±3 с, версия 2026-11-04 вечер (home/area/publish — PR #196, #4abcf4): home 105, signup 73, publish 126, search 122, area 123 (ffmpeg: 104,7 / 72,8 / 126,4 / 121,5 / 123,4). Утром 2026-11-04: 105 / 73 / 130 / 122 / 121. Было 2026-11-03: 86 / 82 / 130 / 107 / 107.
- В каждом файле 2 дорожки: видео (`hdlr=vide`, `avc1`) и звук (`hdlr=soun`, `mp4a`/AAC) — звуковая дорожка есть во всех 5.
(источник: #8790d6 «מומלץ להוסיף קריינות» + комментарий 2026-11-03 «נוספה קריינות … בכל הסרטונים»; длительности — факт принятой версии PR #191; подписи «כדקה וחצי»/«כ-2 דקות» на карточках)
- Примечание: дорожка есть ≠ слышна речь — речь и её совпадение с субтитрами см. GUIDES-07 (ручной).
