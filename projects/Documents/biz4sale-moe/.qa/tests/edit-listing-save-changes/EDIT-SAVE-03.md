# EDIT-SAVE-03: изменить заголовок на шаге 1 → «שמור שינויים» сохраняет сразу, без подтверждений
- Фича/экран: F-10 / F-11 · /addbusiness?id=<id> → /mybusinesses
- Тикеты: #357a06, #917a7d
- Роль/аккаунт: владелец объявления (user)
- Устройство: desktop и Android
- Тип: позитив (основной сценарий тикета и программиста)
- Предусловия: своё объявление в статусе בהמתנה или פעיל. В автотесте PATCH перехватывается, на сервер не уходит.
## Шаги
1. Открыть редактирование объявления.
2. На шаге 1 изменить «כותרת».
3. Нажать «שמור שינויים».

- Нет окна תנאי שימוש / «אישור פרסום» / оплаты; шаги 2–5 не проходятся. (источник: «מה רצוי» — «בלי לאשר שוב»)
- Статус в теле PATCH равен текущему (בהמתנה/פעיל), не сбрасывается. (комментарий программиста)
- Переход на /mybusinesses; toast «השינויים נשמרו בהצלחה» (~5 с, #917a7d, 29.10); при ошибке PATCH — toast «אירעה שגיאה בשמירת המודעה. הפרטים לא נשמרו, אבל הם עדיין בטופס — נסו שוב.» (#775eeb) и остаёмся в форме. Изменение видно в «המודעות שלי» и на /businessdetail (ручная проверка).
