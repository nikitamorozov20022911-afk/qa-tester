- Тикеты: #d31f3b
- Роль/аккаунт: guest
- Устройство: desktop 1440×900; iPhone 13 Mini 375 (WebKit); Android Pixel 7 412 (Chromium)
- Тип: позитив
- Предусловия: прод, только просмотр (SW выкл, cookie «חיוניים בלבד», окно PWA снузено — `b4s_install_prompt_dismissed_at` = сейчас). Объявление «משתלה» — /businessdetail?id=35c34e3d-68f8-4cb7-9e0b-e82ad5b46feb, 4 картинки, без видео. Нет объявления / меньше картинок — пропуск (данные прода).
## Шаги
1. Открыть лайтбокс кликом по первой картинке.
2. Нажать «התמונה הבאה» 3 раза (2, 3, 4), затем ещё раз (с последней).
3. Нажать «התמונה הקודמת» (с первой), затем ещё раз.
## Ожидаемо
- RTL: «התמונה הבאה» — у левого края, «התמונה הקודמת» — у правого. (источник: факт прогона QA 2026-11-10; RTL-сайт)
- Каждое нажатие: счётчик 2/4 → 3/4 → 4/4, на экране другая картинка, каждая целиком (contain). (источник: «מה רצוי» п.2 — «חיצים לתמונה הקודמת והבאה», «מונה»)
- С последней «הבאה» → 1/4, с первой «הקודמת» → 4/4 (по кругу), затем 3/4. (источник: факт прогона QA 2026-11-10 — поведение на краях не оговорено в тикете, принято)
- Находка (не требование): клавиши ←/→ не листают.
