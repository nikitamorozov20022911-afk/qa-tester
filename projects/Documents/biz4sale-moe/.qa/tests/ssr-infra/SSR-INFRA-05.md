# SSR-INFRA-05: SPA-навигация главная → поиск → карточка → назад без перезагрузки
- Фича/экран: SSR/SSG — клиентская навигация после SSR
- Тикеты: #be4863
- Роль/аккаунт: гость
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: прод https://www.biz4sale.co.il, гость, только GET. Карточка — первая ссылка `/businessdetail?id=` из сырого HTML /search; категория — первая `/search?category=` из /sitemap.xml (не выдумывать значение: неизвестная категория отдаёт noindex и пустой #root).
## Шаги
1. Открыть /, поставить метку в window.
2. «צפה בכל העסקים» → /search.
3. Первая ссылка карточки в main → /businessdetail?id=…
4. «Назад» → /search.
## Ожидаемо (источник: #be4863 — SSR не ломает SPA)
- Метка в window сохранилась; за весь путь 1 запрос типа document; `performance.getEntriesByType('navigation').length` = 1.
- 0 `pageerror`.
