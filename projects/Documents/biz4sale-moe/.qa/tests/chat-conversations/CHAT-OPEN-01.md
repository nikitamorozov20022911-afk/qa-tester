# CHAT-OPEN-01: Мобайл — прямая ссылка на переписку сразу показывает переписку, а не меню «אזור אישי»
- Фича/экран: «צ'אט / שיחות» · /messages
- Тикеты: #bb6e6d
- Роль/аккаунт: chat (.qa/auth/chat.json)
- Устройство: mobile — Android Pixel 7 (412×839) и iPhone 13 Mini (375×629, WebKit)
- Тип: позитив
- Предусловия: прод — только чтение: ничего не печатать, не отправлять, не нажимать WhatsApp/звонок/кнопки шапки переписки. Все не-GET/HEAD/OPTIONS запросы блокируются (page.route → abort). Переписка: /messages?conversation=a5002a64-d87f-4434-9974-731aaf9fd5c0&business=c676c730-194b-4bb7-a21b-f84ecbde34c2 (с владельцем «קיוסק פעיל ורווחי»).
## Шаги
1. Открыть прямой URL переписки в загрузке страницы (так открываются ссылки из уведомлений).
2. Дождаться поля «כתוב הודעה...».
## Ожидаемо
- Поле «כתוב הודעה...» целиком в пределах экрана (Pixel 7: 761–827 из 839; iPhone 13 Mini: 551–617 из 629).
- Прокрутка страницы scrollY = 0 (переписка вверху, без ручной прокрутки).
- Меню «אזור אישי» скрыто (заголовок «אזור אישי» высотой 0, не видим).
- Последнее сообщение переписки (последняя отметка времени «дд.мм.гг чч:мм») видно в экране.
