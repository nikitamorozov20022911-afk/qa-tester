# CHAT-OPEN-03: Мобайл — «חזרה לשיחות» возвращает к списку переписок
- Фича/экран: «צ'אט / שיחות» · /messages
- Тикеты: #bb6e6d, #c5ed06
- Роль/аккаунт: chat (.qa/auth/chat.json)
- Устройство: mobile — Android Pixel 7 и iPhone 13 Mini (WebKit)
- Тип: позитив
- Предусловия: прод — только чтение: ничего не печатать, не отправлять, не нажимать WhatsApp/звонок/кнопки шапки переписки. Все не-GET/HEAD/OPTIONS запросы блокируются (page.route → abort). Переписка: /messages?conversation=a5002a64-d87f-4434-9974-731aaf9fd5c0&business=c676c730-194b-4bb7-a21b-f84ecbde34c2 (с владельцем «קיוסק פעיל ורווחי»).
## Шаги
1. Открыть прямой URL переписки, дождаться поля «כתוב הודעה...».
2. Нажать кнопку «חזרה לשיחות» (стрелка в шапке переписки, aria-label).
## Ожидаемо
- Адрес — /messages без conversation.
- Список виден в экране: заголовок «שיחות», поиск «חפש שיחות...», переписка «קיוסק פעיל ורווחי».
- Поле «כתוב הודעה...» исчезло; меню «אזור אישי» снова показано (высота > 0) и стоит **ниже** списка (с 2026-10-27, PR #167; раньше — выше).
