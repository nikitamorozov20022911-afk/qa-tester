# CHAT-ENTER-01: Enter в поле «כתוב הודעה...» — перенос строки, не отправка
- Фича/экран: «צ'אט / שיחות» · /messages?conversation=…
- Тикеты: #1da60a
- Роль/аккаунт: chat (.qa/auth/chat.json)
- Устройство: Android Pixel 7 и desktop 1440×900
- Тип: позитив
- Предусловия: открытая существующая переписка. До набора текста все не-GET/HEAD/OPTIONS запросы блокируются (page.route → abort). Кнопку отправки и Ctrl/Cmd+Enter не нажимать.
## Шаги
1. Открыть переписку, дождаться поля «כתוב הודעה...».
2. Включить блок не-GET запросов.
3. Ввести «QA-AUTO-שורה1», нажать Enter, ввести «QA-AUTO-שורה2».
4. Очистить поле.
## Ожидаемо
- Значение поля = «QA-AUTO-שורה1\nQA-AUTO-שורה2», поле не очищено, сообщение в переписке не появилось, попыток записи сообщения нет.
