# CHAT-OPEN-06: Мобайл — колокольчик → «הודעות» открывает /messages со списком переписок в первом экране
- Фича/экран: «צ'אט / שיחות» · окно колокольчика → /messages
- Тикеты: #c5ed06
- Роль/аккаунт: chat
- Устройство: mobile — Android Pixel 7 (основной), iPhone 13 Mini
- Тип: позитив
- Предусловия: как в CHAT-OPEN-05. Уведомления в окне колокольчика не нажимать (клик по уведомлению помечает его прочитанным — запись).
## Шаги
1. Открыть /home (и отдельно — объявление 5832e079-…).
2. Нажать колокольчик в шапке, в окне «התראות» нажать ссылку «הודעות» (внизу окна).
## Ожидаемо
- Как в CHAT-OPEN-05: /messages без conversation, список с «קיוסק פעיל ורווחי» в первом экране, scrollY 0, меню «אזור אישי» ниже списка.
(источник: «מה רצוי» #c5ed06; комментарий PR #167)
- Не проверено: клик по самому уведомлению «новое сообщение» (нет второго аккаунта, отправлять нельзя).
