# SEO-OG-02: og:image всех объявлений — уменьшенная JPEG 1200×630, ≤ 300KB
- Фича/экран: «תשתית SEO טכנית לאתר» · короткая ссылка объявления /b/<8 символов id>
- Тикеты: #cada05 (вместе с #1d8184, PR #167)
- Роль/аккаунт: guest (краулер WhatsApp, без входа)
- Устройство: не важно (сырой HTML, request/curl с UA «WhatsApp/2.23.20.0 A»)
- Тип: позитив (технический), полный обход
- Предусловия: нет. Только GET, ничего не создавать (прод).
## Шаги
1. GET https://www.biz4sale.co.il/sitemap.xml → все `businessdetail?id=<uuid>`.
2. Для каждого объявления: GET `/b/<первые 8 символов id>` с User-Agent «WhatsApp/2.23.20.0 A».
3. Из сырого HTML прочитать `og:image`, `og:image:type`, `og:image:width`, `og:image:height`.
4. GET URL из og:image; реальные размеры — из заголовка JPEG (SOF).
## Ожидаемо
- Страница `/b/<код>` → 200, og:image есть и не пуст.
- og:image → 200, content-type `image/jpeg`, размер ≤ 300KB (факт 28.10: max 195KB), реальные размеры 1200×630.
- meta og:image:type = image/jpeg, og:image:width = 1200, og:image:height = 630.
(источник: «מה רצוי» #cada05 — «גרסה מוקטנת (למשל 1200×630, JPEG או WebP, עד כ-300KB), כך שהתצוגה המקדימה מופיעה בכל מודעה»; 1200×630/JPEG — пример из «מה רצוי», зафиксирован как факт после фикса для base44 (ретест 28.10: 330/330))
