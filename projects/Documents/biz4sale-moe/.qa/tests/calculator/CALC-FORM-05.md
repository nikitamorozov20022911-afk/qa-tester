# CALC-FORM-05: Валидации полей — пустое обязательное, не число, минус
- Фича/экран: מחשבון כדאיות · форма
- Тикеты: #80ff63, #d45b2a
- Роль/аккаунт: гость
- Устройство: desktop, Android Pixel 7
- Тип: негатив
- Предусловия: прод https://www.biz4sale.co.il/calculator, гость, только чтение (калькулятор клиентский; не-GET запросы обрываются, баннер cookie закрыт заранее «только необходимые»). Поля по id: `#calc-purchasePrice`, `#calc-setupCosts`, `#calc-inventory`, `#calc-reserve`, `#calc-loanAmount`, `#calc-monthlyProfit`, `#calc-ownerSalary`, `#calc-monthlyLoanPayment`. Значения на экране содержат RLM/nbsp — сравнивать после нормализации.
## Шаги
1. Открыть пустую форму.
2. Ввести набор 1, очистить «מחיר רכישה» и «רווח חודשי לפני מס».
3. В «מחיר רכישה» ввести «abc».
4. В «מחיר רכישה» ввести «-5».
## Ожидаемо (источник: #80ff63)
- Пустая форма: «כדי לחשב, חסר: מחיר רכישה, רווח חודשי לפני מס.»
- Очищенные поля: «יש להזין מחיר רכישה», «יש להזין רווח חודשי לפני מס», aria-invalid=true.
- «abc»: «יש להזין מספר בלבד», aria-invalid=true.
- Минус: «הסכום לא יכול להיות שלילי».
