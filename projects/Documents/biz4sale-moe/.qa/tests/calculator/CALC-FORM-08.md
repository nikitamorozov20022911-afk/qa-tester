# CALC-FORM-08: Нечисловой ввод «1e5» и вставка «12abc»; минус в «רווח חודשי» разрешён
- Фича/экран: מחשבון כדאיות · форма
- Тикеты: #d45b2a
- Роль/аккаунт: гость
- Устройство: desktop, Android Pixel 7 (вставка — Chromium, буфер обмена с разрешением)
- Тип: негатив / граничный
- Предусловия: прод https://www.biz4sale.co.il/calculator, гость, только чтение (калькулятор клиентский; не-GET запросы обрываются, баннер cookie закрыт заранее «только необходимые»). Поля по id: `#calc-purchasePrice`, `#calc-setupCosts`, `#calc-inventory`, `#calc-reserve`, `#calc-loanAmount`, `#calc-monthlyProfit`, `#calc-ownerSalary`, `#calc-monthlyLoanPayment`. Значения на экране содержат RLM/nbsp — сравнивать после нормализации.
## Шаги
1. «מחיר רכישה» = «1e5».
2. Очистить, положить в буфер «12abc», вставить (Ctrl/Cmd+V) в «מחיר רכישה».
3. Набор 1, «רווח חודשי לפני מס» = «-5000».
## Ожидаемо (источник: #d45b2a — ולידציה: מספרים בלבד, ערכים שליליים)
- «1e5» и «12abc»: под полем «יש להזין מספר בלבד» (`#calc-purchasePrice-error`), aria-invalid=true.
- «-5000» в רווח: aria-invalid=false, нет `#calc-monthlyProfit-error`; מס 0 ₪, רווח לאחר מס «-20,000 ₪», תזרים «-25,000 ₪».
