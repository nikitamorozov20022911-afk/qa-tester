# CALC-FORM-06: Пересчёт при вводе в каждое из 8 полей — без кнопки
- Фича/экран: מחשבון כדאיות · форма → «תוצאות»
- Тикеты: #d45b2a
- Роль/аккаунт: гость
- Устройство: desktop, Android Pixel 7
- Тип: позитив
- Предусловия: прод https://www.biz4sale.co.il/calculator, гость, только чтение (калькулятор клиентский; не-GET запросы обрываются, баннер cookie закрыт заранее «только необходимые»). Поля по id: `#calc-purchasePrice`, `#calc-setupCosts`, `#calc-inventory`, `#calc-reserve`, `#calc-loanAmount`, `#calc-monthlyProfit`, `#calc-ownerSalary`, `#calc-monthlyLoanPayment`. Значения на экране содержат RLM/nbsp — сравнивать после нормализации.
## Шаги
1. Ввести набор 1 (500,000 / 50,000 / 30,000 / 20,000, הלוואה 200,000, רווח 40,000, שכר 15,000, החזר 5,000, מס 23%).
2. По очереди изменить одно поле (остальные — набор 1), кнопку не нажимать, после каждого вернуть значение набора 1.
## Ожидаемо (источник: #d45b2a «מה רצוי» — חישוב דינמי בזמן הקלדה)
- מחיר רכישה 510,000 → סך השקעה ראשונית 610,000 ₪, הון עצמי 410,000 ₪.
- הוצאות רכישה 60,000 / מלאי 40,000 / רזרבה 30,000 → סך השקעה 610,000 ₪, הון עצמי 410,000 ₪.
- סכום הלוואה 210,000 → הון עצמי 390,000 ₪ (סך השקעה 600,000 ₪).
- רווח חודשי 41,000 → מס 5,980 ₪, רווח לאחר מס 20,020 ₪, תזרים 15,020 ₪.
- שכר בעלים 16,000 → מס 5,520 ₪, רווח לאחר מס 18,480 ₪, תזרים 13,480 ₪.
- החזר הלוואה 6,000 → תזרים 13,250 ₪ (מס 5,750 ₪ без изменений).
