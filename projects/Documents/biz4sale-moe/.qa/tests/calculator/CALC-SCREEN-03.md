# CALC-SCREEN-03: Мобайл — нет горизонтального скролла, форма над результатами
- Фича/экран: מחשבון כדאיות רכישת עסק · /calculator
- Тикеты: #3e4835
- Роль/аккаунт: гость
- Устройство: Android Pixel 7 (412 px)
- Тип: позитив (адаптивность)
- Предусловия: прод https://www.biz4sale.co.il/calculator, гость, только чтение (калькулятор клиентский; не-GET запросы обрываются, баннер cookie закрыт заранее «только необходимые»). Поля по id: `#calc-purchasePrice`, `#calc-setupCosts`, `#calc-inventory`, `#calc-reserve`, `#calc-loanAmount`, `#calc-monthlyProfit`, `#calc-ownerSalary`, `#calc-monthlyLoanPayment`. Значения на экране содержат RLM/nbsp — сравнивать после нормализации.
## Шаги
1. Открыть /calculator на Pixel 7, ввести набор 1.
2. Сравнить положение формы (H2 «השקעה ראשונית») и H2 «תוצאות»; ширину документа и окна.
## Ожидаемо
- document.scrollWidth ≤ ширины окна — без горизонтальной прокрутки. (источник: #3e4835 AC — мобайл)
- Форма выше результатов. (источник: #3e4835 «מה רצוי» — на мобайле форма, затем результаты)
