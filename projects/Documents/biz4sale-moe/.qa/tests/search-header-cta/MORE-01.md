- Предусловия: прод, только просмотр; категория «בית מלון»; поисковый запрос «מסעדה».
## Шаги
1. Открыть `/search?category=בית מלון`, дождаться «נמצאו N עסקים».
2. Прокрутить до «עסקים נוספים שעשויים לעניין אותך», запомнить число карточек.
3. Прокрутить к концу страницы.
4. Открыть `/search?q=מסעדה`.
## Ожидаемо
- После результатов категории есть заголовок «עסקים נוספים שעשויים לעניין אותך» и карточки (а не сразу футер). (источник: «מה רצוי» #839121)
- Карточки блока не повторяют результаты категории. (наблюдение при проверке 29.10; логично по «עסקים נוספים»)
- При прокрутке к концу блок догружается — карточек становится больше. (источник: комментарий программиста — «וממשיך להיטען בגלילה»)
