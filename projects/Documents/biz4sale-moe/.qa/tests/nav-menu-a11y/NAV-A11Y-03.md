# NAV-A11Y-03: Открытое мобильное меню — плавающие WhatsApp и נגישות скрыты, «התחברות» и «פרסום עסק למכירה» нажимаются целиком
- Фича/экран: шапка сайта, мобильное меню (Sheet «תפריט») · `/`, `/search`
- Тикеты: #0651d2 (регресс #7f42b5, #2f6eef)
- Роль/аккаунт: guest
- Устройство: mobile 375×812 и 390×844 (iPhone WebKit + Android Chromium)
- Тип: позитив / визуал
- Предусловия: прод, только чтение (не-GET обрываются, SW выключен); cookie → «חיוניים בלבד»; окно PWA «אל תחמיצו אף הזדמנות» может появиться — закрыть «אולי מאוחר יותר». Плавающий WhatsApp искать по `a[aria-label*="שירות הלקוחות"]` (не по номеру — тот же номер у карточек), נגישות — `button[aria-label="פתח תפריט נגישות"]`. WhatsApp не нажимать.
## Шаги
1. Открыть страницу на ширине 375, дождаться шапки; убедиться, что плавающие WhatsApp и נגישות видны.
2. Нажать кнопку «תפריט» (exact) в banner — открыт dialog «תפריט».
3. Проверить видимость плавающих кнопок.
4. Прокрутить в видимую часть «התחברות», затем «פרסום עסק למכירה» (на /search 375 вторая на ~8 px ниже окна — меню прокручивается).
5. Для каждой кнопки `document.elementFromPoint` в точках: левый край (left+4, центр по высоте) и центр.
6. Повторить на 390.
## Ожидаемо
- Пока меню открыто, плавающие WhatsApp и נגישות не видны (источник: «מה רצוי» «הכפתורים «התחברות» ו«פרסום עסק למכירה» נראים ונלחצים במלואם, למשל על ידי הסתרת הכפתורים הצפים»; способ — «למשל», выбран программистом PR #200).
- Hit-test в каждой точке возвращает саму кнопку (или её потомка), а не WhatsApp/נגישות (источник: «מה רצוי» «נלחצים במלואם»; «מה קיים» — касание края открывало WhatsApp/נגישות).
- Обе кнопки видны в меню (текст целиком).
