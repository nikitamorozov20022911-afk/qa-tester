# NAV-A11Y-01: Кнопка ☰ мобильного меню — доступное имя «תפריט», иконка скрыта от скринридера
- Фича/экран: шапка сайта (banner), мобильное меню · /, /search, /search?category=…, /businessdetail?id=…, /calculator (без /guides — с #359741 гость с /guides уходит на /, проверка была бы ложно-зелёной на главной)
- Тикеты: #2f6eef
- Роль/аккаунт: guest
- Устройство: mobile 375×812 / Pixel 7 (iPhone + Android)
- Тип: позитив
- Предусловия: прод, только чтение (не-GET обрываются, SW выключен, cookie «только необходимые»); окно PWA — «אולי מאוחר יותר». Категория — первая `/search?category=` из sitemap.xml, объявление — первая `/businessdetail?id=` из /search. На странице две кнопки с «תפריט» в имени: меню «תפריט» (в banner) и «פתח תפריט נגישות» (вне banner) — искать `getByRole('button', { name: 'תפריט', exact: true })`.
## Шаги
1. Открыть каждую страницу на мобайле, дождаться шапки.
2. В banner найти кнопку `getByRole('button', { name: 'תפריט', exact: true })`.
3. Проверить её svg-иконку и `aria-expanded`.
## Ожидаемо
- В banner ровно одна кнопка с доступным именем «תפריט», видима (источник: #2f6eef «מה רצוי» «לכפתור יהיה שם נגיש, למשל aria-label="תפריט"»; конкретный способ — «למשל»).
- Иконка svg `aria-hidden="true"` (источник: комментарий программиста PR #198).
- `aria-expanded="false"` до открытия; кнопка «פתח תפריט נגישות» на месте, имя не изменилось (#6ce837).
- Автотест: `.qa/e2e/tests/nav-menu-a11y/menu-button-accessible-name.spec.ts`.
