# NAV-A11Y-04: После закрытия мобильного меню (✕, фон, Esc, пункт меню) плавающие WhatsApp и נגישות возвращаются, 44×44, получают касание
- Фича/экран: мобильное меню, плавающие кнопки (левый нижний угол) · `/` (пункт меню → `/calculator`)
- Тикеты: #0651d2 (регресс #062b41, #96f55c, F-27)
- Роль/аккаунт: guest
- Устройство: mobile (iPhone 13 Mini 375 + Pixel 7)
- Тип: позитив
- Предусловия: как NAV-A11Y-03. WhatsApp не нажимать — проверка касания через `elementFromPoint`.
## Шаги
1. Открыть `/`, открыть меню «תפריט».
2. Закрыть одним из способов: ✕ в меню (aria-label «Close») · касание по затемнённому фону слева от меню · Esc · пункт меню «מחשבון רכישת עסק» (переход на `/calculator`).
3. После закрытия проверить плавающие кнопки: видимость, размер, порядок, hit-test центра.
4. Повторить для каждого способа (с новой загрузки `/`).
## Ожидаемо
- Dialog «תפריט» закрыт; `aria-expanded` кнопки «תפריט» = "false" (кроме перехода по пункту — там новая страница).
- Плавающие WhatsApp и נגישות видны, каждая 44×44 (±1 px) (источник: #96f55c — 44×44 на мобайле).
- WhatsApp над נגישות, левый край на одной линии (±2 px) (источник: #062b41 «מעל כפתור הנגישות… באותו גודל ובאותו יישור לשמאל»).
- `elementFromPoint` в центре каждой — сама кнопка (касание доходит) (источник: комментарий PR #200 «אחרי הסגירה הם חוזרים»; F-27 — кнопка נגישות работает).
