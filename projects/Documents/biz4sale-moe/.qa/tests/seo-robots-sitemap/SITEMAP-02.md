# SITEMAP-02: объявления в sitemap = объявления на /search
- Фича/экран: «תשתית SEO טכנית לאתר» · /sitemap.xml + /search
- Тикеты: #d777c9
- Роль/аккаунт: guest
- Устройство: desktop 1440×900 (браузер для «נמצאו N»)
- Тип: позитив, прод, только чтение (@prod-safe; не-GET запросы блокируются)
- Предусловия: нет.
## Шаги
1. GET /sitemap.xml → уникальные id `/businessdetail?id=`.
2. Открыть /search без фильтров, дождаться «נמצאו N עסקים».
3. GET сырого /search → id карточек SSR-блока.
## Ожидаемо
- N (на /search) = число объявлений в sitemap — в sitemap все активные объявления и только они.
- Каждый id карточки сырого /search есть в sitemap.
