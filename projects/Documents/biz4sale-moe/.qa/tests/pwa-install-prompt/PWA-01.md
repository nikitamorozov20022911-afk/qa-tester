# PWA-01: /guides на iPhone — окно «אל תחמיצו אף הזדמנות» не всплывает поверх играющего видео
- Фича/экран: окно установки PWA («הוספה למסך הבית») · /guides (плеер 260×563)
- Тикеты: #631293 (связано: #81a046 — исходная логика окна)
- Роль/аккаунт: admin (`.qa/auth/admin.json`) — с #359741 /guides видит только админ; гость уходит на / (было: guest)
- Устройство: iphone (Safari/WebKit, ширина ≤ 767 px; 2026-11-05 — эмуляция WebKit 390, решение пользователя)
- Тип: поведение — автотест (`@iphone @prod-safe`) + ручной; прод, ничего не создаётся
- Предусловия: вошёл как admin; нет `b4s_install_prompt_dismissed_at` и `b4s_install_prompt_ios_steps_seen_at` в localStorage; не standalone. Ограничение: вошедшему окно само не показывается нигде (#81a046, PWA-04), поэтому под админом кейс подтверждает только «поверх видео на /guides окна нет»; гостевую логику таймера на /guides (#631293) проверить больше нельзя, пока гайды скрыты.
## Шаги
1. Под админом открыть https://www.biz4sale.co.il/guides.
2. Если показан баннер cookie — «חיוניים בלבד».
3. Запустить любое видео (касание плеера).
4. Смотреть ≥ 15 с (окно на других страницах всплывает через ~3 с после выбора cookie).
## Ожидаемо
- Окно «אל תחמיצו אף הזדמנות» («הוספה עכשיו» / «אולי מאוחר יותר») не появляется; видео играет, страница не затемнена. (источник: «מה רצוי» #631293 «החלון לא יקפוץ מעל סרטון שמתנגן בעמוד /guides»)
- Выбранный способ — не показывать окно на /guides вообще (вариант из «למשל» тикета — допустим).
- Контроль PWA-02 (гость на /) остаётся в том же файле: подтверждает, что окно в этом окружении вообще работает; для админа он не контроль (у вошедшего окно само не всплывает).
- Автотест: `.qa/e2e/tests/pwa-install-prompt/guides-no-prompt-while-playing.spec.ts` (вместо 15 с ожидания — `page.clock.runFor`).
- Кадры: `.qa/screenshots/2026-11-05/631293-T1a-run{1..3}-iphone.png`, `631293-T1b-run{1..3}-iphone.png`; «как было» — `.qa/research/631293/pwa-guides-over-player-iphone.png`.
