- Фича/экран: окно установки PWA · /, /mybusinesses (אזור אישי), /guides
- Тикеты: #631293 (комментарий программиста: «вручную открывается из меню אזור אישי»), #81a046 (залогиненным — только пункт меню)
- Роль/аккаунт: user (сессия `.qa/auth/user.json`)
- Устройство: iphone (WebKit, ≤ 767 px)
- Тип: поведение — автотест (только открытие из меню, `@iphone @prod-safe`) + ручной; прод, ничего не создаётся

## Шаги
1. Открыть / — ждать ≥ 10 с: окна нет.
2. Открыть /mybusinesses (אזור אישי) → нажать «הוספה למסך הבית».
3. Закрыть окно «אולי מאוחר יותר» (не «הוספה עכשיו»).
