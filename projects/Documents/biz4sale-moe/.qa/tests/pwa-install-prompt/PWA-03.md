# PWA-03: «אולי מאוחר יותר» — окно закрывается и не возвращается (снуз 5 дней, ключ b4s_install_prompt_dismissed_at)
- Фича/экран: окно установки PWA · /
- Тикеты: #631293 (регресс), #81a046 («אולי מאוחר יותר» → не показывать 5 дней)
- Роль/аккаунт: guest (новое окно, чистый localStorage)
- Устройство: iphone (WebKit, ≤ 767 px)
- Тип: поведение — автотест (`@iphone @prod-safe`, без проверки истечения 5 дней) + ручной; прод, ничего не создаётся (снуз — только localStorage окна теста)
- Предусловия: как PWA-01.
## Шаги
1. /, «חיוניים בלבד», дождаться окна (PWA-02).
2. Нажать «אולי מאוחר יותר».
3. Обновить страницу, ждать ≥ 15 с.
## Ожидаемо
- Окно закрывается; в localStorage `b4s_install_prompt_dismissed_at` = момент нажатия (мс, Date.now()).
- После обновления окно не появляется (снуз на проде 5 дней = 7200 мин; 5 мин — только TEST-проект Supabase). (источник: #81a046)
- Истечение снуза (через 5 дней окно снова есть) — по коду, автотестом не проверяется.
- Автотест: `.qa/e2e/tests/pwa-install-prompt/later-snooze.spec.ts`.
