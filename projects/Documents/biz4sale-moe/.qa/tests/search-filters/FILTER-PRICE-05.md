# FILTER-PRICE-05: /mapview: поля мин/макс в любом порядке — значения сохраняются
- Фича/экран: F-21 «חיפוש מתקדם עם מסננים מרובים» · /search (боковой фильтр / попап «חיפוש וסינון»), /mapview
- Тикеты: #b4b8c9
- Роль/аккаунт: guest
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: прод https://www.biz4sale.co.il, гость, только чтение (не-GET обрываются, service worker заблокирован, cookie — «только необходимые»). Ожидаемые выдачи — из каталога, который сайт загружает сам (GET rest/v1/business), числа не зашиваются. Выдача сверяется по id из ссылок businessdetail?id= только ДО заголовка «עסקים נוספים שעשויים לעניין אותך» (ниже — 12 карточек рекомендаций, они не фильтруются).
## Шаги
1. Открыть `/mapview?minPrice=1000000&maxPrice=3000000` — запомнить «נמצאו N» (эталон).
2. /mapview → «סינון מתקדם» → мин 1,000,000 и макс 3,000,000 (по цифре мин→макс, по цифре макс→мин, вставкой) → «סנן תוצאות».
## Ожидаемо
- Поля после ввода и после «סנן תוצאות» сохраняют 1000000 / 3000000. (источник: реджект rej_8e7ff245 п.1 — «/mapview»)
- «נמצאו N» = эталону (на карте только объявления с координатами, поэтому эталон — карта, а не каталог). URL карты параметры не показывает — не проверяется.
