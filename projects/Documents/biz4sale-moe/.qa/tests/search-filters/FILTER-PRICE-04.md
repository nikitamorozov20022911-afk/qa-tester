# FILTER-PRICE-04: ручка макс у края = «без ограничения» — видны объявления дороже ₪10,000,000
- Фича/экран: F-21 «חיפוש מתקדם עם מסננים מרובים» · /search (боковой фильтр / попап «חיפוש וסינון»), /mapview
- Тикеты: #b4b8c9
- Роль/аккаунт: guest
- Устройство: desktop 1440×900; android Pixel 7
- Тип: граница
- Предусловия: прод https://www.biz4sale.co.il, гость, только чтение (не-GET обрываются, service worker заблокирован, cookie — «только необходимые»). Ожидаемые выдачи — из каталога, который сайт загружает сам (GET rest/v1/business), числа не зашиваются. Выдача сверяется по id из ссылок businessdetail?id= только ДО заголовка «עסקים נוספים שעשויים לעניין אותך» (ниже — 12 карточек рекомендаций, они не фильтруются).
## Шаги
1. Открыть `/search?minPrice=5000000`, затем «סינון מתקדם».
2. Открыть `/search?minPrice=5000000&maxPrice=10000000`.
3. /search → в поле мин ввести 5,000,000 (макс пуст) → «סנן תוצאות».
4. (мобайл) Ручку мин дотянуть до конца → «סנן תוצאות».
## Ожидаемо
- П.1–3: выдача = все объявления каталога от ₪5,000,000, включая дороже ₪10,000,000 (на 2026-11-02 — 11M/29M/35M/37M); в п.1 поле мин 5000000, макс пуст, подпись «₪5,000,000 - ₪10,000,000», ручка Maximum = 10,000,000; в п.3 URL без maxPrice. (источник: реджект rej_8e7ff245 п.2 — «ידית המקסימום בקצה פירושה ללא הגבלה»)
- `maxPrice=10000000` = без верхней границы (та же выдача).
- П.4: подпись «₪10,000,000 - ₪10,000,000», URL `?minPrice=10000000`, выдача — объявления от ₪10,000,000, нет «לא נמצאו». (источник: «מה קיים» #b4b8c9 — пример 10M–10M «לא נמצאו» как проблема)
