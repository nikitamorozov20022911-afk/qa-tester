# FILTER-PRICE-01: поля «מינימום»/«מקסימום» на десктопе /search — в любом порядке, значения сохраняются
- Фича/экран: F-21 «חיפוש מתקדם עם מסננים מרובים» · /search (боковой фильтр / попап «חיפוש וסינון»), /mapview
- Тикеты: #b4b8c9
- Роль/аккаунт: guest
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: прод https://www.biz4sale.co.il, гость, только чтение (не-GET обрываются, service worker заблокирован, cookie — «только необходимые»). Ожидаемые выдачи — из каталога, который сайт загружает сам (GET rest/v1/business), числа не зашиваются. Выдача сверяется по id из ссылок businessdetail?id= только ДО заголовка «עסקים נוספים שעשויים לעניין אותך» (ниже — 12 карточек рекомендаций, они не фильтруются).
## Шаги
1. /search → «סינון מתקדם».
2. Ввести мин 1,000,000 и макс 3,000,000 — четыре варианта: по цифре и вставкой (fill) × порядок мин→макс и макс→мин.
3. «סנן תוצאות».
## Ожидаемо
- После ввода второго поля первое не стёрлось и значения не поменялись местами. (источник: реджект rej_8e7ff245 п.1, «מה רצוי» — «אפשר לבחור גם מינימום וגם מקסימום … גם בשדות»)
- URL `?minPrice=1000000&maxPrice=3000000`; поля после «סנן תוצאות» те же.
- «נמצאו N» и id выдачи = объявления каталога с ценой в [1,000,000; 3,000,000].
