# FILTER-PRICE-03: попап: диапазон с ₪0, две ручки двигаются независимо
- Фича/экран: F-21 «חיפוש מתקדם עם מסננים מרובים» · /search (боковой фильтр / попап «חיפוש וסינון»), /mapview
- Тикеты: #b4b8c9
- Роль/аккаунт: guest
- Устройство: android Pixel 7
- Тип: позитив
- Предусловия: прод https://www.biz4sale.co.il, гость, только чтение (не-GET обрываются, service worker заблокирован, cookie — «только необходимые»). Ожидаемые выдачи — из каталога, который сайт загружает сам (GET rest/v1/business), числа не зашиваются. Выдача сверяется по id из ссылок businessdetail?id= только ДО заголовка «עסקים נוספים שעשויים לעניין אותך» (ниже — 12 карточек рекомендаций, они не фильтруются).
## Шаги
1. /search → «סינון מתקדם».
2. Проверить старт ползунка.
3. Ручку Minimum (справа, RTL) сдвинуть влево на ~10% ширины.
4. Ручку Maximum (слева) сдвинуть вправо к ~30% от правого края.
5. «סנן תוצאות», снова открыть попап.
## Ожидаемо
- Старт: подпись «₪0 - ₪10,000,000», две ручки (aria Minimum = 0, Maximum = 10,000,000). (источник: «מה רצוי» — «טווח המחירים מתחיל מ-0 … גם בסליידר (שתי ידיות)»)
- Каждая ручка двигает только своё значение; поля = значения ручек; подпись «₪мин - ₪макс».
- URL с этими minPrice/maxPrice; выдача = каталог в диапазоне; при повторном открытии ручки и поля те же.
