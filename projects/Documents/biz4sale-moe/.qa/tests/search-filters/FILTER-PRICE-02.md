## Шаги
1. /search → «סינון מתקדם» (попап).
2. Ввести мин 1,000,000 и макс 3,000,000: по цифре мин→макс, по цифре макс→мин, вставкой мин→макс; выйти из поля.
3. «סנן תוצאות».
4. Снова открыть «סינון מתקדם».
## Ожидаемо
- Значения в полях не стираются; подпись «₪1,000,000 - ₪3,000,000». (источник: «מה רצוי»; реджект rej_8e7ff245 п.1)
- Попап закрылся; URL `?minPrice=1000000&maxPrice=3000000`; выдача = каталог в диапазоне.
- При повторном открытии поля, подпись и ручки (aria-valuenow Minimum/Maximum) — те же значения.
