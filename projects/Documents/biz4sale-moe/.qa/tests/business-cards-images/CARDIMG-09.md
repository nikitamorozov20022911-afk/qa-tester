# CARDIMG-09: ни у одной картинки карточек /search нет однотонных полей >10% (регенерация существующих)
- Фича/экран: карточки /search
- Тикеты: #494e0b
- Роль/аккаунт: guest
- Устройство: desktop 1440×900 (достаточно; файлы одни)
- Тип: визуал / позитив
- Предусловия: прод, только просмотр. Число карточек и доля card3 не фиксируются (156 / 145 на 2026-11-19).
## Шаги
1. Открыть /search, прокрутить, собрать видимые картинки карточек (до ~60 штук с лимитом по времени), дождаться загрузки.
2. Для каждой: загрузить currentSrc в canvas; найти строки сверху/снизу и столбцы слева/справа, однотонные (почти одного цвета по всей линии, чёрный/белый/любой).
## Ожидаемо
- Ни у одной картинки доля однотонных полей по высоте или ширине не превышает 10 %. (источник: «מה רצוי» — «חיתוך אוטומטי של שוליים שחורים/אחידים»; замер 2026-11-19: 0 из 156)
- Среди src большинство `.card3.webp` (≥1; число не фиксируется).
