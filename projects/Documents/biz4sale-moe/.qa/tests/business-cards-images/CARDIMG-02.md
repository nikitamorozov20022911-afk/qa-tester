# CARDIMG-02: .card2.webp сохраняет пропорции оригинала; поля по нужной оси
- Фича/экран: карточки /search и главной
- Тикеты: #0a2499
- Роль/аккаунт: guest
- Устройство: desktop 1440×900; android (Pixel 7)
- Тип: визуал / позитив
- Предусловия: прод. Оригинал = URL картинки карточки без суффикса `.card2.webp` (браузер учитывает EXIF-поворот).
## Шаги
1. Открыть /search, прокрутить первые ~40 карточек, дождаться загрузки картинок.
2. Взять до 12 карточек: вертикальные (ш/в < 0,95), широкие (> 1,4) и остальные.
3. Для каждой загрузить оригинал, сравнить naturalWidth/naturalHeight card2 и оригинала.
## Ожидаемо
- Пропорция card2 ≈ пропорции оригинала (расхождение ≤ 2 %), у вертикальных — не 4:3. (источник: «מה רצוי» — «…להיווצר בלי חיתוך, עם שמירה על היחס המקורי»)
- Нарисованная картинка целиком в окне; вертикальная → поля слева/справа (сверху/снизу 0), широкая шире 4:3 → поля сверху/снизу, ровно 4:3 → без полей. (источник: «מה רצוי» — «בצדדים או למעלה ולמטה יהיו שוליים»)
- Пример ручной проверки: «עסק של תפאורות מתנפחות ענקיות לאירועים» 1122×1402 → card2 480×600, поля по 68 px (375); «חוף פרטי בכנרת» → 573×600.
