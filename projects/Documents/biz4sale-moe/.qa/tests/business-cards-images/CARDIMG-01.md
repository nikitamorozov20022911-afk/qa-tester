# CARDIMG-01: картинки карточек /search не обрезаются — object-fit contain, файл .card2.webp
- Фича/экран: карточки объявлений /search (окно медиа `.aspect-[4/3]`)
- Тикеты: #0a2499
- Роль/аккаунт: guest
- Устройство: desktop 1440×900; android (Pixel 7) — сценарий клиента (Android, /search)
- Тип: визуал / позитив
- Предусловия: прод, только просмотр. Карточки не привязаны к конкретным объявлениям — проверяются все показанные.
## Шаги
1. Открыть /search, дождаться карточек.
2. Для каждой карточки с картинкой — computed `object-fit` у всех `img` окна медиа и `src` видимой картинки.
## Ожидаемо
- Ни у одной картинки карточки нет `object-fit: cover`; видимая картинка — `contain`, растянута на всё окно (inset-0). (источник: «מה רצוי» — «התמונה בכרטיס תוצג במלואה, בלי חיתוך»)
- `src` картинки — `<оригинал>.card2.webp` (новая версия без обрезки, не старый `.card.webp` 800×600). (источник: «מה רצוי» — «גם התמונה לכרטיס (‎.card.webp) צריכה להיווצר בלי חיתוך»; имя card2 — PR #197)
