# CHAT-HDR-01: Шапка переписки на мобильном — имя, объявление и «בעל העסק · телефон» по одной строке
- Фича/экран: чат (תקשורת, F-18 / F-09) · шапка открытой переписки /messages?conversation=…
- Тикеты: #be14fc06
- Роль/аккаунт: chat
- Устройство: mobile — Android Pixel 7 (412) и iPhone 13 Mini (375, WebKit)
- Тип: визуал
- Предусловия: сессия `.qa/auth/chat.json` (пользователь с перепиской с владельцем бизнеса). Переписку открывать навигацией внутри сайта: главная → иконка сообщений в шапке → переписка (прямой URL /messages сейчас показывает пустой список — отдельная находка). Только чтение: ничего не печатать в поле ввода, не отправлять, не нажимать WhatsApp/звонок.
## Шаги
1. Открыть главную под сессией chat.
2. Нажать иконку сообщений в шапке сайта.
3. Открыть переписку с владельцем бизнеса (первая в списке).
4. Дождаться шапки переписки: «שיחה עם [שם]».
5. Измерить строку «שיחה עם [שם]», строку с названием объявления и строку «בעל העסק · <телефон>».
## Ожидаемо
- «שיחה עם [שם]» — одна строка: white-space: nowrap, text-overflow: ellipsis, высота элемента ≤ 1,5 × line-height (lines = 1).
- Название объявления — одна строка (те же свойства, lines = 1).
- «בעל העסק · <телефон>» — одна строка, расположена ниже строки «שיחה עם …» (top ≥ bottom строки имени); номер с dir="ltr".
- Слова не переносятся по одному в строку.
