# CHAT-HDR-04: Длинное имя и длинное название объявления — обрезка «...», одна строка
- Фича/экран: чат · шапка открытой переписки
- Тикеты: #be14fc06
- Роль/аккаунт: chat
- Устройство: mobile — Android Pixel 7, iPhone 13 Mini; дополнительно ширина 320
- Тип: граница
- Предусловия: сессия `.qa/auth/chat.json` (пользователь с перепиской с владельцем бизнеса). Переписку открывать навигацией внутри сайта: главная → иконка сообщений в шапке → переписка (прямой URL /messages сейчас показывает пустой список — отдельная находка). Только чтение: ничего не печатать в поле ввода, не отправлять, не нажимать WhatsApp/звонок.
## Шаги
1–4. Как в CHAT-HDR-01.
5. Только в браузере (в DOM, без сохранения на сайте) заменить текст имени на длинный (например, 60+ символов: «QA-AUTO-שם-ארוך-מאוד-…») и текст названия объявления — на длинный (80+ символов).
6. Измерить строки и кнопки.
## Ожидаемо
- Имя и название объявления — по одной строке, scrollWidth элемента > clientWidth (текст обрезан), text-overflow: ellipsis.
- «בעל העסק · телефон» — одна строка под именем.
- Кнопки — ниже текста, пересечение = 0; scrollWidth документа = ширине окна.
(источник: «מה רצוי»: «מלא או מקוצר עם «...»»)
