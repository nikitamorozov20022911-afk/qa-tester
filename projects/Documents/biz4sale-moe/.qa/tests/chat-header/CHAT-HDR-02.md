# CHAT-HDR-02: Кнопки шапки переписки на мобильном — отдельной строкой, без перекрытия текста
- Фича/экран: чат · шапка открытой переписки
- Тикеты: #be14fc06
- Роль/аккаунт: chat
- Устройство: mobile — Android Pixel 7 и iPhone 13 Mini
- Тип: визуал
- Предусловия: сессия `.qa/auth/chat.json` (пользователь с перепиской с владельцем бизнеса). Переписку открывать навигацией внутри сайта: главная → иконка сообщений в шапке → переписка (прямой URL /messages сейчас показывает пустой список — отдельная находка). Только чтение: ничего не печатать в поле ввода, не отправлять, не нажимать WhatsApp/звонок.
## Шаги
1–4. Как в CHAT-HDR-01 (открыть переписку через иконку сообщений в шапке).
5. Найти кнопки шапки: WhatsApp (ссылка на wa.me), звонок (ссылка tel:), «глаз» (ссылка на /businessdetail…), X (закрыть). Не нажимать.
6. Сравнить прямоугольники (bounding box) кнопок с прямоугольниками текстовых строк шапки (имя, объявление, «בעל העסק · телефон»).
## Ожидаемо
- Все 4 кнопки видимы; WhatsApp href содержит wa.me, звонок href начинается с tel:, «глаз» href содержит /businessdetail.
- Кнопки стоят отдельной строкой ниже текста: top каждой кнопки ≥ bottom нижней текстовой строки.
- Площадь пересечения любой кнопки с любой текстовой строкой = 0.
