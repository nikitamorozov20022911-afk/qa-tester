# CHAT-HDR-03: Шапка переписки на узких экранах 320/360/375/390/412 — без горизонтального скролла и перекрытий
- Фича/экран: чат · шапка открытой переписки
- Тикеты: #be14fc06
- Роль/аккаунт: chat
- Устройство: mobile Android (Chrome), ширины 320, 360, 375, 390, 412
- Тип: граница
- Предусловия: сессия `.qa/auth/chat.json` (пользователь с перепиской с владельцем бизнеса). Переписку открывать навигацией внутри сайта: главная → иконка сообщений в шапке → переписка (прямой URL /messages сейчас показывает пустой список — отдельная находка). Только чтение: ничего не печатать в поле ввода, не отправлять, не нажимать WhatsApp/звонок.
## Шаги
1–4. Как в CHAT-HDR-01.
5. Для каждой ширины 320/360/375/390/412 выставить ширину окна и дождаться перерисовки шапки.
6. Измерить scrollWidth документа, строки шапки и кнопки.
## Ожидаемо
- document.documentElement.scrollWidth = ширине окна (нет горизонтального скролла) на каждой ширине.
- «שיחה עם [שם]», название объявления, «בעל העסק · телефон» — по одной строке (как CHAT-HDR-01).
- Кнопки ниже текста, пересечение с текстом = 0 (как CHAT-HDR-02); кнопки не выходят за край экрана.
