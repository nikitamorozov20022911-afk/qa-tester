- Тикеты: #8bea2a
- Роль/аккаунт: user
- Устройство: desktop 1440×900 и Android (Pixel 7); вручную также 390
- Тип: граница
- Предусловия: прод, вход user. Переход 1→2 создаёт черновик (POST business) — название «QA-TEST …», после проверки удалить черновик в /mybusinesses (корзина → DELETE 2xx). ## Шаги
1. Дойти до шага 5 с «חבילה 2 – מומלצת!».
2. Ввести «QA-AUTO חברת בדיקה בע"מ» (с двойной кавычкой).
3. Очистить, ввести «QA-AUTO Test Company Ltd».
4. Очистить, ввести (набором с клавиатуры) строку из 120 символов.

- Иврит с `בע"מ` и латиница сохраняются в поле без изменений; ошибок валидации нет. (собственная проверка С1 брифа; факт 02.11)
