# ADDBIZ-INV-01: поле «שם לחשבונית» на шаге 5 только при платном пакете
- Фича/экран: /addbusiness, шаг 5 «פרסום המודעה» (пакет — шаг 4 «חבילת פרסום»); F-26 «סליקה של בעלי עסקים»
- Тикеты: #8bea2a, #2e5dd0 (подпись поля)
- Роль/аккаунт: user (.qa/auth/user.json)
- Устройство: desktop 1440×900 и Android (Pixel 7); вручную также 390
- Тип: позитив
- Предусловия: прод, вход user. Переход 1→2 создаёт черновик (POST business) — название «QA-TEST …», после проверки удалить черновик в /mybusinesses (корзина → DELETE 2xx). Пакет выбирается на шаге 4 «חבילת פרסום» (карточка → «שלב הבא»), поле — на шаге 5 «פרסום המודעה». Оплату не делать: POST /api/payments в автотесте всегда перехватывается и обрывается.
## Шаги
1. /addbusiness → шаг 1 (название «QA-TEST …», описание, телефон, цена, категория) → «שלב הבא» → шаг 2 «שלב הבא» → шаг 3 «שלב הבא».
2. Шаг 4: выбрать «חבילה 1 – הכרות חינם» → «שלב הבא».
3. Шаг 5: найти поле «שם לחשבונית».
4. «חזרה» → шаг 4: «חבילה 2 – מומלצת!» → «שלב הבא».
5. «חזרה» → шаг 4: «חבילה 3 – למכור מהר!» → «שלב הבא».
