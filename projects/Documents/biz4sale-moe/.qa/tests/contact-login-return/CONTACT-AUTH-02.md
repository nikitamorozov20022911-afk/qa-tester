# CONTACT-AUTH-02: Выдача /search — «הצגת טלפון» на карточке → попап → SMS сохраняет возврат на эту карточку
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /search → /auth?mode=sms
- Тикеты: #083d10
- Роль/аккаунт: гость (без входа)
- Устройство: desktop (Chrome 1440×900) и Android Pixel 7
- Тип: позитив
- Предусловия: как в CONTACT-AUTH-01; страница /search (первая карточка выдачи).
## Шаги
1. Открыть /search, дождаться карточек.
2. Запомнить id объявления первой карточки с кнопкой «הצגת טלפון» (ссылка /businessdetail?id=… в этой карточке).
3. Нажать «הצגת טלפון» на этой карточке.
4. В попапе нажать «כניסה / הרשמה עם SMS».
## Ожидаемо
- Адрес — /auth?mode=sms.
- sessionStorage.redirectAfterLogin — путь /businessdetail с id этой карточки и contact=1 (на проде также from=%2Fsearch).
