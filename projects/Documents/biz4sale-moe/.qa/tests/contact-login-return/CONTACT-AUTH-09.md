# CONTACT-AUTH-09: Выдача /search — «השארת פרטים» на карточке → та же форма → гостевая отправка возвращает на страницу этого объявления
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /search → /auth
- Тикеты: #3f0a85
- Роль/аккаунт: гость (без входа)
- Устройство: Android Pixel 7 (Chrome)
- Тип: позитив
- Предусловия: как в CONTACT-AUTH-08; карточка в /search с кнопкой «השארת פרטים» (дискретное объявление).
## Шаги
1. Открыть /search, запомнить id объявления первой карточки с «השארת פרטים».
2. Нажать «השארת פרטים» — открылась форма «יצירת קשר עם המוכר».
3. Заполнить QA-AUTO-данными (как в CONTACT-AUTH-08), нажать «שלח הודעה».
## Ожидаемо
- Открывается форма «יצירת קשר עם המוכר».
- b4s_contact_draft.businessId = id этой карточки.
- Адрес — /auth; redirectAfterLogin — /businessdetail с id этой карточки.
