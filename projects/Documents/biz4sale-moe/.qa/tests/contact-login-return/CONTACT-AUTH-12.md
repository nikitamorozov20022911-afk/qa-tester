# CONTACT-AUTH-12: Отказ от входа «назад» с /auth → главная → обычный /auth без адреса возврата и без текста намерения
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /businessdetail → /auth?mode=sms → назад → /home → /auth
- Тикеты: #a88c1c
- Роль/аккаунт: гость (без входа)
- Устройство: Android Pixel 7 (Chrome) и desktop (Chrome 1440×900)
- Тип: негатив (отказ от входа)
- Предусловия: прод — гость, Chromium; не входить, SMS-код не запрашивать («שלח קוד» не нажимать), Google не нажимать, формы не отправлять; все не-GET/HEAD/OPTIONS запросы блокируются. Объявление /businessdetail?id=4d62fda8-629a-4ad5-9913-3f925cbbb1d1. Новая вкладка (попап раз за вкладку — b4s_guest_contact_prompt_shown; redirectAfterLogin — sessionStorage вкладки).
## Шаги
1. Открыть объявление → «הצג מספר טלפון» → в попапе «כניסה / הרשמה עם SMS».
2. На /auth?mode=sms — нажать «назад» браузера.
3. Перейти на главную /home.
4. Открыть /auth.
## Ожидаемо
- После шага 1: /auth?mode=sms, redirectAfterLogin = /businessdetail?id=4d62fda8-…&contact=1, текст «על מנת להתעניין בעסקים» (исходное состояние, CONTACT-AUTH-01).
- После шага 2: снова объявление; redirectAfterLogin отсутствует.
- После шага 4: обычный экран входа — «ברוכים הבאים» / «התחברו לחשבון שלכם»; текстов «להתעניין בעסקים» и «לפרסם באתר» нет; redirectAfterLogin отсутствует.
