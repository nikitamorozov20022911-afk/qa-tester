# CONTACT-AUTH-01: Объявление — «הצג מספר טלפון» → попап → SMS сохраняет возврат на это объявление
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /businessdetail → /auth?mode=sms
- Тикеты: #083d10
- Роль/аккаунт: гость (без входа)
- Устройство: desktop (Chrome 1440×900) и Android Pixel 7
- Тип: позитив
- Предусловия: прод — гость; не входить, SMS-код не запрашивать (на /auth ничего не нажимать), окно Google не открывать, формы не отправлять; все не-GET/HEAD/OPTIONS запросы блокируются. Объявление /businessdetail?id=4d62fda8-629a-4ad5-9913-3f925cbbb1d1 (קיוסק/מינימרקט למכירה, ראשון לציון). Новая вкладка (попап показывается раз за вкладку — sessionStorage b4s_guest_contact_prompt_shown).
## Шаги
1. Открыть объявление.
2. Нажать «הצג מספר טלפון».
3. В попапе «הרשמה קלה, מהירה וחד-פעמית» нажать «כניסה / הרשמה עם SMS».
## Ожидаемо
- После шага 2 открыт попап с кнопками «כניסה / הרשמה עם SMS» и «כניסה / הרשמה עם Google».
- После шага 3 адрес — /auth?mode=sms.
- sessionStorage.redirectAfterLogin = /businessdetail?id=4d62fda8-…&contact=1 (то же объявление, с contact=1).
