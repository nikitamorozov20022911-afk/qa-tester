# CONTACT-AUTH-16: Переходы внутри /auth (почта, вкладки, «שכחתי סיסמה») не стирают адрес возврата и текст намерения
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /auth?mode=sms (внутренние экраны)
- Тикеты: #a88c1c (регресс #083d10)
- Роль/аккаунт: гость (без входа)
- Устройство: Android Pixel 7 (Chrome)
- Тип: позитив (не ложный «уход»)
- Предусловия: прод — гость, Chromium; не входить, SMS-код не запрашивать («שלח קוד» не нажимать), Google не нажимать, формы не отправлять; все не-GET/HEAD/OPTIONS запросы блокируются. Объявление /businessdetail?id=4d62fda8-629a-4ad5-9913-3f925cbbb1d1. Новая вкладка (попап раз за вкладку — b4s_guest_contact_prompt_shown; redirectAfterLogin — sessionStorage вкладки). На /auth не нажимать «שלח קוד», «התחבר», «שלח קישור», Google.
## Шаги
1. Объявление → «הצג מספר טלפון» → «כניסה / הרשמה עם SMS» → /auth?mode=sms.
2. «כניסה עם אימייל וסיסמה» (появилась «שכחתי סיסמה»).
3. Вкладка «הרשמה», затем вкладка «התחברות».
4. «שכחתי סיסמה» (экран «איפוס סיסמה») → «חזרה».
5. «התחברות מהירה עם SMS» (появилась «שלח קוד»).
## Ожидаемо
- После каждого шага 2–5: адрес /auth; redirectAfterLogin = /businessdetail?id=4d62fda8-…&contact=1.
