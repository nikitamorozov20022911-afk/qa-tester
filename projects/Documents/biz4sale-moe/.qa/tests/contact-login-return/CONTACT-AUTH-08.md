# CONTACT-AUTH-08: Дискретное объявление — гость отправляет форму «יצירת קשר עם המוכר» → черновик сохранён → /auth с возвратом на объявление
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /businessdetail (дискретное) → /auth
- Тикеты: #3f0a85 (связанные #6ce2cc, #083d10)
- Роль/аккаунт: гость (без входа)
- Устройство: Android Pixel 7 (Chrome) — устройство клиента; desktop 1440 коротко
- Тип: позитив
- Предусловия: прод — гость; все не-GET/HEAD/OPTIONS запросы блокируются (проверено: гостевая отправка не делает ни одного не-GET запроса — ничего не создаёт). Дискретное объявление /businessdetail?id=4a91620b-b4ef-4785-bb20-d0d40a67f977 («משחקייה מצליחה למכירה», чужое реальное — только гостем, без входа). Данные — с префиксом QA-AUTO.
## Шаги
1. Открыть дискретное объявление, нажать «שלח הודעה למוכר».
2. В форме «יצירת קשר עם המוכר» заполнить: שם מלא «QA-AUTO», טלפון «0500000000», אימייל «qa-auto@example.com», הודעה «QA-AUTO בדיקת טיוטה».
3. Нажать «שלח הודעה».
## Ожидаемо
- В форме сообщение «עליך להתחבר כדי לשלוח הודעה.».
- sessionStorage.b4s_contact_draft: businessId = это объявление, fields.message = введённое сообщение, at — сейчас.
- Через ~2 с адрес — /auth; на /auth текст «על מנת להתעניין בעסקים».
- sessionStorage.redirectAfterLogin — /businessdetail с id этого объявления.
