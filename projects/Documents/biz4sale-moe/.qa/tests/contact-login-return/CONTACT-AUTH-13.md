# CONTACT-AUTH-13: Отказ от входа уходом на другой адрес (ручной ввод) — значение очищено, обычный /auth
- Фича/экран: «יצירת קשר / התחברות מפופאפ» · /auth?mode=sms → /search → /auth
- Тикеты: #a88c1c
- Роль/аккаунт: гость (без входа)
- Устройство: Android Pixel 7 (Chrome) и desktop (Chrome 1440×900)
- Тип: негатив (отказ от входа)
- Предусловия: прод — гость, Chromium; не входить, SMS-код не запрашивать («שלח קוד» не нажимать), Google не нажимать, формы не отправлять; все не-GET/HEAD/OPTIONS запросы блокируются. Объявление /businessdetail?id=4d62fda8-629a-4ad5-9913-3f925cbbb1d1. Новая вкладка (попап раз за вкладку — b4s_guest_contact_prompt_shown; redirectAfterLogin — sessionStorage вкладки).
## Шаги
1. Объявление → «הצג מספר טלפון» → «כניסה / הרשמה עם SMS» → /auth?mode=sms.
2. В той же вкладке ввести адрес /search.
3. Открыть /auth.
## Ожидаемо
- После шага 2: /search, redirectAfterLogin отсутствует.
- После шага 3: обычный экран («ברוכים הבאים»), нет «להתעניין בעסקים» / «לפרסם באתר», redirectAfterLogin отсутствует.
