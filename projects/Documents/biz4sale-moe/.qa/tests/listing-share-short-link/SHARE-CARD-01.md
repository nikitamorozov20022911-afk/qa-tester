# SHARE-CARD-01: Кнопка «שיתוף מודעה» в карточке /search — та же короткая ссылка, что на странице и в WhatsApp карточки
- Фича/экран: שיתוף מודעה · /search (карточка объявления)
- Тикеты: #c5d7e2 (PR #177)
- Роль/аккаунт: guest и user
- Устройство: desktop 1440×900; Android Pixel 7
- Тип: позитив
- Предусловия: ПРОД, только чтение. `navigator.share` подменён (запись аргумента). Ссылку WhatsApp продавцу НЕ нажимать — только читать `href` (`a[href*="wa.me"]`, параметр `text`).
## Шаги
1. Открыть /search, дождаться карточек.
2. В первой карточке, где есть кнопка шаринга: прочитать id карточки (`/businessdetail?id=`), заголовок и `href` её ссылки WhatsApp продавцу.
3. Нажать кнопку с `title="שיתוף מודעה"` (aria-label `שיתוף המודעה <כותרת>`).
## Ожидаемо
- Кнопка есть, aria-label = `שיתוף המודעה <כותרת>`.
- `navigator.share` вызван с `title`=<כותרת>, `text`=`חשבתי שיכול לעניין אותך: <כותרת>`, `url`=`https://www.biz4sale.co.il/b/<код>` (источник: #c5d7e2 «מה רצוי»).
- `<код>` = первые 8 hex id карточки = код на странице объявления (SHARE-PAGE-01) = окончание ссылки в WhatsApp-сообщении карточки (`…/b/<код>`) (источник: #c5d7e2 «מה רצוי» — тот же формат, что в WhatsApp продавцу).
- Нет `businessdetail`, `id=`, `from=`.
