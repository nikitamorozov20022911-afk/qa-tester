# SHARE-OG-01: Превью короткой ссылки для краулеров Facebook/WhatsApp — 200 + og:title/og:image объявления
- Фича/экран: короткая ссылка /b/<код> · HTML для краулеров
- Тикеты: #c5d7e2 (PR #177); #1d8184
- Роль/аккаунт: guest (HTTP-запрос)
- Устройство: desktop (без браузера)
- Тип: позитив
- Предусловия: ПРОД, только GET. Код и заголовок — первой карточки /search (или из share).
## Шаги
1. GET `https://www.biz4sale.co.il/b/<код>` с `User-Agent: facebookexternalhit/1.1`, без редиректов.
2. То же с `User-Agent: WhatsApp/2.23.20.0 A`.
3. GET адреса из `og:image`.
## Ожидаемо
- Оба ответа 200, HTML; `og:title` содержит заголовок объявления; `og:image` — https-адрес картинки этого объявления (источник: #c5d7e2 — красивое превью при шаринге, как в WhatsApp продавцу).
- `og:image` отвечает 200, `content-type: image/jpeg`.
