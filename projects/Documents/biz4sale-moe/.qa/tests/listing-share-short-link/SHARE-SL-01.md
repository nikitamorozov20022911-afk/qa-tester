# SHARE-SL-01: Короткая ссылка из «שתף» открывает это же объявление — с service worker и без
- Фича/экран: короткая ссылка /b/<код>
- Тикеты: #c5d7e2 (PR #177); механизм /b/ — #1d8184 (кейсы whatsapp-seller/WA-LINK-*)
- Роль/аккаунт: guest
- Устройство: desktop 1440×900; Android Pixel 7
- Тип: позитив
- Предусловия: ПРОД, только чтение. Код берётся из share (SHARE-PAGE-01/SHARE-CARD-01) для первой карточки /search; полный GUID и h1 запомнить.
## Шаги
1. С SW: открыть главную, дождаться `navigator.serviceWorker.controller`, в той же вкладке открыть `/b/<код>`.
2. Без SW (`serviceWorkers: 'block'`): сразу открыть `/b/<код>`.
## Ожидаемо
- Адрес `/businessdetail?id=<GUID того же объявления>`; h1 = заголовку из share (источник: #c5d7e2 «מה רצוי» — ссылка ведёт на объявление).
- Не «הדף לא נמצא».
