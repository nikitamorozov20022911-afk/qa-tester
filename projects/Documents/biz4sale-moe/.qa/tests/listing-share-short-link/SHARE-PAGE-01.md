# SHARE-PAGE-01: «שתף» на странице объявления — navigator.share с короткой ссылкой /b/<код>
- Фича/экран: שיתוף מודעה · /businessdetail (кнопка «שתף»)
- Тикеты: #c5d7e2 (PR #177)
- Роль/аккаунт: guest и user (.qa/auth/user.json) — результат одинаковый (см. SHARE-ROLE-01)
- Устройство: desktop 1440×900; Android Pixel 7 (проверено на реальном Pixel 6)
- Тип: позитив
- Предусловия: ПРОД, только чтение. Объявление выбирать динамически — первая карточка в /search (id не хардкодить). До перехода подменить `navigator.share` (записать аргумент, вернуть Promise.resolve) — системное окно не открывать, никуда не отправлять. Кнопки WhatsApp продавцу не нажимать.
## Шаги
1. Открыть /search, дождаться карточек; запомнить id первой карточки (из ссылки `/businessdetail?id=<GUID>`) и её заголовок.
2. Перейти в карточку — открывается /businessdetail?id=<GUID>&from=… ; дождаться h1.
3. Нажать «שתף».
## Ожидаемо
- `navigator.share` вызван один раз с объектом:
  - `title` = заголовок объявления (h1);
  - `text` = `חשבתי שיכול לעניין אותך: <כותרת>`;
  - `url` = `https://www.biz4sale.co.il/b/<первые 8 hex id>` (источник: #c5d7e2 «מה רצוי» — короткая ссылка как в WhatsApp продавцу, #1d8184).
- Ни в одном поле нет `businessdetail`, `id=`, `from=` (источник: #c5d7e2 «מה רצוי» — без длинного адреса).
- Находка (не требование): в share нет строки «לצפייה במודעה», ссылка — отдельным полем `url`.
