# ADMIN-PKG-01: объявление с бесплатным пакетом в «ניהול עסקים» показывается как «חבילה בחינם»
- Фича/экран: панель админа /admin → вкладка «ניהול עסקים»
- Тикеты: #f67768
- Роль/аккаунт: admin
- Устройство: desktop
- Тип: позитив (только просмотр, данные не меняются)
- Предусловия: на проде есть объявления с «חבילה 1 – הכרות חינם» (в списке «הכל» таких ~338).
## Шаги
1. Открыть /admin под admin, вкладка «ניהול עסקים».
2. В фильтре статуса выбрать «הכל».
3. Просмотреть колонки «חבילה» и «תשלום».
## Ожидаемо
- Объявления без платного пакета (не черновики): «חבילה» = «חבילה בחינם», «תשלום» = «חינם». (источник: «מה רצוי» #f67768 + решение пользователя 29.10)
- Ни у одного объявления, кроме статуса «טיוטה», нет «ללא חבילה» или «—». Черновики («טיוטה») — «— / ללא חבילה». (факт 29.10)
- Платные — «חבילה 2/3 … עד <дата>» / «שולם».
