# ADMIN-MOB-01: вход в «מסוף ניהול» с телефона — панель видна, без белого экрана и прокрутки вбок
- Фича/экран: мобильное меню → «מסוף ניהול» → /admin (S-13 פאנל ניהול)
- Тикеты: #6dd27f (тикет 89, בקשת לקוח)
- Роль/аккаунт: admin (`.qa/auth/admin.json`)
- Устройство: Android (Pixel, 412px) — сценарий тикета; также iPhone
- Тип: позитив (только просмотр, данные не меняются)
- Предусловия: в «ניהול משתמשים» много страниц (на проде ~45) — естественно есть.
## Шаги
1. Под admin на телефоне открыть главную.
2. Открыть меню (☰ «תפריט») → «מסוף ניהול».
3. Дождаться заголовка «ניהול - פאנל מנהל» (до 15 с; «אין הרשאה» может мигнуть при первом открытии).
4. Замерить ширину страницы.
## Ожидаемо
- Заголовок «ניהול - פאנל מנהל» виден, белого экрана нет. (источник: «מה רצוי» #6dd27f)
- `document.documentElement.scrollWidth` ≤ `innerWidth`, `scrollX` = 0 — страница по ширине экрана, без прокрутки вбок (было 1156px при 412px, scrollX −743). (источник: «מה קיים» / «מה רצוי» #6dd27f)
- Широкая таблица прокручивается в своём контейнере — это не прокрутка страницы.
## Не проверяется (урок L-20261110-1)
Все вкладки, пагинация, колонки, связанные тикеты — только сам симптом.
