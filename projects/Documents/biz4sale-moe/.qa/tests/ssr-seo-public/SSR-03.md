## Шаги
1. Категории — из sitemap. Для каждой: GET без JS → [data-seo-body], JSON-LD ItemList.
2. Для категории с N ≥ 1: открыть в браузере, прочитать «נמצאו N עסקים».
## Ожидаемо
- Есть SSR-блок; ItemList.numberOfItems — целое ≥ 0; при N ≥ 1 в SSR-блоке есть ссылки на карточки.
- numberOfItems = N из «נמצאו» в браузере.
