# SEO-META-02: meta description, canonical, og:* на публичных страницах
- Фича/экран: SEO metadata
- Тикеты: #b489db
- Роль/аккаунт: guest
- Тип: позитив (технический), прод, только чтение (@prod-safe)
- Устройство: не важно
## Шаги
1. Все URL sitemap → meta description, link canonical, og:title/description/url/image.
2. og:image не-объявлений (уникальные URL) → GET.
## Ожидаемо
- description, og:title, og:description, og:image — непусты; canonical один, абсолютный https://www.biz4sale.co.il/…, без utm_/from/source; og:url = canonical.
- Категория — self-canonical (тот же category); объявление — canonical /businessdetail?id=<свой uuid>.
- og:image → 200 image/jpeg (картинки объявлений — уже в seo-technical 2.1).
