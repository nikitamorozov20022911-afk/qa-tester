# WA-LINK-03: Неверный или несуществующий код /b/<код> → главная, не пустая страница (с SW и без)
- Фича/экран: WhatsApp למוכר · короткая ссылка
- Тикеты: #1d8184 (реджект, Р2)
- Роль/аккаунт: guest
- Устройство: desktop 1440×900 и Android Pixel 7
- Тип: негатив
- Предусловия: только чтение, не-GET обрываются.
## Шаги
1. Без SW: открыть `/b/00000000`, `/b/zzz`.
2. С SW: открыть главную, дождаться `navigator.serviceWorker.controller`, затем `/b/00000000`, `/b/zzz` в той же вкладке.
## Ожидаемо
- Адрес → `/` (главная), заголовок не «הדף לא נמצא», на странице есть содержимое главной. (источник: реджект rej_dbe214…, מצב רצוי: «קוד לא קיים או שגוי מעביר לדף הבית, ולא לדף ריק»)
## Не требование
- Пустой `/b/` → обычная 404 сайта «הדף לא נמצא» (как любой несуществующий адрес) — решение пользователя 10-28, не проверяем.
