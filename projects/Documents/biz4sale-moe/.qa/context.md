## Правила проекта (важнее общих правил плагина)
- **САЙТ — ПРОД.** Всё, что агент создаёт (объявления, заявки «השארת פרטים», избранное, сообщения, профили), — сразу после проверки удалить. Каждый созданный объект записывать в «Тестовые данные для чистки» (что, где, id) до удаления; удаление на сайте — по подтверждению пользователя. Не создавать данные без необходимости, не трогать реальные объявления и пользователей.
- Тестовые данные помечать в тексте «QA-TEST» для однозначного поиска.
- Вход делает пользователь сам; агент только тестирует. Сессия истекла → попросить повторить qa-login.
- Начинаем с аккаунта админа.

## Технические заметки
- 2026-11-05 · автотесты прод, iPhone: PWA-окно «אל תחמיצו אף הזדמנות» всплывает через 3 с после клика cookie (обработчик addLocatorHandler кликает cookie на первом действии) — посреди теста блокирует прокрутку (scrollY → 0) и прячет кнопки из дерева доступности (getByRole count 0 → ложные skip/падения). Закрывать заранее: addInitScript → localStorage b4s_install_prompt_dismissed_at = Date.now() (снуз как после «אולי מאוחר יותר»), обработчик — запасной. (businessdetail-gallery, #a6abaf)
- Вход: /auth — email+пароль (`npm run qa-login`, пароли в .qa/accounts.env заполняет пользователь), также SMS и Google (`npm run qa-login:manual -- <id>`). Логин запускает пользователь, агент тестирует под сохранённой сессией.
- Роли на главной: קונה / מוכר. Разделы: /search, /packages (חבילות פרסום), /addbusiness, /businessdetail?id=…
- Cookie-баннер: выбирать «חיוניים בלבד».
- Превью ссылок в WhatsApp: строит клиент отправителя; в WhatsApp Web/Desktop карточка появляется через 3–5 с после вставки — отправлять только после её появления; для повторной проверки добавлять новый ?v=N (WhatsApp кэширует по точному URL).
