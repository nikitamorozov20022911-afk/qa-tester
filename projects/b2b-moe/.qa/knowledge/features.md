# Features (תכונות) — מערכת קטלוג והזמנות B2B

Источник: «מפרט» mifrat (вкладка spec), режим «עבודה» (поля формы, `[N]` = порядковый номер пункта в «עבודה») и режим «ספר» («בלוקי פיצ'רים», «סיכומי מודולים», «פרק ב — מיפוי תכונות»).

- Всего תכונה: 52 (по «מיפוי תכונות»: 52 תכונה / 57 מסך).
- id F-xx = номер F-n из «ספר» (порядок в «בלוקי פיצ'רים», сверено с упоминаниями F-n в «סיכומי מודולים»). F-24…F-28 в документе нет.
- F-53…F-57 — 5 фич этапа 3 без F-номера в מפרט (есть только в «מיפוי תכונות» и «עבודה»); id присвоен при извлечении.
- Приоритет: поле «עדיפות» в «עבודה» (выбранное значение) → חובה=חובה, כדאי=חשוב, נחמד לשלב=נחמד; совпадает с «מיפוי תכונות» у всех 52.
- Поле формы «סיפור משתמש» во всех 52 пустое; User Story взята из поля «תיאור». Если формулировка в «בלוקי פיצ'רים» отличается — приведена отдельно.
- AC приведены дословно из двух мест: блок «תנאי קבלה» внутри поля «תיאור» и поле формы «Acceptance Criteria (קריטריוני קבלה)».
- «Экраны модуля» — все מסך того же модуля по «מיפוי תכונות» (прямая связь фича→экран в מפרט полем не задана).

## F-01 — ניהול קטלוג מוצרים

- **Модуль:** שלב 1 — ניהול קטלוג
- **Приоритет:** חובה (עדיפות: חובה)
- **Источник:** עבודה [1]; ספר — מיפוי תכונות #01, בלוקי פיצ'רים שלב 1 #01
- **Экраны модуля:** רשימת מוצרים (ניהול) — עבודה [44]; טופס מוצר (יצירה/עריכה) — עבודה [45]; ניהול תמונות מוצר — עבודה [46]; ניהול קטגוריות והירארכיה — עבודה [47]; בקרת זמינות מוצר — עבודה [48]

**User Story:** בתור המפיץ אני יוצר, עורך, משבית ומסיר מוצרים בקטלוג כדי שיהיה לי מקור-אמת אחד למה שאני מוכר.

**AC (תיאור — תנאי קבלה):**
- בהינתן שאני מחובר כמפיץ, כאשר אני יוצר מוצר חדש עם שדות חובה תקינים, אז המוצר נשמר ומופיע ברשימת המוצרים.
- בהינתן מוצר קיים, כאשר אני עורך את פרטיו ושומר, אז השינויים נשמרים ומשתקפים בקטלוג של הלקוחות.
- בהינתן מוצר קיים, כאשר אני מוחק אותו, אז הוא יורד מהקטלוג ואינו ניתן להזמנה.
- בהינתן ניסיון יצירת מוצר ללא שם או מק"ט, כאשר אני שומר, אז מתקבלת שגיאת ולידציה והמוצר אינו נשמר.
- בהינתן שאינני מחובר כמפיץ, כאשר אני מנסה לגשת לניהול המוצרים, אז הגישה נדחית.

**AC (поле формы):**
- בהינתן מפיץ מחובר, יצירת מוצר חדש עם שדות חובה תקינים שומרת אותו ומציגה אותו ברשימת המוצרים (מסלול הצלחה).
- כל מוצר נשמר עם שם, תיאור, מק"ט, יחידת מכירה ומחיר בסיס, וכל השדות מוצגים בכרטיס המוצר.
- מוצר המסומן כלא זמין מוצג ככזה בקטלוג ואינו ניתן להזמנה (מצב זמינות).
- עריכת מוצר קיים שומרת את השינויים ומשקפת אותם מיידית בקטלוג הלקוחות; מחיקה מורידה אותו מהקטלוג (מצבי עריכה/מחיקה).
- יצירה/שמירה ללא שם או מק"ט מחזירה שגיאת ולידציה והמוצר אינו נשמר (מצב קצה/שגיאה).
- משתמש שאינו מפיץ מורשה אינו יכול לגשת לניהול המוצרים והגישה נדחית (הרשאות/אבטחה).
- כל מסכי ניהול המוצר מוצגים בעברית מלאה בכיווניות RTL כולל הודעות הוולידציה.

## F-02 — תמונות מוצר

- **Модуль:** שלב 1 — ניהול קטלוג
- **Приоритет:** חובה (עדיפות: חובה)
- **Источник:** עבודה [2]; ספר — מיפוי תכונות #02, בלוקי פיצ'רים שלב 1 #02
- **Экраны модуля:** רשימת מוצרים (ניהול) — עבודה [44]; טופס מוצר (יצירה/עריכה) — עבודה [45]; ניהול תמונות מוצר — עבודה [46]; ניהול קטגוריות והירארכיה — עבודה [47]; בקרת זמינות מוצר — עבודה [48]

**User Story:** בתור המפיץ אני מעלה תמונה אחת או יותר לכל מוצר כדי שהלקוח יזהה את הפריט בקטלוג.

**AC (תיאור — תנאי קבלה):**
- בהינתן מוצר בעריכה, כאשר אני מעלה קובץ תמונה תקין, אז התמונה נשמרת ומוצגת בכרטיס המוצר.
- בהינתן מוצר עם כמה תמונות, כאשר הלקוח גולש בקטלוג, אז הוא רואה את התמונה הראשית ויכול לדפדף בנותרות.
- בהינתן העלאת קובץ בפורמט/גודל לא נתמך, כאשר אני מעלה, אז מתקבלת שגיאה ברורה והתמונה אינה נשמרת.
- בהינתן מוצר ללא תמונה, כאשר הוא מוצג בקטלוג, אז מוצגת תמונת ברירת מחדל (placeholder).

**AC (поле формы):**
- בהינתן מוצר בעריכה, העלאת קובץ תמונה תקין שומרת אותו לאחסון הקבצים (Supabase Storage) ומציגה אותו בכרטיס המוצר (מסלול הצלחה).
- מוצר עם כמה תמונות מציג תמונה ראשית וניתן לדפדף בנותרות; מוצר ללא תמונה מציג תמונת placeholder (מצבים).
- כל תמונה שהועלתה משויכת לפרטי המוצר ונשמרת יחד עמו.
- העלאת קובץ בפורמט או בגודל לא נתמך מחזירה שגיאה ברורה והתמונה אינה נשמרת (מצב קצה/שגיאה).
- כשל בהעלאה אל אחסון הקבצים מציג הודעת שגיאה ומאפשר ניסיון חוזר ללא איבוד שאר פרטי המוצר (כשל אינטגרציה).
- רק מפיץ מורשה יכול להעלות או למחוק תמונות מוצר (הרשאות/אבטחה).
- ממשק העלאת התמונה מוצג בעברית RTL.
- צפייה ודפדוף בתמונות מותאמים למסך מובייל.

- הקטגוריות וההיררכיה משמשות לסינון וניווט בקטלוג הלקוח.
- שיוך מוצר לקטגוריה מתבצע במסגרת ניהול הקטלוג ומשתקף בקטלוג.
- קטגוריה ריקה מוצגת ללקוח עם מצב ריק מתאים בניווט (מצב ריק).
- מחיקת קטגוריה עם מוצרים משויכים מבקשת שיוך מחדש או חוסמת את המחיקה (מצב קצה/שגיאה).
- כל מסכי הקטגוריות מוצגים בעברית RTL.

**AC (תיאור — תנאי קבלה):**
- בהינתן שאני מחובר כלקוח, כאשר אני פותח את הקטלוג, אז אני רואה את המוצרים הזמינים מאורגנים בקטגוריות.
- בהינתן מחרוזת חיפוש, כאשר אני מקליד שם מוצר, אז התוצאות מסוננות בהתאם בזמן אמת.
- בהינתן בחירת קטגוריה, כאשר אני מסנן לפיה, אז מוצגים רק מוצרי אותה קטגוריה.
- בהינתן חיפוש ללא תוצאות, כאשר אין התאמה, אז מוצג מצב ריק עם הצעה לנקות סינון.
- בהינתן קטלוג עם מאות מוצרים, כאשר אני גולש, אז הטעינה מהירה וחלקה (עימוד/טעינה הדרגתית).

**AC (поле формы):**
- בהינתן לקוח מחובר, פתיחת הקטלוג מציגה את המוצרים הזמינים מאורגנים בקטגוריות (מסלול הצלחה).
- הקלדת שם מוצר מסננת את התוצאות בזמן אמת ובחירת קטגוריה מציגה רק את מוצריה (מצבי חיפוש/סינון).
- בעת הגלישה מוצג לכל מוצר המחיר פר-לקוח הרלוונטי במקום מחיר הבסיס.
- חיפוש/סינון ללא התאמה מציג מצב ריק עם הצעה לנקות סינון (מצב ריק).
- קטלוג עם מאות מוצרים נטען מהר וחלק באמצעות עימוד/טעינה הדרגתית; כשל טעינה מציג שגיאה עם 'נסה שוב' (ביצועים/שגיאה).
- הלקוח רואה אך ורק את הקטלוג והמחירים שלו ולעולם לא של לקוח אחר (בידוד נתונים/אבטחה).
- הגלישה, החיפוש והסינון מותאמים למסך מובייל.

## F-06 — עגלת קניות

- **Модуль:** שלב 1 — אזור הקטלוג ללקוח
- **Приоритет:** חובה (עדיפות: חובה)
- **Источник:** עבודה [6]; ספר — מיפוי תכונות #11, בלוקי פיצ'רים שלב 1 #06
- **Экраны модуля:** קטלוג הלקוח (גלישה וסינון) — עבודה [49]; כרטיס מוצר (לקוח) — עבודה [50]; עגלת קניות — עבודה [51]; ביצוע הזמנה — עבודה [52]; אישור קליטת הזמנה — עבודה [53]; היסטוריית הזמנות (לקוח) — עבודה [61]

**User Story:** בתור הלקוח העסקי אני מוסיף מוצרים לעגלה, מעדכן כמויות ומסיר פריטים כדי להרכיב את ההזמנה לפני שליחתה.

**AC (תיאור — תנאי קבלה):**
- בהינתן מוצר זמין בקטלוג, כאשר אני מוסיף אותו לעגלה, אז הפריט נוסף עם הכמות והמחיר פר-לקוח שלי.
- בהינתן פריט בעגלה, כאשר אני משנה כמות, אז סכום הביניים מתעדכן בהתאם.
- בהינתן פריט בעגלה, כאשר אני מסיר אותו, אז הוא יורד מהעגלה והסכום מתעדכן.
- בהינתן עגלה ריקה, כאשר אני פותח אותה, אז מוצג מצב ריק עם קישור חזרה לקטלוג.
- בהינתן פריט שהפך ללא זמין, כאשר אני נכנס לעגלה, אז המערכת מסמנת אותו ומונעת המשך עם פריט מושבת.

**AC (поле формы):**
- בהינתן מוצר זמין, הוספתו לעגלה מוסיפה אותו עם הכמות והמחיר פר-לקוח של הלקוח (מסלול הצלחה).
- שינוי כמות פריט מעדכן את סכום הביניים, והסרת פריט מורידה אותו ומעדכנת את הסכום (מצבי עדכון).
- סכומי העגלה מחושבים לפי המחיר פר-לקוח ולא לפי מחיר הבסיס.
- עגלה ריקה מציגה מצב ריק עם קישור חזרה לקטלוג (מצב ריק).
- פריט שהפך ללא זמין מסומן בעגלה והמערכת מונעת המשך עמו (מצב קצה/שגיאה).
