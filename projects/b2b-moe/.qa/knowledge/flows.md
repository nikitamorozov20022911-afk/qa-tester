# Flows (תהליכי משתמש) — מערכת קטלוג והזמנות B2B

Источник: «מפרט» (mifrat), режим «ספר», раздел «תהליכי משתמש» — 47 процессов («תהליך משתמש · N / 47»). Снято 2026-10-03.

Ограничения источника:
- FL-01…FL-43: в режиме «ספר» раскрыт только блок «תיאור» (шаги + «→» исход + «[מסך: …]»). Поля טריגר / מטרה / סיום מוצלח / כשל-חסימה в «ספר» не показаны — помечено «не раскрыто». Исход каждого шага после «→» — дословно из תיאור.
- FL-44…FL-47: в «ספר» раскрыты только טריגר / מטרה / סיום מוצלח / כשל-חסימה; блока «תיאור» со шагами и ссылками на экраны нет.
- Режим «עבודה» (поля формы) не открывался — вкладка общая, навигация запрещена. Недостающие поля можно добрать оттуда.
- Тексты на иврите — дословно.
