- Фича/экран: /settings, #business-tax-id
- Тикеты: #61c0f4 (commit 1b38252, миграция 20261119190000; עבר QA 19.11)
- Роль/аккаунт: admin (מפיץ «באנגו דלי»)
- Устройство: desktop 1440
- Тип: негатив + граница + позитив
- Предусловия: МЕНЯЕТ данные бизнеса → после теста вернуть исходное значение (на 19.11 — пусто/null).
## Шаги
1. /settings → «פרטי העסק» → ввести «12 34abc» → «שמירה».
2. Поле очистить, набрать 19 цифр.
3. Очистить поле → «שמירה».
4. Ввести цифры → «שמירה» → обновить страницу.
## Ожидаемо
1. «ח.פ. / ת.ז. יכול לכלול ספרות בלבד», поле aria-invalid, запрос записи не уходит, после обновления значение прежнее (проверка — при сохранении, не при вводе).
2. maxlength=15 → в поле 15 цифр («עד 15 ספרות», как ח.פ. в карточке клиента).
3. Сохранение пустого проходит без ошибки (поле необязательное).
4. Значение сохраняется и показывается после обновления.
