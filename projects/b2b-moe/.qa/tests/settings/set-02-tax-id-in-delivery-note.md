1. Поле пусто → открыть #504: экран и print.
2. Сохранить цифры (напр. 900123456) → #504: экран и print.
3. (Вручную) новый утверждённый заказ → קבלה: ח.פ. под названием и в блоке «מנפיק».

1. Строки «ח.פ. / עוסק מורשה» нет, пустой строки нет, ошибок нет (מה רצוי: «אם השדה ריק — … בלי שורה ריקה ובלי שגיאה»).
2. «ח.פ. / עוסק מורשה: 900123456» под «באנגו דלי» (экран и печать).
3. קבלה — снимок на момент «אשר הזמנה»: у старых (#684/#685) ח.פ. не появляется (по комментарию программиста; вопрос ретро-обновления пользователю не снят). Автотестом не покрыто — нужен новый заказ (QA-AUTO, ₪5; реально проверено на #697).
