- Тикеты: #89b5f0 (536a4ad455a483d7ea89b5f0; עבר QA 26.10); связанный #7e2789 (то же в карточке заказа — dlv-11)

## Шаги
1. /orders → «כל החודשים» → «נדחו» → открыть заказ, взять id из адреса.
2. Открыть `/delivery/<id>` прямым адресом.
3. То же для второго отклонённого заказа и на 390.
4. Регресс: заказ «ממתינה לאישור» (фильтр «שלב ההזמנה») → `/delivery/<id>`.
5. Регресс: утверждённый заказ («ממתינה לליקוט») → `/delivery/<id>` (ничего не сохранять).
