# dlv-12: пока грузятся водители — нет «עדיין אין נהגים פעילים»; при пустом списке — есть
- Фича/экран: S-13 /orders/<id> блок «משלוח» (поле «נהג»); S-36 /delivery/<id> панель «שיוך נהג ומסלול»
- Тикеты: #a8bdcb (99d6995d55c6009d86a8bdcb; עבר QA 25.10)
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: состояние загрузки (тайминг) + пустое состояние (эмуляция)
- Предусловия: утверждённый заказ клиента «test» с адресом (берётся динамически: этапы ממתינה לליקוט → בליקוט במחסן → מוכנה למשלוח → בדרך ללקוח). Ничего не сохраняется.
## Шаги
1. В своём окне браузера задержать ответ GET /rest/v1/profiles?…role=eq.driver… на 3 с (ответ настоящий); наблюдатель DOM (MutationObserver с начала документа) на фразу «עדיין אין נהגים פעילים».
2. Открыть /orders/<id> (холодная загрузка), дождаться списка водителей.
3. То же для /delivery/<id>.
4. Подменить ответ водителей на пустой список [] (только в своём окне) → открыть оба экрана.
## Ожидаемо
1–3. За всё время загрузки фраза ни разу не появилась в DOM; после загрузки в «נהג» есть «יוסי הנהג» (источник: «מה רצוי» — «בזמן טעינת הנהגים מוצג מצב טעינה (או כלום)»).
4. После загрузки пустого списка — «עדיין אין נהגים פעילים. הוסיפו עובד עם תפקיד «נהג חלוקה» במסך הצוות.» на обоих экранах (источник: «מה רצוי» — «מוצגת רק אם אחרי הטעינה באמת אין נהגים»; эмуляция — реальных данных без водителей нет).
