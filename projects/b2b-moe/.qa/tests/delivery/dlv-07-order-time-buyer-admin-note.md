# dlv-07: время заказа — у клиента (список + детали), у מפיץ (карточка заказа) и «שעת הזמנה» на экране תעודת משלוח
- Фича/экран: F-14 / S-11 «ההזמנות שלי» (/shop/orders, /shop/order/<id>); S-13 /orders/<id>; S-36 /delivery/<id>
- Тикеты: #599f82 (4fe8a3e9427d9465f2599f82, commit 682c767; ручная QA 18.10, «הושלם»)
- Роль/аккаунт: buyer (test) + admin — два окна (asUser)
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: у клиента есть заказ «סופקה» (у него есть תעודת משלוח); только чтение
## Шаги
1. buyer → /shop/orders: первые строки; заказ «סופקה» → детали «הזמנה #N».
2. admin → /orders/<тот же id> → «תאריך הזמנה».
3. admin → /delivery/<id> (экран, не печать).
## Ожидаемо
1. У клиента в строке и в деталях — дата и время «D בחודש YYYY, HH:MM» (напр. «21 באוקטובר 2026, 12:17»), одинаковые (источник: «מה רצוי» п.1 «גם בפרטי ההזמנה של הלקוח»; формат клиента — решение программиста, пример тикета «14.10.2026, 18:30» не обязателен).
2. У מפיץ — «DD.MM.YYYY, HH:MM», то же время (коммент 682c767).
3. В תעודה «תאריך הזמנה: DD.MM.YYYY» и сразу под ним «שעת הזמנה: HH:MM» — то же время (источник: «מה רצוי» п.2).
