# dlv-10: заказ QA-AUTO — время заказа = момент отправки; שיוך с часом сохраняется и виден везде; смена часа в תעודה
- Фича/экран: buyer корзина → /shop/orders; admin /orders/<id>, /delivery, /delivery/<id>; водитель
- Тикеты: #599f82 (commits 682c767, 3281b3d)
- Роль/аккаунт: buyer + admin (asUser), водитель «יוסי הנהג» через «כניסה כעובד»
- Устройство: desktop 1440×900
- Тип: позитив (создаёт данные, @data)
- Предусловия: у клиента «test» есть כתובת משלוח (если пусто — временно «QA-AUTO כתובת, רחוב בדיקה 1, תל אביב», возврат в finally). Не параллельно с тестами корзины buyer.
## Шаги
1. buyer оформляет «QA-AUTO-delivery-hour-<ts>» (1 × מצית קליפט), засечь момент отправки.
2. buyer «ההזמנות שלי» → строка и детали; admin /orders/<id>.
3. admin: утвердить → נהג יוסי הנהג + תאריך (сегодня+3, после перехода на зимнее время 25.10) + час 16:00 → «שמירת שיבוץ» → обновить → «סמן כמוכנה למשלוח».
4. /delivery: карточка; печать доски («דוח משלוחים»); תעודה экран + печать.
5. Водитель: /delivery → карточка → תעודה.
6. admin в תעודה: час → 17:45, «שייך ושלח לנהג» → обновить; доска.
7. Очистка: водитель «יצאה למשלוח» → «סופקה» (заказ неудаляем).
## Ожидаемо
1–2. Время заказа у клиента/מפיץ = моменту отправки (±1 мин), одинаковое (источник: «מה רצוי» п.1 «השעה צריכה להישמר אוטומטית»).
3. «השיבוץ נשמר»; после обновления дата и 16:00 на месте, час не сдвинут.
4. «אספקה: עד DD.MM.YYYY בשעה 16:00»; в отчёте «DD.MM.YYYY עד 16:00»; תעודה «תאריך אספקה: …» / «שעת יעד לאספקה: עד 16:00» и в печати.
5. Водитель видит «אספקה: עד DD.MM.YYYY בשעה 16:00» и то же в תעודה (источник: «מה רצוי» п.3).
6. «שעת יעד לאספקה: עד 17:45», «נהג: יוסי הנהג», доска обновилась.
