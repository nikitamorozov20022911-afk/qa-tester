# dlv-01: מפיץ — תעודת משלוח: טבלת פריטים פרוסה על כל הרוחב + «הדפסה / PDF»
- Фича/экран: F-36 תעודות משלוח ושיוך נהג/מסלול / S-36 (FL-31)
- Тикеты: 6a7492a2d81dd018c86a348d #6a7492a2; 6a70b0b7fc28e23b23bf55d0 #6a70b0b7 (кнопка печати)
- Роль/аккаунт: admin (מפיץ ראשי)
- Устройство: desktop
- Тип: позитив / UI
## Предусловия
На /delivery есть хотя бы одна תעודת משלוח с ≥1 פריט.
## Шаги
1. /delivery → клик по карточке «תעודת משלוח · הזמנה #N».
2. Посмотреть таблицу פריטים (колонки שם פריט · מק"ט · כמות · מחיר יחידה · סה״כ).
3. «הדפסה / PDF».
## Ожидаемо
1. URL /delivery/<orderId>, h1 «תעודת משלוח · הזמנה #N», «ת. משלוח #DN-N», «תאריך הזמנה», «פרטי משלוח» (לקוח, כתובת-ссылка на Google Maps, «איש קשר», «טלפון» tel:), «סה"כ פריטים», «סה"כ לתשלום».
2. Колонки распределены по всей ширине таблицы: первая колонка у правого края, «סה״כ» — у левого края, суммарная ширина заголовков = ширине таблицы; нет пустой половины (источник: «מה רצוי» #6a7492a2 — "העמודות יתפרסו באופן אחיד על פני כל רוחב הטבלה … ללא ריכוז כל המידע בצד אחד").
3. Вызывается печать браузера (window.print) — из неё сохраняется PDF. Визуальный зум/вид PDF не автоматизируется.
