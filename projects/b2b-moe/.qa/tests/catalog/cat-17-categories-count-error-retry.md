# cat-17: «קטגוריות» — сбой загрузки счётчиков: видимое сообщение и «נסה שוב»
- Фича/экран: F-03 / S-04 (`/catalog/categories`)
- Тикеты: #133950be
- Роль/аккаунт: admin
- Устройство: телефон 390 (основной) + 360/320/1440
- Тип: негатив / состояние ошибки
- Предусловия: только чтение; записи в Supabase абортируются. Сбой — `page.route` abort на `rest/v1/products?…` (счётчики строятся из него).
## Шаги
1. Обрывать `rest/v1/products`, открыть `/catalog/categories`, подождать ~20 с.
2. Снять блок → «נסה שוב».
3. Без блока — открыть страницу.
## Ожидаемо
1. Через ~16 с (после повторов) над списком role=alert «אירעה שגיאה בטעינת מספר המוצרים בקטגוריות. נסה שוב.» с кнопкой «נסה שוב»; у категорий «—», «0 מוצרים» нет; текст не обрезан, нет горизонтальной прокрутки на 360/320 («מה רצוי»: видимое сообщение «אירעה שגיאה בטעינת … נסה שוב.» с «נסה שוב», как на других экранах).
2. Счётчики загружаются, сообщение исчезает.
3. Обычная загрузка, сообщения нет; задержка 10 с без ложной ошибки.
