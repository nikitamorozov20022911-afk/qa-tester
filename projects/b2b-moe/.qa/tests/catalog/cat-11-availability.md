# cat-11: מפיץ — כיבוי זמינות: «לא זמין» בניהול, «אזל» ואי אפשר להזמין אצל הלקוח
- Фича/экран: F-04 / S-05; F-05 / S-06, S-07
- Тикеты: 6a38cf5e524a187d2c244c49 #6a38cf5e
- Роль/аккаунт: admin; buyer
- Устройство: desktop
- Тип: функциональный
- Предусловия: товар QA-AUTO-catalog-… (без остатка).
## Шаги
1. admin: в строке товара выключить switch «זמינות <товар>».
2. Табы «זמינים» / «לא זמינים».
3. buyer: найти товар в `/shop`, открыть его страницу.
4. Сценарий «уже в корзине» и «не-מפיץ меняет זמינות».
## Ожидаемо
1. switch aria-checked=false, под именем метка «לא זמין».
2. «לא זמינים» +1, «זמינים» −1.
3. Карточка с бейджем «אזל»; на странице «אזל מהמלאי», кнопка «המוצר אזל מהמלאי» disabled, +/− disabled.
4. (не автоматизировано) для товара в корзине — нужен товар с остатком; не-מפיץ — buyer в админку не попадает (см. cat-13).
