# cat-18: Удаление родительской категории — заблокировано, пока есть подкатегории; счётчик родителя включает подкатегории
- Фича/экран: F-03 / S-04 (`/catalog/categories`), D-16
- Тикеты: #da8b4481
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (+ 390 вручную)
- Тип: негатив / целостность иерархии
- Предусловия: только свои «QA-AUTO-catalog-…» категории и товар; после — удалить (сначала подкатегории). Глубина иерархии — 2 уровня (3-й уровень в UI невозможен).
## Шаги
1. Родитель QA + подкатегория с товаром QA → ⋮ родителя.
2. Родитель QA + ПУСТАЯ подкатегория → ⋮ родителя.
3. Удалить пустую подкатегорию, затем родителя.
4. Регресс: подкатегория с прямым товаром → ⋮.
## Ожидаемо
1. У родителя счётчик включает товары подкатегорий («מוצר אחד», title «כולל המוצרים בתת-הקטגוריות»); «מחיקה» disabled «מכילה תת-קטגוריות».
2. «מחיקה» disabled «מכילה תת-קטגוריות» — подкатегория не становится молча корневой («מה רצוי»: удаление родителя с подкатегориями заблокировано с объяснением; иерархия сохраняется).
3. Пустая категория без детей — диалог «מחיקת קטגוריה» → удалена; после этого у родителя «מחיקה» доступна и он удаляется.
4. Категория с прямым товаром — disabled «מכיל מוצרים».
