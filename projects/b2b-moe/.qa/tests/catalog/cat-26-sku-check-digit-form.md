# cat-26: форма товара — контрольная цифра מק"ט (EAN-8 / UPC-A / EAN-13): предупреждение и сохранение только с подтверждением
- Фича/экран: F-01 / S-02 «מוצר חדש» /catalog/new, «עריכת מוצר» /catalog/<id>/edit
- Тикеты: #1ee7e8 (4ac9e0a6fc1df8a9fd1ee7e8; commit 8b8a350; עבר QA 28.10)
- Роль/аккаунт: admin
- Устройство: desktop 1440
- Тип: негатив + граница + позитив
- Предусловия: свои товары QA-AUTO-1ee7e8-<ts>-A/B/C с уникальными EAN (из времени прогона); удалить после.
## Шаги
1. «מוצר חדש»: имя A, מק"ט — EAN-13 с неверной контрольной → «שמירה» → «תיקון המק"ט» → ввести верный → «שמירה».
2. Ввести по очереди коды разных длин (таблица ниже) — есть ли предупреждение.
3. «מוצר חדש» B с неверным кодом → «שמירה» → «שמירה בכל זאת».
4. «מוצר חדש» C с тем же кодом, что у B → «שמירה» → «שמירה בכל זאת».
5. «עריכת מוצר» A: מק"ט с ошибкой в середине → «שמירה» → «שמירה בכל זאת».
## Ожидаемо
1. Под полем «ספרת הביקורת של הברקוד שגויה — בדקו את הספרות», aria-invalid=true; «שמירה» → окно «לשמור מק"ט עם ספרת ביקורת שגויה?» с кодом и кнопками «תיקון המק"ט» / «שמירה בכל זאת»; до подтверждения — 0 запросов записи; «תיקון המק"ט» — окно закрыто, остаёмся на форме, ничего не сохранено; верный код — без предупреждения и без окна, POST 201, «נוסף לקטלוג.» («מה רצוי»: «להציג אזהרה ברורה ולא לשמור בלי אישור מפורש»).
2. Предупреждение: 96385075 (EAN-8), 036000291453 (UPC-A), 5710840209438 и 5710840290437 (EAN-13). Без предупреждения: 96385074, 036000291452, 5710840209437; внутренние 12245 / 1 / 0; 7 / 10 / 14 цифр; буквы (ABC123, QA-AUTO-X-1) («מה רצוי»: «כשהמק"ט הוא 8 / 12 / 13 ספרות»).
3. «שמירה בכל זאת» — POST 201, товар в каталоге с этим מק"ט.
4. Дубль — 409, «מק"ט זה כבר קיים בקטלוג», товар C не создан (F-01, прежняя проверка).
5. Редактирование — то же предупреждение и окно, 0 запросов до подтверждения; после — сохранено (PATCH 2xx), в каталоге новый מק"ט.
## Не автоматизируется
- Находки: после «תיקון המק"ט» фокус не возвращается в поле; импорт из Excel не проверял контрольную цифру (исправлено в #dc1afa, кейс cat-29); ранее сохранённые неверные מק"ט не исправляются (не требовалось).
