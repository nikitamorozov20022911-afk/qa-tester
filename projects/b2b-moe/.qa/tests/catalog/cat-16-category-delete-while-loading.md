# cat-16: קטגוריות — «מחיקה» недоступна, пока счётчики товаров не загружены; сервер не удаляет категорию с товарами
- Фича/экран: F-03 / S-04 (`/catalog/categories`), D-16
- Тикеты: #19daa080 (высокий)
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (+ телефон для п.1)
- Тип: негатив / гонка / безопасность данных
- Предусловия: UI-часть — только меню (Escape), реальные категории не меняются; серверная часть — ТОЛЬКО на своих «QA-AUTO-catalog-cat/sub-<ts>» с QA-AUTO-товаром. Счётчики «N מוצרים» строятся из GET `rest/v1/products` на этой странице.
## Шаги
1. Задержать `rest/v1/products` на ~8 с, открыть `/catalog/categories`, ⋮ первой категории.
2. Дождаться загрузки, ⋮ категории с N>0 товаров.
3. Обрывать `rest/v1/products` (abort), открыть страницу, ⋮.
4. QA-подкатегория с активным QA-товаром: `DELETE rest/v1/categories?id=eq.<id>` с токеном сессии admin, затем перечитать.
## Ожидаемо
1. У строк — status «טוען…» (не «0 מוצרים»); пункт «מחיקה טוען…» disabled.
2. «מחיקה מכיל מוצרים» disabled (D-16).
3. После повторов (~15 с) счётчик «—», «מחיקה לא ניתן לבדוק את המוצרים» disabled, «0 מוצרים» нет; над списком role=alert «אירעה שגיאה בטעינת מספר המוצרים בקטגוריות. נסה שוב.» с кнопкой «נסה שוב» (#133950be, подробно cat-17).
4. HTTP 400, тело содержит `CATEGORY_HAS_PRODUCTS`; категория на месте, у неё «מוצר אחד» (после #6fcb020f, 05.10).
