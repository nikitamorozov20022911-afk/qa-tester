2. Закрыть, клик по ячейке «מיקום במחסן» («ללא מיקום»).
3. Закрыть, клик по ячейке картинки («הוספת תמונה למוצר — <товар>»).
4. (#10cc07dc) Товары с местом на 1-й странице (кнопка «מיקום במחסן — <товар>» не «ללא מיקום»): прочитать текст ячейки, `title` и aria-name кнопки.
5. QA-товар без места: ячейка «מיקום במחסן».
6. Клик «מיקום במחסן — <QA-товар>» → в окне «מיקום במחסן» «בחרו פריט אחסון» (ארון) → «בחרו מדף ב«…»» (полка пустого места) → «שמירה»; обновить страницу.
7. Принять 1 шт. кликом по числу «במלאי» (место подставится — inv-02) → посмотреть ячейку.
8. (строки мест) Товар в 2+ местах («הוספת מיקום» — #7b8b97e9; данные — inv-06 п.D): каждая строка места в ячейке; при >3 — «+N».
9. Ширина 375 (iPhone 13 mini): /catalog, тот же товар.
