# cat-30: импорт из Excel — ручная привязка нераспознанной колонки к полю (кнопка колонки → меню полей)
- Фича/экран: F-01 · /catalog/import: пояснение «עמודה נוספת אחת לא תיובא», панель «התאמת עמודות» («שינוי עמודות»), предпросмотр
- Тикеты: #6ac0be (27183a5a2057ee2cd26ac0be; commit 8c22452; עבר QA 29.10). Рамки — #7c5052 (AC3–AC4, реджект: без Dropdown, без «יחידת מכירה»); тексты ошибок модели — #38e1e5 (ui-15).
- Роль/аккаунт: admin (при параллельной проверке — admin-3)
- Устройство: desktop 1440×900
- Тип: позитив + негатив (ошибки модели) + граница
- Предусловия: ответ `functions/v1/import-map` подменён (`e2e/tests/_ai-mock.ts`): 200 с пустым `columns`, баланс, 500 timeout, ответ через 5 с. Настоящий (платный) вызов модели не делается. Имена `QA-AUTO-6ac0be-<ts>-*`. Запись в базу заблокирована; «ייבוא» — с перехватом POST products.
## Шаги
1. CSV `שם מוצר,מחיר לצרכן` → «עמודה נוספת אחת לא תיובא» → пояснение → кнопка «שיוך העמודה «מחיר לצרכן» לנתון» → меню.
2. «שינוי עמודות»: строки полей без колонки; кнопка колонки внизу → «מחיר בסיס».
3. Выключить «ייבוא מחיר בסיס» → снова привязать → «ייבוא מוצר אחד».
4. То же при ответе модели «баланс» и «500 timeout».
5. CSV `שם מוצר,קוד מוצר,מחיר לצרכן,זרזיף קרפלוני`, модель отвечает через 5 с (מחיר לצרכן → מחיר קנייה, זרזיף → תיאור): до ответа привязать «מחיר לצרכן» → «מחיר בסיס» и выключить «מק"ט».
6. CSV `שם מוצר,מחיר לצרכן,זרזיף קרפלוני`: «מחיר לצרכן» → «מחיר בסיס», затем «זרזיף קרפלוני» → «מחיר בסיס במקום העמודה «מחיר לצרכן»».
7. CSV `תווית,קוד מוצר` (нет колонки имени) → «תווית» → «שם מוצר».
## Ожидаемо
1. Пояснение: «…לחצו עליה ובחרו איזה נתון היא.» (прежнего «פתחו «שינוי עמודות» ובחרו לה שדה» нет); меню — 8 полей: שם מוצר (как «במקום העמודה «שם מוצר»»), מק"ט, קטגוריה, כמות באריזה, מחיר קנייה, מחיר בסיס, תיאור, זמין למכירה; «יחידת מכירה» нет; Esc закрывает.
2. У полей без колонки — «לא זוהתה עמודה · אפשר לשייך עמודה מהרשימה למטה», переключатели неактивны; в строках нет select/combobox/Dropdown; после выбора: «מחיר בסיס» — «מהעמודה «מחיר לצרכן» · לדוגמה: 12.5», переключатель включён, в предпросмотре колонка «מחיר» = 12.5, кнопка колонки исчезла из списка «לא תיובא» («מה רצוי»: «אפשר לבחור לכל שדה עמודה מהקובץ, כולל עמודה שלא זוהתה»).
3. Выключение убирает цену из предпросмотра, колонка снова в списке; после повторной привязки POST products содержит base_price 12.5.
4. Есть примечание («זיהוי עמודות אוטומטי אינו זמין כרגע…» / «לא הצלחנו לזהות את שאר העמודות אוטומטית. שייכו אותן ידנית.»), привязка работает, импорт не заблокирован (#7c5052 AC4; «מה רצוי»: «גם כשהמודל לא זמין או לא זיהה»).
5. После ответа: «עמודה אחת זוהתה אוטומטית…», «תיאור» — от модели; «מחיר בסיס» по-прежнему из «מחיר לצרכן», «מחיר קנייה» колонку не забрал, «מק"ט» остался выключен (коммент программиста: опоздавший ответ не затирает ручной выбор).
6. «מחיר בסיס» — из «זרזיף קרפלוני», цена 7, одна колонка цены; «מחיר לצרכן» снова кнопкой в списке «לא תיובא» (без двойного маппинга).
7. До привязки: alert «לא זוהתה עמודת "שם מוצר" בקובץ. לחצו על העמודה הנכונה ברשימה למעלה ובחרו «שם מוצר»…», «ייבוא 0 מוצרים» неактивна; после — имя в предпросмотре, «שם מוצר» «מהעמודה «תווית»», alert исчез, «ייבוא מוצר אחד» активна.
