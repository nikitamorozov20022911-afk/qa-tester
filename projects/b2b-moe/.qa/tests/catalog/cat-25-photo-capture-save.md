## Шаги
1. /catalog → поиск товара → «הוספת תמונה למוצר — <товар>».
2. Дождаться активной «צילום», запомнить её позицию → «צילום».
3. «צילום חוזר» → «צילום» ещё раз.
4. «סגירה» без «שמירה»; посмотреть строку товара.
5. Открыть снова → «צילום» → «שמירה».
6. «סגירה» → строка товара; обновить страницу.
## Ожидаемо
1. Окно «תמונות המוצר» прижато к верху экрана (y≈16 на 1440×900), подсказка «כוונו את המצלמה לאריזת המוצר ולחצו «צילום».».
2. Выбор файла не открывается (нет filechooser); вместо «צילום» — «צילום חוזר» и «שמירה», подсказка «בדקו את התמונה ולחצו «שמירה» כדי להוסיף אותה למוצר.»; загрузки в storage нет, миниатюры «ראשי» нет (מה רצוי: «אין לפתוח חלון לבחירת תמונה»; коммент программиста).
3. Снова живая камера; второй «צילום» — тоже без выбора файла.
4. Ничего не сохранено: в строке по-прежнему «הוספת תמונה למוצר — <товар>».
5. Миниатюра «ראשי», «צילום» вернулась на то же место (|Δ| ≤ 1px) (коммент: окно прижато к верху, кнопки не съезжают).
6. В строке — «תמונות המוצר — <товар>» с картинкой; после обновления остаётся (מה רצוי: «משויכת למוצר הנכון ומוצגת בקטלוג»).
- Только вручную: реальная камера и касание на iPad/Safari (системный выбор файла iOS не эмулируется).
