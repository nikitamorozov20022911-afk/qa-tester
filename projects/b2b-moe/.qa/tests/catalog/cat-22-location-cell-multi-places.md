# cat-22: Колонка «מיקום במחסן» у товара в нескольких местах — строки с кодом места, кнопка «+N» со всеми местами, строка открывает только своё место
- Фича/экран: S-01 «קטלוג וניהול», колонка «מיקום במחסן»; окно «מיקום במחסן»; «קליטת מלאי»
- Тикеты: #7b8b97e9 (עבר QA 12.10; реджект 11.10 п.2 «+N» и коды)
- Роль/аккаунт: admin («test admin»)
- Устройство: desktop 1440×900; 390 (эмуляция + Android Pixel 6 касанием вручную); реальный iPhone — вручную
- Тип: UI / позитив
- Предусловия: товар «QA-AUTO-7b8b-M-…» в 5 ПУСТЫХ местах (первое — «מיקום במחסן», остальные — «הוספת מיקום»), остатки 5/2/1/0/0.
## Шаги
1. /catalog → поиск M → колонка «מיקום במחסן».
2. Нажать «+2» → посмотреть список → Esc; снова «+2» → клик вне меню.
3. Перезагрузить страницу → шаги 1–2.
4. Клик по 2-й строке колонки → окно → «ביטול»; «+2» → пункт места, которого нет в строках → окно → «ביטול».
5. Клик по числу «במלאי» → открыть «מקום היעד» → «ביטול».
6. Ширина 390: «+2» → список; горизонтальная прокрутка страницы.
## Ожидаемо
1. 3 строки, каждая начинается с кода своего места: «F-21 | קומה 1 | ארון F | <מדף>», строки разные; кнопка «+2» (aria-label «כל המקומות של המוצר», aria-haspopup=menu), «הוספת מיקום».
2. Меню со всеми 5 местами: «<קוד> · קומה 1 · ארון X · <מדף>» + «מונחות כאן N יחידות» или «משויך למקום זה, ללא כמות» (для мест с 0); Esc и клик вне закрывают.
3. После перезагрузки — то же.
4. Окно «מיקום במחסן» показывает только выбранное место («המקום הנוכחי (N יחידות): … | <קוד>»), других кодов нет.
5. Варианты — ровно 5 мест товара + «ללא מקום — לשיוך בהמשך»; остаток не меняется.
6. Меню открывается, 5 пунктов; страница без горизонтального скролла (scrollWidth ≤ innerWidth).
- Находка (не реджект): «מונחות כאן 1 יחידות» — мн.ч. при 1.
