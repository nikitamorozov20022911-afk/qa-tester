## Шаги
1. `/catalog` → «העמוד הבא» ×2 («מציג 17–24 מתוך N»), прокрутить вниз, открыть товар по имени.
2. В редактировании нажать «ביטול».
3. Ввести поиск (например «כפיות»), «מיון» → «שם — ת׳ עד א׳», открыть товар, вернуться кнопкой браузера «назад».
## Ожидаемо

3. Поле поиска сохраняет текст, порядок строк — по выбранной сортировке, счётчик тот же («יש לשמור גם את מצב הסינון, המיון והחיפוש»).
