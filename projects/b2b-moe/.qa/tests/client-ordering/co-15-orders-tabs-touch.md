# co-15: לקוח, טלפון — לשוניות «ההזמנות שלי» ≥ 44×44, בלי גלילה אופקית
- Фича/экран: F-14 / S-11 (`/shop/orders`)
- Тикеты: #203f0163
- Роль/аккаунт: buyer
- Устройство: mobile — 320 / 360 / 375 / 390 (touch) + 1440 для сравнения
- Тип: UI / мобильный
- Предусловия: —
## Шаги
1. Открыть `/shop/orders` на телефоне; замерить вкладки «הכל / פתוחות / הושלמו» на 320/360/375/390.
2. Проверить `scrollWidth ≤ clientWidth`.
3. Переключить вкладки касанием.
## Ожидаемо
1. Каждая вкладка ≥ 44×44 («מה רצוי»; программист: «הכל» 44×44, «פתוחות» 60×44, «הושלמו» 59×44).
2. Горизонтальной прокрутки нет.
3. Касание переключает вкладку (aria-selected=true); подчёркивание активной — по ширине слова (вручную/визуально).
