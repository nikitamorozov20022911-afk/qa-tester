# co-26: «מוצרים אחרונים» — поиск, «במלאי בלבד», «מחירון אישי», сортировка работают внутри категории

- Тикеты: #8103a9 (комментарий программиста 14.10)
- Роль/аккаунт: buyer
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: в «מוצרים אחרונים» ≥ 2 товара.
## Шаги
1. «מוצרים אחרונים» → поиск по слову из названия второго товара; затем несуществующее слово; очистить поле.
2. «סינון ומיון» → «במלאי בלבד» → «הצגת …»; вернуть «הכל» (זמינות).
3. «סינון ומיון» → «מחירון אישי בלבד» → «הצגת …»; вернуть «כל המוצרים».
4. «סינון ומיון» → «מחיר: מהזול ליקר» → «הצגת …».
## Ожидаемо
1. Только товары категории с этим словом, счётчик ≤ N; несуществующее → «לא נמצאו מוצרים תואמים»; пустое поле → снова N (AC F-05 «חיפוש/סינון ללא התאמה מציג מצב ריק»).
2. Категория остаётся «מוצרים אחרונים», карточек «אזל» нет, счётчик ≤ N.
3. Категория остаётся, счётчик ≤ N.
4. Категория остаётся, тот же набор N, цены не убывают.
