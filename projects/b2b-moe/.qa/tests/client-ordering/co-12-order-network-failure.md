# co-12: לקוח — כשל בשליחת הזמנה: שגיאה, העגלה נשמרת, בלי הזמנה כפולה
- Фича/экран: F-07 / S-09
- Тикеты: 6a38cf5f125a16091d3b25bb #6a38cf5f (TC-023); #a5f94502 (офлайн, 2026-10-04)
- Роль/аккаунт: buyer
- Устройство: desktop 1440×900
- Тип: негатив
- Предусловия: товар в корзине; запрос `rpc/place_order` отвечает ошибкой (имитация 503) / сеть отключена.
## Шаги
1. На «ביצוע הזמנה» нажать «שליחת הזמנה» при ошибке сервера.
2. Отключить сеть (offline) и нажать «שליחת הזמנה».
3. Вернуть сеть, подождать ≥ 60 с, проверить «ההזמנות שלי».
4. Нажать «שליחת הזמנה» ещё раз.
## Ожидаемо
1. Alert «שליחת ההזמנה נכשלה. העגלה נשמרה — אפשר לנסות שוב.», остаёмся на /shop/checkout, «פריטים בעגלה 1», кнопка «שליחת הזמנה» снова активна (AC «מוצגת שגיאה והעגלה נשמרת לניסיון חוזר»).
2. Сразу (< 1 с; замер < 150 мс) «אין חיבור לרשת. העגלה נשמרה — אפשר לנסות לשלוח שוב כשהחיבור יחזור.», кнопка активна (нет зависшего «שולח…»), остаёмся на /shop/checkout, корзина цела (#a5f94502).
3. Заказ сам НЕ создаётся после возврата сети — верхний заказ в списке прежний.
4. Создаётся ровно один заказ («ההזמנה נקלטה!»), дублей нет. Заказ «QA-AUTO-client-ordering-offline-…» затем отклоняется admin.
- Вручную: офлайн-сохранения у admin (товар, категория) и «לוקט» в ליקוט тоже падают сразу; добавление в корзину офлайн — локально, синхронизация при возврате сети.
