# co-31: корзина — пока грузятся цены, вместо суммы скелет; «סה״כ משוער ₪0.00» / «סה״כ לתשלום ₪0.00» не появляются ни на одном кадре
- Фича/экран: S-08 «עגלת קניות» /shop/cart, S-09 «ביצוע הזמנה» /shop/checkout; F-06
- Тикеты: #b82eba (078609fc7981f8ca96b82eba; commit f6b3f8a; עבר QA 26.10); рядом — #f5aa41 (co-23)
- Роль/аккаунт: buyer (клиент «test»)
- Устройство: desktop 1280×900 (мобильная колонка); вручную также iPhone-эмуляция 390
- Тип: позитив / тайминг
- Предусловия: корзина buyer общая — снять снимок, очистить; товар с ценой ≠ ₪0.00 (у клиента test «פינלנדיה 200 מ"ל» стоит ₪0.00 — не подходит). Заказ не оформлять. В конце — очистить и вернуть снимок. Не параллельно с cart-checkout / order-lifecycle / inventory-lifecycle / cart-remove-no-flash.
## Шаги
1. Запись кадров (MutationObserver на строке суммы: текст суммы + наличие .animate-pulse).
2. Перезагрузить /shop → «הוספה לעגלה — <товар>» → «עגלה» в нижнем меню.
3. Задержка ответа rpc/customer_products 1.5 с (route.continue после паузы, без подмены) → «עגלה» → перезагрузить корзину.
4. В корзине — «הוספה לעגלה» из «השלימו את ההזמנה».
5. «המשך לביצוע הזמנה» → /shop/checkout; перезагрузить с задержкой 1.5 с. «שליחת הזמנה» не нажимать.
## Ожидаемо
1. Ни на одном кадре «סה״כ משוער ₪0.00» (тикет «מה רצוי» — «בזמן הטעינה לא להציג סכום שגוי ₪0.00»).
2. Пока цены грузятся — скелет на месте суммы (в кадре без суммы всегда есть скелет); при задержке 1.5 с скелет виден, суммы «₪…» в строке нет («להציג מצב טעינה (שלד) במקום הסכום»).
3. После загрузки «סה״כ משוער» = сумма строк (по цене פר-לקוח), «פריטים בעגלה» = числу строк (F-06 demand «סכומי העגלה מחושבים לפי המחיר פר-לקוח»).
4. Добавление из «השלימו את ההזמנה» — сумма не сбрасывается в ₪0.00, затем = сумма 2 строк («מה קיים» — сбрасывалась ~380 мс).
5. «סה״כ לתשלום» на ביצוע הזמנה — без ₪0.00 (и при задержке), = сумме корзины (коммент f6b3f8a).
## Находки (не требования тикета)
- Строки корзины на ~470 мс / 1.8 с становятся скелетами при первом открытии.
- «פינלנדיה 200 מ"ל» — ₪0.00 для клиента test.
- «+»/«−» некоторых товаров неактивны при кол-ве 1 (вероятно, остаток).
