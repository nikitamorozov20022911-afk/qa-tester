# co-22: Клиент — список категорий обновляется без reload: опустевшая категория уходит сразу и не открывается в «0 מוצרים»
- Фича/экран: F-05 / S-06 (`/shop`), шторка «סינון ומיון»
- Тикеты: #157fed2c (עבר QA 2026-10-14; реджекты #0 rej_1791369328521, #1 rej_1791706936788, #2 rej_1791802571140 закрыты); связано #899df3e5 (co-18)
- Роль/аккаунт: admin (.qa/auth/admin.json) + buyer «test» (.qa/auth/buyer.json) — одновременно, два окна
- Устройство: desktop 1440×900 + iPhone 390 (эмуляция) у buyer; admin — десктоп
- Тип: позитив / граница (гонка данных)
- Предусловия: admin создаёт корневые «QA-AUTO-157f-…-A», «…-B» и товар «…-P» (цена 1, без остатка) в A; в конце всё удаляется.
## Шаги
1. buyer `/shop` → чип A → «A · מוצר אחד», карточка P. admin: P → категория B («שמירה»). buyer (без reload): «הכל», снова чип A.
2. buyer: A + шторка «מיון» «שם: א׳–ת׳» → «הצגת מוצר אחד». admin: P → B. buyer: шторка → «נקה הכל» → «הצגת N מוצרים».
3. buyer: A. admin: P → B. buyer: шторка → «זמינות» «במלאי בלבד» → «הצגת …».
4. buyer: A, сортировки «שם» и «מומלץ» (обе выдачи A в кэше). admin: P → B. buyer: шторка → «שם: א׳–ת׳» → «הצגת …».
5. admin: P → A. buyer (на «הכל»): шторка → другая сортировка → «הצגת …» → чип A.
## Ожидаемо
1. Чип A уходит из строки ≤ 1 с (порог автотеста 3 с; не по 30-с таймеру), выбран «הכל», заголовок «כל המוצרים», «0 מוצרים» и «לא נמצאו מוצרים תואמים» нет; чип B появился (מה רצוי: «רשימת הקטגוריות … מתעדכנת בלי רענון ידני … קטגוריה שהתרוקנה לא מוצגת ולא נפתחת ל«0 מוצרים»»).
2. После «נקה הכל» в шторке строки A нет сразу, выбрано «כל הקטגוריות», B есть; после закрытия — чипа A нет (rej #2: «גם «נקה הכל» קורא מחדש את רשימת הקטגוריות — קטגוריה שהתרוקנה יוצאת מהשורה ומהשכבה מיד»).
3–4. В шторке A пропадает сразу после смены «זמינות»/сортировки; после закрытия шторки ни разу не показан заголовок «A» с «מוצר אחד» (прежняя выдача), чипа A нет, «הכל» (rej #1 «כל שינוי ב«סינון ומיון» … קורא מחדש … לפני הצגת המוצרים»; rej #2 «לא מוצגת תוצאה שמורה … בלי מוצר שכבר לא בקטגוריה ובלי מספר שגוי בכותרת»).
5. После смены сортировки A снова в шторке и в строке; клик по A — сразу «A · מוצר אחד» и карточка P, без «0 מוצרים» (rej #0 «כשקטגוריה מתמלאת שוב, המוצרים שלה מוצגים בלי לעבור דרך «הכל»»).
- Известно (вне объёма, 14.10): после возврата во вкладку браузера прежняя выдача видна 0.4–0.74 с до обновления (Т2 «מתעדכנת בלי רענון» выполнено <1 с); только открытие шторки категории не перечитывает — не требование.
