# co-25: «מוצרים אחרונים» — все заказанные товары, каждый один раз, по дате последнего заказа; архивных нет
- Фича/экран: F-05 / S-06 (`/shop`), источник данных — F-14 «ההזמנות שלי»
- Тикеты: #8103a9 (9f381ae90c6d4f6b828103a9, commit 1d63a05)
- Роль/аккаунт: buyer
- Устройство: desktop 1440×900
- Тип: позитив
- Предусловия: у buyer есть заказы; часть товаров из старых заказов удалена (архив).
## Шаги
1. «הזמנות» (/shop/orders): выписать товары всех заказов (новые сверху) — в автотесте из ответа `orders?select=…order_items(…products(name,sku))`.
2. /shop → «מוצרים אחרונים», прокрутить список до конца.
## Ожидаемо
- Каждый товар в списке один раз; число карточек = счётчику (מה רצוי п.3 «אם הלקוח הזמין את אותו מוצר מספר פעמים, המוצר יופיע פעם אחת בלבד»).
- Каждый товар списка есть в истории заказов клиента (п.2 «המוצרים שנכללו בהזמנות שנשלחו על ידי הלקוח»).
- Порядок — по последнему заказу товара, новые первыми (п.3 «לפי מועד ההזמנה האחרון שלהם, מהחדש לישן»).
- Товар из истории, которого нет в списке, — удалён из каталога (архив): поиском в «הכל» не находится (комментарий 14.10 «товар из архива не показывается»).
- Отклонённые («נדחתה») заказы учитываются — так сдано и принято 18.10 (вопрос В1 брифа закрыт фактом).
- Пример на 25.10: 11 товаров, первые — «פינלנדיה 200 מ"ל» (#615), «מצית קליפט» (#593), «רד לייבל 200 מ"ל» (#557); QA-AUTO из истории — все в архиве и не показываются.
