# co-24: «מוצרים אחרונים» — чип сразу после «הכל», тот же стиль; есть в «סינון ומיון»
- Фича/экран: F-05 / S-06 (`/shop`), шторка «סינון ומיון»
- Тикеты: #8103a9 (9f381ae90c6d4f6b828103a9, commit 1d63a05; прошёл ручную QA 18.10, «הושלם»)
- Роль/аккаунт: buyer (клиент «test», есть отправленные заказы)
- Устройство: desktop 1440×900 (вручную также iPhone 390)
- Тип: позитив / визуал
- Предусловия: у buyer есть хотя бы один отправленный заказ с товаром не из архива.
## Шаги
1. Открыть /shop, дождаться чипов категорий.
2. Сравнить чип «מוצרים אחרונים» с соседями (место, высота, фон, шрифт).
3. Нажать «מוצרים אחרונים».
4. Открыть «סינון ומיון» → в «קטגוריה» выбрать «מוצרים אחרונים» → «הצגת …».
## Ожидаемо
1–2. Чип «מוצרים אחרונים» идёт сразу после «הכל» (RTL: второй справа, левее «הכל», правее остальных), на той же строке; высота, фон, скругление и шрифт как у невыбранных чипов (מה רצוי п.1: «משמאל לקטגוריית "הכל"… להשתלב בעיצוב הקיים»).
3. Чип выбран (aria-pressed, заливка как у выбранного «הכל»), «הכל» становится невыбранным; заголовок списка «מוצרים אחרונים», счётчик «N מוצרים» / «מוצר אחד»; подкатегорий (второй строки) нет.
4. В шторке «מוצרים אחרונים» — сразу после «כל הקטגוריות»; после «הצגת» — тот же заголовок и та же выдача (комментарий программиста 14.10).
