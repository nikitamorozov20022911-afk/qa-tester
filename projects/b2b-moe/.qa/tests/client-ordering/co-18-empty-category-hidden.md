- Фича/экран: F-05 / S-06 (`/shop`), F-03 / S-04 (`/catalog/categories`)
- Тикеты: #899df3e5 (commit 499e1e1)
- Роль/аккаунт: admin (данные, .qa/auth/admin.json) + buyer «test» (.qa/auth/buyer.json)
- Устройство: desktop 1440×900 (+ телефон 390 / iPhone 13 Mini / Pixel 7 — вручную)
- Тип: позитив / граница
- Предусловия: admin создаёт пустую корневую «QA-AUTO-…-empty» и QA-AUTO-товар (в другой категории); в конце всё удаляется.
## Шаги
1. buyer `/shop` (reload): строка чипов, в т.ч. прокрутка до конца строки.
2. Открыть шторку «סינון ומיון» → блок «קטגוריה».
3. admin: товару QA-AUTO задать «קטגוריה» = «…-empty» → buyer `/shop` (reload).
4. Нажать появившийся чип.
5. admin: вернуть товару прежнюю категорию → buyer `/shop` (reload).
## Ожидаемо
1. Чипа «…-empty» нет; «הכל» и счётчик «כל המוצרים · N מוצרים» — без изменений (מה רצוי: «קטגוריה שאין בה מוצרים לא מוצגת ללקוח בקטלוג (לא בשורת הקטגוריות …)»).
2. В списке категорий шторки «…-empty» нет («… ולא בסינון»).
3. Чип «…-empty» появился («ברגע שנוסף אליה מוצר — היא מופיעה»), есть и в шторке.
4. Чип нажат (aria-pressed), второй строки нет (одна «הכל»), «מוצר אחד», карточка товара.
5. Чипа «…-empty» снова нет.
