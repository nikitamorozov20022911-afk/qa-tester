- Тикеты: #899df3e5 (комментарий программиста: «хотя бы один активный товар (не в архиве)»); связано #0309a9bf (удаление с остатком «ללא מקום»)
- Роль/аккаунт: admin (данные) + buyer «test»
- Устройство: desktop 1440×900
- Тип: граница
- Предусловия: admin: категория «QA-AUTO-catvis-arch-…», в ней QA-AUTO-товар; приход 3 шт. «ללא מקום — לשיוך בהמשך» (появляются движения).
## Шаги
1. buyer `/shop`: чип категории.
2. admin: удалить товар (⋮ → «מחיקה» → «מחיקה»).
3. buyer `/shop` (reload): строка чипов и шторка «סינון ומיון».
4. admin `/catalog/categories`.
## Ожидаемо
1. Чип виден (активный товар).
2. Сообщение «"<товар>" הוסר מהקטלוג. ההזמנות והתנועות שמזכירות אותו נשמרו.» — товар ушёл в архив (не удалён полностью).
3. Чипа категории нет, в шторке её нет — архивный товар не считается.
4. Категория в списке у מפיץ есть (её можно удалить).
- Побочный эффект: 2 записи «יומן תנועות» (קליטה, מחיקת מוצר) и архивный товар остаются навсегда — как в delete-unplaced-stock.spec.ts.
