- Тип: позитив / регресс бага / обратная проверка (после снятия — «ריק»)
- Предусловия: п.1–3 — любой товар с «מיקום במחסן» (на 03.10: «פינלנדיה 200 מ"ל» → «קומה 1 | ארון H | אלכוהול 1 | H-03», кол-во 0). п.4–9 — свой товар QA-AUTO- **с остатком 0** (без приёмки) и два свободных места: полка шкафа (12.10: A-15) и отдельный «ארגז אחד» (12.10: P14-01 «מתחת למדרגות»); перед привязкой оба места «ריק».
## Шаги
1. «קטלוג ומלאי» → поиск товара → колонка «מיקום במחסן».
2. «מפת המחסן» → вкладка нужной קומה → в сайдбаре «האחסון במחסן» строка шкафа.
3. Клик по шкафу → список мест (מדפים).
4. (#d9258e0b) «קטלוג ומלאי» → товар с остатком 0 → «מיקום במחסן» → этаж → шкаф → свободная полка → «שמירה». Затем в строке товара «הוספת מיקום» → элемент «ארגז אחד» → его ארגז → «שמירה».
5. «מפת המחסן» → этаж: строки шкафа и элемента-ארגז в сайдбаре «האחסון במחסן»; заливка этих мест на канвасе.
6. Клик по шкафу → строка полки → клик по полке (инспектор «תכולת המדף»); то же для ארגז.
7. Перезагрузка страницы → повтор п.5–6. Телефон 390×844 → карта, те же места.
8. На полке у товара «הסרה מהמקום» → окно «הסרת המוצר מהמקום» → «הסרה». Перезагрузка.
9. «קטלוג ומלאי» → ячейка «מיקום במחסן» товара.
## Ожидаемо
1. В каталоге место показано (קומה · ארון · מדף · קוד).
2. Строка шкафа — «N מוצרים משויכים», не «ריק» (#6a8f3153 «המיקום לא צריך להיות מוצג כ־„ריק” כל עוד קיים מוצר שמשויך אליו»).
3. Полка H-03 — без «ריק» (кол-во «0»), под ней товар с кнопками «העברה למיקום אחר» / «הסרה מהמקום».
4. После «שמירה» в каталоге место показано; после «הוספת מיקום» — тост «…שויך למקום נוסף». Остаток товара — 0.
5. Строка шкафа «ארון A | 0 | 15 מדפים | מוצר אחד משויך», строка элемента-ארגז «… | 0 | ארגז אחד | מוצר אחד משויך» (было «ריק»); на канвасе оба места занятые — заливка #e4ecf7 (пустое — #ffffff) (#d9258e0b AC: «אותו מיקום במפת המחסן מוצג כתפוס ומציג את המוצר או אינדיקציה לכך שמוצר משויך אליו»).
6. Строка полки «מדף 15 | A-15 | 0» — без «ריק»; в инспекторе — имя товара, «0», «העברה למיקום אחר» / «הסרה מהמקום». То же для ארגז (#d9258e0b AC: «המיקום לא מוצג כריק כל עוד קיים מוצר שמשויך אליו»).
7. После перезагрузки и на 390×844 — то же (занято, не «ריק»).
8. После «הסרה מהמקום» полка снова «ריק», заливка #ffffff, сохраняется после перезагрузки; ארגז (второе место) остаётся занятым.
9. В ячейке «מיקום במחסן» нет «קבוע» (#10cc07dc).
