# wm-13: «האחסון במחסן» — שורת משטח סופרת ארגזים; «ריק» רק כשאין מלאי
- Фича/экран: F-53 / S-40 (`/warehouse/map`, сайдбар «האחסון במחסן»)
- Тикеты: #16c27b1d
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (+ 360/390 — вручную)
- Тип: позитив / согласованность данных
- Предусловия: только просмотр. Числа зависят от реального склада — проверяется согласованность, а не значения (на 04.10: «משטח 1 · 20 · מוצר אחד בארגזים», после списаний 04.10 — 18).
## Шаги
1. «קומה 2» → список «האחסון במחסן» → строка «משטח 1».
2. Открыть «משטח 1» → «ארגזים על המשטח».
3. «קומה 1» → пустая паллета (напр. «משטח 3», 4 ארגזים).
4. Поиск в карте по имени паллеты.
## Ожидаемо
1. Строка: имя · число · «… בארגזים», не «ריק».
2. Число в строке = сумме количеств ארגזים в панели.
3. «0 … ריק»; «ריק» только при 0 (нет остатка ни на паллете, ни в ящиках).
4. В результате поиска то же число, не «ריק».
- Находка (W4, не баг): панели паллет различаются (зона/паллета).
