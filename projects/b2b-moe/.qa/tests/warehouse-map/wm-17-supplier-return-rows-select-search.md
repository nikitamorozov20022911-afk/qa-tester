2. Отметить строку A «ללא שיוך למקום».
3. Отметить строку A «מדף G-xx», кол-во 1; снять её.
4. Поиск по B → отметить B.
5. Поиск по A → «בחירת הכל» → «ניקוי הבחירה».
6. Поиск снова по префиксу; «ביטול».

1. 3 строки: «A · <מק"ט> זמין 2 · מדף G-xx», «A · … זמין 2 · ללא שיוך למקום», «B · … זמין 1 · ללא שיוך למקום»; «3 פריטים» (מה רצוי «כל שורה בחלון היא מוצר + מקום»).
