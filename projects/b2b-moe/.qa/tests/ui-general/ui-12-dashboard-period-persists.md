# ui-12: לוח בקרה — выбранный период сохраняется после обновления (?period=)
- Фича/экран: /dashboard, «תקופה»
- Тикеты: #6f3c9b (0937df95a575a7245b6f3c9b, commit b006249; עבר QA 21.10); связан #279e07
- Роль/аккаунт: admin
- Устройство: desktop 1440×900
- Тип: позитив / граница
- Предусловия: нет
## Шаги
1. /dashboard → «היום» / «7 הימים האחרונים» / «90 הימים האחרונים» → F5.
2. С ?period=7 выбрать «30 הימים האחרונים» → F5.
3. Открыть /dashboard?period=abc (и ?period=2).
## Ожидаемо
1. Адрес /dashboard?period=1|7|90, после F5 выбор и график («הכנסות לאורך N ימים») те же (источник: «מה רצוי» — «שרענון לא יחזיר ל-30 ימים»).
2. 30 — адрес без параметра; после F5 — 30 (комментарий программиста).
3. Невалидный параметр → 30 дней, страница работает.
