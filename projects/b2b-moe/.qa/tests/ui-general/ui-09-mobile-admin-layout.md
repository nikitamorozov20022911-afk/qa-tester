# ui-09: מובייל (מפיץ) — לוח בקרה, מוצרים, הזמנות, תעודת משלוח: RTL ושדות קומפקטיים
- Фича/экран: F-22 / S-28, S-51, S-12, S-17 (D-09)
- Тикеты: 6a8597e8ee89f6559ef2fdbf #6a8597e8; #4f5292 (п.3 — карточки вместо таблицы, 26.10)
- Роль/аккаунт: admin
- Устройство: mobile (iPhone 13 Mini 375 / Pixel 7)
- Тип: UI / адаптивность
## Шаги
1. `/dashboard` → «דוח לרואה חשבון».
2. `/catalog`.
3. `/orders`, «כל החודשים» — список карточками (таблицу больше не прокручивают вбок, #4f5292).
4. `/delivery` → любая «תעודת משלוח».
## Ожидаемо
0. На всех экранах нет горизонтальной прокрутки страницы (scrollWidth = ширина экрана).
1. «מתאריך»/«עד תאריך» в ряд, каждое ≈ половина ширины (не во всю ширину), дата видна полностью (scrollWidth ≤ clientWidth).
2. Кнопки «קטגוריות», «קליטת מלאי», «מוצר חדש» под заголовком, выровнены по правому краю (RTL); «עודכן לאחרונה» — дата полностью; вкладки «הכל · זמינים · לא זמינים» начинаются справа, «הכל» крайняя правая. (Импорт/экспорт Excel — в меню «אקסל».)
3. Вкладки «הכל · ממתינות לאישור · אושרו · נדחו» начинаются справа; в каждой карточке статусы не перекрывают кнопку «⋮» («פעולות») по площади, «⋮» в пределах экрана без прокрутки вбок (подробно — ord-36, #4f5292).
4. «תאריך אספקה» компактное (≈ половина ширины), справа, дата/маска видна полностью.
