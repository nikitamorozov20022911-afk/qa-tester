# ui-03: כפתורי «לוח בקרה» ו«הגדרות» בתפריט הצד פעילים; לפי הרשאות
- Фича/экран: F-22 / S-28, S-51
- Тикеты: 6a70b4a9b4cbca872d502bad #6a70b4a9
- Роль/аккаунт: admin; נציג через «כניסה כעובד» (משה כהן)
- Устройство: desktop
- Тип: позитив / доступ
## Шаги
1. Под admin со страницы `/catalog` нажать «הגדרות», затем «לוח בקרה».
2. Под נציג: проверить пункты меню.
## Ожидаемо
1. «הגדרות» → `/settings`, h1 «הגדרות»; «לוח בקרה» → `/dashboard`, h1 «לוח בקרה» («לוח בקרה יעביר למסך לוח הבקרה. הגדרות יעביר למסך ההגדרות.»).
2. У נציג меню «לוח בקרה · הזמנות · לקוחות · הגדרות» — без «תמחור», «צוות והרשאות», «קטלוג ומלאי» («משתמש ללא הרשאה לא יראה את הכפתור»).
