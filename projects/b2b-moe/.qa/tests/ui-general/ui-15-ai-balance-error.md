# ui-15: AI-места — при исчерпанном балансе провайдера понятное сообщение «…אינו זמין כרגע: השירות מושבת זמנית אצל הספק (נגמרה יתרת השימוש)…»; обычная ошибка — прежний текст
- Фича/экран: /orders/new «קריאת הודעה»; buyer /shop «הזמנה מהירה» (текст и «זיהוי מוצר מתמונה»); /catalog/new «ניסוח תיאור»; /catalog/import «שינוי עמודות»; /settings «רענון המלצות»; /catalog «קליטת מלאי» → «הוספת פריט למלאי» → «זיהוי מוצר מתמונה»
- Тикеты: #38e1e5 (8c83fd31555fc1e41438e1e5; 1a7db70; עבר QA 28.10). Связано: #e7e338 (ee7ff9a), #7c5052–55, #89105f, #628c72
- Роль/аккаунт: admin; buyer (для «הזמנה מהירה»)
- Устройство: desktop 1440×900
- Тип: негатив / тексты
- Предусловия: ответ AI-функции подменяется (page.route functions/v1/{order-photo|order-text|describe|import-map|recommend}); настоящий баланс проверить нельзя. Ничего не сохраняется (запись в базу из окна блокируется).
## Шаги
1. На каждом месте — по очереди варианты ответа: `{ok:false, code:"MODEL_FAILED", <поле>: "Your credit balance is too low…"}` для полей `error` (200 и 400), `error.message` (200 и 400), `message` (200), `detail` (200); и обычная ошибка `error:"Request timed out"` (200) / `{error:"timeout"}` (500) — чередуя.
2. Импорт: загрузить CSV с нераспознанной колонкой → «שינוי עמודות». Фото: тестовая картинка 64×64.
## Ожидаемо
1. Баланс (любое поле, 200/400): «…אינו זמין כרגע: השירות מושבת זמנית אצל הספק (נגמרה יתרת השימוש), ולכן ניסיון חוזר לא יעזור.» + хвост места («מה רצוי»: «הודעה ברורה … בלי קשר לשדה», «כך גם בשאר מקומות ה-AI»):
   - текст заказа (מפיץ и «הזמנה מהירה»): «קריאת הרשימה אינה זמינה כרגע: … בינתיים חפשו את המוצרים בקטלוג.»
   - фото («הזמנה מהירה», «הוספת פריט למלאי»): «זיהוי מוצר מתמונה אינו זמין כרגע: … בינתיים חפשו את המוצר בקטלוג.»
   - «ניסוח תיאור»: «הניסוח האוטומטי אינו זמין כרגע: … אפשר לכתוב את התיאור ידנית.»
   - импорт: «זיהוי עמודות אוטומטי אינו זמין כרגע: … שייכו את העמודות שנותרו ידנית.»
   - «רענון המלצות»: «רענון ההמלצות אינו זמין כרגע: …»
2. Обычная ошибка (timeout) — прежний текст: «לא הצלחנו לקרוא את הרשימה. נסה שוב…» / «לא הצלחנו לזהות את המוצר בתמונה. נסה שוב…» / «הניסוח נכשל. אפשר לנסות שוב…» / «לא הצלחנו לזהות את שאר העמודות אוטומטית. שייכו אותן ידנית.» / «רענון ההמלצות נכשל. בדוק את החיבור ונסה שוב.» (С1: не путать все ошибки с балансом).
3. Ровно один вызов функции на действие; ничего не записано в базу.

- Код `UNREACHABLE` с текстом о балансе (Т1.7) — путь не-2xx покрыт вариантами 400.
- Нормальная работа AI (С2) — платно; order-from-message 30.1 (@ai).
