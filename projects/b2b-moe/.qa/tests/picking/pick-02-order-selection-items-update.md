# pick-02: בחירת הזמנות למסלול משותף — רשימת הפריטים מתעדכנת, ביטול סימון נשמר, אזהרת פיצול
- Фича/экран: F-51 / S-37 (/warehouse/picking); роль R-06
- Тикеты: 6a749043674c1b535ed8c454 #6a749043; 6a730420197e2126a47897d7 #6a730420
- Роль/аккаунт: admin → «כניסה כעובד» под «עובד מחסן בדיקה»
- Устройство: desktop 1440×900
- Тип: функциональный / позитив + граничный (частично собранный общий маршрут)
- Предусловия: два своих утверждённых заказа QA-AUTO-picking (o1: A+B, o2: A). Реальные заказы не отмечать.
## Шаги
1. Отметить чекбоксы «הזמנה <o1> במסלול משותף» и «הזמנה <o2> במסלול משותף».
2. «הצגת הפריטים · 2 הזמנות».
3. «כל ההזמנות» → снять отметку o2 → «הצגת הפריטים».
4. Уйти на /warehouse/map и вернуться на /warehouse/picking.
5. Выбрать o1+o2 → «התחלת ליקוט · 2 הזמנות»; отметить «לוקט» позицию o2; вернуться в очередь, отметить только o1.
6. В общем списке «בטל סימון»; вернуться, отметить только o1 → «התחלת ליקוט».
## Ожидаемо
1. «2 נבחרו · N בתור», кнопка «ניקוי»; URL ?order=<id1>,<id2>; кнопка «הצגת הפריטים · 2 הזמנות».
2. Заголовок «מסלול משותף · 2 הזמנות», «#o1 · #o2», «פריטים לליקוט · 3», у каждой позиции метка «הזמנה #…».
3. URL ?order=<id1>; «1 נבחרו»; заголовок «הזמנה #o1», только 2 позиции заказа o1, позиций o2 нет («יש להציג אך ורק את הפריטים של הזמנה… אין להציג פריטים של הזמנות שאינן מסומנות עוד»).
4. Ни один заказ не отмечен заново («ההזמנה תישאר ללא סימון ולא תסומן מחדש באופן אוטומטי»).
5. «רשימת ליקוט», подзаголовок «גל · 2 הזמנות», 0/3. После «לוקט» и выбора только o1 — предупреждение «כבר לוקטו פריטים במסלול המשותף (2 הזמנות), ולכן לא ניתן לפצל אותו. «התחלת ליקוט» תפתח את המסלול המלא…» (dev-комментарий к #6a749043).
6. Предупреждение «המסלול הקיים משותף ל־2 הזמנות. «התחלת ליקוט» עבור ההזמנה שנבחרה תחליף אותו, וההזמנות שהוסרו יחזרו לתור ללא מסלול.»; после старта — список только o1 («הזמנה #o1 · …», 0/2), o2 в очереди без метки «בליקוט» («ההזמנה שבוטלה לא תופיע במסלול הליקוט»).
