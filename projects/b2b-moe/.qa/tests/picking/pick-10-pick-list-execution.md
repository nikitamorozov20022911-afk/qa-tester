1. Выбрать заказ → «התחלת ליקוט».
2. Посмотреть шапку, прогресс, поле сканирования, позиции и нижнюю панель.
3. Ввести в поле код ячейки первой позиции + Enter.
4. «לוקט» у позиции 1, затем «בטל סימון», снова «לוקט»; «לוקט» у позиции 2.
5. «סיום ליקוט».
6. Под admin открыть детали заказа.
