## Шаги
1. К1: /catalog → клик по числу «במלאי» товара → «הוספת פריט למלאי».
2. В «לאיזה מקום (לא חובה)» выбрать по очереди каждое из 3 мест.
3. Нажать на подпись места товара на карте (2 разных места).
4. Кнопки «ארון X» → название полки.
5. Нажать на серое место вдали от мест товара.
6. К2: кнопка «קליטת מלאי» в шапке → до выбора товара посмотреть окно → выбрать товар.
7. М: «מפת המחסן» → место товара → «הוספת פריט למדף» → выбрать товар.
8. К1: выбрать место на карте → «כמות» 1 → «הוספה»; каталог; карта → место.
9. 390: шаги 1–3, «מקום הקליטה» для каждого места.
## Ожидаемо
1. Под списком — «מיקום במפת המחסן»: карта всего склада (tablist этажей, «קנבס המחסן»); 3 места товара яркие, рядом подпись с названием места; все остальные места серые (opacity ≤ 0.5) и без зоны выбора; текст «המקומות שהמוצר משויך אליהם מודגשים; שאר המחסן אפור ואינו ניתן לבחירה.»; по умолчанию выбрано одно из мест товара (מה נדרש #6cdf674f п.0–3).
2–4. Список, «נבחר: … (<код>)», кнопки «ארון/מדף», «מקום הקליטה» и отметка на карте всегда об одном месте; тёмная подпись («נבחר») только у выбранного места, у двух других — белая, при любой длине названия (מה נדרש п.4; rej_1791803663363 Р1/Р2/Р4; rej_1791708229952 синхронизация).
5. Выбор не меняется, окно открыто («באפור, בלי אפשרות לבחור אותם»).
6. До выбора товара карты нет; после — та же карта с местами товара.
7. Карты в окне нет, подсказки нет, выбрано место, с которого пришли (комментарий владельца 07.10).
8. Тост «1 של <שם> נקלטו למדף <קוד>.», «במלאי» 1, в панели места — 1 (F-49 «כל מיקום נשמר עם הכמות»).
9. Код места в «מקום הקליטה» одной строкой (`getClientRects().length === 1`; rej_1791803663363 Р5); названия из нескольких слов могут переноситься между словами — не баг.
