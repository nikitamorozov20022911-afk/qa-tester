2. Через клик по количеству QA-товара: «מקום היעד» = существующая ячейка, «כמות» 5, «הערה» (не обязательно) → «הוספה».
3. Посмотреть колонку «מיקום במחסן».
4. ⋮ → «מחיקה» у QA-товара с остатком в ячейке.
5. «מעבר למפת המחסן» → в панели ячейки у товара «הסרה מהמקום» → «הסרה»; снова ⋮ → «מחיקה» → «מחיקה».

## Ожидаемо
1. Диалог «הוספת פריט למלאי»: «מוצר» (поиск по имени/מק"ט + «זיהוי מוצר מתמונה»), «לאיזה מקום (לא חובה)» — список существующих ячеек «<פריסה> · <ארון> · <מדף> (<קוד>)», «כמות», «הערה — לא חובה — נשמרת ביומן התנועות»; «הוספה» неактивна, пока нет товара и количества.
2. Тост «5 של <שם> נקלטו למדף <קוד>.»; остаток 5.
3. «<פריסה> | <ארון> | <מדף> | <קוד>» (место сохранено за SKU).
4. Диалог «לא ניתן למחוק מוצר עם מלאי»: «"<שם>" — משויך למקום במחסן: רשומות עדיין N במיקום אחד.» (N=1 — «רשומה עדיין יחידה אחת במיקום אחד.») + «הקישו על המקום › «הסרה מהמקום», ואז ניתן יהיה למחוק את המוצר.» + «סגירה» / «מעבר למפת המחסן» (#d7b7ec74).
5. «מעבר למפת המחסן» открывает карту с выбранным местом; окно «להסיר את «<שם>» ממקום זה? המוצר יישאר במלאי, ללא מקום במחסן.»; затем пункт меню — просто «מחיקה» без подписи «יש מלאי במחסן» (#98be590c), удаление разрешено обычным окном «מחיקת מוצר» БЕЗ абзаца «…ייגרעו מהמלאי…»; после — «"<שם>" הוסר מהקטלוג. ההזמנות והתנועות שמזכירות אותו נשמרו.»; в «יומן תנועות» — «ללא מקום · <קוד> ← ללא מקום», записи «מחיקת מוצר · … נגרע מהמלאי» нет (#d7b7ec74, подробно inv-07).
- A (вход 1): «לאיזה מקום (לא חובה)» = место A («נבחר: …»), тост «2 של <A> נקלטו למדף <קוד>.», «במלאי» 2, бейджа «ללא מקום» нет. Вход 2: место подставлено сразу после выбора A (и при медленной загрузке списка мест), НЕТ «הפריט כבר מאוחסן ב־<מקום>. קלטו את הכמות לאותו מקום.»; после — 3. Карта: в месте A с 3 (не «ריק»). Журнал: «קליטה · מחוץ למחסן ← <קוד>» ×2, «← ללא מקום» нет (מה רצוי #2830b76e; AC F-49 «כמות המלאי מתעדכנת ומיקום האחסון נשמר ומשויך למוצר»).
- B: привязка через карту тоже место товара (уточнение владельца 07.10) — на обоих входах подставлено место B; приём идёт в него.
- C: при остатке «ללא מקום» приём в место товара НЕ блокируется — нет «יש כבר N של הפריט שטרם שויכו למקום. שייכו אותן למקום לפני קליטה נוספת.» (блок STOCK_UNASSIGNED снят, миграция 20261008100000), «הוספה» активна; место +1, «ללא מקום» 2 остаётся (в строке «במלאי» 4, бейдж «ללא מקום»). Ручной выбор «ללא מקום» при выбранном товаре не перетирается автозаполнением.
- D: «לאיזה מקום» — выбор только из мест товара C (не все места склада); по умолчанию выбрано одно из мест товара (11.10 — место с остатком; какое именно — владелец не уточнял, не реджект); количество уходит именно в выбранное место (карта, журнал), другое не меняется. Обе строки мест в ячейке «מיקום במחסן» — без «קבוע» (#10cc07dc).
- E: «ללא מקום — לשיוך בהמשך» + «אפשר לשייך למקום בהמשך, ממסך «ניהול מלאי»»; доступны все места склада; приём «ללא מקום» работает как раньше.
- F: A → место A; D → «ללא מקום»; снова A → место A; «ביטול» — без изменений. (11.10: ручной «ללא מקום» перетирается при смене товара — не требование тикета, не проверяем.)
- G: у каждой приёмки «מחוץ למחסן ← <קוד>», товар, количество, «test admin»; «← ללא מקום» только там, где выбрали вручную/товар без места.
