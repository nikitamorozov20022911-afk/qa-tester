# inv-07: Удаление товара с остатком «ללא מקום» — не привязан → удаляется; привязан → блок (ед./мн. ч., несколько мест); гонка PRODUCT_HAS_PLACE
- Фича/экран: S-01 «קטלוג וניהול» (⋮ → «מחיקה»), «מפת המחסן» («יומן תנועות»)
- Тикеты: #d17c625a (решение владельца 11.10, עבר QA 12.10); #d7b7ec74 (обычное окно без «ייגרעו», без записи «מחיקת מוצר»); история: #0309a9bf (отменено), #98be590c, #2830b76e

- Тип: функциональный / позитив + негатив (гонка)
- Предусловия: свои товары «QA-AUTO-d17c-…»; места — пустые полки («ריק»). Остаток «ללא מקום» у привязанного товара: сначала привязать место, затем «קליטת מלאי» с «ללא מקום — לשיוך בהמשך». Приёмки — неудаляемые записи журнала.
## Шаги
1. U (без места): приёмка 3 шт. «ללא מקום» → ⋮ → «מחיקה» → «ביטול»; снова → «מחיקה» → «מחיקה»; «יומן תנועות» → поиск по U.
2. C: привязать к месту, затем 1 шт. «ללא מקום» → ⋮ → «מחיקה» → прочитать → «סגירה»; ещё 1 шт. «ללא מקום» → снова «מחיקה».
3. D: два места; 1 шт. в первое место + 1 шт. «ללא מקום» → ⋮ → «מחיקה».
4. R (привязан, 0): окно «מחיקת מוצר» открыто; во второй вкладке приёмка 1 шт. «ללא מקום»; в первой — «מחיקה».
## Ожидаемо
1. Пункт «מחיקה» без «יש מלאי במחסן»; обычное окно «מחיקת מוצר» без «ייגרעו» и без «החזרה לספק»; после «ביטול» остаток 3; после «מחיקה» — 200, тост «… הוסר מהקטלוג. ההזמנות והתנועות שמזכירות אותו נשמרו.»; в журнале «קליטה · … ← ללא מקום», записи «מחיקת מוצר»/«נגרע מהמלאי» нет (решение 05.10, #d7b7ec74).
2. Блок «לא ניתן למחוק מוצר עם מלאי»: «… משויך למקום במחסן, ורשומה עדיין יחידה אחת ללא מקום.» (ед.ч., не «רשומות עדיין 1»), место в списке; при 2 — «ורשומות עדיין 2 ללא מקום.»; «סגירה»/«מעבר למפת המחסן», удаления нет (решение 11.10: «ללא מקום» у привязанного — тоже остаток).
3. «— משויך ל-2 מקומות במחסן, ורשומה בהם עדיין יחידה אחת, ועוד 1 ללא מקום.»; в списке оба места (первое «<קוד> · 1», второе без количества).
4. rpc/delete_product → 400 PRODUCT_HAS_PLACE; окно становится блоком с «מעבר למפת המחסן»; товар не удалён, остаток 1.
- Не баг: остаток «ללא מקום» при удалении непривязанного товара исчезает без записи в журнале (#d7b7ec74).
