# inv-08: Удаление товара, привязанного к месту — остаток 0 удаляется сразу; остаток в месте — блок с картой; гонка PRODUCT_HAS_STOCK
- Фича/экран: S-01 «קטלוג וניהול» (⋮ → «מחיקה»), «מפת המחסן»
- Тикеты: #d17c625a (решение владельца 11.10, עבר QA 12.10); раньше #d7b7ec74 (ед.ч., серверная ошибка). Требование «גם עם כמות 0 → блок» ОТМЕНЕНО 11.10.
- Роль/аккаунт: admin («test admin», .qa/auth/admin.json)
- Устройство: desktop 1440×900 (+ 390 вручную — окна целиком)
- Тип: функциональный / позитив + негатив (гонка)
- Предусловия: свои товары «QA-AUTO-d17c-…»; места — ПУСТЫЕ полки («ריק» на карте, проверить перед тестом; карту не менять). Каждая приёмка — неудаляемая запись «קליטה» в יומן תנועות; уборка — «הסרה מהמקום» и удаление.
## Шаги
1. A1: привязать к пустому месту («מיקום במחסן»), остаток 0 → ⋮ → «מחיקה» → «ביטול»; снова → «מחיקה» → «מחיקה». Карта → место.
2. A2: два места («מיקום במחסן» + «הוספת מיקום»), остаток 0 → ⋮ → «מחיקה» → «מחיקה». Карта → оба места.
3. B: одно место, приёмка 2 шт. в место → ⋮ → «מחיקה» → прочитать окно → «סגירה».
4. B: ⋮ → «מחיקה» → «מעבר למפת המחסן» → в панели места «הסרה מהמקום» → прочитать подтверждение → «הסרה» → /catalog → ⋮ → «מחיקה» → «מחיקה».
5. R (привязан, 0): ⋮ → «מחיקה» — окно оставить открытым; во второй вкладке принять 1 шт. в место; в первой нажать «מחיקה».
## Ожидаемо
1. Пункт — просто «מחיקה» (без «יש מלאי במחסן»); обычное окно «מחיקת מוצר»: «האם למחוק את "<שם>"? … הפעולה אינה ניתנת לביטול.», «ביטול»/«מחיקה»; после «ביטול» товар на месте; после «מחיקה» — rpc/delete_product 200, тост «"<שם>" נמחק.», товара нет в /catalog; место снова «ריק» (решение 11.10).
2. То же; оба места «ריק».
3. Пункт «מחיקה · יש מלאי במחסן»; окно «לא ניתן למחוק מוצר עם מלאי»: «"<שם>" — משויך למקום במחסן, ורשומות בו עדיין 2.», строка места «קומה 1 | ארון X | <מדף> | <קוד> · 2», «…«הסרה מהמקום», ואז ניתן יהיה למחוק את המוצר.»; кнопки «סגירה» / «מעבר למפת המחסן», кнопки удаления нет.
4. Карта открыта с выбранным местом (панель «תכולת המדף», товар 2); «להסיר את «<שם>» ממקום זה? המוצר יישאר במלאי, ללא מקום במחסן.»; после «הסרה» в каталоге «ללא מיקום», остаток 2; удаление — обычное окно, 200, тост «"<שם>" הוסר מהקטלוג. ההזמנות והתנועות שמזכירות אותו נשמרו.» (у товара есть движения — архив).
5. rpc/delete_product → 400 PRODUCT_HAS_STOCK; окно превращается в блок «לא ניתן למחוק מוצר עם מלאי» с «מעבר למפת המחסן»; товар не удалён, остаток 1.
- Остаток «ללא מקום» у привязанного товара — inv-07. Несколько мест с остатком — cat-23.
