# auth-16: «כניסה כעובד» — баннер с именем и «כניסה כעובד פעילה» целиком на любой ширине; «אין אזור מוקצה» с баннером
- Фича/экран: F-44 баннер имперсонации (все экраны), 403, `/no-access` («אין אזור מוקצה»)
- Тикеты: #dac8c6d1 (после реджекта 04.10)
- Роль/аккаунт: admin → «כניסה כעובד» «משה כהן» (נציג), «עובד מחסן בדיקה»; регресс — rep.json
- Устройство: 1440 / 390 / 360 / 320
- Тип: визуал / адаптивность
- Предусловия: сессия admin. «התנתקות» не нажимать (отзовёт токен сохранённой сессии).
## Шаги
1. Войти как «משה כהן» («כניסה כעובד»).
2. `/team` (403) и `/orders` на 1440/390/360/320 — замерить текст баннера.
3. С 403 на 360 — «חזרה לחשבון הניהול».
4. Войти как «משה כהן» / «עובד מחסן בדיקה» → открыть `/no-access` на 4 ширинах → «חזרה לחשבון הניהול».
5. Регресс: rep.json сам на `/team`.
## Ожидаемо
2. «מחובר/ת כרגע בתור <имя> — כניסה כעובד פעילה» полностью: без «…», scrollWidth ≤ clientWidth, в пределах экрана; на < 640px «כניסה כעובד פעילה» отдельной строкой (1440 — 1 строка, 390/360 — 2, 320 — 3); кнопка «חזרה לחשבון הניהול» видна (реджект 04.10: в любой ширине имя + «כניסה כעובד פעילה» без обрезки).
3. Возврат на `/team` админа, баннера нет.
4. h1 «אין אזור מוקצה», баннер целиком и кнопка; возврат на `/team` без баннера.
5. 403 без баннера.
