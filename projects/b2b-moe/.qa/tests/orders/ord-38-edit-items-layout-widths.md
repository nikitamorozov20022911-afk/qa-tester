## Ожидаемо
1. Нет горизонтальной прокрутки: scrollWidth документа = ширине экрана, у карточки scrollWidth = clientWidth, внутри нет прокручиваемых вбок блоков («מה רצוי» #cb3f40 «בלי גלילה לרוחב»; #c6b040 «בתוך הכרטיס בלי גלילה לרוחב»).
2. Фокус на цене не сдвигает имя (±1px), окно не прокручено вбок (#cb3f40 «מה קיים» — «בלחיצה על שדה המחיר הטבלה זזה»).
3. Сумма строки «₪1,000.00» / «₪10,000.00» / «₪100,000.00» целиком (scrollWidth = clientWidth), внутри карточки, не пересекает поле цены (rej_c92f2546 מצב רצוי); в рядах — ниже поля цены; поле «מחיר יחידה» ≥ 160px, введённая цена видна целиком (#af3ea6, ord-40); удаление внутри карточки, центр — сама кнопка (#c6b040 «הפח… נלחץ»). Карточка < 600 — заголовков нет; ≥ 600 (1440) — таблица с заголовками.
4. «כמות — מספר שלם בלבד», «במלאי 3 בלבד — לא ניתן להזמין יותר», «מחיר במחירון: ₪1.00 · המחיר שונה להזמנה זו בלבד» — внутри карточки и экрана («כל השדות וההודעות בתוך המסך»).
5. Заказ прежний «— 1 ₪1.00 ₪1.00».
- Норма: длинное имя — одна строка nowrap + многоточие, в карточке (как #e1e502).
