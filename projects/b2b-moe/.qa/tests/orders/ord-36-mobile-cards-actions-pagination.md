# ord-36: «הזמנות» בטלפון — כרטיסים, «⋮» ועימוד בתוך המסך בלי גלילה לרוחב
- Фича/экран: F-08 / S-12 «רשימת הזמנות נכנסות»; F-22 / S-28, D-09 (רספונסיביות)
- Тикеты: #4f5292 (b6e81fc6b1f9f8bc5f4f5292; עבר QA 26.10)
- Роль/аккаунт: admin (מפיץ, .qa/auth/admin.json)
- Устройство: mobile — iPhone эмуляция 360 / 375 / 390 (основное 390×664); регресс desktop 1024 (с сайдбаром) и 1440
- Тип: позитив + визуал (адаптивность)
- Предусловия: > 8 заказов (на staging «כל החודשים» ≈ 177 → 23 страницы). Только чтение: клики по пагинации, открытие меню «⋮», открытие заказа — без אישור/דחייה.
## Шаги
1. `/orders`, «כל החודשים», вкладка «הכל», ширина 390 (затем 375, 360).
2. Не прокручивая вбок: посмотреть каждую карточку на странице (8 шт.) — номер, клиент, дата, «⋮» («פעולות»).
3. Нажать «⋮» последней карточки на странице.
4. Прокрутить вниз до конца (только вертикально) — пагинация.
5. «העמוד הבא» → «העמוד הקודם» → номер последней страницы.
6. Нажать на карточку (по номеру заказа).
7. Регресс: 1024×768 (сайдбар открыт) и 1440×900 — те же «⋮» и пагинация.
## Ожидаемо
1. Нет горизонтальной прокрутки: ни у страницы (`scrollWidth ≤ innerWidth`), ни у контейнеров списка (источник: «מה רצוי» — «גלויים בלי גלילה לרוחב»).
2. «⋮» каждой из 8 карточек целиком в пределах экрана по горизонтали; клик открывает меню строки («פרטי הזמנה»), адрес остаётся `/orders` (источник: «מה רצוי»).
3. Пагинация «העמוד הקודם» · номера · «העמוד הבא» целиком в экране после вертикальной прокрутки; «העמוד הבא» → «מציג 9–16 מתוך N תוצאות», «העמוד הקודם» → «מציג 1–8 מתוך N», последняя страница достижима — «מציג X–N מתוך N» (источник: «מה רצוי», шаги 2–3 тикета).
4. В карточке номер, клиент и дата видны полностью (не обрезаны, в экране); строка 1 «מספר · לקוח · ⋮», строка 2 «תאריך · פריטים · סכום», затем статусы (источник: «מה קיים» — «תאריך (חתוך)»; коммент программиста 99228ff).
5. Клик по карточке открывает заказ `/orders/<id>`, «הזמנה #N» (источник: S-12 «יציאה: לחיצה על הזמנה פותחת את פרטיה»).
6. Карточки — пока ширина списка < 900px (телефон, 1024 с сайдбаром, до ≈1260 с сайдбаром); от 900px списка — таблица как Figma 6:2 (1440: номер и дата в одной строке).
7. Пагинация в RTL: «העמוד הקודם» справа, «העמוד הבא» слева (как на 1440).
## Не требование / наблюдения
- «למשל» тикета (карточки, пагинация во всю ширину) — способ, не требование.
- Мобильного кадра Figma нет — дизайн 390 не сверен.
- Находка 26.10 (не в этом тикете): a11y — кнопка «פעולות» внутри role=button карточки.
- Вкладки статусов на 360 (прокручивались, «נדחו 82» обрезано) — исправлено #0f04ee (עבר QA 26.10), см. ord-41.
