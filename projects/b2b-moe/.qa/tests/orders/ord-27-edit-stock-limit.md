- Тикеты: #6a98bd (c2ee2c6f2605577fc76a98bd, commits adbff48 + 5d1c014; реджект rej_efca2251; עבר QA 25.10); решение пользователя 20.10
- Роль/аккаунт: admin (заказы создаёт buyer «test»)
- Устройство: desktop 1440×900 (вручную также 390, 820)
- Тип: негатив / граница
- Предусловия: свои товары QA-AUTO-6a98-<ts> (₪1): A — остаток 2, Z — остаток 1 «ללא מקום». Заказ 1 (test, «ממתינה לאישור») — A ×1; заказ 2 (test, «ממתינה לאישור») — Z ×1 (занимает весь остаток Z). После — оба заказа отклонить, товары удалить.
- Доступный остаток = физический минус другие ожидающие заказы — принятое поведение (пользователь 25.10).
## Шаги
1. Заказ 1 → «עריכה» → «+» → «+».
2. Ввести 3 / 5 / 10 → Tab → «שמור שינויים»; затем «ביטול».
3. «עריכה» → «+» (2) → поиск A → выбрать A; поиск Z → выбрать Z → «ביטול».
4. «עריכה» → «+» (2) → «שמור שינויים» → обновить страницу.
## Ожидаемо
1. Кол-во останавливается на 2, «+» disabled.
2. После ухода с поля — «במלאי 2 בלבד — לא ניתן להזמין יותר»; «שמור שינויים» не сохраняет (остаёмся в «עריכת הזמנה», запросов записи нет); после «ביטול» в заказе прежнее кол-во 1 (rej_efca2251 «מצב רצוי»).
3. «במלאי 2 בלבד מA — לא ניתן להוסיף עוד.», вторая строка A не появляется, кол-во A 2; «אין מלאי זמין לZ.», строки Z нет (коммент программиста 22.10).
4. Ровно 2 сохраняется: строка «— 2 ₪1.00 ₪2.00», и после обновления (F-10 AC1).
