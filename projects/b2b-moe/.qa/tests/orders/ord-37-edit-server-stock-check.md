# ord-37: «עריכת הזמנה» — сервер (update_order_items) отклоняет кол-во больше доступного остатка, в т.ч. в обход UI
- Фича/экран: /orders/<id>/edit, RPC POST /rest/v1/rpc/update_order_items
- Тикеты: #929aa5 (00db90c4b1c362d37e929aa5; commit 26ec00e, миграция 20261025100000; עבר QA 26.10); связан #6a98bd (ord-27), решение пользователя 20.10
- Роль/аккаунт: admin (заказы создаёт buyer «test»)
- Устройство: desktop 1440×900 (ширина не важна — серверная проверка)
- Тип: негатив / граница / безопасность
- Предусловия: свой товар QA-AUTO-929a-<ts> (₪1, остаток 2 «ללא מקום»); заказ 1 и заказ 2 клиента test, оба «ממתינה לאישור», товар ×1. После — заказы отклонить, товар удалить.
- Тело RPC: {"p_order_id", "p_items":[{"product_id","qty"[,"unit_price"]}]}. Обход UI — подмена тела перехваченного запроса «שמור שינויים» (page.route); токены не читать и не логировать.
## Шаги
1. Заказ 1 → «עריכה» → кол-во 2 → Tab (экран показывает лимит) → вернуть 1.
2. «שמור שינויים», в уходящем запросе qty → 2; затем ещё раз с qty → 5.
3. «ביטול» → обновить карточку.
4. Отклонить заказ 2 → заказ 1 → «עריכה» → «שמור שינויים» с подменой qty → 3.
5. В UI кол-во 2 → «שמור שינויים» без подмены → обновить карточку.
## Ожидаемо
1. «במלאי 1 בלבד — לא ניתן להזמין יותר» (доступно = 2 − 1 в другом ожидающем заказе) — то же N, что вернёт сервер (Д1).
2. Каждый раз 400, code «22023», message «INSUFFICIENT_STOCK:<שם>:1»; на экране «הכמות של <שם> גדולה מהמלאי (1). עדכן אותה ונסה שוב.»; остаёмся в «עריכת הזמנה» («מה רצוי» — «update_order_items דוחה כמות גדולה מהמלאי הזמין (שגיאה ברורה)… גם בעקיפת הממשק»).
3. В заказе прежнее «— 1 ₪1.00 ₪1.00», и после обновления.
4. 400, «INSUFFICIENT_STOCK:<שם>:2» (резерв отклонённого заказа освободился — N = 2), баннер с (2).
5. Ровно доступное — 200, «— 2 ₪1.00 ₪2.00» в карточке и после обновления (граница N).
- Вручную проверено также: прямой fetch RPC (qty 5/6), гонка двух окон (второе сохранение получает отказ), по 3 раза. В автотесте гонка не делается (зависит от времени).
- Не проверяется: прямой PATCH /rest/v1/order_items мимо RPC (вне тикета), create_walkin_order (#80bb3c).
