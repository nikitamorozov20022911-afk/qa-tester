2. «הזמנות» → «הזמנה מהודעה» → клиент «test» → сообщение «2 מצית קליפט, 1 דוידוף גולד» → «קריאת הודעה».
3. У товара с меньшим остатком «+» до «остаток + 1».
4. Сообщение «1 נקש» → «קריאת הודעה».
5. НЕ нажимать «רישום ההזמנה».

1. functions/v1/order-photo — HTTP 200, ok:true; нет «לא הצלחנו לקרוא את הרשימה» (реджект rej_c4c2451e «מצב רצוי»).
