- Фича/экран: /orders/walk-in, поле «חיפוש מוצר להוספה למכירה» (walk-in-sale)
- Тикеты: #5711c3 (commit adbff48; עבר QA 25.10)
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (вручную также iPad 820)
- Тип: позитив + негатив
- Предусловия: свои товары QA-AUTO-5711-<ts> (₪1): «P צהוב» (остаток 3) и «P ארוך צהוב» (3, по алфавиту раньше); «P ירוק» (остаток 0) и «טבק P ירוק» (3); у каждого свой מק"ט. «רישום המכירה» НЕ нажимать. После — товары удалить.
## Шаги
1. Ввести полное имя «P צהוב», дождаться списка, Enter.
2. Ввести точный מק"ט товара «P ארוך צהוב», Enter.
3. Ввести частичное «P» (общий префикс), Enter.
4. Ввести «  p צהוב  » (другой регистр латиницы, пробелы по краям), Enter.
5. Ввести полное имя «P ירוק» (остаток 0), Enter.
## Ожидаемо
1. В списке «P צהוב» первым и выделен; добавлена строка «P צהוב» (одна), «נוסף: P צהוב» (источник: «מה רצוי» — «Enter מוסיף את המוצר שהשם שלו זהה בדיוק לטקסט שהוקלד»; коммент программиста — точное первым и выделено).
2. Добавлен «P ארוך צהוב» («מה רצוי» — «או המק"ט»).
3. Добавлен выделенный (первый) пункт списка («מה רצוי» — «את המוצר המסומן ברשימה»).
4. Добавлен «P צהוב» (коммент — без учёта регистра/пробелов).
5. Под поиском «P ירוק — אזל מהמלאי.»; ничего не добавлено (не подставлен «טבק P ירוק»), пустое состояние (решение 20.10, #80bb3c).
Не автоматизируется: выбор стрелками ↓/↑ + Enter (поведение не описано, по решению пользователя не тестируем).
