# ord-22: «מכירה מיידית» — баннер «הכמות של … אינה תקינה» исчезает сразу после исправления количества
- Фича/экран: /orders/walk-in, «פריטי המכירה» (walk-in-sale)
- Тикеты: #ccd3fa (עבר QA 25.10)
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (вручную также iPad 820)
- Тип: негатив (валидация) / состояние сообщения
- Предусловия: свой товар QA-AUTO-ccd3-<ts> (₪1, остаток 3). Продажу при верном количестве НЕ регистрировать. После — товар удалить.
## Шаги
1. Добавить товар, в «כמות — <имя>» ввести 1.5, нажать «רישום המכירה».
2. Исправить: а) ввести 2; б) «הוספת יחידה» («+»); в) «הסרת <имя>» (удалить строку).
## Ожидаемо
1. Баннер «הכמות של <имя> אינה תקינה. עדכן אותה ונסה שוב.», окно подтверждения не открывается.
2. Сразу после исправления (без повторного «רישום המכירה») баннер исчезает: а) поле = 2; б) поле = 2; в) пустое состояние «עדיין לא נוספו פריטים…» (источник: «מה רצוי» — «כשהכמות תוקנה למספר תקין — הבאנר נעלם מיד»).
