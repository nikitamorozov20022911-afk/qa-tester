- Тикеты: 6a7496dea9762946a4c325d0 #6a7496de

- Тип: позитив (только просмотр; «רישום המכירה» не нажимать — списывает склад)
## Шаги
1. /orders → «מכירה מיידית».
2. В «חיפוש מוצר להוספה למכירה» ввести «קליפט», Enter.
3. Нажимать «הוספת יחידה» до остатка.
4. (Только вручную на QA-AUTO- товаре) «רישום המכירה».
## Ожидаемо
1. «מכירה מיידית», «מכירה בקופה — תשלום במזומן, ללא משלוח…»; блоки «פריטי המכירה», «לקוח» (לקוח קיים / «שם הלקוח»), «תשלום» («אמצעי תשלום: מזומן», «סכום שהתקבל»); «רישום המכירה» disabled без товаров.
2. Опция «מצית קליפט נותרו N ₪5.00»; строка с кол-вом 1, «רישום המכירה» активна, «סכום שהתקבל» = сумма.
3. На N «הוספת יחידה» disabled + «זו כל הכמות במלאי (N)» (מה רצוי «לא יהיה ניתן למכור כמות גדולה יותר מהכמות הזמינה במלאי»).
4. Сообщение об успехе с итогом, остаток уменьшен на проданное, продажа в списке заказов — не проверено (нет QA-AUTO- товара).
