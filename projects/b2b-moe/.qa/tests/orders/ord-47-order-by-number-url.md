- Предусловия: у admin существует заказ #685 (uuid a6f2f8c0-6d4d-4a8b-a03f-44f041778a3d); #683 — чужой для buyer и rep.
## Шаги
1. admin: /orders/685; /orders/999999, /abc, /0; /orders/685/edit, /orders/685/receipt; /orders/<uuid>.
2. buyer: /shop/order/685 (свой), /shop/order/683 (чужой).
3. rep: /orders/683. dist2: /orders/685 и /orders/<uuid #685 admin>.
4. admin: /orders/<uuid> при abort запросов rest/v1/orders.
## Ожидаемо
- /orders/685 → редирект на /orders/a6f2f8c0-…, «הזמנה #685»; нет «נסה שוב», нет ответов ≥400 (מה רצוי: «פותח את ההזמנה … או מציג «ההזמנה לא נמצאה»»).
- 999999 / abc / 0 → «ההזמנה לא נמצאה.» + «חזרה להזמנות», без «נסה שוב», без ≥400.
- /edit и /receipt по номеру — открываются у того же заказа (комментарий программиста).
- buyer: свой открывается; чужой (#683) — не найден. rep: #683 — не найден. dist2: ни номер, ни uuid чужого бизнеса не раскрывают заказ (#3c03f6).
- Настоящая ошибка загрузки (abort orders): «טעינת ההזמנה נכשלה.» с «נסה שוב» (ord-04).
