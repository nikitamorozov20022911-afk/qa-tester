# ord-26: «מכירה מיידית» — нельзя выбрать больше остатка; товар с остатком 0 не добавляется
- Фича/экран: /orders/walk-in (walk-in-sale)
- Тикеты: #80bb3c (commits c31d763, e9ba7e1; реджект rej_21e989aa закрыт; עבר QA 25.10); решение пользователя 20.10 «нельзя продать больше реального остатка»
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (вручную также 390, iPad 820)
- Тип: негатив / граница
- Предусловия: свои товары QA-AUTO-80bb-<ts> (₪1): A — остаток 2 «ללא מקום», O — остаток 0; у каждого свой מק"ט. «רישום המכירה» нажимается только с неверным количеством (окно не должно открыться); продажа НЕ регистрируется. После — товары удалить.
## Шаги
1. Добавить A → «+» → «+».
2. Ввести в кол-во 3 → уйти с поля → «רישום המכירה». То же для 5.
3. Ввести 1.5 → уйти с поля.
4. Поиск по имени O → клик по пункту; затем מק"ט O + Enter.
## Ожидаемо
1. Кол-во останавливается на 2, «+» disabled, «זו כל הכמות במלאי (2)» (решение 20.10; коммент программиста).
2. После blur — «במלאי 2 בלבד — לא ניתן למכור יותר», поле aria-invalid="true"; «רישום המכירה» → баннер «הכמות של A אינה תקינה. עדכן אותה ונסה שוב.», окно подтверждения не открывается (rej_21e989aa «מצב רצוי»).
3. «כמות — מספר שלם בלבד» (rej_0248275a п.3).
4. Пункт O — «אזל מהמלאי», aria-disabled="true", по клику строка не добавляется; по מק"ט+Enter — «O — אזל מהמלאי.», строк нет.
5. Предупреждений «יימכרו ללא מלאי» / «המכירה תירשם בכל זאת» нет нигде.
- Не автоматизируется: реальная регистрация продажи (ровно 2 → остаток 0, «נותרו N יחידות בלבד…» при падении остатка после добавления) — необратимо (заказ «לקוח מזדמן» и списание неудаляемы).
