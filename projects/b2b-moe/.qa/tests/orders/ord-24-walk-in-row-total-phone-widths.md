# ord-24: «מכירה מיידית» на телефоне — «סה"כ» строки целиком и не заходит под поле цены (320–414), на 820/1440 табличный вид
- Фича/экран: /orders/walk-in, «פריטי המכירה» (walk-in-sale)
- Тикеты: #a88293 (711f180d7b4c9ecb4ea88293; עבר QA 25.10)
- Роль/аккаунт: admin
- Устройство: эмуляция телефона 360 (основной), 320 / 375 / 390 / 414; контроль 820 и 1440
- Тип: визуал / граница
- Предусловия: свой товар QA-AUTO-a882-<ts> (₪1, остаток 5 «ללא מקום»). «רישום המכירה» НЕ нажимать. После — товар удалить.
## Шаги
1. /orders/walk-in → добавить товар → «+» до 5.
2. «מחיר יחידה» = 200 (строка ₪1,000.00), затем 2000 (₪10,000.00), 20000 (₪100,000.00).
3. На каждой ширине 320 / 360 / 375 / 390 / 414 — замерить «סה"כ» строки и поле цены; 820 и 1440 — то же.
4. «חזרה להזמנות».
## Ожидаемо
1. Телефон: сумма строки видна целиком («₪1,000.00» / «₪10,000.00» / «₪100,000.00», scrollWidth = clientWidth), отдельным рядом под полем цены, прямоугольники суммы и поля цены не пересекаются (источник: «מה רצוי» #a88293 — «הסכום של השורה מוצג במלואו בכל רוחב טלפון, בלי לעלות על שדה המחיר»).
2. Страница без горизонтальной прокрутки (scrollWidth документа = ширине экрана) (F-22 / D-09).
3. 820 / 1440 — табличный вид: сумма в одном ряду с полем цены, без наложения (регресс #e1e502).
