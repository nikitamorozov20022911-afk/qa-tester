- Устройство: desktop
- Тип: функциональный
- Предусловия: товар «QA-AUTO-pricing-<ts>» (מק"ט QA-AUTO-PR-<ts>, מחיר בסיס 100) создан в `/catalog/new`.
## Шаги
1. `/pricing/groups` → «קבוצה חדשה» → пусто → «שמירה».
2. Имя «QA-AUTO-group-<ts>» → «שמירה».
3. ⋮ → «שיוך מוצרים». Поиск «zzzz-no-such».
4. Поиск по имени и по מק"ט QA-товара; отметить checkbox, замерить время до checked.
5. «סיום».
6. Снова «שיוך מוצרים» → снять отметку → «סיום».
7. ⋮ → «מחיקה» → подтвердить.
## Ожидаемо
1. «נא להזין שם קבוצה», поле invalid.
2. Строка группы: «מספר מוצרים» 0, «לקוחות משויכים» 0 (пустая группа — как пустая).
3. Есть поле «חיפוש מוצר» (placeholder «חיפוש מוצר לפי שם או מק"ט»); «לא נמצאו מוצרים התואמים לחיפוש.» (#6a8da12d).
4. Находится и по имени, и по מק"ט; checkbox отмечается мгновенно (< 1 с; замер 12 мс) (#6a8da12d «ללא עיכוב מורגש»).
5. «מספר מוצרים» = 1 (AC 1). Подсказка «מוצר יכול להשתייך לקבוצה אחת בלבד.» — правило для «товар в нескольких группах».
6. «מספר מוצרים» = 0.
7. Диалог «מחיקת קבוצה» («המוצרים בקבוצה לא יימחקו»), группа исчезает.
