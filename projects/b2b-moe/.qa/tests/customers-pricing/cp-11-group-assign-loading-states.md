# cp-11: «שיוך מוצרים» — שלד בזמן טעינה, שגיאה עם «נסה שוב», «אין מוצרים» רק כשהקטלוג ריק
- Фича/экран: F-17 / S-23 (`/pricing/groups` → ⋮ → «שיוך מוצרים»)
- Тикеты: #966c4100
- Роль/аккаунт: admin
- Устройство: desktop 1440×900 (+ телефон — вручную)
- Тип: состояния / негатив
- Предусловия: есть хотя бы одна группа; окно только открывается и закрывается (Escape/«סיום») без отметок. Список товаров окна — GET `rest/v1/products?…` (перехват ставится ПОСЛЕ загрузки страницы).
## Шаги
1. Задержать запрос товаров на ~6 с, открыть «שיוך מוצרים» у первой группы.
2. Обрывать запрос товаров (abort), открыть окно; снять перехват, нажать «נסה שוב».
3. Ответить на запрос товаров `200 []`, открыть окно.
## Ожидаемо
1. Сразу — скелет строк (`aria-busy="true"`), нет «אין מוצרים בקטלוג עדיין.», нет чекбоксов; затем список товаров (чекбоксы), скелет исчезает, «пусто» так и не появляется («מה רצוי»: спиннер/скелет пока грузится; «אין מוצרים…» только если каталог реально пуст).
2. «אירעה שגיאה בטעינת המוצרים. נסה שוב.» + кнопка «נסה שוב» (после повторов приложения, до ~15 с), без «אין מוצרים…»; «נסה שוב» загружает список (комментарий программиста).
3. «אין מוצרים בקטלוג עדיין.», чекбоксов нет, ошибки нет.
- Вручную (не автоматизировано): фоновое обновление списка с ошибкой во время присвоения не убирает уже показанный список.
