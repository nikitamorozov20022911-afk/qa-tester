# SafePay — תהליכי משתמש (flows)

Источник: mifrat «מפרט», проект SafePay (https://mifrat.com/Project?id=69e115aa1b31563236cf6b60&tab=spec), режим «ספר», раздел «ד — תהליכי משתמש» (11 תהליכים). Извлечено 2026-10-03.

Примечания по извлечению:
- В документации у каждого תהליך есть только поля: название, «תיאור», «שלבי התהליך» (шаг + экран). Отдельных полей «триггер», «успех», «сбои» в «מפרט» нет.
- «Триггер» = дословно шаг 01, «Успех» = дословно последний шаг; «Сбои/блокировки» — только то, что дословно сказано в описании/шагах. Если ничего — «в документации нет».
- Режим «עבודה»: в списке «תהליכים (11)» те же 11 названий; отдельной формы с доп. полями для תהליך не открылось (клик открывал чужие карточки «ערוך תכונה» — закрыты без сохранения). Источник всех данных — режим «ספר».
- Названия экранов — дословно, как в «מפרט» (совпадают с названиями מסכים в списке תכונות).

## FL-01 — הרשמה והזדהות
- Источник: «מפרט» → ספר → ד. תהליכי משתמש → תהליך משתמש · 1 / 11
- תיאור: מסע המשתמש החדש — ממסך הפתיחה ועד חשבון פעיל. אימות תעודת זהות הוא אופציונלי בשלב זה.
- Триггер (шаг 01): המשתמש פותח את האפליקציה ורואה את מסך הפתיחה.
- Шаги:
  1. המשתמש פותח את האפליקציה ורואה את מסך הפתיחה. — экран: Splash Screen
  2. שלוש שקופיות היכרות עם אפשרות דילוג קדימה ואחורה. — экран: Onboarding — קרוסלת היכרות
  3. המשתמש מזין מספר טלפון ומאשר את תנאי השימוש. — экран: ברוכים הבאים — הזנת טלפון
  4. הקלדת קוד בן 6 ספרות. קוד שגוי מציג מצב שגיאה אדום תוך שמירת המספר. — экран: שלחנו לכם קוד אימות
  5. השלמת שם מלא, תאריך לידה ותמונה. צילום תעודת זהות מסומן כאופציונלי. — экран: יצירת פרופיל
  6. מסך הצלחה ומעבר למסך הבית. — экран: הכל מוכן! — סיום הרשמה
- Успех: מסך הצלחה ומעבר למסך הבית.
- Сбои/блокировки: «קוד שגוי מציג מצב שגיאה אדום תוך שמירת המספר.» (шаг 4). Другие — в документации нет.
- Экраны: Splash Screen → Onboarding — קרוסלת היכרות → ברוכים הבאים — הזנת טלפון → שלחנו לכם קוד אימות → יצירת פרופיל → הכל מוכן! — סיום הרשמה

- Триггер (шаг 01): מתפריט '...' בוחרים 'ביטול עסקה' (מסומן באדום).
- Шаги:
  1. מתפריט '...' בוחרים 'ביטול עסקה' (מסומן באדום). — экран: פרטי עסקה
  2. היוזם שולח בקשת ביטול. הכסף נשאר בנאמנות. — экран: בקשת ביטול עסקה
  3. הצד השני מקבל התראה ומאשר או דוחה את הביטול. — экран: בקשת ביטול עסקה
  4. ביטול מאושר — העסקה עוברת ל'בוטל' והכסף חוזר למשלם. — экран: פרטי עסקה
- Успех: ביטול מאושר — העסקה עוברת ל'בוטל' והכסף חוזר למשלם.
- Сбои/блокировки: «שני הצדדים חייבים לאשר — אחרת העסקה חוזרת למצבה הקודם.» (תיאור); הצד השני יכול לדחות את הביטול (шаг 3).
- Экраны: פרטי עסקה → בקשת ביטול עסקה → פרטי עסקה

## FL-04 — פתיחת עסקה בטוחה
- Источник: «מפרט» → ספר → ד. תהליכי משתמש → תהליך משתמש · 4 / 11
- תיאור: מסלול פתיחת עסקה — מבחירת התפקיד ועד עסקה פתוחה הממתינה לאישור הצד השני.
- Триггер (шаг 01): לחיצה על 'עסקה בטוחה' פותחת שיט בחירת תפקיד: 'אני משלם' או 'אני מבקש תשלום'.
- Шаги:
  1. לחיצה על 'עסקה בטוחה' פותחת שיט בחירת תפקיד: 'אני משלם' או 'אני מבקש תשלום'. — экран: עסקאות — רשימת עסקאות
  2. מילוי כותרת, סוג עסקה, תנאים, עלות ותאריכים. ניתן לנסח תנאים בעזרת AI. — экран: עסקה חדשה
  3. אם נבחר מסלול 'בחירה מנותני שירות' — חיפוש ובחירת עסק, וחזרה לטופס. — экран: בחירת נותן שירות לעסקה
  4. העסקה נפתחת במצב 'ממתין לאישור' ומוצגת לשני הצדדים. — экран: פרטי עסקה
- Успех: העסקה נפתחת במצב 'ממתין לאישור' ומוצגת לשני הצדדים.
- Сбои/блокировки: в документации нет.
- Экраны: עסקאות — רשימת עסקאות → עסקה חדשה → (опционально) בחירת נותן שירות לעסקה → פרטי עסקה

## FL-05 — טעינה ומשיכה מהארנק
- Источник: «מפרט» → ספר → ד. תהליכי משתמש → תהליך משתמש · 5 / 11
- תיאור: הדפוס האחיד של כל תנועות הכסף במוצר: סכום ← אמצעי ← פרטים ← מסך אישור.
- Триггер (шаг 01): בחירת פעולה מהירה: טעינת כסף או משיכת כסף.
- Шаги:
  1. בחירת פעולה מהירה: טעינת כסף או משיכת כסף. — экран: מסך הבית — הארנק שלי
  2. הזנת סכום. כפתור ההמשך חסום כל עוד הסכום 0. — экран: טעינת כסף
  3. מסלול כרטיס: פרטי כרטיס, שמירה לפעם הבאה, ואישור עמלת סליקה. — экран: פרטי כרטיס לטעינה
  4. מסלול העברה בנקאית: פרטי חשבון SafePay עצמה להעתקה. — экран: פרטים להעברה בנקאית — טעינת כסף
  5. מסך אישור אחיד המסיים כל תנועת כסף. — экран: אישור פעולה — מסך הצלחה
- Успех: מסך אישור אחיד המסיים כל תנועת כסף.
- Сбои/блокировки: «כפתור ההמשך חסום כל עוד הסכום 0.» (шаг 2). Другие — в документации нет.
- Экраны: מסך הבית — הארנק שלי → טעינת כסף → פרטי כרטיס לטעינה | פרטים להעברה בנקאית — טעינת כסף → אישור פעולה — מסך הצלחה
- Примечание: шаги описывают только экраны טעינה; экраны משיכה (משיכת כסף, פרטי חשבון למשיכה) есть в списке תכונות, но в шагах этого תהליך не названы.

## FL-06 — שחרור כסף בהסכמה דו-צדדית
- Источник: «מפרט» → ספר → ד. תהליכי משתמש → תהליך משתמש · 6 / 11
- תיאור: סגירת עסקה תקינה: נותן השירות מבקש את הכסף והלקוח מאשר. אף צד אינו משחרר כסף לבד.
- Триггер (шаг 01): הכסף שמור בנאמנות והשירות הושלם.
- Шаги:
  1. הכסף שמור בנאמנות והשירות הושלם. — экран: פרטי עסקה
  2. נותן השירות מסמן checkbox הצהרה ושולח בקשה. הכסף טרם שוחרר. — экран: בקשת שחרור כסף (צד נותן שירות)
  3. הלקוח מקבל התראה, מסמן את ההצהרה ומאשר — הכסף עובר בפועל. — экран: אישור תשלום (צד לקוח)
  4. בתום העסקה נפתחת אפשרות לדרג את הצד השני. — экран: דירוג וביקורת
- Успех: הלקוח ... מאשר — הכסף עובר בפועל; בתום העסקה נפתחת אפשרות לדרג את הצד השני.
- Сбои/блокировки: «אף צד אינו משחרר כסף לבד.» (תיאור); «הכסף טרם שוחרר» до подтверждения клиента (шаг 2). Сценарий отказа клиента — в документации нет.
- Экраны: פרטי עסקה → בקשת שחרור כסף (צד נותן שירות) → אישור תשלום (צד לקוח) → דירוג וביקורת

- Сбои/блокировки: «זמין רק כשהכסף כבר בנאמנות.» (шаг 1); «לכל צד אישור או דחייה» (шаг 4) → эскалация к בורר (шаг 5); «הכסף נשאר נעול בנאמנות לאורך כל התהליך.» (תיאור).
- Экраны: פרטי עסקה → פתיחת מחלוקת — בחירת מסלול → מחלוקת עם גישור AI — טופס → הצעת גישור בעזרת AI → הצעת פתרון בעזרת בורר אנושי
