Вход: телефон → код OTP (тестовый код — в тикетах; вводит пользователь в accounts.env / при ручном входе). Один номер = один аккаунт; новый номер создаёт нового пользователя.
| id | телефон | роль | тариф / состояние | сессия |
|---|---|---|---|---|
| guest | — | гость | — | без логина |
| client | — (уточнить по тикетам) | לקוח — платящая сторона | — | .qa/auth/client.json |
| provider | — (уточнить по тикетам) | נותן/ת שירות — получающая сторона | — | .qa/auth/provider.json |
Известные номера из тикетов: 0521234567 → «נועה לוי» (найден в поиске получателя на /wallet/transfer).

## Правила проекта (важнее общих правил плагина)
- Документацию («מפרט») только читать.
- Тестовые номера с OTP 123456: только 0500000001–06 (все заняты); для новых пользователей/второго ребёнка запрошены номера у программиста (реджекты #6a86f7b2fbf9).
- mifrat: сессия агентов .qa/auth/mifrat.json (node .qa/e2e/mifrat-login.mjs), реджекты — mifrat-reject.mjs, новые баги — mifrat-newbug.mjs.

## Технические заметки
- 2026-10-22: mifrat MCP: вложения через upload_path отклоняются («upload_not_complete», хотя PUT 200 и файл есть) — передавать { url: публичный адрес из attachment_upload_start, filename, type, size }.
- Expo Router, web. Вход: /phone (`data-testid="phone-input"`, кнопка «שלחו לי קוד אימות») → /otp → /create-profile (новый) или /wallet (главная).
- Тестовый OTP работает только в сборке без Supabase (dev-session, см. тикет про цикл onboarding 2026-09-07).
- Placeholder телефона в дизайне/на сайте `045-1234567` — `isValidPhone` его отклоняет (известный SPEC-STALE тикет).
- Персоны «מפרט»: מיכל לוי (נותנת שירות), אורי כהן (לקוח), דוד וייס (הורה, ארנק משותף), נועה ישראלי (ילד/ה).
- Модули: אינטגרציות ותשתית, חשבון וזהות, ארנק ותנועות כסף, עסקה בטוחה, נותני שירות, מחלוקות, ארנקים, אירועים וכרטיסים (+1).

- 2026-10-11: AI подключён по-настоящему — edge-функция `ai` (ops `draft_terms`, `propose_split`) отвечает моделью, не шаблоном (разные объяснения → разный раздел суммы). Фолбэк-шаблон в приложении включается только при `provider_not_configured`. Модель пишет нейтральный род «נותן/ת», «ללקוח/ה». Списка событий / кнопки к /events/<id> нет — тикет #92e2cb61.
