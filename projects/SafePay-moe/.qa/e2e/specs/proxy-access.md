#### 1.3 בעל החשבון: הפעלה וכיבוי של כל אחת משלוש ההרשאות נשמרים אחרי רענון; המצב המקורי משוחזר @iphone @data (#5068e1)

**Users:** owner17
**Steps:**
1. «פרופיל» → «גיבוי ומיופה כוח»; запомнить исходное состояние трёх переключателей.
2. Для каждого права по очереди: переключить в противоположное, дождаться сохранения, обновить страницу, снова открыть «גיבוי ומיופה כוח», прочитать состояние.
3. Вернуть исходное состояние каждого права; обновить и убедиться.
**Expected:**
- после переключения нет «השינוי לא נשמר. נסו שוב.» (реджект: раньше при включении права — ошибка)

- в конце состояние всех трёх прав = исходному (очистка в `finally`); данные общего аккаунта 17 меняются → `@data`, деньги не затрагиваются
