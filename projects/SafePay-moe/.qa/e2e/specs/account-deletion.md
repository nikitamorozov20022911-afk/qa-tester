# План автотестов: מחיקת חשבון

Источник: тикеты #b3171a («"מחיקת חשבון" רק מנתקת את המשתמש», 1f50c7e6fd040f902bb3171a) и #152172 (экран «מחיקת חשבון», demands 4–10, Figma 6075-3656); бриф `.qa/research/b3171a.md`, `.qa/research/doc-ac/152172.md`. עבר QA пользователем 17.11.2026. Тесты не сгенерированы и не прогонялись.
Правило проекта (урок L-20261117-P3): аккаунт с открытым не удаляется сразу, а переходит в «ממתין למחיקה» — это правильно, не дефект. Ответ клиента 28.10 («удалять сразу») не применять.

**Все тесты `@data @destructive`** — удаляют аккаунт безвозвратно. Условия:
- Пропускаются без `QA_ALLOW_ACCOUNT_DELETE=1` (`test.skip(!process.env.QA_ALLOW_ACCOUNT_DELETE, ...)` в начале каждого теста).
- Только одноразовые номера **0500000017–0500000099, кроме 0500000098** (код входа 123456). Каждый тест берёт свой номер (1.1 — 0500000017, 1.2 — 0500000018; при повторном прогоне — следующий свободный по журналу `qa-auto-created.jsonl`). **Никогда** 0500000001–0500000016 (общие роли, арбитр 06) и 0500000098 («בודק יתרה», ₪1, остаётся нетронутым).
- Роль не через seed: аккаунт создаётся в самом тесте (регистрация), поэтому `Seed` — гость. Сохранённые сессии `.qa/auth/*.json` не использовать.
- Создаваемые данные — с префиксом `QA-AUTO-`; номер и результат записывать в `qa-auto-created.jsonl` (для отчёта о тестовых данных). Деньги не вносить, баланс аккаунта остаётся ₪0.
- Не `@prod-safe`. Прогон — только по `/qa-regress` с явным флагом; тесты не зависят друг от друга (разные номера), `serial` не нужен.
Дефекты тикетов вне этого плана: SMS при автоудалении (demand 10, нет SMS в вебе), таймер 10 минут, вывод на банк, iPhone-нативное — `@manual`, генератору не передаются.

### 1. מחיקת חשבון
**Seed:** `tests/seed.spec.ts`

#### 1.1 חשבון נקי: רישום → "מחיקת חשבון" → מודאל אישור → מחיקה מיידית, כניסה חוזרת עם אותו מספר פותחת "יצירת פרופיל" ריק @desktop @data @destructive (#b3171a #152172)
**Device:** desktop (поведение не зависит от ширины; проверка на iPhone — вручную, @manual)
**Users:** guest (новый одноразовый номер 0500000017)
**Steps:**
1. Пропустить тест без `QA_ALLOW_ACCOUNT_DELETE=1`. Открыть сайт, на экране телефона ввести 0500000017, код 123456.
2. Пройти регистрацию до конца: на «יצירת פרופיל» заполнить имя `QA-AUTO מחיקה נקי`, сохранить; дождаться главной («הארנק שלי»). Ничего не создавать (ни сделок, ни событий, ни платежей).
3. Вкладка «פרופיל» → строка «מחיקת חשבון».
4. В открывшемся модале прочитать текст и кнопки.
5. Нажать «מחיקת חשבון לצמיתות».
6. Войти снова тем же номером 0500000017, код 123456.
**Expected:**
- шаг 4: модал с вопросом «האם את/ה בטוח שברצונך למחוק חשבון זה לצמיתות?» (demand 1); кнопка «מחיקת חשבון לצמיתות» — красная/деструктивная (demand 2: сверять по `getByRole('button')`, цвет — по computed `background-color`/`color` в красной гамме; если выбор цвета неоднозначен — проверять только наличие); вторичная кнопка «חזרה ללא מחיקה» (demand 3); текста «בחשבון עדיין יש דברים פתוחים» в модале нет (ничего открытого)
- шаг 5: аккаунт удаляется сразу (demand 4, 9): пользователь выходит на экран ввода телефона; плашки «החשבון יימחק אוטומטית…» и «ממתין למחיקה» нигде не появляются
- шаг 6: после кода открывается пустой экран «יצירת פרופיל» (поля имени/почты пусты, без имени `QA-AUTO מחיקה נקי`), а не прежний аккаунт и не главная (demand 9: «אותו מספר יכול להירשם מחדש כחשבון חדש וריק»; тикет #b3171a «מה רצוי»)
- очистка: после шага 6 новый профиль не создавать (номер остаётся пустым, «בלי תשלום»); номер 0500000017 внести в `qa-auto-created.jsonl` как использованный

#### 1.2 חשבון עם אירוע עתידי: מודאל מציג פריט פתוח, אחרי אישור "ממתין למחיקה" עם פלאשה בדף הבית, "ביטול בקשת המחיקה" מסיר אותה @desktop @data @destructive (#b3171a #152172)
**Device:** desktop
**Users:** guest (новый одноразовый номер 0500000018)
**Steps:**
1. Пропустить тест без `QA_ALLOW_ACCOUNT_DELETE=1`. Регистрация 0500000018 / код 123456, имя `QA-AUTO מחיקה אירוע`.
2. Вкладка «פרופיל» → «יצירת אירוע»: создать событие `QA-AUTO event <время>` с датой в будущем (+30 дней), минимально допустимыми полями; платные билеты/цену не задавать, если форма позволяет (иначе цена ₪1 — генератор уточняет в живой сборке; если создание события недоступно новому аккаунту — остановиться и сообщить, не подменять элементом без события).
3. «פרופיל» → «מחיקת חשבון».
4. Прочитать список в модале; нажать «מחיקת חשבון לצמיתות».

**Expected:**

- шаг 4 (после подтверждения): аккаунт НЕ удалён и не выброшен на экран телефона — пользователь остаётся внутри приложения (правило L-20261117-P3; demand 5: «עובר למצב ממתין למחיקה»)
- шаг 5: сверху главной плашка «החשבון יימחק אוטומטית כשהעסקאות הפתוחות ייסגרו» со списком открытого (в нём `QA-AUTO event <время>`) и кнопкой «ביטול בקשת המחיקה» (demand 8)
- шаг 6–7: плашка исчезает и после перезагрузки не возвращается; профиль/главная работают как обычно, имя `QA-AUTO מחיקה אירוע` на месте — аккаунт вернулся к обычному использованию (demand 8: «ביטול מחזיר את החשבון לשימוש רגיל»)
- очистка: аккаунт 0500000018 остаётся живым с событием `QA-AUTO event <время>` — в «Тестовые данные в чистку» (событие закрыть/удалить вручную или оставить; не использовать номер повторно); запись в `qa-auto-created.jsonl`

### 2. «ממתין למחיקה» — действия, запрещённые из-за запроса удаления (#152172)
**Seed:** `tests/seed.pending16.spec.ts` (аккаунт 050-0000016 «QA מחיקה B» в состоянии «ממתין למחיקה», сессия `.qa/auth/pending16.json`)

Источник: тикет #152172 (треб. 7; реджект rej_20bdfeb… 17.11, перепроверка עבר QA пользователем 18.11.2026; бриф `research/152172.md`; скриншоты `.qa/screenshots/2026-11-18/152172-*`). Правило L-20261117-P3 (запрос удаления при открытых пунктах → «ממתין למחיקה», не дефект) — действует.
**В отличие от блока 1 — только чтение, деструктивных действий нет:** тесты НЕ нажимают «ביטול בקשת המחיקה» и «מחיקת חשבון לצמיתות», не вводят суммы, не отправляют формы. Закрывают окно «חזרה». Не `@destructive`, не `@data`, `@prod-safe`.
**Предусловие (готовит пользователь, не тест):** аккаунт 050-0000016 остаётся в «ממתין למחיקה» (событие 01.06.2027 не удалено); сессия — `qa-login` для нового аккаунта `pending16` (в `accounts.json` добавлен: `QA_USER_PENDING16_PHONE=0500000016`, код входа тот же `QA_OTP`). Если баннер «ממתין למחיקה» на главной не виден — `test.skip`: аккаунт вышел из состояния (кто-то нажал «ביטול…»).
