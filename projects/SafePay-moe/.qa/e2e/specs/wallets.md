### 4. טעינת כסף בכרטיס — סירוב המעבד
**Seed:** `tests/seed.client.spec.ts`

Источник: кейс `.qa/tests/wallets/WAL-008.md`, тикет #6aabdaf745fcf2c9f2a7f36d (עבר QA 12.10.2026; проверен на Android-сборке). В вебе отказ процессора эмулируется блокировкой запроса пополнения через `page.route`. Реальное пополнение с сетью («הטעינה בוצעה בהצלחה», +₪1) не автоматизируется — меняет баланс.
Карта — только опубликованный тестовый номер `4111111111111111` (CVC `123`, תוקף `12/30`), только в веб-сборке. Галочку «שמירת הכרטיס לטעינות הבאות» не ставить (иначе сохраняется карта).

#### 4.1 טעינה בכרטיס: סירוב המעבד — שורת שגיאה, בלי מסך הצלחה, יתרה ללא שינוי @android (#6aabdaf745fc)
**Device:** android — `@android` (сценарий тикета — Android; в вебе — Chrome Pixel 7)
**Users:** client (сессия `.qa/auth/client.json`)
**Данные:** не меняет данные, если запрос пополнения заблокирован. Не `@prod-safe`: при ошибке в шаблоне блокировки запрос с тестовой картой ушёл бы на прод — запускать только на staging.
**Steps:**
1. Открыть «הארנק שלי» (`/wallet`); запомнить баланс (сумма «₪…») и число строк «טעינה בכרטיס אשראי» в «פעולות אחרונות».

3. Заполнить «שם בעל הכרטיס» = «QA-AUTO Test», «מספר כרטיס» = `4111111111111111`, «תוקף» = `12/30`, «CVC» = `123`; поставить галочку «אני מאשר עמלת סליקה…».
4. До нажатия установить `page.route` на запрос пополнения (генератор определяет запрос по сети при «אישור טעינה» — Supabase function/RPC/REST создания טעינה; auth/profile/GET-чтения не блокировать) → `route.abort('failed')`. Для страховки абортить и любой другой не-GET запрос к `*.supabase.co`, кроме `/auth/`, пока открыт экран карты; зафиксировать, что перехват сработал хотя бы один раз (иначе тест падает).
5. Нажать «אישור טעינה»; дождаться строки ошибки (через `expect`, без фиксированных пауз).
6. Снять блокировку (`page.unroute`), вернуться в «הארנק שלי» (`/wallet`).
**Expected:**
- шаг 2: на `/wallet/load` кнопка «הבא» неактивна при ₪0 и активна после «1» (S-13 AC4)
- шаг 3: поля «שם בעל הכרטיס», «מספר כרטיס», «CVC», «תוקף», галочки «שמירת הכרטיס לטעינות הבאות» и «אני מאשר עמלת סליקה…», кнопка «אישור טעינה» (S-14 AC1–6)
- шаг 5: над кнопкой видна строка «לא ניתן להשלים את הטעינה כרגע.» (кейс WAL-008 / тикет: отказ процессора должен быть пойман)
- шаг 5: текста «הטעינה בוצעה בהצלחה» на странице нет; экран «פרטי כרטיס» остаётся (поля карты и «אישור טעינה» видны)
