# WAL-013: «פרטי כרטיס» (טעינת כסף) — галочки над «אישור טעינה» и нажимаются при открытой клавиатуре, клавиатура закрывается, «חזרה» → «טעינת כסף» с ₪1
- Фича/экран: טעינת כסף (S-13) → פרטי כרטיס לטעינה (S-14), поток FL-05
- Тикеты: #d64ac3 (3413934a7b7ba8b560d64ac3), реджект rej_47c75e9e87f61ba870d6da97; связанные #197466, #d528b4 (WAL-011), #2d80c8
- Роль/аккаунт: client 0500000004, сессия .qa/auth/client.json
- Устройство: iPhone 17, нативное il.co.safepay.app 0.1.1 build 16
- Тип: позитив, визуал (без оплаты)
- Предусловия: сумма ₪1; данные карты НЕ вводить, «אישור טעינה» НЕ нажимать (в поля — максимум 1–2 цифры, чтобы открыть клавиатуру, и стереть)
## Шаги
1. Главная → «טעינת כסף» → «1» → «הבא» → «סליקה באשראי» → «פרטי כרטיס».
2. По очереди фокус в «שם בעל הכרטיס», «מספר כרטיס», «תוקף», «CVC» — смотреть галочки и кнопку.
3. При открытой клавиатуре поставить/снять обе галочки.
4. Закрыть клавиатуру: тап по заголовку, по пустому месту, свайп формы вниз.
5. С закрытой клавиатурой сверить раскладку с Figma 6072-14080.
6. «חזרה» (стрелка, и свайп от края) → «טעינת כסף»; ещё «חזרה» → главная.
## Ожидаемо
- В любом из 4 полей обе галочки «שמירת הכרטיס לטעינות הבאות» и «אני מאשר עמלת סליקה» видны над «אישור טעינה», кнопка их не закрывает; поле в фокусе видно (тикет п.1; коммент 25.10)
- Галочки нажимаются при открытой клавиатуре; отметка «אני מאשר עמלת סליקה» делает «אישור טעינה» активной, клавиатура остаётся (тикет п.1 «ולחיצות»; коммент 25.10)
- Тексты галочек в строке над кнопкой не обрезаны и не наезжают
- Тап вне поля и свайп формы вниз закрывают клавиатуру (тикет п.2; реджект п.2)
- Клавиатура закрыта → поля → галочки → кнопка, как Figma 6072-14080; кнопка над индикатором «домой» (#197466)
- «סכום לטעינה ₪1», срок «MM/YY» (#d528b4; L-20261008-P2)
- «חזרה» → «טעינת כסף» с ₪1, не главная; дальше «חזרה» → главная (тикет п.3; FL-05)
## Только на нативном iPhone (@ios-native)
- Экранная клавиатура, её закрытие тапом/свайпом, «строка галочек над кнопкой», индикатор «домой», системный свайп «назад» — только на устройстве. В вебе — раскладка, нажимаемость галочек при фокусе в поле, «חזרה» с суммой.
