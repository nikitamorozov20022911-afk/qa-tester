# WAL-016: Сейф на экранах успеха — пополнение (монета входит), новая сделка (пустой сейф запирается), депозит (монета входит, «הכסף שמור בנאמנות»), перевод (сейф открывается, монета выходит); звук монет при приземлении
- Фича/экран: экраны успеха денежных операций (S-19 AC2–3 / F-15 AC5; «אישור פעולה — מסך הצלחה»)
- Тикеты: #26ed72 (829c1ab2141b80150326ed72; реджект 26.10 «звук как бокалы» исправлен 28.10); связанные #7564a2 (WAL-014 — монет по балансу), #e2eb7e (WAL-018 — звуки по операциям), #f45918 (WAL-017 — разброс)
- Роль/аккаунт: client 0500000004 (баланс, карта 4242), получатель/вторая сторона — provider 0500000005
- Устройство: iPhone 17, нативное 0.1.1 (19), режим звонка, громкость
- Тип: позитив, визуальный, звук, денежный (₪1 — только с согласия пользователя)
- Предусловия: OTA подтянут (закрыть/открыть дважды)
## Шаги
1. «טעינת כסף» ₪1 картой → экран успеха.
2. «עסקה חדשה» с 05 → «פתיחת עסקה בטוחה» → экран «העסקה נוצרה בהצלחה».
3. 05 подтверждает условия; 04 → «הפקדת התשלום» ₪1 → экран успеха.
4. «העברה מיידית» ₪1 → 05 → «זה האדם הנכון — השלמת ההעברה» → экран успеха.
5. Беззвучный режим → повторить шаг 1 (или 3).
## Ожидаемо
- Пополнение: монета входит в сейф; депозит: монета входит, «הכסף שמור בנאמנות»; новая сделка: пустой сейф запирается, «העסקה נוצרה בהצלחה»; перевод: сейф открывается, монета выходит (тикет; решение с владельцем 25.10)
- Пополнение и депозит: звук настоящих монет при касании монетой стопки, не «стекло/бокалы», успевает доиграть до перехода (реджект R1; коммент 28.10)
- Беззвучный режим / «Уменьшение движения» — тишина; на сайте звука нет (коммент 26.10/28.10)
- Подпись действия на экране успеха (S-19 AC2, F-15 AC5)
