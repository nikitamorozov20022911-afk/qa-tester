- Предусловия: известна «היתרה שלך» до операции
## Шаги
1. «טעינת כסף» ₪1 картой → экран успеха: посчитать монеты в сейфе, сравнить с «היתרה שלך» после операции.
2. «העברה מיידית» ₪1 → 05, войти с главной → экран завершённого перевода: монеты по «היתרה שלך».
3. «עסקה חדשה» (без депозита) → экран создания: сейф.
4. Сделка в статусе к оплате → «הפקדה» ₪1 → экран «הכסף שמור בנאמנות»: монеты по сумме сделки.
## Ожидаемо
- Пополнение / завершённый перевод / вывод: число монет по «היתרה שלך» после операции — больше денег = больше монет (тикет «מה רצוי» 4; коммент программиста 25–26.10)
- Шкала: ₪0 — пусто; 1 монета на каждые ₪20 до ₪100 (1–5); дальше постепенно; от ₪10,000 — полный (коммент программиста 26.10)
- Депозит в сделку: монет по сумме сделки (₪1 → 1 монета), «הכסף שמור בנאמנות» (коммент программиста)
