# AUTH-002: Passkey — добавление в «אמצעי התחברות» и вход «כניסה עם Passkey» без кода
- Фича/экран: פרופיל → אמצעי התחברות · экран входа
- Тикеты: #afa241 (אימייל ו-Passkey); iOS — отдельный тикет #b0d9dbd2 (после Apple Team ID)
- Роль/аккаунт: provider (0500000005)
- Устройство: Android (Google Password Manager)
- Тип: позитив
- Предусловия: ключ создаёт ТОЛЬКО пользователь (он в его Google-аккаунте); после теста ключ можно удалить
## Шаги
1. פרופיל → «אמצעי התחברות» → «הוספת Passkey» → подтвердить системным окном (пользователь).
2. Выйти из аккаунта.
3. Экран входа → «כניסה עם Passkey» → выбрать ключ.
## Ожидаемо
- После добавления: строка «Google Password Manager · טרם נעשה בו שימוש»
- Вход без SMS-кода под 05
- После входа в «אמצעי התחברות»: «שימוש אחרון עכשיו»
