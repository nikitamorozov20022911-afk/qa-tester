# AUTH-007: Заставка — «живые» монеты в сейфе (блеск, покачивание, подпрыгивание при приземлении); при «הפחתת תנועה» монеты стоят
- Фича/экран: מסך פתיחה / Splash (F-05 / S-01)
- Тикеты: #edb378 (7b30ece37064bd9326edb378, просьба клиента 01.11); основа — AUTH-004 (#f3a917), AUTH-005 (#7564a2); разброс — AUTH-005/WAL-017 (#f45918)
- Роль/аккаунт: любой (гость и залогинен)
- Устройство: iPhone 17, нативное il.co.safepay.app 0.1.1 (19) + OTA (закрыть/открыть дважды)
- Тип: визуальный
- Предусловия: приложение полностью закрыто; запись экрана
## Шаги
1. Холодный старт ×2 (залогинен и гость), записать ~2 с заставки, разобрать кадры.
2. Настройки iPhone → Универсальный доступ → Движение → «Уменьшение движения» вкл. (с разрешения пользователя) → холодный старт.
3. Вернуть «Уменьшение движения» как было.
## Ожидаемо
- Монеты внутри сейфа не статичны: по кадрам видны блеск/искра, вращение/покачивание части монет, подпрыгивание монет под приземлившейся монетой (тикет «מה רצוי» — «מטבעות חיים»; эффекты — «למשל», коммент программиста 01.11)
- Движение не выстраивает монеты в ряды (#f45918)
- При «Уменьшении движения» монеты не двигаются (коммент программиста 01.11; #87ee9a)
- Фон, логотип, «SafePay» на месте; после ~2 с переход дальше (S-01 AC1–3)
## Только на нативном / вручную (@ios-native @manual)
- Весь кейс: анимация нативной заставки, в DOM веб-сборки не измеряется (auth.md 4.1–4.2 — только ручной регресс).
