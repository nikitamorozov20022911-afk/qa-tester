# AUTH-001: Вход по email — код, неверный код, «שינוי אימייל», «אמצעי התחברות»
- Фича/экран: התחברות · вход по email, экран кода, פרופיל → אמצעי התחברות
- Тикеты: #afa241 (אימייל ו-Passkey)
- Роль/аккаунт: новый email (temp-mail), затем 0500000005
- Устройство: Android (il.co.safepay.app)
- Тип: позитив + негатив
- Предусловия: временный ящик (temp-mail); код вводит пользователь
## Шаги
1. Экран входа → «המשך עם אימייל» → ввести адрес → «שליחת קוד».
2. Ввести неверный код (6 цифр).
3. «שינוי אימייל» → вернуться, адрес сохранён в поле.
4. Ввести верный код → регистрация/вход.
5. Выйти, войти тем же email ещё раз.
6. פרופיל → «אמצעי התחברות» → добавить телефон (тот же экран кода).
## Ожидаемо
- Неверный код: «הקוד שהוזן שגוי, נסו שוב», адрес не сбрасывается
- Повторный вход не просит профиль заново
- В «אמצעי התחברות» видны email и телефон
- Известное (в общем тикете мелких правок): длинный email обрезан в плашке; на экране кода буквенная клавиатура
