# PRV-002: «נסו שוב» в состоянии ошибки на /providers — боковые отступы 16px
- Фича/экран: נותני שירות · S-35 «חיפוש נותן שירות», error state
- Тикеты: #7da5215c
- Роль/аккаунт: client (0500000004)
- Устройство: mobile 375×812, desktop 1440×900
- Тип: визуал
- Предусловия: запрос списка נותני שירות падает (в тесте — блокировка сетевого запроса)
## Шаги
1. Заблокировать запрос списка исполнителей, открыть `/providers`.
2. Замерить кнопку «נסו שוב».
3. Снять блокировку, нажать «נסו שוב».
## Ожидаемо
- «לא הצלחנו לטעון את נותני השירות» / «בדקו את החיבור לאינטרנט ונסו שוב.»
- У «נסו שוב» внутренний отступ слева и справа ≈16px (коммент программиста к #7da5215c: «וגם ל"נסו שוב" באותו מסך»)
- После снятия блокировки «נסו שוב» загружает список (регресс)
