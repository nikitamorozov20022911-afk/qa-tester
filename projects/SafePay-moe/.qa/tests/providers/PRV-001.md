# PRV-001: «ניקוי החיפוש והסינון» в пустом поиске — боковые отступы 16px, очищает поиск
- Фича/экран: נותני שירות · S-35 / F-47 «חיפוש נותן שירות» (`/providers`), empty state (AC4)
- Тикеты: #7da5215c
- Роль/аккаунт: client (0500000004) — вкладка есть у любого пользователя
- Устройство: mobile 375×812, 320, desktop 1440×900
- Тип: визуал + позитив
- Предусловия: нет
## Шаги
1. Нижняя навигация «נותני שירות» (`/providers`).
2. В поиск ввести слово без результатов (напр. «ךךקקקק»).
3. Замерить кнопку «ניקוי החיפוש והסינון»; нажать её.
## Ожидаемо
- Empty state «לא מצאנו נותני שירות» / «נסו מילה אחרת, או שנו את הסינון.»
- У «ניקוי החיפוש והסינון» внутренний отступ слева и справа ≈16px (текст не касается края, не переносится, не обрезается на 320) (#7da5215c «מה רצוי» 2 — «כמו בשאר כפתורי ה-pill»; 16px — коммент программиста)
- После нажатия поиск пуст, список נותני שירות снова показан (S-35 AC4, регресс)
