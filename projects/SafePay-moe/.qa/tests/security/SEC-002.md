# SEC-002: REVOKE — deal_events и money_movements append-only: client не делает INSERT/UPDATE/DELETE (403)
- Фича/экран: безопасность БД (Supabase / PostgREST), без UI
- Тикеты: #6a9e9592f020cfee7fb9cb5e
- Роль/аккаунт: client (0500000004)
- Устройство: desktop (API-тест)
- Тип: негатив / безопасность
- Предусловия: как SEC-001
## Шаги
1. POST `deal_events` {deal_id: несуществующий uuid}; PATCH и DELETE `deal_events?id=eq.<несуществующий>`.
2. То же для `money_movements` (wallet_id: несуществующий uuid).
## Ожидаемо
- Все 6 запросов → HTTP 403, код 42501 (AC 6 «deal_events ו-money_movements הם append-only בפועל — אין INSERT, אין UPDATE ואין DELETE ללקוח»)
- Ничего не создаётся: при выданной привилегии БД ответила бы ошибкой FK / 204 по пустой выборке, а не 403
