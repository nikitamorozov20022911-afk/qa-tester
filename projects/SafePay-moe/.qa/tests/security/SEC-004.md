# SEC-004: Face ID — «נעילה וזיהוי ביומטרי» в профиле, блокировка при холодном старте и после > 1 мин в фоне, Face ID перед депозитом/переводом/освобождением, отмена не проводит, разовое предложение после входа
- Фича/экран: פרופיל → «נעילה וזיהוי ביומטרי» (док. «פרופיל», решение владельца 28.10); экран блокировки; денежные подтверждения
- Тикеты: #907ebd (ee95909b02a2aaa9f7907ebd, просьба клиента)
- Роль/аккаунт: client 0500000004 (на телефоне); 05 — выкл. (настройка на аккаунт)
- Устройство: iPhone 17, нативное 0.1.1 (19/20), Face ID
- Тип: позитив + негатив, денежный (₪1 — с согласия)
- Предусловия: после теста выключить переключатель и отозвать Face ID у SafePay (делает пользователь)
## Шаги
1. Выйти/переустановить → вход по коду → предложение «להפעיל Face ID?» → «הפעלה».
2. «פרופיל» → «נעילה וזיהוי ביומטרי» — вкл/выкл (Face ID подтверждает).
3. Полностью закрыть → открыть.
4. Свернуть на 30 с → вернуться; свернуть на > 1 мин (70 с) → вернуться.
5. Депозит в נאמנות → Face ID «ביטול»; затем успех. То же — освобождение денег, последний шаг перевода.
## Ожидаемо
- Предложение после входа — один раз; «הפעלה» запрашивает Face ID (док. Д3)
- Строка «נעילה וזיהוי ביומטרי» со статусом «מופעל»/«כבוי», по умолчанию «כבוי»; переключение — только после Face ID (док. Д1–Д2)
- Холодный старт с сессией → экран блокировки, вход по Face ID, запасной — код телефона; «ביטול נעילה», «יציאה מהחשבון» (Д4, Д7, Д11)
- Фон 30 с — без блокировки; > 1 мин — блокировка (Д5)
- Перед депозитом / освобождением / переводом — Face ID; отмена → ничего не отправлено, деньги не ушли (Д9)
## Только на нативном / вручную (@ios-native @manual @data)
- Весь Face ID — только на устройстве. Веб-автотест — только строка профиля со статусом (profile.md 2.1).
