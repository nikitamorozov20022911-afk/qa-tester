# Сканирование билета с подтверждением оплаты (#4a52ea) — 2026-11-08
Роли: организатор (сканер, iPhone), покупатель (Pixel).
- TSA-001 Ручной код → «הכרטיס תקין · ממתין לאישור התשלום של הקונה», счётчик «נסרקו» не растёт.
- TSA-002 Повторный скан до подтверждения → то же ожидание, второй запрос не появляется.
- TSA-003 Покупатель: Push «אישור תשלום לכרטיס» + запись в «ממתין לפעולה» → билет «ממתין לאישור תשלום», сумма, «אישור תשלום».
- TSA-004 После «אישור תשלום» сканер сам → ✓ «אפשר להיכנס», счётчик +1; у покупателя «נסרק · היום · HH:MM».
- TSA-005 Повторный скан после подтверждения → «הכרטיס לא אושר · הכרטיס כבר נסרק · <время>».
- TSA-006 В сканере в ожидании только «לכרטיס הבא», обхода нет.
- TSA-007 Деньги: −₪ נאמנות покупателя, +₪ организатору только после подтверждения.
- Статус покупки в списке «הכרטיסים שלי» на каждом этапе (בתוקף → ממתין לאישור תשלום → נסרק · …) — кейсы MTS-002…004 в `my-tickets-status.md` (#ecd872).
