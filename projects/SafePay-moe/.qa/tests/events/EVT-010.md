# EVT-010: Событие — формат цены, количество до 6, проверка email, двойное «קניית כרטיס» → одна покупка
- Фича/экран: יצירת אירוע · רכישת כרטיס לאירוע
- Тикеты: #d0f598 (אירועים)
- Роль/аккаунт: provider 05 создаёт, client 04 покупает
- Устройство: Android
- Тип: негатив + позитив
- Предусловия: покупка ₪1 — спросить; событие открывать диплинком safepay://events/<id>
## Шаги
1. 05: «יצירת אירוע», цена «5,5» и «-5»; затем «5.5».
2. 04: открыть событие, «+» до упора.
3. Ввести неверный email.
4. Верный email, два быстрых нажатия «קניית כרטיס».
## Ожидаемо
- «5,5» / «-5» → «יש להזין מחיר בפורמט 5.50»; «5.5» → ₪5.50
- Количество не больше 6
- Неверный email → «כתובת האימייל אינה תקינה»
- Одна покупка «-₪1», «הרכישה בוצעה בהצלחה!», деньги в נאמנות поставщика
