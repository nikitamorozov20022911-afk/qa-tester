# NTF-002: Уведомление «ארנק» («פעולה נחסמה בגלל מגבלה») при клике только помечается прочитанным, экран не меняется
- Фича/экран: התראות · S-12 / F-17 AC4 (`/notifications`, фильтр «ארנק»)
- Тикеты: #ccd9d865bc2f2ee955f517d1
- Роль/аккаунт: client (0500000004) — есть уведомления «פעולה נחסמה בגלל מגבלה» (лимит ребёнка, 05.10)
- Устройство: mobile 375×812, desktop 1440×900
- Тип: граница (что НЕ должно открываться)
- Предусловия: нет; создавать уведомление лимита не нужно (⛔ требует платежа ребёнка)
## Шаги
1. `/notifications` → фильтр «ארנק».
2. Нажать первое уведомление «פעולה נחסמה בגלל מגבלה».
## Ожидаемо
- Фильтры «הכל / ממתין לפעולה / עסקאות / ארנק» (F-17 AC1); в «ארנק» — «פעולה נחסמה בגלל מגבלה» с пояснением «הפעולה נחסמה כי היא חורגת מהמגבלה שהוגדרה.» (F-17 AC4)
- После клика URL остаётся `/notifications`, карточка прочитанная (белый фон) (коммент программиста 07.10: «התראת ארנק רק מסומנת»)
