# NTF-001: Клик по уведомлению сделки открывает эту сделку и помечает уведомление прочитанным; «חזרה» → «התראות», прочитанное остаётся после обновления
- Фича/экран: התראות · S-12 / F-17 (`/notifications`) → S-28 «פרטי עסקה» (`/deals/<id>`)
- Тикеты: #ccd9d865bc2f2ee955f517d1
- Роль/аккаунт: обе стороны — client (0500000004) и provider (0500000005, «שירה כהן»)
- Устройство: mobile 375×812 (основное), 320, desktop 1440×900
- Тип: позитив
- Предусловия: у получателя есть свежее непрочитанное уведомление сделки. Для провайдера — клиент создаёт сделку `QA-AUTO-` с «שירה כהן» (уведомление «בקשת עסקה חדשה»)
## Шаги
1. Клиент создаёт сделку с «שירה כהן» (без депозита).
2. Провайдер: колокольчик «התראות» (`notifications-button`) → `/notifications` → фильтр «ממתין לפעולה».
3. Найти карточку «בקשת עסקה חדשה» с названием сделки; проверить, что она непрочитанная (голубой фон).
4. Нажать на карточку.
5. Нажать «חזרה»; обновить страницу.
6. Клиент: `/notifications` → «ממתין לפעולה» → клик по уведомлению сделки («בקשה לאישור תשלום» / «נדרשת הפקדת כסף»).
## Ожидаемо
- Карточка: заголовок, «название · ₪сумма», пояснение «הצד השני פתח עסקה חדשה. יש לעבור על תנאי העסקה ולאשר אותם.», относительное время (F-17 AC5; текст после правки «אותו»→«אותם», перепроверка 08.10)
- Клик → `/deals/<id>` именно этой сделки (её название на экране) (тикет «מה רצוי»: «פותחת את מסך העסקה הרלוונטי»; Criteria)
- После возврата карточка прочитанная (белый фон) и остаётся такой после обновления (тикет «מה רצוי»: «מסמנת אותה כנקראה»; перепроверка 08.10 «назад/reload ✅»)
- То же у клиента для «בקשה לאישור תשלום» и «נדרשת הפקדת כסף» (тикет «מה קיים»: «אצל שני הצדדים»)
## Не проверяем
- Уведомление «ממתין»-типа внутри фильтра «עסקאות» (находка перепроверки 08.10 по D3) — не требование тикета
