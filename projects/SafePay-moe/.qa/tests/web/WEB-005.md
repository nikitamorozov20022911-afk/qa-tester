# WEB-005: Зоны касания в вебе — слои `-hit` не меньше 44×44
- Фича/экран: таб-бар, S-11 ארנק, S-12 התראות, S-35/S-36 поиск и фильтр поставщиков, S-20 אמצעי תשלום, S-18 העברה, S-28 פרטי עסקה, S-41 דירוג, S-25 עסקה חדשה, выбор поставщика
- Тикеты: #25cd5bd027aa981b6bfa2eb2
- Роль/аккаунт: client (0500000004) — у аккаунта есть карты и сделки
- Устройство: веб 375/1440 (Chrome); слои `-hit` фиксированного размера, от ширины не зависят
- Тип: позитив (доступность, размер касания)
- Предусловия: сохранённая веб-сессия client; только просмотр — ничего не удалять, не отправлять; сделка — первая в «עסקאות»
## Шаги
1. `/wallet`: вкладки таб-бара (`tab-*-hit`), колокольчик (`notifications-button-hit`).
2. `/notifications`: чипы фильтра.
3. `/providers`: поиск/очистка (`provider-search-submit`, `provider-search-clear` — после ввода текста), кнопка фильтра; открыть фильтр → чипы и «נקה/י הכל» (`provider-filter-clear`).
4. Способы оплаты: значок удаления карты (`payment-card-*-delete`) — не нажимать.
5. `/wallet/transfer`: ввести цифры в поле телефона → «×» (`transfer-phone-clear`).
6. Первая сделка клиента: шапка — «חזרה» (`back-button`), меню (`deal-menu`).
7. `/deals/rate?id=<первая сделка>`: звёзды `rate-star-1…5`.
8. `/deals/new`: чекбокс `clause-check-0`.
9. На каждом шаге: `boundingBox()` слоя `[data-testid$="-hit"]` контрола.
## Ожидаемо
- Каждый слой `-hit` из списка: ширина ≥ 44 и высота ≥ 44 (T2 тикета: «44×44 לפחות»)
- Видимый размер иконок не изменился (T2 «בלי לשנות את המראה») — сверка глазами, не в автотесте
- Исключение программиста P4 (строки согласия «פרטי כרטיס», 38) — ждёт решения дизайна, не проверяется
