# WEB-001: Оболочка веб-экспорта — <html lang="he" dir="rtl">, <title>SafePay</title>; 404 и /_sitemap → кошелёк
- Фича/экран: веб-оболочка (все маршруты) · контекст S-11 «מסך הבית — הארנק שלי»
- Тикеты: #6aabdaf745fcf2c9f2a7f36f
- Роль/аккаунт: client (0500000004); проверялось также гостем и provider
- Устройство: веб 375/1440 (Chrome)
- Тип: позитив (метаданные документа, RTL)
- Предусловия: сохранённая веб-сессия client
## Шаги
1. Получить исходный HTML (без JS, `curl`/`request.get`) маршрутов `/`, `/wallet`, `/notifications`, `/deals/edit?id=<первая сделка клиента>`.
2. Открыть `/wallet` в браузере, дождаться гидрации; перейти по вкладкам (client-side навигация) на «עסקאות», «פרופיל», колокольчик → `/notifications`.
3. Открыть несуществующий адрес `/no-such-page`.
4. Открыть `/_sitemap`.
## Ожидаемо
- В исходном HTML каждого маршрута: `<html lang="he" dir="rtl">`, `<title …>SafePay</title>` не пустой (T2 тикета)
- В DOM после гидрации и после каждой client-side навигации: `document.documentElement.lang === "he"`, `dir === "rtl"`, `document.title === "SafePay"` (T2; комментарий 07.10)
- `/no-such-page` и `/_sitemap` → переадресация на `/wallet` (главная), страница не пустая (комментарий программиста 07.10)
