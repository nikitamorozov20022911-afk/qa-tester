# WEB-002: Стрелка «חזרה» при прямом входе по URL — fallback на родительский экран
- Фича/экран: S-12 ≡ F-17 «התראות» (`/notifications`) → S-11 ארנק; выборка экранов со стрелкой назад
- Тикеты: #6aabdaf745fcf2c9f2a7f370
- Роль/аккаунт: client (0500000004)
- Устройство: веб 375/1440 (Chrome)
- Тип: позитив (навигация без истории)
- Предусловия: сохранённая веб-сессия client; каждый экран открывается в новой вкладке (пустая история)
## Шаги
1. Новая вкладка → прямой вход `/notifications` → нажать «חזרה» (`[data-testid=back-button]`).
2. То же для `/wallet/load`, `/wallet/transfer`, `/profile/edit`, `/deals/new`.
3. Из приложения: `/wallet` → колокольчик → `/notifications` → «חזרה».
## Ожидаемо
- `/notifications` → `/wallet` (T2: «חץ החזרה מחזיר לארנק … כ-fallback כאשר אין היסטוריה»)
- `/wallet/load` → `/wallet`, `/wallet/transfer` → `/wallet`, `/profile/edit` → `/profile`, `/deals/new` → `/deals` (комментарий 07.10 «בכל המסכים»)
- При обычной навигации «חזרה» возвращает на предыдущий экран (`/wallet`)
- Экран «התראות» открывается с фильтрами «הכל / ממתין לפעולה / עסקאות / ארנק» (S-12 AC1)
- Не проверяется: «יצירת פרופיל» (стрелка выходит из аккаунта — разрушает общую сессию)
