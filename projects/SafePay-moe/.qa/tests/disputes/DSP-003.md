# DSP-003: Вкладка «מחלוקת» (AI, ждём вторую сторону) — нет кнопки без действия
- Фича/экран: מחלוקות · S-28 «פרטי עסקה», вкладка «מחלוקת» (AC11)
- Тикеты: #7be825aa
- Роль/аккаунт: client (0500000004) и provider (0500000005)
- Устройство: mobile 375×812 и desktop 1440×900
- Тип: позитив / регресс бага
- Предусловия: клиент только что открыл спор с גישור AI, поставщик ещё не ответил (статус «ממתין לאישור הצד השני»), предложения нет
## Шаги
1. Клиент: `/deals/<id>?tab=dispute` (и ещё раз после обновления страницы).
2. Осмотреть нижнюю панель.
3. Поставщик: та же сделка → вкладка «מחלוקת».
## Ожидаемо
- Карточка «מחלוקת עם גישור AI», чип «ממתין לאישור הצד השני»; «פרטי המחלוקת» с סיבה/הסבר; блок «קבצים שצורפו למחלוקת» (S-28 AC11)
- Внизу нет кнопки «צפייה במחלוקת» и нет «צפייה בהצעת הגישור» — только круглая кнопка чата (#7be825aa «מה רצוי»: «שלא מוצג כפתור ללא פעולה… ואין עדיין הצעה»; коммент программиста)
- У поставщика на вкладке «מחלוקת» тоже нет «צפייה במחלוקת» (вместо неё карточка согласия, см. DSP-006)
- Замечание 03.10 (не баг тикета): после «אישור» у поставщика кнопка «צפייה במחלוקת» мелькает ~0.5 с — в автотест не включаем.
