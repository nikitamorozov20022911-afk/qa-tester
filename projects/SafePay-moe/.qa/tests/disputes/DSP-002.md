- Фича/экран: מחלוקות · S-42 → S-45 «מחלוקת עם בורר אנושי» / S-43 «מחלוקת עם גישור AI»
- Тикеты: #6a86f7c3
- Роль/аккаунт: client (0500000004)
- Устройство: mobile 375×812 и desktop 1440×900

- Предусловия: как в DSP-001 (сделка в נאמנות без спора)
## Шаги
1. Открыть сделку → «···» → «פתיחת מחלוקת».
2. Осмотреть вариант «פתיחת מחלוקת בעזרת בורר אנושי».
3. Нажать его → открылся экран формы. Нажать «ביטול» (форму не отправлять).
4. Снова открыть шит → «פתיחת מחלוקת בעזרת AI» → открылся экран формы AI. Вернуться назад, не отправляя.
## Ожидаемо
- В шите нет чипа «בתשלום · ₪150» и вообще текста «₪150» / «בתשלום ·» — у варианта только заголовок и подпись (реджект #6a86f7c3, «מצב רצוי»; Figma 6072-12264)
- Экран «מחלוקת עם בורר אנושי» содержит карточку «עלות שירות בורר אנושי» с суммой «₪150» (коммент программиста 01.10 + реджект: «עלות הבורר מוצגת רק במסך הבא»). Сумма ₪150 временная — меняется по решению #6a86f7d1, тогда обновить кейс.
- Вариант AI ведёт на экран «מחלוקת עם גישור AI» (регресс, черновой чек-лист п.6)
- Никаких запросов на создание спора (форма не отправлена).
