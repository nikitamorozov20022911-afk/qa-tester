## Ожидаемо
- Шит клиента: заголовок «אישור תשלום והעברת הכסף», текст «לאחר שליחת הבקשה, הצד השני יקבל התראה ויוכל לאשר את קבלת הכסף.», та же галочка; кнопка неактивна без галочки (F-42; «מה רצוי» 2–4)

- Сделка только для чтения: нет «פתיחת מחלוקת», «בקשה לקבלת הכסף», «אישור קבלת השירות ותשלום»; меню клиента «···» — только «דירוג נותן השירות»; у поставщика меню «···» нет (F-29 AC8)

- «היתרה שלך» поставщика выросла на сумму сделки («מה רצוי» 7 — «מעביר את הכסף בפועל»)
