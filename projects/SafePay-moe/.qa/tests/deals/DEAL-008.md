1. Закрыть приложение из app switcher, открыть → «עסקאות» в нижнем баре. ×3 (запись экрана).
2. Повторный визит: «עסקאות» → «הארנק שלי» → «עסקאות» (и через другие вкладки). ×3.
3. Офлайн (режим полёта) → открыть «עסקאות» → «נסו שוב» после включения сети.
## Ожидаемо
- Ни в один момент нет пустого белого экрана: сразу заголовок «עסקאות» + «מעקב אחרי התשלומים המוגנים שלך» и skeleton/индикатор, затем список (тикет «מה רצוי»; S-24 AC1)
- Статус-бар читаем (белый на тёмной шапке) (тикет «מה רצוי»; Figma 6075-3512)
- Повторный заход в уже открытую вкладку — не белый (реджект rej_bfdd748c…, коммент программиста 25.10)
- После загрузки: чипы «הכל / דורש פעולה / פעילות / במחלוקת / הושלמו», группы, строки (название, вторая сторона, сумма, чип); вкладка «עסקאות» активна (S-24 AC3–5, AC7)
- Ошибка загрузки: «לא הצלחנו לטעון את העסקאות» + «נסו שוב»; после включения сети повтор загружает список (тикет «מה רצוי»)
## Только на нативном iPhone (@ios-native)
- Холодный старт приложения, читаемость статус-бара, режим полёта — на устройстве. В вебе: свежая загрузка страницы, повторный заход через бар, офлайн через блокировку запроса.
## Не проверяем
- Длительность загрузки («~14 с» / «~1 с») — требование по времени, не автоматизируем.
