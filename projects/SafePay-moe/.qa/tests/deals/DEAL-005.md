# DEAL-005: Чужая сделка по ссылке — «העסקה לא נמצאה.»; без сети — «לא הצלחנו לטעון את העסקה.» + «נסו שוב»
- Фича/экран: פרטי עסקה (диплинк)
- Тикеты: #e312b6 ([deals] זר שפותח קישור לעסקה…)
- Роль/аккаунт: provider (0500000005), сделка между другими пользователями (id — qa-auto-created.jsonl)
- Устройство: Android
- Тип: негатив (доступ, сеть)
- Предусловия: авиарежим включает/выключает пользователь
## Шаги
1. `adb shell am start -a android.intent.action.VIEW -d "safepay://deals/<чужой id>" il.co.safepay.app`
2. Повторить в авиарежиме (3 раза).
3. Включить сеть → «נסו שוב».
## Ожидаемо
- Онлайн: «העסקה לא נמצאה.», данные сделки не видны
- Офлайн: «לא הצלחנו לטעון את העסקה.» и «נסו שוב»
- После сети «נסו שוב» → «העסקה לא נמצאה.»
- Подэкраны сделки по ссылке не открываются вообще (ограничение диплинков, не баг тикета)
