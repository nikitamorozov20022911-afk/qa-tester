# PRF-001: «צילום תעודת זהות» — камера / галерея / «ביטול», снимок в поле, «הסרת התמונה»
- Фича/экран: עריכת פרופיל → צילום תעודת זהות
- Тикеты: #c41917 (עיצוב מוקאפ: צילום תעודת זהות)
- Роль/аккаунт: client (0500000004)
- Устройство: Android
- Тип: позитив
- Предусловия: снимок с камеры делает пользователь; галерею и личные фото НЕ скриншотить; снимок не сохранять
## Шаги
1. פרופיל → «עריכת פרופיל» → «צילום תעודת זהות».
2. Проверить шит: «צילום במצלמה», «בחירה מהגלריה», «ביטול»; «ביטול» закрывает шит.
3. «צילום במצלמה» → снимок (пользователь) → подтвердить.
4. «הסרת התמונה».
## Ожидаемо
- Снимок появляется в поле удостоверения
- «הסרת התמונה» очищает поле
- Не сохранять профиль со снимком (тестовые данные)
