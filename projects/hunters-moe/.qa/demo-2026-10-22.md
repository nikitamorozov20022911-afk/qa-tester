## Сценарии

**1. Хед-хантер → компания, полный профиль**
claude-test: «שיתופים» → DEMO-1 → отправить **DEMO-1 נועה לוי** → «פרופיל מלא».
demo-company-1 (инкогнито): колокольчик → DEMO-1 → кандидаты → открыть **из списка** («נצפה») → принять.
claude-test: уведомление и новый статус.

**2. Анонимная отправка**
claude-test: DEMO-1 → отправить **DEMO-2 יונתן כהן** → «פרופיל אנונימי».
Компания видит только AI-описание → «שאלות נוספות» → хед-хантер отвечает в «ממתינים» → компания просит полный профиль / NDA → хед-хантер одобряет → компания видит полный профиль → принимает.

**3. Кандидат подаёт заявку сам**
demo-talent-1 (משה כהן): вакансии → DEMO-1 → подать заявку.
Компания: уведомление → посмотреть → решение. Кандидат: статус у себя.

**4. Хед-хантер ↔ хед-хантер**
demo-hunter-2: «שיתופים» → DEMO-4 (комиссия 30%) → отправить **DEMO-4 דניאל שפירא**.
claude-test: «המשרות שלי» → DEMO-4 → кандидаты → статус. Дополнительно: «הד-האנטרים» → чат.

**5. Тендер (вживую, бесплатно)**
demo-company-1: «+ פרסום» → מכרז → назвать «DEMO-5 · …» → опубликовать.
claude-test или demo-company-6 (HR): тендеры → подать предложение. Компания: выбрать.

**6. Админ**
demo-admin: /admin/users → пользователи и роли → вакансии, заявки (видно всё созданное выше) → цены, FAQ, журнал. Блокировка и разблокировка — только на demo-talent-7.

**7. FREE против PLUS**
demo-hunter-3 (FREE) против claude-test (PLUS): тот же экран, разные возможности.

## Не делать на созвоне
- Не регистрировать новых пользователей (лимит писем, застревание в статусе «ממתין»).
- Не проводить реальную оплату. Публикация вакансий и тендеров компании сейчас бесплатна («בתקופת ההשקה»).
- Кандидата компании открывать из списка, не по прямой ссылке.
- Показывать на десктопе, на иврите.
