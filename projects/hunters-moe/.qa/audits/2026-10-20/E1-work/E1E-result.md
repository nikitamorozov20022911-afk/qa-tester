## Вопросы к PM

## Карта флоу: модерация в админке (как на сайте фактически)
```
Публикация (хедхантер/компания) ──(без модерации)──> вакансия «פעיל» сразу
   admin: /admin/jobs?q=J-xx → строка (номер, название, владелец+email, статус, дата, кол-во кандидатов, «צפייה», combobox «שינוי סטטוס המשרה»)
       → /admin/jobs/<id>: все поля + счётчики подач по статусам + «העברה לסטטוס: מקודם/לא פעיל/פג תוקף/בארכיון» + бесплатные услуги (קידום/הפצה/הארכה «מתן ללא עלות») + «צפייה באתר»
Тендер (компания) ──(без модерации)──> «פעיל»
   admin: /admin/tenders?q=T-xx → /admin/tenders/<id>: поля + список предложений (кто, сумма, статус, текст) + «העברה לסטטוס: סגור/פג תוקף/נדחה» + «הפצה להד האנטרים»
Подача (хедхантер/талант) → статусы меняют стороны
   admin: /admin/applications?q=… → строка (вакансия, подавший, имя кандидата, גלוי/אנונימי, статус, дата, «עדכון ידני»)
       ✗ карточки подачи нет (история, ответы, NDA не видны)
NDA (подпись при подаче) → admin: /admin/users/<id> → «הסכמי סודיות (NDA)» у обеих сторон, «צפייה» = файл подписи
Окно оплаты (открыто, не оплачено) → admin: /admin/users/<id> → «תשלומים»: заказ «ממתין»   (/admin/payments = 404)
Жалоба → /admin/reports → статус פתוח/בטיפול/טופל (E1C)
Журнал /admin/log (?area=users|jobs|tenders|applications|reports|messages|pricing|content, ?page=N; ?q= игнорируется)
   = только действия админов; действий пользователей нет
```
