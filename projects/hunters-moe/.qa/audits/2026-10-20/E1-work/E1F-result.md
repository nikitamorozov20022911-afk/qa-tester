## Карта флоу: решения по тендеру и жизненный цикл (как на сайте)

```
Хедхантер/HR: /tenders → T-58 → форма «הגשת הצעה למכרז» (₪, הערות, ✓ אישור)
   ├─ лимит есть → «נותרו לכם N מתוך 2» → «הגשת הצעה» → «ההצעה הוגשה בהצלחה» → «ממתין לתשובה מהחברה»
   └─ лимит исчерпан → «ניצלתם את 2 ההצעות… החל מ-01.11» (формы нет; FREE → «שדרוג ל-PLUS», E1B)
        ↓
Компания: колокольчик «התקבלה הצעה חדשה למכרז „…”» → /tenders/<id> → «הצעות שהוגשו (N)»
   → раскрыть строку → [אישור ההצעה] [דחיית ההצעה] [שליחת הודעה]
        ├─ אישור (1 клик, без подтверждения) → строка «אושרה», кнопки решения исчезают
        │     → хедхантер: колокольчик «איזה כיף! <חברה> אישרו את ההצעה שלכם, שוחחו בצ’אט עכשיו.» → тендер «ההצעה שלכם אושרה… ההמשך יתואם בצ׳אט»
        │     → «ההצעות שלי»: бейдж «ההצעה אושרה»
        │     → тендер остаётся «פעיל», остальные предложения «ממתין לתשובה», можно одобрить ещё
        ├─ דחייה → (не проверено: не на ком) ожидаемо «נדחתה» + «לצערנו <חברה> לא אישרו את ההצעה שלכם»
        └─ שליחת הודעה → /messages?c=<id> → «עדיין אין שיחות» (403, известно)
Контакты сторон после одобрения не раскрываются; канал связи — только чат.
Закрытие тендера: из UI нет (C3 #1); после одобрения сам не закрывается; «סגור» у старых T-51/T-52 появляется иным путём (админ/срок?).

Вакансия (владелец): окно вакансии → «פעולות משרה» → «העברה לארכיון» → «להעביר את המשרה לארכיון?» [חזרה | הארכה בשבועיים | העברה לארכיון]
   → тост «המשרה הועברה לארכיון» → статус «בארכיון», `/my-jobs?archived=1`
   → отправитель: ссылка/колокольчик → 404; подачи и статусы у отправителя больше не видны
```
