Главное:
1. Вся цепочка между двумя хедхантерами работает: публикация → подача анонимно → «נצפה» → доп. вопрос → ответ → запрос полного профиля → одобрение / отказ → «התקבל/ה לעבודה» / «נדחה». Статусы у обеих сторон совпадают на каждом шаге. Уведомления приходят обеим сторонам и (кроме «новой подачи») ведут прямо в карточку подачи.
2. **Приватность в порядке**: имени, телефона, email, LinkedIn и места работы Alpha/Bravo/Charlie у владельца нет ни на экране, ни в HTML/RSC, ни в сетевых ответах. Проверено 3 раза для Alpha до раскрытия, для Bravo после отказа и для Charlie. Supabase REST на чтение отдаёт `[]` / 403. Прямой URL `/applications/<id>` нераскрытой подачи даёт владельцу 404.
3. **NDA вакансии бесплатный и подписывается** (текст + подпись мышью, «יש לחתום כדי להמשיך» без подписи), виден в «הסכמים» у обеих сторон («שנתיים מתום התהליך»). Но владелец **не получает уведомления о подписании** (§73 AC04). В подаче **нет статусов** «Waiting for NDA / NDA Signed» и вообще отметки про NDA (§06 AC01). **Явной кнопки отказа** на экране NDA нет (§46 AC04).
4. У PLUS-отправителя «לחייב NDA» стоит **₪35**, как у FREE. Окно оплаты открыто и закрыто, не оплачено ⛔.
5. Как и у компании (C3 #5): у хедхантера-владельца нет «מתאים / לא מתאים» и «בקשת NDA».

## Карта флоу (как на сайте фактически)

**F1. Публикация вакансии хедхантером**
`+ פרסום → פרסום משרה → שלב 1 (поля, NDA לא/כן) → שלב 2 שאלות סינון → «המשרה שלכם פורסמה בהצלחה» → upsell «לא תודה» → J-81 פעילה (14 дней) → у других хедхантеров в /collaborations; «משרה חדשה בתחום שלכם» только при совпадении תחום`

**F2. Добавление кандидата**
`המועמדים שלי → + הוספה → אנונימי/גלוי + поля → «המשך» (кандидат уже сохранён) → שלב 2 כותרת + תקציר AI → «סיום» → «המועמד נוסף בהצלחה»`

**F3. Анонимная подача**
`панель вакансии → список «הגשת מועמד» → «הגשה» у кандидата → [если NDA вакансии: экран NDA → подпись → «חתימה וסיום»] → מלא/אנונימי + NDA (₪35 / חינם) → шаг 2: תקציר AI, חוזקות, ответы, שכר, אזור, הערות → «סיום והגשה» → «המועמד/ת הוגש/ה בהצלחה», «נשלח» → владельцу «התקבלה מועמדות חדשה» (ведёт на вакансию)`

**F4. Вопросы**
`владелец: карточка → «שאלות נוספות» (до 3) → «שליחת השאלות» → «נשלחו שאלות» → отправителю «…שאלו שאלות על <кандидат>» → карточка → «שליחת התשובות» → «התקבלו תשובות» → владельцу «התקבלו תשובות על המועמד/ת» → в карточке «השאלות שלכם» с ответом; в «ממתינים → קיבלתם תשובות»`

**F5. Запрос и раскрытие профиля**
`владелец: «בקשת פרופיל מלא» → «התבקש פרופיל מלא» → отправителю «…ביקשו את הפרופיל המלא של <кандидат>» → карточка: «שליחת פרופיל מלא» | «דחיית הבקשה»`
`  ├ одобрение → «פרופיל מלא אושר» → владельцу «הפרופיל המלא של <имя> … התקבל» → /applications/<id> (имя, телефон, email, LinkedIn; без места работы)`
`  └ отказ → «פרופיל מלא נדחה» → владельцу «הבקשה לפרופיל המלא של המועמד/ת … נדחתה»; PII не раскрыта; /applications/<id> → 404`

**F6. NDA**
