# C1 · Соответствие документации — гость и публичные страницы
Волна 1 (параллельно с C2–C5, M1). Сначала прочитать `_rules.md`.

**Auth-файлы:** никаких (только гость, без логина). Можно запускать в любое время.

**Пункты спецификации:**
- §01 респонсивность публичных страниц (десктоп 1440, планшет 768, телефон 375 — только базовая раскладка; детальная мобилка — в M1)
- §02 мультиязычность и RTL: he/en/ru/ar на всех публичных страницах (переключатель, `<html lang dir>`, нет текста другого языка)
- §07 приватность для гостя: закрытые URL (/profile, /my-jobs, /collaborations/<id>, /admin, /messages, /tenders, /hunters …) не открываются без входа; ничего личного не видно
- §09 главная, §10 /headhunters, §11 /organizations, §12 /talents — каждый AC: блоки, CTA, ссылки, тексты
- §84 FAQ на лендинге (/headhunters#faq) — у гостя; /faq → /login задумано
- Вход: /login, /forgot-password (без реальной смены пароля), ссылки Google/LinkedIn (не входить), reCAPTCHA-подпись, юр. страницы /terms /privacy /accessibility (известно: пока заглушка «בהכנה»)
- §13/§16/§18/§19 регистрация — только экраны до отправки письма (форма, выбор роли, валидация). Не регистрироваться до конца (блокер: письмо → localhost).
- Футер, шапка, 404 для несуществующих адресов.

**Miro:** экраны лендингов и регистрации — сверить состав и порядок.
