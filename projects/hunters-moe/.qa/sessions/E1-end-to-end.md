**Сценарии (каждый — по шагам, на каждом шаге проверить обе стороны и колокольчик):**
1. §41 анонимная кандидатура от начала до конца: хедхантер публикует вакансию → другой хедхантер подаёт анонимного кандидата → владелец смотрит («נצפה») → §43 вопросы → §40 запрос полного профиля → раскрытие / отказ → статусы §06 → «התקבל/ה לעבודה» / «נדחה» → уведомления §73 → админка видит всё (§81).
2. §36 поэтапное раскрытие + §45/§46 NDA: подача с NDA (если NDA платный — ⛔ отметить и остановиться на оплате), подписанное NDA в «הסכמים» у обеих сторон, срок 2 года.
3. Компания: тендер → предложения хедхантеров → выбор/отклонение → закрытие тендера (§33, §35, §66).
4. Талант: отклик на вакансию компании → компания смотрит → статус → уведомление таланту (§37, §52, §74).
5. §82 → §83: жалоба с сайта → в админке → (уведомление админу — известно: реджект #62222f).
6. Miro: Candidacy Flow и Work Representation — пройти все ветки, которые можно без оплаты и без новых аккаунтов; расхождения записать.
7. §07 приватность: на каждом шаге проверить, что анонимный кандидат/талант не раскрывается раньше времени (имя, телефон, email, файлы, через API-ответы тоже).
