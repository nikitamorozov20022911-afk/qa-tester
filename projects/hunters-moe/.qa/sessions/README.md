# Прогон 2026-10-20 — как запускать сессии

Каждая строка — отдельная сессия Claude Code в папке `/Users/avielshnaider/hunters-moe` (у каждой свои субагенты).
**Сессии одной волны идут параллельно** — у них не пересекаются auth-файлы. **Следующую волну запускать, когда закончилась предыдущая** (иначе две сессии возьмут один auth-файл → Supabase сбросит вход, и обе сломаются).

| Волна | Код | Что проверяет | Auth-файлы |
|---|---|---|---|
| 1 | C1 | Соответствие док.: гость, публичные страницы, языки | — |
| 1 | C2 | Соответствие док.: хедхантер PLUS/FREE | hunter_plus, hunter_free_2 |
| 1 | C3 | Соответствие док.: компания и HR | company, company_6, hunter_free |
| 1 | C4 | Соответствие док.: талант | talent, talent_2, company_2 |
| 1 | C5 | Соответствие док.: админка | admin |
| 1 | M1 | Мобилка: гость | — |
| 2 | N1 | Негатив: гость (можно и в волне 1) | — |
| 2 | N2 | Негатив: хедхантер | hunter_plus, hunter_free_2 |
| 2 | N3 | Негатив: компания и HR | company, company_6, hunter_free |
| 2 | N4 | Негатив: талант | talent, talent_2, company_2 |
| 2 | N5 | Негатив: админка | admin |
| 3 | E1 | Сквозные сценарии между ролями + Miro | все |
| 4 | M2 | Мобилка: залогиненные роли | все |
| 4b | F1 | Сайт против Figma: поиск различий (экраны всех ролей) | все |
| 5 | R | Сводный отчёт, черновики багов, handoff | — |

Ускорение: N-сессию одной роли можно запускать сразу, как закончилась C-сессия той же роли (N2 после C2 и т.д.) — не дожидаясь всей волны.

## Текст для запуска (вставить в новую сессию, заменить КОД и файл)
```
Прогон 2026-10-20, сессия <КОД>. Прочитай .qa/sessions/_rules.md и .qa/sessions/<ФАЙЛ>.md и выполни бриф полностью, со своими субагентами. Используй только auth-файлы из брифа. Доску mifrat не трогай. В конце — отчёт в .qa/audits/2026-10-20/<КОД>.md и резюме по-русски.
```

Файлы брифов: `C1-guest.md`, `C2-headhunter.md`, `C3-company-hr.md`, `C4-talent.md`, `C5-admin.md`, `M1-mobile-guest.md`, `N1-guest.md`, `N2-headhunter.md`, `N3-company-hr.md`, `N4-talent.md`, `N5-admin.md`, `E1-end-to-end.md`, `M2-mobile-roles.md`, `F1-figma.md`, `R-report.md`.
