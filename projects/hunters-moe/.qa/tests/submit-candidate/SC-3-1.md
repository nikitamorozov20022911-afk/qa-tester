# SC-3-1: Окно подачи на тендер (HR) — нейтральные строки о кандидате, шаги 1→2 без отправки

- Тикеты: #f2c5ce
- Роль/аккаунт: company_6 (demo-company-6, HR)
- Устройство: desktop 1440×900
- Тип: позитив (тексты), read-only — финальную «הגשה»/«סיום והגשה» не нажимать
- Предусловия: T-44 /tenders/65d2b6a1-234b-47db-9984-b4dcbe984452; в панели есть кандидат (в тикете «מיכל לוי»).
## Шаги
1. T-44 → в панели у кандидата «הגשה» → шаг 1 (анонимно/полный) → «המשך».
2. Прочитать заголовок окна, блок «הגשה דיסקרטית»/«הגשה אנונימית», подписи полей, боковой блок. Закрыть без отправки.
3. Повторить с «פרופיל מלא».
## Ожидаемо
- Заголовок «הגשת מועמד/ת: <имя>»; «…ללא הפרטים האישיים של המועמד/ת»; поле «תקציר המועמד/ת»; боковой блок «סטטוס מועמד/ת». (источник: #f2c5ce «מה רצוי»)
- Нет муж.-только форм: «המועמד» без «/ת», «הגשת מועמד:», «סטטוס מועמד» без «/ת». (решение 2026-10-19 (context.md): о кандидате нейтрально через «/», муж.-только — реджект)
