# JUD-1-2: Повторная рассылка — предупреждение до траты; «ביטול» ничего не тратит
- Фича/экран: job-upgrade-distribution / «שדרוג משרה» → предупреждение «להפיץ שוב את המשרה?»
- Тикеты: #ae3aed
- Роль/аккаунт: hunter_plus (claude-test)
- Устройство: desktop 1440×900
- Тип: позитив, read-only (@prod-safe). НИКОГДА не нажимать «הפצה נוספת».
- Предусловия: как JUD-1-1.
## Шаги
1. Открыть «שדרוג משרה» на J-70; запомнить X из «נותרו X מתוך 5 הפצות חינם החודש».
2. Выбрать карточку «שירותי הפצה» → кнопка «הפעלת ההפצה» → нажать.
3. Прочитать предупреждение. Нажать «ביטול».
4. «לא תודה»; снова открыть «שדרוג משרה» на J-70, прочитать счётчик; «לא תודה».
## Ожидаемо
- Шаг 3: окно «להפיץ שוב את המשרה?», текст «המשרה כבר הופצה ב-22.10.2026. הפצה נוספת תנצל הפצה חינמית נוספת (נותרו X מתוך 5). להמשיך?» (X = из шага 1), кнопки «ביטול» и «הפצה נוספת» (источник: «מה רצוי» п.2).
- После «ביטול» предупреждение закрыто, ничего не активировано; счётчик в шаге 4 = X (не уменьшился).
- Риск: если предупреждение пропадёт (регресс), клик в шаге 2 потратит 1 бесплатную рассылку и разошлёт уведомление демо-хантерам — сообщить.
- Не автоматизируем: «הפצה נוספת» (трата рассылки, Т3) — проверено вручную как наличие кнопки.
