- Роль/аккаунт: hunter_free (demo-hunter-2) → company_2 (demo-company-2) → hunter_free → company_2 (multi-role)
- Устройство: desktop 1440×900
- Тип: позитив, меняет данные (QA-AUTO)
- Предусловия: J-135 «QA-AUTO 2110 cand» активна; у hunter_free есть свободный лимит подач.
## Шаги
