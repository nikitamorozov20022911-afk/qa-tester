# LF-4-1: Logged-in user sees «החשבון שלי» (לוח בקרה / הפרופיל שלי / הודעות) in the public footer
- Фича/экран: landing-footer / публичные страницы у вошедшего
- Тикеты: #41dc55 (299263bd150d7ff2b841dc55)
- Роль/аккаунт: talent (demo-talent-1), hunter_plus (claude-test); при ручной проверке также talent_2, hunter_free_2
- Устройство: desktop 1440x900
- Тип: позитив, read-only
- Предусловия: вход сохранённой сессией; staging
## Шаги
1. Под каждой ролью открыть /, /about, /headhunters, /organizations, /talents (he).
2. Прокрутить к подвалу; дождаться, пока видны все 12 ссылок подвала (до гидрации гостевые ссылки — невидимая заглушка, их не считать).
3. Прочитать колонку «החשבון שלי» и все ссылки подвала.
4. Открыть каждую из трёх ссылок аккаунта.
## Ожидаемо
- В подвале заголовок «החשבון שלי» и ссылки «לוח בקרה», «הפרופיל שלי», «הודעות»; видимых ссылок подвала ровно 12.
- Нет видимых ссылок «הרשמה» / «התחברות», нет видимой ссылки на /login или /register; нет заголовка «הצטרפות».
- Каждая ссылка аккаунта открывает страницу со статусом 200, не /login.
(источник: «מה רצוי» #41dc55 «For a logged-in user the footer on public pages shows the same account links as in the cabinet («לוח בקרה», «הפרופיל שלי», «הודעות») instead of «הרשמה / התחברות»»)
Примечание: невидимая гостевая заглушка до гидрации (0.2–3.4 с) — находка 02.11, не баг тикета; «הצטרפות לניסיון חינם» у вошедшего на /about — находка, не проверяем.
