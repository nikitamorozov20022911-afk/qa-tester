# LF-3-3: Every footer link opens an existing page (no 404 / soft-404)
- Фича/экран: landing-footer
- Тикеты: #a953ab (6a719ec66585a431d2a953ab)
- Роль/аккаунт: guest (без входа)
- Устройство: desktop 1440x900
- Тип: позитив, read-only
- Предусловия: гость; staging https://hunters-sooty.vercel.app; языки he `/`, en `/en`, ru `/ru`, ar `/ar` (или переключатель в шапке)
## Шаги
1. Для he/en/ru/ar открыть / и прокрутить к подвалу.
2. Собрать все внутренние ссылки подвала (тот же домен; без mailto:/tel: и внешних соцсетей — их проверяет LF-1-2), уникальные по href.
3. Открыть каждую ссылку (page.goto или клик), дождаться загрузки.
## Ожидаемо
- Ответ документа — HTTP 200 (не 4xx/5xx).
- На странице есть видимый H1 с непустым текстом; H1 и заголовок не содержат «404», «לא נמצא», «Not found», «не найдена», «غير موجود» (нет soft-404).
- Ни одна ссылка подвала не имеет href «#» / пустого href.
- Ожидаемые пункты (программист 26.10): headhunters, organizations, talents, join / log in, about, contact, FAQ — каждый ведёт на реальную страницу.
