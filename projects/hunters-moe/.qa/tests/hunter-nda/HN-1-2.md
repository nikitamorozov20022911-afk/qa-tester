# HN-1-2: Задержанная подача A на вакансию B после отказа B — «בוטל · ה-NDA נדחה», колокольчик «…ולכן ההגשה לא נשלחה»
- Фича/экран: hunter-nda / панель «הגשת מועמד/ת» вакансии B у A, колокольчик A
- Тикеты: #d0bc44
- Роль/аккаунт: A = hunter_plus (claude-test), B = владелец вакансии хед-хантер без NDA с A
- Устройство: desktop 1440×900
- Тип: позитив, два пользователя, создаёт данные (подача QA-AUTO кандидата → отменяется отказом)
- Предусловия: пара без NDA; активная вакансия B (проверено на J-150 «QA 0711 משרה האנטר 3»); QA-AUTO кандидат A, не поданный на неё.
## Шаги
1. A: вакансия B → «הגשת <кандидат> למשרה» → баннер «הגשה ראשונה להד האנטר הזה…» → «פרופיל אנונימי», «אין צורך ב-NDA» → «המשך» → «סיום והגשה».
2. B: колокольчик/чат → «סירוב» на запрос NDA.
3. A: вакансия B → панель; колокольчик.
## Ожидаемо
- В панели A у кандидата «בוטל · ה-NDA נדחה» и причина «<B> סירבו לאשר את ה-NDA…», не «נשלח/ה». (источник: #d0bc44 «מה רצוי» п.2)
- Колокольчик A: «…ולכן ההגשה לא נשלחה». (п.3 — для подачи)
- Находка (не проверяется): в списке кандидатов A «נשלח/ה», пока карточка «ממתין/ה ל-NDA»; счётчик B «מועמדים שהוגשו» 1 при пустом списке.
