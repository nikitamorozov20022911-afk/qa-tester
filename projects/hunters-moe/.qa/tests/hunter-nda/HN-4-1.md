# HN-4-1: Хед-хантер без NDA → вакансия владельца → «שליחת הודעה»: чат сразу, бар ожидания, заполненный NDA до одобрения; владелец видит «אישור ה-NDA»/«סירוב»; после одобрения срок +3 месяца
- Фича/экран: hunter-nda / /collaborations/<id> → /messages; /profile?tab=agreements
- Тикеты: #0224f4, #1d9069
- Роль/аккаунт: хед-хантер без NDA с владельцем (на 08.11 проверено claude-test ↔ company demo-company-1 «סופר פארם», J-148) + владелец вакансии (компания или хед-хантер)
- Устройство: desktop 1440×900
- Тип: позитив, два пользователя, меняет данные (запрос NDA; одобрение расходует пару на 3 месяца)
- Предусловия: пара без NDA в силе. После 08.11 claude-test↔סופר פארם одобрено до 08.02.2027 → нужна другая пара.
## Шаги
1. Хед-хантер: вакансия → «מנהל/ת המשרה» → «שליחת הודעה».
2. Хед-хантер: «צפייה ב-NDA».
3. Владелец: тот же чат → бар запроса, «צפייה ב-NDA».
4. Владелец: «אישור ה-NDA». Оба: поле активно. Хед-хантер: «הסכמים».
## Ожидаемо
- Шаг 1: сразу открыт чат (без шага подписи); бар «ממתינים לאישור של <владелец> ל-NDA. אפשר לכתוב אחרי האישור.»; «כתיבת הודעה» disabled. (#1d9069 AC2; коммент программиста)
- Шаг 2: «NDA סטנדרטי» → «פרטי ההסכם»: «שמכם: <хед-хантер>», «הצד השני: <владелец>», «בנושא: <вакансия>», «חברה / מפרסם/ת המשרה: <владелец>», «תאריך: <дата>», «תוקף: 3 חודשים מיום האישור של הצד השני». (#0224f4 AC2, реджект п.2)
- Шаг 3: «<хед-хантер> פנו אליכם, וה-NDA הסטנדרטי ביניכם כבר חתום מצדם. כדי לכתוב זה לזה, אשרו אותו (בתוקף ל-3 חודשים).» + «אישור ה-NDA», «סירוב», «צפייה ב-NDA»; поле владельца disabled. (#0224f4 AC3, AC5)
- Шаг 4: бар исчезает, поле активно у обоих; в «הסכמים» строка владельца: «תאריך חתימה» = сегодня, «תוקף» = сегодня + 3 месяца. (AC6)
