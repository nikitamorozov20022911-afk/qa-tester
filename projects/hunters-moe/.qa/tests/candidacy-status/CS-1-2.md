# CS-1-2: Компания: статусы кандидата через косую черту (список вакансии и меню статуса)
- Фича/экран: candidacy-status / drawer вакансии «מועמדים שהוגשו» + /applications/<id>
- Тикеты: #3973c6
- Роль/аккаунт: company_2 (demo-company-2)
- Устройство: desktop 1440×900
- Тип: copy/визуал, read-only (статус не менять, меню закрыть Esc)
- Предусловия: J-135 «QA-AUTO 2110 cand» с 8 подачами разных статусов.
## Шаги
1. «המשרות שלי» → J-135 → drawer «מועמדים שהוגשו» — прочитать статусы всех строк.
2. Открыть подачу в статусе «נצפה/תה» → кнопка статуса → прочитать пункты меню → Esc.
## Ожидаемо
- Статусы, описывающие кандидата, — только через косую черту: «נשלח/ה», «נצפה/תה», «נדחה/תה», «התקבל/ה לעבודה»; без форм «נשלח», «נצפה», «נדחה» без «/». (источник: «מה רצוי» #3973c6)
- Статусы не про кандидата остаются: «התבקש פרופיל מלא», «סגור». (מה רצוי)
- Меню статуса: «נצפה/תה», «התקבל/ה לעבודה», «נדחה/תה», «סגור».
