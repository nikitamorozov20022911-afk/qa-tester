# CT-2-2: Заявка на вакансию — владелец: запрос полного профиля, затем «מתאים/ה» → 4 строки
- Фича/экран: candidacy-timeline / «המשרות שלי» → J-49 → «מועמדים שהוגשו» → подача
- Тикеты: #cea191
- Роль/аккаунт: company (demo-company-1)
- Устройство: desktop 1440×900
- Тип: позитив, меняет статус тестовой заявки
- Предусловия: CT-2-1 (новая заявка «נשלח/ה»).
## Шаги
1. J-49 → «מועמדים שהוגשו» → открыть новую подачу.
2. «בקשת פרופיל מלא» (подтвердить, если спросит) → кнопка стала «התבקש פרופיל מלא».
3. «מתאים/ה» → подтвердить → «סומן/ה כמתאים/ה».
4. Закрыть, открыть снова из списка; прочитать «סטטוס מועמד» и статус в списке.
## Ожидаемо
- Ровно 4 строки «נשלח/ה» → «נצפה/תה» → «התבקש פרופיל מלא» → «סומן/ה כמתאים/ה», без повтора, и после повторного открытия. (источник: «מה רצוי» «The same for job applications»)
- Владельцу видны оба состояния.
