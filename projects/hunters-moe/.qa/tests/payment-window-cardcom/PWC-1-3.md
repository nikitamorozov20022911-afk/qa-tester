# PWC-1-3: Мобильный поворот 375×812 ↔ 812×375 — поля Cardcom сохраняют вёрстку
- Фича/экран: payment-window-cardcom / popup «תשלום»
- Тикеты: #43c7ff
- Роль/аккаунт: hunter_free_2 (demo-hunter-3, FREE)
- Предусловия: staging https://hunters-sooty.vercel.app; Cardcom отвечает (не 500). Окно «תשלום» открывается без списания: /profile?tab=subscription → «בחירת חבילה» → PLUS → «המשך עם החבילה שנבחרה». Если у аккаунта есть сохранённая карта — выбрать «כרטיס אשראי» (#bc3456). Никогда не вводить данные карты и не нажимать «אישור תשלום»; закрыть окно Escape.
- Устройство: mobile (iPhone 13 Mini), 375×812 ↔ 812×375
- Тип: граница/визуал, read-only
## Шаги
1. Открыть окно «תשלום» (PLUS) в портрете 375×812.
2. Повернуть: 812×375 → 375×812 → 812×375 → 375×812.
3. После каждого поворота измерить iframe #CardComCardNumber / #CardComCvv и контейнеры.
## Ожидаемо
- Ширина iframe = ширине контейнера (±1px), поля видимы (прокрутить к полю внутри окна при необходимости). (источник: «מה רצוי» — «desktop and mobile rotation»)
- Нет горизонтальной прокрутки страницы; пустые поля без красной рамки.
