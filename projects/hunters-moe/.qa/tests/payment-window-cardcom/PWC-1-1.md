# PWC-1-1: Окно «תשלום» — поля Cardcom (номер, CVV) загружаются
- Фича/экран: payment-window-cardcom / popup «תשלום» (S-22, §69)
- Тикеты: #43c7ff
- Роль/аккаунт: hunter_free_2 (demo-hunter-3, FREE)
- Предусловия: staging https://hunters-sooty.vercel.app; Cardcom отвечает (не 500). Окно «תשלום» открывается без списания: /profile?tab=subscription → «בחירת חבילה» → PLUS → «המשך עם החבילה שנבחרה». Если у аккаунта есть сохранённая карта — выбрать «כרטיס אשראי» (#bc3456). Никогда не вводить данные карты и не нажимать «אישור תשלום»; закрыть окно Escape.
- Устройство: desktop 1440×900
- Тип: позитив, read-only
## Шаги
1. Открыть окно «תשלום» для PLUS (см. предусловия).
2. Дождаться полей «מספר כרטיס» и «CVV».
## Ожидаемо
- iframe #CardComCardNumber и #CardComCvv видимы, ширина и высота > 0; внутри каждого есть поле ввода. (источник: #43c7ff «מה רצוי» — поля Cardcom работают)
- Нет текста «לא הצלחנו להתחבר לחברת הסליקה». (контекст #214b19)
- Окно закрывается Escape.
