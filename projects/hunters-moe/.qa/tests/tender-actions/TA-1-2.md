## Шаги
1. Создать обычный тендер QA-AUTO через мастер, опубликовать.
2. «•••» → «עריכת מכרז»: изменить название, сохранить.
3. «•••» → «הארכת המכרז»: новая дата +14 дней, «מכרז רגיל — ללא עלות», «אישור».
4. «•••» → «סגירת מכרז» → «ביטול»; затем снова → «סגירת המכרז».
5. «כל המכרזים» — поиск по названию.
6. «•••» → «העברה לארכיון» → подтвердить; открыть «ארכיון».
## Ожидаемо
- Новое название на карточке; новая «תאריך תוקף», без окна оплаты.
- Подтверждение «לסגור את המכרז?»; после «ביטול» — «פעיל»; после закрытия — «סגור», «המכרז סגור ואינו מקבל הצעות.», в меню только «העברה לארכיון».
- Закрытого нет в «כל המכרזים»; в «מכרזים בארכיון» — с бейджем «בארכיון». (источник: needed behavior #cf6dc1)
