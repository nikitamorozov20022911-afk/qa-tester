- Тикеты: #1866b9
- Роль/аккаунт: none (request without auth)
- Устройство: — (API)
- Тип: безопасность / негатив
- Предусловия: Supabase project ref — from the auth cookie name `sb-<ref>-auth-token` in .qa/auth/talent.json.
## Шаги
1. GET https://<ref>.supabase.co/storage/v1/object/public/documents/<any path> without auth.
2. GET https://<ref>.supabase.co/storage/v1/object/sign/documents/<any path> without token.

- (2) not 200 (token required).
