# CW-4-3: Payment window texts and coupon errors — headhunter
- Фича/экран: copywriting / Payment window texts and coupon errors
- Тикеты: #f8ec88 (ранее записан как #8ed3a0fe)
- Роль/аккаунт: hunter_plus (claude-test)
- Устройство: desktop 1440×900
- Тип: позитив + негатив (купон), read-only — оплату не подтверждать
- Предусловия: У hunter_plus есть своя вакансия с «שדרוג משרה»; цена «שירותי הפצה» > ₪0 (₪350 на 2026-10-18).
## Шаги
1. «המשרות שלי» → своя вакансия → «שדרוג משרה» → «שירותי הפצה» → «לרכישה». Откроется окно «תשלום».
2. Прочитать подпись способа оплаты и подпись чекбокса сохранения карты.
3. «קוד קופון»: оставить пустым → «אישור».
4. Ввести «QA-AUTO-WRONG» → «אישור».
5. Закрыть окно стрелкой «>» (не нажимать «אישור תשלום»).
## Ожидаемо
- В окне нет «עתידות» и нет «דיירקט»; есть «כרטיס אשראי» и «לרכישות עתידיות» (сейчас «שמירת פרטי הכרטיס לרכישות עתידיות»). (источник: «מה רצוי» #f8ec88)
- Пустой купон → сообщение «יש להזין קוד קופון». (источник: «מה רצוי»)
- Неверный купон → сообщение «קוד הקופון אינו בתוקף». (источник: «מה רצוי»)
- Окно показывает товар, сумму и «סה״כ». (§69 AC02)
