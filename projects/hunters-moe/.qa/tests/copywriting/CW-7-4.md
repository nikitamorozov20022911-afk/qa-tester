# CW-7-4: Admin tables are usable on mobile
- Фича/экран: copywriting / Admin tables are usable on mobile

- Роль/аккаунт: admin
- Устройство: mobile — iPhone 13 Mini 375×812 (Safari) + Pixel 7 412×915 (Chrome)
- Тип: позитив, read-only
- Предусловия: —
## Шаги
1. По очереди: /admin/users, /admin/jobs, /admin/tenders, /admin/applications, /admin/lists, /admin/log, /admin/pricing.
2. Если таблица шире контейнера — проверить подсказку на левом краю (RTL) и прокрутить к колонке действий.
## Ожидаемо
- Страница без горизонтальной прокрутки (scrollWidth ≤ innerWidth). (источник: «מה רצוי» #e11528)
- Для каждой таблицы: либо карточки «label: value», либо при scrollWidth > clientWidth виден элемент-подсказка (тень/стрелка) у края скрытых колонок; после прокрутки контейнера колонка действий/статуса видна.
