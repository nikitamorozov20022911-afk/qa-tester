# AN-1-5: Админ — заявка с NDA только запрошенным: «ממתין/ה ל-NDA», без «צפייה בהסכם»
- Фича/экран: application-nda-indicator / /admin/applications/<id>
- Тикеты: #68f480
- Роль/аккаунт: admin (demo-admin)
- Устройство: desktop 1440×900
- Тип: негатив/состояние, read-only (@prod-safe)
- Предусловия: заявка d7a89587-59a9-40cd-832e-84e399f80ec7 (J-45 «ראש צוות פיתוח Frontend», «רון שגיא», отправитель claude-test «נועם כהן») — NDA запрошено, не подписано.
## Шаги
1. Открыть /admin/applications/d7a89587-59a9-40cd-832e-84e399f80ec7.
2. Прочитать заголовок с бейджами, блок «NDA» и блок «סטטוס מועמד».
## Ожидаемо
- Бейдж «ממתין/ה ל-NDA»; в блоке «NDA» значение «ממתין לחתימה»; в «סטטוס מועמד» строки «נשלח/ה» → «ממתין/ה ל-NDA», строки «NDA נחתם» нет. (реджект №1 «the same status is shown to the owner, the sender and in admin»)
- Кнопки/ссылки «צפייה בהסכם» нет, текста «נחתם ב-» в блоке NDA нет. (реджект №2 «While only requested — no link»)
