# AN-3-2: Админ — лента статусов и блок NDA подписанной заявки
- Фича/экран: application-nda-indicator / /admin/applications/<id>
- Тикеты: #68f480
- Роль/аккаунт: admin (demo-admin)
- Устройство: desktop 1440×900
- Тип: позитив (регресс реджекта №1), read-only (@prod-safe)
- Предусловия: как AN-1-1.
## Шаги
1. Открыть /admin/applications/0cc56444-27c3-4d3d-82cf-d83e8cddb5b1.
2. Прочитать бейджи заголовка, блок «סטטוס מועמד», блок «NDA».
## Ожидаемо
- Бейдж «NDA נחתם»; в «סטטוס מועמד» строки по порядку נשלח/ה → נצפה/תה → ממתין/ה ל-NDA → NDA נחתם, последняя с датой 22.10.2026. (реджект №1 «the same status is shown to the owner, the sender and in admin»; закрыт 22.10 «NDA status with date for owner, sender and admin»)
- В блоке «NDA» — «נחתם ב-22.10.2026» и кнопка «צפייה בהסכם». (реджект №2 «Admin: NDA block … («נחתם ב-<date>»)»)
