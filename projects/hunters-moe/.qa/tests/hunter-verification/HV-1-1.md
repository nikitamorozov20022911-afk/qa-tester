# HV-1-1: Верифицированный хед-хантер пишет в чат с любым хед-хантером сразу — строка «אתם מאומתים (NDA Committed)…», без бара ожидания
- Фича/экран: hunter-verification / /messages
- Тикеты: #1eabe4 (связан #0224f4)
- Роль/аккаунт: hunter_free_2 (demo-hunter-3, верификация до 07.11.2027)
- Устройство: desktop 1440×900
- Тип: позитив, read-only (ничего не вводим)
- Предусловия: чаты с «הד האנטר דמו 1» (c=525fb19b…) и «דב האנטר» (c=11ec1344…) — без одобренного NDA второй стороной.
## Шаги
1. /messages → чат «הד האנטר דמו 1».
2. Чат «דב האנטר».
## Ожидаемо
- В каждом чате строка «אתם מאומתים (NDA Committed) – אין צורך ב-NDA, אפשר לכתוב מיד.»; нет текста «ממתינים לאישור»; поле «כתיבת הודעה» активно. (источник: #1eabe4 AC7 «A verified user does not need to sign an NDA each time when working with other headhunters»; решение пользователя 07.11 — верифицированный пишет сразу)
