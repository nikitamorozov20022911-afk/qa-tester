# TO-1-1: Форма предложения на тендер — валидация суммы, ничего не отправляется
- Фича/экран: tender-offers / Tender details «הגשת הצעה למכרז»
- Тикеты: #1004e9
- Роль/аккаунт: company_6 (HR)
- Устройство: desktop 1440×900
- Тип: негатив/граница, read-only
- Предусловия: Открытый чужой тендер без предложения этого HR.
## Шаги
1. Открыть тендер → форма «הגשת הצעה למכרז».
2. По очереди −50, 0, 12.5, 1.5, abc, 999999999, 1000000000000 → кнопка отправки.
3. Закрыть без отправки.
## Ожидаемо
- −50, 0, 12.5, 1.5, abc → «יש להזין סכום בשקלים שלמים גדול מ-0».
- 999999999, 1000000000000 → «הסכום המרבי הוא ₪9,999,999».
- Ни одного запроса на создание предложения; «ההצעה שלכם נשלחה» не появляется. (источник: needed behavior #1004e9)
