# qa-tester — установка и начало работы

## Установка (один раз на компьютер)
1. Распакуй архив в постоянное место, например `~/qa-tester-kit` (папку не удалять — из неё ставятся обновления).
2. Запусти:
```bash
bash ~/qa-tester-kit/install.sh
```
3. Перезапусти приложение Claude.

Требования: Claude Code, **Node.js 22** (установить: `nvm install 22 && nvm alias default 22` или Node 22 LTS с nodejs.org). Плагин сам запускает всё под Node 22, даже если по умолчанию в терминале другая версия.⁠​‌​‌​​​‌​‌​​​​​‌​‌​‌​‌​​​​‌​‌‌​‌​‌​​‌‌‌​​‌​​‌‌​‌​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​​​‌​‌‌​‌​​‌‌​​‌‌​​‌‌​‌​​​​‌‌​‌​​​​‌‌​​​​​​‌‌‌​​​​​‌‌​‌‌​​‌​​​‌​​​‌​​​​‌‌​​‌‌​‌​​​​‌‌​‌​‌​‌​​​​‌​​​‌‌​​​​​‌‌‌‌‌​​​‌​​‌‌‌​​‌‌​‌​​‌​‌‌​‌​‌‌​‌‌​‌​​‌​‌‌‌​‌​​​‌‌​​​​‌​​‌​​​​​​‌​​‌‌​‌​‌‌​‌‌‌‌​‌‌‌​​‌​​‌‌​‌‌‌‌​‌‌‌‌​‌​​‌‌​‌‌‌‌​‌‌‌​‌‌​⁣

## Настоящий телефон по кабелю (по желанию)
Можно тестировать на своём iPhone (Safari и приложения) и Android по USB — нужны Mac, Xcode (iPhone) и/или Android Studio (Android). Напиши агенту «хочу тестить на телефоне через кабель» — он проверит компьютер и проведёт по установке шаг за шагом (скилл `qa-device`). Данные телефона и подписи сохраняются только на этом компьютере (`~/.qa-tester/devices.md`) и никуда не отправляются.

## Новый проект
1. Создай папку проекта: `mkdir -p ~/Documents/qa/<проект>` и открой в ней новую сессию Claude (вкладка Code).
2. Напиши `/qa-onboard` со ссылками на доску mifrat и сайт.
3. В окне браузера плагина один раз войди в mifrat и напиши «зашел».
4. Если нужны аккаунты сайта — заполни `.qa/accounts.env` и запусти `cd .qa/e2e && ../bin/with-node22 npm run qa-login` (зависимости уже поставил /qa-onboard).
5. Напиши `/qa` — начинаем тестирование.

## Команды
- `/qa` — сессия тестирования тикетов из «בבדיקות»; `/qa #hash` — один тикет.
- «сделай хендофф» / «продолжаем» — перенос сессии.
- `/qa-regress` — регресс автотестов (только по команде).
- Поправки в чате агент записывает как уроки сам (`.qa/lessons.md` и `~/.qa-tester/lessons.md`) и применяет дальше.
